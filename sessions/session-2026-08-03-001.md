# 四、AI教学过程

## 1. 核心概念

财务管理 = 企业如何"搞钱、用钱、分钱"的系统决策活动；现金流管理只是五大内容之一（营运资金管理）。

五大内容：筹资管理 / 投资管理 / 营运资金管理 / 成本管理 / 收入与分配管理。

## 2. 底层逻辑

所有权与经营权分离 → 代理问题 → 需要专门"替股东看钱"的系统工作；公司制企业有限责任、易筹资、但有代理问题与双重课税。

## 3. 考试角度

第一章为开篇非重点章：约4分，全客观题。核心考点：企业组织形式、财务管理目标优缺点、利益冲突与协调。

## 4. 常见错误

- 以偏概全（把局部当整体）
- 混淆"利润最大化不考虑时间价值"与"股东财富最大化考虑时间价值"
- 误以为相关者利益最大化把其他相关者放首要地位（实际股东首要）

## 5. 案例应用

2022单选：不属于公司制企业缺点的是 → D 股东承担无限连带责任（有限责任恰是公司制优点）。

# 五、理解验证

## AI验证问题

"四个目标里，哪一个是'上市公司专属'的？哪一个是教材最推崇、但实务最难算的？哪一个是所有目标的共同基石？"

## 学生回答（2026-08-05 确认）

1. 股东财富最大化 = "上市公司专属" → 正确（非上市公司无股价，无法用股价×股数度量）
2. 股东财富最大化 = 所有目标共同基石 → 正确（教材原话：各种财务管理目标都以股东财富最大化为基石）
3. 企业价值最大化（学生表述为"公司价值最大化"，已统一术语）= 教材最推崇、但实务难精确计量 → 正确（未来现金流现值最难精确计量）

三个判断全部精准，且敏锐指出"股东财富最大化同时占据上市公司专属+共同基石两个位置"，理解到位。

- 五大内容框架：**熟练（Strong）**——能独立复述五大模块，并能纠正"以偏概全"偏差
