# 🧩 第一节 成本管理概述

## 📍 知识点：成本管理内容 ⭐⭐⭐

### ① 意义
降低成本为扩大再生产创造条件、增加利润提高经济效益、帮助企业取得竞争优势。

### ② 目标
- 总体目标：成本领先战略、差异化战略；
- 具体目标：成本计算目标、成本控制目标。

### ③ 原则
融合性、适应性、成本效益、重要性。

### ④ 主要内容（7 项）🔥
```
事前管理：成本预测 → 成本决策 → 成本计划
事中管理：成本控制
事后管理：成本核算 → 成本分析 → 成本考核
```
- **成本预测是成本管理的第一步（起点）**（2014 单选 A）；
- **成本决策** = 从多个成本方案中选择最优方案（2020 单选 D）；
- 成本核算分财务成本核算（历史成本）和管理成本核算（历史/现在/未来）。

# 🧩 第二节 本量利分析与应用（主观题核心）

## 📍 知识点 1：本量利分析基本原理 ⭐⭐⭐⭐⭐

### ① 含义与假设
- 研究成本、业务量和利润三者内在联系的定量分析方法；
- **四大基本假设**（🔥 多选）：
  1. 总成本由固定成本和变动成本两部分组成；
  2. 销售收入与业务量呈**完全线性关系**；
  3. **产销平衡**；
  4. **产品产销结构稳定**（2023 多选 ABCD / 2015 单选 D 错误：不是营业成本和期间费用）。

### ② 基本关系式
```
息税前利润 = 销售收入 − 变动成本 − 固定成本
           = 销售量 ×（单价 − 单位变动成本）− 固定成本
```

### ③ 边际贡献（🔥🔥 必背）
```
单位边际贡献 = 单价 − 单位变动成本
边际贡献总额 = 销售收入 − 变动成本 = 单位边际贡献 × 销售量
边际贡献率 = 单位边际贡献/单价 = 边际贡献总额/销售收入
变动成本率 = 单位变动成本/单价 = 变动成本总额/销售收入
边际贡献率 ＋ 变动成本率 = 1
利润 = 销售量×单位边际贡献 − 固定成本 = 边际贡献总额 − 固定成本
```
- 固定成本**不影响**边际贡献（2019 判断 ×）；
- 例：收入 100、变动成本 60、固定成本 16 → 边际贡献率 = (100−60)/100 = 40%（2017 单选）。

---

## 📍 知识点 2：单一产品本量利分析 ⭐⭐⭐⭐⭐

### ① 盈亏平衡分析（保本分析）🔥🔥
```
盈亏平衡销售量 = 固定成本 ÷（单价 − 单位变动成本）= 固定成本 ÷ 单位边际贡献
盈亏平衡销售额 = 盈亏平衡销售量 × 单价 = 固定成本 ÷ 边际贡献率
盈亏平衡作业率（保本点作业率）= 盈亏平衡销售量（额）÷ 正常销售量（额）
```
- **盈亏平衡点越低，企业风险越小、利润越高**（2018 判断 ×："越高越安全"错）；
- 降低盈亏平衡销售量：降低固定成本总额、降低单位变动成本、提高销售单价；
- 会导致盈亏平衡点**上升**：单价下降、固定成本上升、单位变动成本上升（2023 多选 BCD）；销售量下降**不影响**盈亏平衡点（只影响安全边际）。

### ② 安全边际分析 🔥🔥
```
安全边际量 = 实际（预计）销售量 − 盈亏平衡销售量
安全边际额 = 实际（预计）销售额 − 盈亏平衡销售额 = 安全边际量 × 单价
安全边际率 = 安全边际量 ÷ 实际（预计）销售量 = 安全边际额 ÷ 实际（预计）销售额
盈亏平衡作业率 ＋ 安全边际率 = 1
利润 = 安全边际额 × 边际贡献率 = 安全边际量 × 单位边际贡献
销售利润率 = 安全边际率 × 边际贡献率
```
- 安全边际或安全边际率越大，经营风险**越小**（2017 单选 A）；
- 经营安全程度标准：40% 以上很安全、30%~40% 安全、20%~30% 较安全、10%~20% 值得注意、10% 以下危险；
- ⚠️ **边际贡献率和变动成本率之和为 1**；销售利润率 = 安全边际率 × 边际贡献率（2023 单选 D 错误：不是×边际贡献）；
- 例：单价 100、单位变动 40、固定 120000、销量 5000 → 保本量 = 2000、安全边际量 3000、安全边际率 60%（2024 单选 B）；
- 例：变动成本率 60%、保本作业率 70% → 销售利润率 = (1−70%)×(1−60%) = 12%（2021 单选 C）；
- 盈亏平衡状态 → 安全边际率为 0（2024 判断 √）。

### ③ 常考计算（🔥）
- 单价 30、单位变动 18、固定 6000 万、销量 800 万件 → 保本量 = 6000/12 = 500 万 → 安全边际率 = (800−500)/800 = 37.5%（2023 单选）；
- 提高安全边际且不降低保本点：**增加销售量**（提高单价、降低固定成本会降低保本点，提高单位变动成本会提高保本点）（2022 单选 C）；
- 单价和单位变动成本同时提高 1 元 → 单位边际贡献不变、保本量不变、安全边际量不变、**边际贡献率变大**（2023 多选 ABD）。

## 📍 知识点 3：多种产品本量利分析 ⭐⭐⭐⭐

四种方法：**加权平均法、联合单位法、分算法、主要产品法**。

### ① 加权平均法
```
加权平均边际贡献率 = Σ(各种产品销售额 − 变动成本) ÷ Σ各种产品销售额
综合盈亏平衡销售额 = 固定成本总额 ÷ 加权平均边际贡献率
某产品盈亏平衡销售额 = 综合盈亏平衡销售额 × 该产品销售比重
```
- 综合盈亏平衡点受固定成本总额、销售结构、单价、单位变动成本影响（2017 多选 ABCD）。

### ② 联合单位法
- 以各种产品产销实物量的最小比例作为一个联合单位（如 A:B:C = 3:2:1）；
- 联合单价 = Σ（单价×比例），联合单位变动成本 = Σ（单位变动成本×比例）；
- 联合保本业务量 = 固定成本 ÷（联合单价 − 联合单位变动成本）。

### ③ 分算法
- 将固定成本按一定标准（销售额、边际贡献、工时等）分配至各产品，再按单一品种分析；
- 专属于某种产品的固定成本直接计入；公共固定成本选标准分配（2017 单选 D：适用"固定成本合理分配"的是分算法）。

### ④ 主要产品法
- 存在一种主要产品（边际贡献占比较大）时，视同单一品种分析；只能选**一种**主要产品，以**边际贡献**为标志。

## 📍 知识点 4：目标利润分析 ⭐⭐⭐⭐

```
目标利润销售量 =（固定成本 ＋ 目标利润）÷ 单位边际贡献
目标利润销售额 =（固定成本 ＋ 目标利润）÷ 边际贡献率
税后目标利润：
实现目标利润销售量 = [固定成本 ＋ 税后目标利润/(1−T) ＋ 利息] ÷ 单位边际贡献
```
- 目标利润销售量公式**只能用于单种产品**；目标利润销售额可用于单种和多种产品；
- ⚠️ 目标利润的变动影响实现目标利润的销售量/销售额，**不影响盈亏平衡点的销售额**（2021 判断 ×）；
- 例：单价 60、单位变动 20、固定 50000、目标利润 10000 → 销量 = 60000/40 = 1500 件（2022 单选 D）。

---

## 📍 知识点 5：敏感性分析 ⭐⭐⭐⭐

```
敏感系数 = 利润变动百分比 ÷ 因素变动百分比
```
- 敏感系数为负 → 反向变动；判断敏感性看**绝对值**；
- 各因素敏感程度排序（利润为正时）：**单价 > 单位变动成本 > 销售量 > 固定成本**；
- 利润对销售量的敏感系数 = **经营杠杆系数**（2020 单选 A）；
- 销售量敏感系数 = 基期边际贡献 ÷ 基期息税前利润；固定成本敏感系数 = −（基期固定成本 ÷ 基期息税前利润）；
- ⚠️ 利润为正时，销售量对利润的影响程度**大于**固定成本（2024 判断 √）；固定成本敏感系数**小于**销售量（2018 判断 ×）；
- 例：销量 5000、单价 100、单位变动 60、固定 12 万 → 边际贡献 20 万、EBIT 8 万 → 销售量敏感系数 = 20/8 = 2.5（2024 单选 D）。

## 📍 知识点 6：本量利分析在经营决策中的应用 ⭐⭐⭐

### ① 产品生产和定价策略
- 盈亏平衡点之上才有利润；可计算可接受最低售价：最低售价 =（目标利润 ＋ 固定成本）÷ 销量 ＋ 单位变动成本。

### ② 生产工艺设备的选择
- 通过两种方案的利润方程相等求"成本无差别点"产销量：
```
原生产线利润 = 8X − 50000；新生产线利润 = 10X − 80000
8X − 50000 = 10X − 80000 → X = 15000 件
销量 < 15000 用原生产线；> 15000 用新生产线
```

### ③ 新产品投产选择
- 新增产品的投产减少原有产品产销 → 原有产品减少的边际贡献为**机会成本**，应扣除后再比较各方案增加的息税前利润。

# 🧩 第三节 标准成本控制与分析（主观题核心）

## 📍 知识点 1：标准成本概念 ⭐⭐⭐

| 类型 | 含义 |
|-|-|
| **理想标准成本** | 生产过程无浪费、机器无故障、人员无闲置、产品无废品条件下制定（2023 判断 ×：这是理想不是正常） |
| **正常标准成本** | 正常情况下企业经过努力可达到，考虑不可避免的损失、故障、偏差；具有客观性、现实性、激励性，**实践中广泛应用** |

## 📍 知识点 2：标准成本的制定 ⭐⭐⭐⭐

- 标准成本 = 用量标准 × 价格标准；
- 直接材料标准成本 = 单位产品材料标准用量 × 材料标准单价；
- 直接人工标准成本 = 单位产品标准工时 × 小时标准工资率（= 标准工资总额 ÷ 标准总工时）；
- 制造费用标准成本 = 工时用量标准 × 标准制造费用分配率。

### 🎯 责任归属（🔥 判断/单选）
- 用量差异主要责任部门：**生产部门**；
- 直接材料价格差异：**采购部门**；
- 直接人工价格（工资率）差异：**人事部门**；
- 制造费用价格差异：生产部门；
- ⚠️ 直接材料运输方式不同影响**价格**差异（2022 单选 B 不属于用量差异）；
- 工作环境好坏影响**效率**差异，不影响工资率差异（2016 单选 B）；
- 产品成本出现的不利/有利差异**不都**由生产部门负责（2020 判断 ×）。

---

## 📍 知识点 3：成本差异计算 ⭐⭐⭐⭐⭐（主观题必考）

### ① 基本公式
```
总差异 = 实际产量下实际成本 − 实际产量下标准成本
       = 用量差异 ＋ 价格差异
用量差异 =（实际用量 − 实际产量下标准用量）× 标准价格
价格差异 =（实际价格 − 标准价格）× 实际用量
【口诀】价标量实：价差用"标准量"，量差用"标准价"
```
- 差异为正 = 超支；差异为负 = 节约。

### ② 各项差异（🔥🔥 必背表）
```
直接材料：
  数量差异 =（实际用量 − 标准用量）× 标准单价
  价格差异 =（实际单价 − 标准单价）× 实际用量
直接人工：
  效率差异 =（实际工时 − 标准工时）× 标准工资率
  工资率差异 =（实际工资率 − 标准工资率）× 实际工时
变动制造费用：
  效率差异 =（实际工时 − 标准工时）× 标准分配率
  耗费差异 =（实际分配率 − 标准分配率）× 实际工时
```

### ③ 常考计算
- 直接材料：实际用量 1200、标准用量 60×18=1080、标准价 270 → 量差 = (1200−1080)×270 = 32400（2018 单选 C）；
- 变动制造费用：实际工时 6300、标准工时 3000×2=6000、标准分配率 3 → 效率差异 = (6300−6000)×3 = 900（2021 单选 D）；
- 变动制造费用效率差异 = (1296 − 600×2)×24 = 2304（2017 单选 D）；
- 效率差异、工资率差异都是"**实际工时**"× 差值；量差用标准价/标准工资率/标准分配率。

---

## 📍 知识点 4：固定制造费用差异分析 ⭐⭐⭐⭐⭐

### ① 两差异分析法
```
固定制造费用成本差异 = 实际固定制造费用 − 实际产量标准工时 × 标准分配率
耗费差异 = 实际固定制造费用 − 预算产量标准工时 × 标准分配率
能量差异 =（预算产量标准工时 − 实际产量标准工时）× 标准分配率
```

### ② 三差异分析法
```
耗费差异（同两差异）
产量差异 =（预算产量标准工时 − 实际工时）× 标准分配率
效率差异 =（实际工时 − 实际产量标准工时）× 标准分配率
```

### ③ 常考计算
- 预算产量 6000、固定制造费用预算 54000、工时标准 2、实际产量 5000、实际工时 11500、实际费用 48300 → 标准分配率 = 54000/6000 = 9 元/小时 → 总差异 = 48300 − 5000×2×9 = 3300（2025 单选 A）；
- 预算 10000 件、实际 9000 件、标准分配率 8、工时标准 1.5、实际费用 180000 → 差异 = 180000 − 9000×1.5×8 = 72000 超支（2018 单选 A）。

# 🧩 第四节 作业成本与责任成本

## 📍 知识点 1：作业成本法 ⭐⭐⭐⭐

### ① 基本原则
"**作业消耗资源、产出消耗作业**"，程序：**资源 → 作业 → 产品**（2020 单选 B）。

### ② 核心概念
- **资源费用**：有形/无形资源耗费；
- **作业**：基于特定目的重复执行的任务，是连接资源和成本对象的桥梁；分**主要作业**（被最终成本对象消耗）和**次要作业**（被原材料、主要作业等中间对象消耗）；
- ⚠️ 次要作业 ≠ 非增值作业，**不一定要消除**（2025 判断 ×）；
- **成本动因**（成本驱动因素）：诱导成本发生的原因，分**资源动因**（引起作业成本变动）和**作业动因**（引起产品成本变动）；
- **作业中心**（成本库）：按统一作业动因汇集资源耗费；**一个作业中心可以包含多个作业**（2020 判断 ×）。

### ③ 作业分类（5 类，🔥 多选）
```
产量级作业：数量与产品数量正比（产品加工、检验）
批别级作业：数量与批量数正比（设备调试、生产准备）
品种级作业：与品种多少正比（新产品设计、质量改进、流程设计、产品广告）
顾客级作业：为服务特定客户（技术支持、咨询、独特包装）
设施级作业：提供基本能力、与产量或销量无关（管理作业、针对整体广告）
```
- 设备调试、生产准备 = **批别级**；厂房维护 = 设施级；新产品设计 = 品种级（2021 多选 AC）。

### ④ 成本动因类型（交易/持续时间/强度）
- 交易动因：按执行频率/次数计量（订单数、收据数）——每次资源相同选交易动因；
- 持续时间动因：按执行时间计量——每次时间不同选持续时间动因；
- 强度动因：直接衡量每次执行所需资源（特别复杂产品）——作业特殊或复杂选强度动因。

### ⑤ 优缺点
- 优点：提高决策准确性、促进绩效管理改进、提高作业链管理能力；
- 缺点：存在较大主观性、操作复杂、开发维护费用高。

## 📍 知识点 2：作业成本管理 ⭐⭐⭐⭐

### ① 增值作业（🔥 三条件同时满足）
```
① 该作业导致状态改变；
② 该状态的变化不能由其他作业完成；
③ 该作业使其他作业得以进行。
```
- 增值作业：零件组装；非增值作业：产品运输、产品检验、次品返工（重复作业）（2017 单选 D、2023 多选 BCD）；
- 划分依据：**是否有助于增加顾客价值**（2020 单选 D）。

### ② 成本节约的四种途径（🔥）
```
作业消除：消除非增值作业（改供应商直送原料使用部门）
作业选择：达到同样目的选取最佳方案（外购转外包）
作业减少：不断改进降低作业消耗的资源或时间（减少整备次数）
作业共享：利用规模经济提高增值作业效率（新产品尽量利用现有零件）
```
> ⚠️ 例：将外购交货地点从厂外仓库改为材料耗用车间 = **作业消除**（不是作业选择）（2018 单选 A 错误项）。

### ③ 作业业绩考核
- 财务指标：增值成本、非增值成本；非财务指标：效率、质量、时间（投入产出比、次品率、生产周期）（2015 判断 √）。

## 📍 知识点 3：责任成本管理 ⭐⭐⭐⭐⭐（高频）

### ① 责任中心分类

**（1）成本中心** 🔥🔥
```
含义：有权发生并控制成本的单位
特点：①不考核收入，只考核成本；②只对可控成本负责，不负责不可控成本；③责任成本是考核主要内容
考核指标：
  预算成本节约额 = 实际产量预算责任成本 − 实际责任成本
  预算成本节约率 = 预算成本节约额 ÷ 实际产量预算责任成本
```
- 可控成本三条件：成本中心可**预见**、可**计量**、可**调节和控制**（2015 多选 ABC）；
- 成本中心**不需要**对本中心全部成本负责（只对可控成本）（2021 单选 D、2017 判断 ×、2023 单选 A 错误）；
- 例：预算产量 3500、预算单位成本 150，实际产量 4000、实际单位成本 145.5 → 节约额 = 150×4000 − 145.5×4000 = 18000，节约率 3%。

**（2）利润中心** 🔥
```
含义：既能控制成本，又能控制收入和利润的责任单位
分类：自然利润中心（直接对外）、人为利润中心（内部结算）
考核指标：
  边际贡献 = 销售收入 − 变动成本
  可控边际贡献 = 边际贡献 − 中心负责人可控固定成本（评价管理者业绩的理想指标）
  部门边际贡献 = 可控边际贡献 − 负责人不可控固定成本（评价部门业绩）
```
- 可控边际贡献 = 100 − 46 − 15 = 39（2023 单选 C）；
- 评价利润中心**管理者**业绩的理想指标 = **可控边际贡献**（2019 单选 C）。

**（3）投资中心** 🔥
```
含义：既能控制成本、收入和利润，又能控制投入资金
投资报酬率 = 息税前利润 ÷ 平均经营资产
剩余收益 = 息税前利润 −（平均经营资产 × 最低投资报酬率）
```

| 指标 | 优点 | 缺点 |
|-|-|-|
| 投资报酬率 | 根据会计资料客观、可跨部门比较、利于资产存量调整优化配置 | 会引起短视行为 |
| 剩余收益 | 弥补投资报酬率使局部与整体利益冲突的不足 | 绝对指标难以跨规模比较、仅反映当期业绩、也会导致短视 |

- 最低投资报酬率根据**资本成本**确定，一般等于或**大于**资本成本（2020 单选 B 错误）；
- 例：剩余收益 = 2000×12.6% − 2000×12% = 12 万（2023 单选 B）；
- X 中心投资收益率 = 10800/90000 = 12%，剩余收益 = 10800 − 90000×8% = 3600（2023 多选 ABC）。

### ② 内部转移价格（🔥 单选）
```
价格型：以市场价格为基础，含成本和毛利，适用于内部利润中心
成本型：以标准成本等稳定成本数据为基础，适用于内部成本中心
       （完全成本、完全成本加成、变动成本、变动成本加固定制造费用四种形式）
协商型：通过协商机制制定，适用于分权程度较高情形
       协商价格上限 = 市场价格，下限 = 单位变动成本（2019/2017/2016 单选 D）
```
- ⚠️ 提高内部服务价格 → M 利润增加、N 利润减少、**企业总利润不变**（2023 多选 AC）；
- 以成本为基础制定内部转移价格**不适合用固定成本**作基础（2019 单选 C）。
