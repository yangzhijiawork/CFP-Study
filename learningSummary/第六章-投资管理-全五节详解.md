# 🧩 第一节 投资管理概述

## 📍 知识点 1：投资的分类 ⭐⭐⭐⭐（单选/多选）

| 分类标准 | 类别 | 含义 |
|-|-|-|
| 投资活动与生产经营的关系 | **直接投资** | 资金直接投放于形成生产经营能力的实体性资产，直接谋取经营利润 |
| | **间接投资** | 资金投放于股票、债券等资产上 |
| 投资对象存在形态和性质 | **项目投资** | 购买具有实质内涵的经营资产（有形+无形），属于**直接投资** |
| | **证券投资** | 通过证券资产权利间接控制企业，属于**间接投资** |
| 对企业生产经营前景的影响 | **发展性投资**（战略性） | 对企业未来全局有重要影响（开发新产品、兼并收购、扩大规模） |
| | **维持性投资**（战术性） | 维持现有生产经营正常进行（更新替换旧设备） |
| 投资的方向 | **对内投资** | 本企业范围内部资金投放，都是直接投资 |
| | **对外投资** | 向本企业范围以外投放，主要是间接投资，也可以是直接投资 |
| 投资项目相互关系 | **独立投资** | 互不关联、互不影响，可同时并存 |
| | **互斥投资** | 相互关联、相互替代，不能同时并存 |

### 三判断（🔥 讲义总结）
1. 项目投资都是直接投资 → **√**；
2. 证券投资都是间接投资 → **√**；
3. 对内投资都是直接投资 → **√**；
4. 对外投资都是间接投资 → **×**（对外投资可以是直接投资，如设子公司）。

> 📌 真题印证：购买公司债券 = 间接投资（2018 单选 D）；开发新产品/兼并收购/扩大规模 = 发展性投资，更新替换旧设备 = 维持性投资（2016 多选 ACD）。

## 📍 知识点 2：投资管理原则 ⭐⭐
可行性分析原则、结构平衡原则、动态监控原则。

# 🧩 第二节 投资项目财务评价指标（主观题核心）

## 📍 知识点 1：项目现金流量 ⭐⭐⭐⭐⭐

投资项目从经济寿命周期看分三个时点阶段：

### ① 投资期（主要是现金流出）
- 在长期资产上的投资：固定资产、无形资产、递延资产的现金支出；
- 垫支的营运资金 = 追加的流动资产扩大量 − 结算性流动负债扩大量。
> 例：流动资产增加 600、结算性流动负债增加 200 → 垫支营运资金 = 400（2024 单选 C）

### ② 营业期（既有流入也有流出）
- 内容：营业收入、付现营运成本、大修理支出、所得税；
- 假设现金流量发生在当期期末。

**营业现金净流量（3 个公式，🔥🔥 必背）**
```
① = 营业收入 − 付现成本 − 所得税
② = 税后营业利润 ＋ 非付现成本
③ = 收入×(1−T) − 付现成本×(1−T) ＋ 非付现成本×T
```
- 折旧、摊销都是**非付现成本**（2023/2024 判断 ×：大修理摊销不能作付现成本）；
- 例：收入 600000、付现成本 400000、折旧 100000、税率 25% → 营业现金净流量 = 600000×75% − 400000×75% ＋ 100000×25% = 175000（2017 单选）。

### ③ 终结期
- 内容：固定资产变价净收入、垫支营运资金的收回、固定资产变现净损失**抵税**、固定资产变现净收益**纳税**；
- 固定资产变现净损益 = 变价净收入 − 固定资产账面价值；
- 账面价值 = 固定资产原值 − 按税法计提的累计折旧。
> 例：报废净残值 3500、税法净残值 5000、税率 25% → 现金净流量 = 3500＋(5000−3500)×25% = 3875（2015 单选）

> 📌 真题印证：讲义第 3~6 页 + 习题 → **营业现金净流量三种算法是综合题必考第一步**。

---

## 📍 知识点 2：净现值（NPV）⭐⭐⭐⭐⭐

### ① 公式
```
NPV = 未来现金净流量现值 − 原始投资额现值
```

### ② 判定标准
- NPV > 0 → 方案可行（实际收益率 > 所要求收益率）；
- NPV < 0 → 方案不可取；
- 其他条件相同时，NPV 越大方案越好。

### ③ 评价
- **优点**：适用性强、能灵活考虑投资风险；
- **缺点**：贴现率不易确定；不适宜独立投资方案比较决策；有时不能对寿命期不同的互斥方案直接决策（2022 多选 ABD）。

### 🎯 常考易错点
- NPV > 0 说明实际收益率 > 折现率（2022 多选 A 正确）；
- 净现值法对原始投资额现值不同、寿命期不同的方案有局限；
- NPV 不适宜独立方案比较（因为只看绝对额，忽视投资额大小）。

---

## 📍 知识点 3：年金净流量（ANCF）⭐⭐⭐⭐⭐

### ① 公式
```
年金净流量 = 现金净流量总现值 ÷ 年金现值系数 = NPV ÷ (P/A, i, n)
```
本质：各年现金流量中的**超额投资报酬额**。

### ② 判定标准
- ANCF > 0 → 方案可行；
- **寿命期不同**的投资方案比较时，ANCF 越大方案越好。

### ③ 适用
- **年金净流量法是互斥方案最恰当的决策方法**（寿命相同也可用，寿命不同必须用）；
- 例：投资 840、寿命 10 年、年现金流 180、(P/A,10%,10)=7 → ANCF = (−840＋180×7)/7 = 60（2018 单选）。

---

## 📍 知识点 4：现值指数（PVI）⭐⭐⭐⭐⭐

### ① 公式
```
现值指数 = 未来现金净流量现值 ÷ 原始投资额现值 = 1 ＋ NPV÷原始投资额现值
```

### ② 判定标准
- PVI ≥ 1（NPV ≥ 0）→ 方案可行；PVI < 1（NPV < 0）→ 不可行；
- PVI 越大方案越好；
- ⚠️ 独立方案中 PVI **大于 1** 才可行（2021 判断 ×："大于 0"错）。

### ③ 评价
- **优点**：便于对原始投资额不同的投资方案比较（反映投资效率）；
- **缺点**：仅代表获得收益的能力，不能等价于项目本身实际收益率；
- 例：原始投资现值 100、NPV 25 → PVI = 125/100 = 1.25（2024/2014 单选）。

---

## 📍 知识点 5：内含收益率（IRR）⭐⭐⭐⭐⭐

### ① 定义与原理
- IRR = 使 NPV = 0 的贴现率（未来每年现金净流量现值恰好等于原始投资额现值）；
- 未来每年现金净流量相等：A×(P/A,i,n) − 原始投资额 = 0；
- 不相等：逐次测试法 + 内插法。

### ② 判定标准
- IRR > 必要收益率（折现率）→ 方案可行；
- NPV > 0 ⟺ IRR > 折现率。

### ③ 评价
- **优点**：反映项目实际可能达到的投资收益率、易于高层理解；便于独立方案比较决策；
- **缺点**：计算复杂、不易直接考虑风险；互斥方案原始投资额不等时有时无法正确决策（2020 单选 B）。

### 🎯 常考易错点
- IRR 不受**资本成本（必要报酬率）**影响（2014 单选 B）；但受原始投资额、项目计算期、现金净流量影响（2022 多选 BCD）；
- 折现率 15% NPV=45、17% NPV=−10 → IRR = 15%＋(0−45)/(−10−45)×2% = 16.64%（2025 单选）；
- 折现率 8% NPV=25、10% NPV=8、12% NPV=−12 → IRR 介于 10%~12%（2022 单选）；
- 折现率 10% NPV=100、14% NPV=−150 → IRR = 11.6%（2021 单选）；
- 单方案可行性判断：**年金净流量 > 0** 一定可行（2023 单选 B）。

---

## 📍 知识点 6：回收期（PP）⭐⭐⭐⭐

### ① 分类
- **静态回收期**：未来现金净流量累计到原始投资额所经历的时间（不考虑时间价值）；
- **动态回收期**：未来现金净流量**现值**等于原始投资额现值所经历的时间。

### ② 计算
- 每年现金净流量相等：回收期 = 原始投资额 ÷ 每年现金净流量；
- 不相等：回收期 = M ＋ 第 M 年尚未回收额 ÷ 第(M+1)年现金净流量；
- ⚠️ 每年现金净流量不相等**也能算**静态回收期（2020 单选 A 错误）。

### ③ 评价
- **优点**：计算简便、易于理解；
- **缺点**：没有考虑回收期以后的现金流量（2021 多选 ACD：考虑了全部现金流量的有 PVI/ANCF/IRR，**没有动态回收期**）；
- 回收期越短越好；**动态回收期短于项目寿命期 → NPV > 0**（2019 单选）；
- ⚠️ 项目可行性取决于**现金流量**是否超过成本，不是利润总额（2019/2025 判断 ×）。

### ④ 指标横向对比（🔥 必背）
| 指标 | 方法评价 |
|-|-|
| 净现值 | 适用性强、能考虑风险；贴现率难确定；不适于独立方案、寿命不同互斥方案 |
| 年金净流量 | 净现值法辅助方法；**适用于期限不同的方案**；不适于原始投资额不等的独立方案 |
| 现值指数 | 净现值法辅助方法；便于比较原始投资额不同的方案；不等于实际收益率 |
| 内含收益率 | 反映实际投资报酬率、便于独立方案比较；计算复杂 |
| 回收期 | 计算简单；**未考虑回收期以后现金流量** |

# 🧩 第三节 项目投资管理（主观题核心）

## 📍 知识点 1：独立投资方案决策 ⭐⭐⭐⭐⭐

- 独立方案 = 互不依赖、可同时并存；属于**筛分决策**；
- 决策核心：确定各独立方案的投资**优先顺序**，以获利程度为评价标准；
- **排序方法**：一般用**内含收益率法**；原始投资额不同、期限相同 → 可用**现值指数**；原始投资额相同、期限不同 → 可用**年金净流量**；
- ⚠️ 内含收益率是万能的，各种情况都可以用（2025 多选 AB、2024 判断 √）。

## 📍 知识点 2：互斥投资方案决策 ⭐⭐⭐⭐⭐

```
寿命期相同：用净现值决策（不论原始投资额大小，获利数额即 NPV 大的最优）
寿命期不同：用年金净流量决策（或共同年限法）
结论：年金净流量法是互斥方案最恰当的决策方法
```
- ⚠️ 原始投资额不等、寿命期相同 → 选 NPV 大的（也即 ANCF 大的，因折现率相同 NPV 大则 ANCF 大）（2023 单选 D 错误）；
- 寿命期不同 → **只能用年金净流量**，不能直接用净现值（2021 单选 D、2018 单选 C）；
- 共同年限法：找各项目寿命期的最小公倍期数作共同有效寿命期。

## 📍 知识点 3：固定资产更新决策 ⭐⭐⭐⭐

### ① 寿命期相同
- 选择**现金流出总现值小**的方案（净现值法）；
- 考虑的现金流量：新旧设备目前市场价值、残值变价收入（抵减流出）、年营运成本；
- **旧设备的初始购置成本是沉没成本，不用考虑**（2017 多选 ABD）；
- 旧设备变现净损失可抵税。

### ② 寿命期不同
- 选择**年金成本小**的方案；
- 旧设备变现金净流量 = 变价收入 ＋（账面价值 − 变价收入）×T；
> 例：原值 1000、累计折旧 800、变价收入 120、税率 25% → 变现净流量 = 120＋(1000−800−120)×25% = 140 万（2021 单选 C）

> 📌 真题印证：讲义第 22~26 页 → **固定资产更新决策是综合题典型，年金成本计算务必掌握**。

# 🧩 第四节 证券投资管理

## 📍 知识点 1：证券资产特点与投资目的 ⭐⭐⭐

- 特点：价值虚拟性、可分割性、持有目的多元性、强流动性、高风险性；
- 目的：分散资金投向降低风险、利用闲置资金增加收益、稳定客户关系保障经营、提高资产流动性增强偿债能力；
- 利用闲置资金进行债券投资主要目的 = **谋取投资收益**（2017 单选 A）。

## 📍 知识点 2：证券资产投资风险 ⭐⭐⭐⭐（单选高频）

| 类型 | 风险 | 含义 |
|-|-|-|
| **系统风险** | 价格风险 | 市场利率上升 → 证券资产价格普遍下跌 |
| | 再投资风险 | 市场利率下降 → 无法通过再投资实现预期收益 |
| | 购买力风险 | 通货膨胀 → 货币购买力下降（名义收益率不变、实际收益率降低） |
| **非系统风险** | 违约风险 | 发行者无法按时兑付利息和偿还本金 |
| | 变现风险 | 无法以正常价格平仓出货 |
| | 破产风险 | 发行者破产清算时无法收回权益 |

### 🎯 常考易错点
- 市场利率上升 → 价格风险（2023 单选 C）；
- 市场利率大幅下降（预期上升却降）→ 再投资风险（2020 单选 A）；
- 通胀期间投资实体资产规避 = 购买力风险（2014 单选 D）；
- ST 公司无法足额付息 → 违约风险（2018 单选 D）；
- 购买力风险是**系统风险**，无法通过多元化组合分散（2023 单选 C 错误项）。

## 📍 知识点 3：债券投资 ⭐⭐⭐⭐

### ① 债券价值（未来利息和本金的现值）
```
V = 票面利息×(P/A, i, n) ＋ 面值×(P/F, i, n)
```

### ② 债券期限对价值的影响（🔥 判断）
- 只有溢价/折价债券，不同期限下债券价值才不同；
- 债券期限越短，票面利率对价值影响越小；
- **债券期限越长，价值越偏离面值**（2025 判断 √、2022 判断 √）；
- 溢价债券期限延长 → 价值**上升**（2021 多选 D 错误）。

### ③ 市场利率对价值的影响（🔥🔥 判断）
- **市场利率与债券价值反向变动**（2019/2017/2016）；
- **长期债券对市场利率的敏感性大于短期债券**（2015 单选 B 错误）；
- 折现率越大、债券价值越低（2023 单选 D 错误）；
- 票面利率 > 市场利率 → 溢价发行（2022 判断 √）；
- 付息次数越多，债券价值越大（2022 单选 A 正确）。

### ④ 债券内部收益率
- 溢价债券 IRR < 票面利率；折价债券 IRR > 票面利率；平价债券 IRR = 票面利率；
- ⚠️ 折价发行债券 IRR **高于**票面利率（2023 判断 ×）；
- 债券内在价值计算**不包含市场价**（2018 单选 A）；内含收益率计算**不包含市场利率**（2016 单选 C）；
- 收益来源：名义利息、利息再投资、价差收益三部分（2019 判断 ×：不只利息收益）。

## 📍 知识点 4：股票投资 ⭐⭐⭐⭐

### ① 股票价值
- 未来现金流量的现值（股利 + 出售价款）；
- 固定增长模型：V = D1÷(R−g) = D0×(1+g)÷(R−g)；
- 零成长：V = D÷R。

### ② 股票内部收益率
- 固定增长模型：R = D1÷P0 ＋ g = 预期股利收益率 ＋ 股利增长率（2017 判断 √）；
- 股票收益来源：股利收益、股利再投资、转让价差。

# 🧩 第五节 基金投资与期权投资

## 📍 知识点 1：证券投资基金 ⭐⭐⭐⭐

### ① 特点
集合理财专业化管理、组合投资分散风险、利益共享风险共担、权力隔离运作机制、严格监管。

### ② 分类（🔥 单选高频）

| 分类标准 | 类别 |
|-|-|
| 法律形式 | 契约型、公司型 |
| 运作方式 | 封闭式、开放式 |
| 投资对象 | 股票基金（80% 以上投资股票）、债券基金（80% 以上债券）、货币市场基金（仅货币工具）、混合基金 |
| 投资目标 | 增长型、收入型、平衡型 |
| 投资理念 | 主动型、被动（指数）型 |
| 募集方式 | 私募、公募 |

> ⚠️ 易错：82% 大额存单 + 11% 债券 + 7% 股票 → **混合基金**（2024 单选 B）；10% 股票 + 5% 短期国债 + 85% 公司债券 → **债券基金**（2021 单选 D）。
> ⚠️ 基金管理人和托管人**不承担**基金投资风险（2020 单选 A 错误）。

### ③ 基金业绩评价
- 绝对收益：持有期间收益率、现金流和时间加权收益率、平均收益率（算术/几何）；
- 相对收益：相对业绩比较基准的收益。

## 📍 知识点 2：私募股权投资基金 ⭐⭐⭐
- 投资对象为私人股权（未上市企业普通股、可转换优先股和可转换债券等）；
- 特点：投资周期长、收益波动大、专业要求高、投后非财务资源注入；
- ⚠️ 主要投资对象**不是上市公司**（2023 单选 C 错误）；只能以非公开方式募集。

## 📍 知识点 3：期权投资 ⭐⭐⭐

### ① 期权概念
- 期权（选择权）合约：持有人可选择在特定时期以约定价格买入/卖出标的资产，可选择行权或不行权；
- 按执行时间：欧式期权、美式期权；
- 按买方权利：看涨期权、看跌期权。

### ② 到期日价值与净损益（🔥 会算即可）
```
看涨期权买方：
  到期日市价 > 执行价 → 行权，到期日价值 = 市价 − 执行价，净损益 = 价值 − 期权费
  到期日市价 ≤ 执行价 → 不行权，价值 = 0，净损失 = 期权费
看跌期权买方：
  到期日市价 < 执行价 → 行权，价值 = 执行价 − 市价
  到期日市价 ≥ 执行价 → 不行权，价值 = 0
```
- 买方最大损失 = **期权费**（2023 单选 C）。
