# 🧩 第一节 资金需要量预测

## 📍 知识点 1：因素分析法（分析调整法）⭐⭐⭐⭐

```
资金需要量 =（基期资金平均占用额 − 不合理资金占用额）
            × (1 ＋ 预测期销售增长率) ÷ (1 ＋ 预测期资金周转速度增长率)
```
- 特点：计算简便、容易掌握，但预测结果不太精确；适用于品种繁多、规格复杂、资金用量较小的项目；
- ⚠️ 销售增长 → 分子 (1+增长率)；**资金周转加速 → 分母 (1+增长率)**（加速会减少资金占用）。

### 🎯 常考计算
- (400−80)×(1+3%)/(1+2%) = 323.14（2025 单选）
- 销售增长率 = (900−1000)/1000 = −10%，(5000−400)×(1−10%)/(1−1%) = 4181.82（2022 单选）
- 不合理率 19%：4000×(1−19%)×(1−20%)/(1−25%) = 3456（2024 单选）
- (4500−4500×15%)×(1+20%) = 4590（2017 单选）

> 📌 真题印证：讲义第 1~3 页 → **因素分析法公式是客观题必考**。

## 📍 知识点 2：销售百分比法 ⭐⭐⭐⭐⭐（主观题核心）

### ① 基本原理
假设**某些资产和负债**与销售额存在稳定百分比关系，据此预计外部资金需要量。
- ⚠️ 是"某些"（敏感性项目），**不是所有**资产和负债（2023/2020 判断 ×）。

### ② 敏感性项目
```
经营性资产（敏感性）：库存现金、应收账款、存货
经营性负债（敏感性）：应付票据、应付账款、预提费用
非敏感性：短期借款、短期融资券、长期负债（筹资性负债）、固定资产（一般）
```

### ③ 公式（🔥🔥 必背）
```
需要增加的资金量 = 增加的敏感性资产 − 增加的敏感性负债
                 = 增量收入 ×（基期敏感资产占销售额% − 基期敏感负债占销售额%）
增加的留存收益 = 预计销售收入 × 销售净利率 × 收益留存率
外部融资需求量 = 增加的敏感性资产 − 增加的敏感性负债 − 增加的留存收益
```
- 非敏感性资产增加 → 外部融资需求量**增加**（2022 判断 √）；
- ⚠️ 经营性负债包括应付票据、应付账款，**不包括短期借款、短期融资券、长期负债**（2025/2016/2014 单选）。

### ④ 常考计算
- 敏感资产 50%、敏感负债 10%、销售增长 20%、净利率 10%、留存率 30%：
  外部融资 = 1000×20%×(50%−10%) − 1000×(1+20%)×10%×30% = 44 万（2021 单选）

## 📍 知识点 3：资金习性预测法 ⭐⭐⭐⭐

### ① 资金习性
资金与产销量之间的依存关系：**不变资金、变动资金、半变动资金**（半变动可分解为不变+变动）。
```
资金总额 y = 不变资金 a ＋ 变动资金 b×产销量 x
```

### ② 高低点法（🔥 单选常考）
- 选择**销售收入最高点和最低点**对应的两组数据（不是资金占用量最高/最低）；
- ⚠️ 高点（收入最大）的资金占用量不一定最大（2017 单选 C）；
- 例题：(1100,21) 和 (760,19) → 先确定最高、最低销售收入。

### ③ 资金分类判断
- 原材料的保险储备 = 不变资金；直接构成产品实体的原材料 = 变动资金；与产销量不同比例变动的辅助材料 = 半变动资金；**最低储备之外的存货 = 变动资金**（2022 多选 D 错误）。

# 🧩 第二节 资本成本

## 📍 知识点 1：资本成本的概念与构成 ⭐⭐⭐⭐⭐（高频）

### ① 含义
资本成本 = 企业为筹集和使用资金而付出的代价，包括：
```
① 筹资费用：在资本筹措过程中为获取资本付出的代价（视为筹资数额的扣除）
   ——借款手续费、股票发行费、证券印刷费、公证费、律师费
② 占用费用（用资费用）：使用过程中因占用资本付出的代价（资本成本的主要内容）
   ——利息、股利、租赁资金利息
```
- ⚠️ **留存收益没有筹资费用，但有占用费，因此存在资本成本**（2020/2019 多选/单选）；
- ⚠️ 银行借款利息属于**占用费**，不是筹资费（2020 判断 ×）。

### ② 资本成本的作用（4 条）
1. 比较筹资方式、选择筹资方案的依据；
2. **平均资本成本是衡量资本结构是否合理的重要依据**；
3. 评价投资项目可行性的主要标准；
4. 评价企业整体业绩的重要依据。

---

## 📍 知识点 2：影响资本成本的因素 ⭐⭐⭐

```
投资者要求的收益率 = 无风险收益率 ＋ 风险收益率 = 纯粹利率 ＋ 通货膨胀率 ＋ 风险收益率
```
1. **总体经济环境**：经济稳定、通胀低 → 资本成本低；
2. **资本市场条件**：市场缺乏效率、流动性低 → 投资者风险大 → 要求收益率高 → 资本成本高；
3. **企业经营状况和融资状况**：经营风险高、财务风险大 → 资本成本高；
4. **企业对筹资规模和时限的需求**：规模大、时限长 → 资本成本高（非线性关系）。

> 📌 真题印证：证券市场流动性恶化 → 资本成本上升（2019 单选 C）；经营风险加大、通胀提高 → 借款成本上升（2018 多选 BC）。

---

## 📍 知识点 3：个别资本成本的计算 ⭐⭐⭐⭐⭐（主观题核心）

### ① 一般模式
```
资本成本率 = 年资金占用费 ÷（筹资总额 − 筹资费用）
           = 年资金占用费 ÷ [筹资总额 × (1 − 筹资费用率)]
```

### ② 各筹资方式公式

| 方式 | 公式 | 注意 |
|-|-|-|
| 银行借款 | 年利率×(1−所得税税率) ÷ (1−筹资费用率) | 分子**×（1−T）**，利息抵税 |
| 公司债券 | [面值×票面利率×(1−T)] ÷ [发行价格×(1−筹资费用率)] | 分子按**面值+票面利率**；分母按**发行价** |
| 优先股 | 年固定股息 ÷ [发行价格×(1−筹资费用率)] | 分子**不×（1−T）**，股息税后支付 |
| 普通股（股利增长模型） | D1 ÷ [P0×(1−f)] ＋ g = D0×(1+g) ÷ [P0×(1−f)] ＋ g | D1 是下期股利 |
| 普通股（CAPM） | Rf ＋ β×(Rm−Rf) | 用资本资产定价模型 |
| 留存收益 | 同普通股股利增长模型，但**不考虑筹资费用** | 无筹资费 |

### ③ 常考计算（🔥🔥）
- 银行借款：200 万、年利率 8%、筹资费率 0.5%、税率 25% → 8%×(1−25%)/(1−0.5%) = 6.03%（2021/2015 单选）
- 债券：10000 万、利率 8%、发行费率 1.5%、税率 25% → 8%×(1−25%)/(1−1.5%) = 6.09%（2014 单选）
- 债券实际利率（无税）：100×8%/[90×(1−5%)] = 9.36%（2020 单选）
- 优先股：溢价发行面值 100、溢价 10%、股息率 8%、发行费 2% → 8/[110×(1−2%)] = 7.42%（2023 单选）
- 普通股：市价 30、费率 2%、D0=0.6、g=10% → 0.6×1.1/[30×0.98]＋10% = 12.24%（讲义例题）
- CAPM：Rf=4%、β=1.2、Rm=12% → 4%＋1.2×8% = 13.6%（2023 单选）
- 留存收益：D0=0.5、市价 50、g=8% → 0.5×1.08/50＋8% = 9.08%（2023 单选）

### 🎯 常考易错点
- **债务资本成本考虑企业所得税**（利息抵税）；股权成本不考虑（2018 单选 B）；
- 优先股股息**不能**税前扣除（2020 单选 6.53%）；
- 债券资本成本影响因素：发行费用、票面利率、发行价格、利息支付频率（2020 多选 ABCD）；
- 影响债券/优先股资本成本的都是"**价格、利率、费用**"；留存收益=普通股但不扣筹资费。

## 📍 知识点 4：平均资本成本（WACC）⭐⭐⭐⭐

```
WACC = Σ（个别资本成本 × 权数）
```
三种权数对比：

| 权数 | 反映 | 特点 |
|-|-|-|
| 账面价值权数 | 过去 | 资料易取得、结果稳定；不适合评价现时资本结构 |
| 市场价值权数 | 现在 | 能反映现时资本成本水平、利于资本结构决策；不适用未来筹资决策 |
| 目标价值权数 | 未来 | 适用于未来筹资决策；目标价值确定有主观性 |

> 📌 真题印证：目标价值权数更适用于未来筹资决策、市场价值反映现时（2019 多选 ACD）；采用市场价值权数不适用于未来筹资决策（2018 判断 ×）。

---

## 📍 知识点 5：边际资本成本 ⭐⭐⭐⭐

- 边际资本成本 = **企业追加筹资的加权平均成本**，是企业进行追加筹资的决策依据；
- 筹资方案组合时，边际资本成本的权数采用**目标价值权数**（2025/2021 判断 √）。

---

## 📍 知识点 6：项目资本成本 ⭐⭐⭐

- 项目资本成本 = 项目本身所需投资资本的机会成本（项目最低可接受的报酬率）；
- 估计方法：①使用企业当前综合资本成本（需项目风险与企业平均风险相同 + 资本结构相同）；②**可比公司法**（替代公司法）；
- 可比公司法调整（"双资双权"法）：
```
卸载财务杠杆：β资产 = β权益 ÷ [1＋(1−T)×(负债/权益)]
加载财务杠杆：β权益 = β资产 × [1＋(1−T)×(负债/权益)]
```
> 例题：B 公司 β权益 0.9、D/E=1/1、T=25% → β资产=0.9/[1+0.75×1]=0.51；再加载项目 A 的 D/E=0.3/0.7 → β权益=0.51×[1+0.75×0.3/0.7]=0.67；股东权益成本=6%+0.67×5%=9.35%；项目资本成本=6%×0.75×0.3+9.35%×0.7=7.9%。

## 📍 知识点 7：金融工具价值评估 ⭐⭐⭐⭐（客观题）

### ① 债券价值
- 典型债券（固定利率、每年付息、到期还本）：V = 面值×票面利率×(P/A,i,n) ＋ 面值×(P/F,i,n)；
- 纯贴现债券：V = 面值×(P/F,i,n)；
- 永续债券：V = 年利息 I ÷ 利率 i。

### ② 普通股价值
- 零成长股票：V = D ÷ R（永续年金）；
- 固定成长股票：V = D0×(1+g)÷(R−g) = D1÷(R−g)；
- 例：D1=5、R=10%、g=5% → V = 5/5% = 100 元（2022 单选）；
- 例：D0=0.5、g=5%、R=10% → V = 0.5×1.05/5% = 10.5 元（2020 单选）。

### ③ 优先股价值
V = 每年固定股利 ÷ 必要报酬率（永续年金）。

# 🧩 第三节 杠杆效应（主观题核心）

## 📍 知识点 0：基础概念（先背熟）

| 概念 | 公式 |
|-|-|
| 边际贡献总额 | 销售收入 − 变动成本 = 单位边际贡献 × 销售量 |
| 单位边际贡献 | 单价 − 单位变动成本 |
| 边际贡献率 | 边际贡献/销售收入 = 单位边际贡献/单价 |
| 变动成本率 | 变动成本/销售收入 = 单位变动成本/单价 |
| **边际贡献率 ＋ 变动成本率 = 1** | |
| 息税前利润 EBIT | 销售收入 − 变动成本 − 固定成本 = 边际贡献 − 固定成本 |

## 📍 知识点 1：经营杠杆（DOL）⭐⭐⭐⭐⭐

### ① 定义
由于**固定性经营成本**的存在，使企业**资产报酬（息税前利润）变动率大于业务量变动率**的现象。

### ② 公式
```
经营杠杆系数 DOL = 息税前利润变动率 ÷ 产销量（业务量）变动率
                  = 基期边际贡献 ÷ 基期息税前利润 = (EBIT ＋ F) ÷ EBIT
```

### ③ 核心结论（🔥🔥 判断/多选）
- 只要存在**固定性经营成本**，DOL 总是**大于 1**；
- **固定成本、单位变动成本与 DOL 同向变动**；销售量、单价与 DOL **反向变动**（2021/2019/2020 多选）；
- 销售额越小（越接近盈亏平衡点），DOL 越大、经营风险越大；销售额处于盈亏临界点时 DOL → ∞；
- 经营杠杆系数 = 息税前利润对销售量的**敏感系数** = 经营杠杆系数（2022 多选 C、2020 单选 A）；
- 经营杠杆本身不是收益不确定的根源，只是**放大**经营风险（2022 多选 B 错误）。

### ④ 常考计算
- 固定成本 200、EBIT 300 → DOL = (300+200)/300 = 1.67（2019 单选）
- DOL = M/(M−F) 或 1 + F/EBIT

> 📌 真题印证：讲义第 23~26 页 → **DOL 影响因素 + 计算是高频考点**。

---

## 📍 知识点 2：财务杠杆（DFL）⭐⭐⭐⭐⭐

### ① 定义
由于**固定性资本成本**（固定利息、优先股利、固定融资租赁费）的存在，使企业**普通股收益（EPS）变动率大于息税前利润变动率**的现象。

### ② 公式
```
财务杠杆系数 DFL = 普通股收益变动率 ÷ 息税前利润变动率
                  = 基期息税前利润 ÷ 基期利润总额
                  = EBIT ÷ (EBIT − I − DP/(1−T))
```

### ③ 核心结论
- 只要有**固定性资本成本**，DFL 总是大于 1；
- 财务杠杆系数越大，**财务风险越大**；
- 影响 DFL 的因素：债务资本比重、普通股盈余水平、所得税税率（优先股）；
- ⚠️ **DFL = 普通股收益变动率 ÷ 息税前利润变动率**，不是产销量变动率（2022 判断 ×）；
- 固定利息费用影响财务杠杆、不影响经营杠杆（2022 单选 B）；
- 融资租赁属于债务筹资 → 带来财务杠杆效应（2018 单选 C）；
- 存在固定股息优先股时，优先股股息越高，DFL 越大（2021 判断 √）。

### ④ 常考计算
- EBIT 1000、利息 400 → DFL = 1000/600 = 1.67（2018 单选）
- EBIT 3000、DFL 1.2 → 3000/1.2=2500，利息=3000−2500=500（2024 单选）
- 普通股收益增长 20%×DFL3 = 60% → 100×(1+60%)=160 万（2020 单选）

## 📍 知识点 3：总杠杆（DTL）⭐⭐⭐⭐⭐

### ① 定义
由于**固定经营成本和固定资本成本**的共同存在，导致普通股每股收益变动率**大于产销业务量变动率**。

### ② 公式
```
总杠杆系数 DTL = 普通股盈余变动率 ÷ 产销量变动率
                = 基期边际贡献 ÷ 基期利润总额
                = 经营杠杆系数 × 财务杠杆系数（假设无优先股）
```

### ③ 常考计算（🔥🔥）
- 销售额 100、变动成本率 60%、固定成本 20、利息 4 → DTL = 100×40%/(100×40%−20−4) = 2.5（2020 单选）
- DOL=1.6、DTL=3.2：销量+10% → EBIT+16%、EPS+32%；EBIT+20% → EPS+40%（2025 多选 ABD）
- DOL=1.2、DFL=1.5，目标 EPS 增长 18% → 产销量增长率 = 18%/1.8 = 10%（2025 单选）
- 全部资本来源于普通股 → DFL=1，DTL=DOL（2018 判断 √）
- 总杠杆一定时，经营杠杆与财务杠杆可以**此消彼长、不同组合**（2022 判断 √）

### ④ 总杠杆与公司风险
```
成本特性：
├─ 固定资产比重大（资本密集型）：DOL 高、经营风险大 → 主要靠权益资本、保持较小 DFL
└─ 变动成本比重大（劳动密集型）：DOL 低、经营风险小 → 主要靠债务资本、保持较大 DFL
发展阶段：
├─ 初创阶段：经营风险大 → 主要靠权益资本、低程度使用财务杠杆
└─ 扩张成熟阶段：经营风险小 → 可扩大债务比重、高程度使用财务杠杆
```

# 🧩 第四节 资本结构

## 📍 知识点 1：资本结构基础知识 ⭐⭐⭐

- **广义资本结构**：全部债务与股东权益的构成比例；
- **狭义资本结构**（财务分析常用）：长期负债与股东权益的构成比例；
- 最优资本结构标准：**平均资本成本率最低 + 企业价值最大**；
- ⚠️ 最佳资本结构**不是长期固定不变**的（2014 单选 D）。

## 📍 知识点 2：资本结构理论 ⭐⭐⭐⭐（单选/多选）

| 理论 | 核心观点 |
|-|-|
| **无税 MM 理论** | 不考虑所得税，企业价值**不受资本结构影响**；权益资本成本随负债比例增加而加大 |
| **修正 MM 理论** | 考虑所得税，利息抵税 → 企业价值**随债务比例上升而增加** |
| **权衡理论** | 有负债企业价值 = 无负债价值 ＋ 税赋节约现值 − **财务困境成本现值** |
| **代理理论** | 股利政策/债务筹资能减少两权分离的代理成本，但带来债务代理成本；需平衡 |
| **优序融资理论** | 内部筹资 → 债务融资 → 股权融资（先内后债再股） |

### 🎯 常考易错点
- 修正 MM 理论：企业价值随资产负债率增加而**增加**（2022 多选 A 错误）；
- 权衡理论公式含"税赋节约 − 财务困境成本"（2019 单选 B）；
- 优序融资：内部筹资 > 借款 > 发行债券 > 可转换债券 > 发行新股（2021 判断 ×）；
- 认为资本结构影响企业价值的有：修正 MM、代理、权衡（**无税 MM 不算**）（2020 多选 BCD）。

## 📍 知识点 3：影响资本结构的因素 ⭐⭐⭐

```
①企业经营状况的稳定性和成长率：稳定→可多负担固定财务费用；成长率高→可高负债
②企业的财务状况和信用等级：好→易获得债务资本
③企业的资产结构：大量固定资产→发行股票；多流动资产→依赖流动负债；资产可抵押→负债多；以技术研发为主→负债少
④投资人和管理当局态度：股权分散→多用权益筹资分散风险；少数股东控制→避免普通股稀释控股权；稳健当局→低负债
⑤行业特征和发展周期：成熟产业→提高债务比重；高新企业→降低债务比重；初创→控负债；成熟→适度增债；收缩→降债
⑥税务政策和货币政策：所得税率高→债务抵税作用大；紧缩货币→利率高→债务成本大
```

> 📌 真题印证：影响资本结构决策的因素（2015 多选 ABCD 全选）；资本市场缺乏效率 → 资本成本高（2025 判断 ×）。

## 📍 知识点 4：资本结构优化 ⭐⭐⭐⭐⭐（主观题核心）

### ① 每股收益分析法（EBIT 无差别点法）
```
（EBIT − I1）×（1−T）− DP1          （EBIT − I2）×（1−T）− DP2
──────────────────  =  ──────────────────
        N1                                N2
```
决策规则（负债 vs 权益）：
- 预计/实际 EBIT **小于**无差别点 → 选择**股权筹资**（风险小）；
- 预计/实际 EBIT **大于**无差别点 → 选择**债务筹资**（杠杆收益大）；
- 多个方案需画图分段比较。

### ② 平均资本成本比较法
- 通过计算比较各种筹资组合方案的平均资本成本，选择**平均资本成本率最低**的方案；
- 侧重于从**资本投入**角度优化分析（2019 判断 √）。

### ③ 公司价值分析法（🔥 唯一考虑风险）
- 企业价值 V = 股票价值 S ＋ 债务价值 B；
- 股票价值 S = (EBIT − I)×(1−T) ÷ Ks，Ks = Rf ＋ β×(Rm−Rf)；
- 平均资本成本 = 税前债务成本×(1−T)×债务比重 ＋ 权益成本×权益比重；
- 最优资本结构：**公司总价值最高 + 平均资本成本率最低**；
- 例题：债务 400 万时公司价值最高（2579 万）、平均资本成本最低（11.64%）；
- ⚠️ **公司价值分析法考虑了市场风险**（2022/2016 单选），每股收益分析法、平均资本成本比较法只从账面角度、没考虑风险（2018 多选 ACD）。

### ④ 资本结构优化方法总结
```
每股收益分析法、平均资本成本比较法、公司价值分析法（=资本结构优化三法）
```

## 📍 知识点 5：双重股权结构（AB 股）⭐⭐⭐

- 同股不同权：A 类 1 股 1 票、B 类 1 股 N 票；A 类由投资人和公众持有、B 类由创业团队持有；
- 适用：科技创新企业；实现**控制权不流失**、降低被恶意收购可能性；
- **优点**：避免股权纷争、保障创始人对企业控制权、防止恶意收购、提高运行效率；
- **缺点**：容易导致独裁、控股股东损害非控股股东利益、可能加剧道德风险和逆向选择；
- ⚠️ 双重股权结构**不能避免**控股股东损害非控股股东利益（2022 单选 B 错误）。
