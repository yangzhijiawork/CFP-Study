# 🧩 第一节 预算管理概述

## 📍 知识点 1：预算的特征与分类 ⭐⭐⭐⭐

### ① 预算特征
- 预算必须与**战略或目标保持一致**；
- **数量化和可执行性**是预算最主要的特征。

### ② 预算分类（🔥 高频多选/单选）

```
按内容不同：
├─ 经营预算（辅助/分预算）——销售、生产、直接材料、直接人工、制造费用、产品成本、销售及管理费用
├─ 专门决策预算（资本支出预算）
└─ 财务预算（总预算）——资金预算、预计利润表、预计资产负债表
按覆盖期限不同：
├─ 长期预算（1 年以上）
└─ 短期预算（1 年期以内，经营/财务预算多为 1 年期）
```

- ⚠️ **经营预算和财务预算多为 1 年期短期预算**，不是长期（2025 判断 ×）；
- ⚠️ **财务预算 = 总预算**，经营预算和专门决策预算 = 辅助预算/分预算（2022 多选 BD）；
- ⚠️ 资金预算属于**财务预算**，不是经营预算（2023/2017 单选 D/A）。

### ③ 预算体系（编制顺序 🔥🔥）
```
销售预算（起点）
   ↓
生产预算
   ↓
直接材料/直接人工/制造费用预算
   ↓
产品成本预算
   ↓
专门决策预算 ＋ 经营预算 → 资金预算 → 预计利润表 → 预计资产负债表（终点）
```

---

## 📍 知识点 2：预算管理原则与组织 ⭐⭐

- **原则（5 条）**：战略导向、过程控制、融合性、平衡管理、权变性；
- 预算管理应刚性与柔性相结合。
- **组织分工**：
  - 董事会（或类似机构）：负总责；
  - 预算管理委员会：确定目标、政策、措施；审议、平衡、下达预算；
  - 财务管理部门：跟踪管理、监督执行、分析差异；
  - 企业职能部门（基层单位）：本部门预算编制、执行、分析。

# 🧩 第二节 预算的编制方法与程序

## 📍 知识点 1：增量预算法 vs 零基预算法 ⭐⭐⭐⭐

| 对比项 | 增量预算法 | 零基预算法 |
|-|-|-|
| 原理 | 以历史期实际经济活动及预算为基础，结合变动情况调整 | 不以历史为基础，以零为起点，从实际需要出发 |
| 特征 | 以过去费用水平为基础，不需作较大调整 | 不受现有费用项目和现行预算束缚 |
| 优点 | 简便 | 不受历史不合理因素影响、灵活应对环境变化、增加透明度、调动节约积极性 |
| 缺点 | 无效费用开支合理化，造成预算浪费 | 工作量较大、成本较高、准确性受管理水平影响 |

### 🎯 常考易错点
- 在上年费用基础上增加 16% → **增量预算**（2025 单选）
- 零基预算工作量**大**、成本**高**，不是"工作量较小"（2020/2025 单选/多选）
- 增量预算不利于调动节约积极性（2018 判断 ×）

> 📌 **真题印证**：习题第 1~11 题 → **增量 vs 零基是本章第一高频考点**。

---

## 📍 知识点 2：固定预算法 vs 弹性预算法 ⭐⭐⭐⭐

| 对比项 | 固定预算法（静态） | 弹性预算法（动态） |
|-|-|-|
| 基础 | 以预算期内正常、最可实现的某一业务量水平为固定基础 | 在分析业务量与预算项目数量依存关系基础上，分别确定不同业务量水平 |
| 优点 | —— | 考虑不同业务量水平，更贴近实际 |
| 缺点 | 适应性差、可比性差 | 编制工作量大、依赖预测准确性 |

### ① 弹性预算的两种计算方法
- **公式法**：y = a ＋ bx（把成本分解为固定 + 变动）；
- **列表法**：列出不同业务量水平的预算方案，评价考核时需用插值法。

### ② 弹性预算计算（🔥 主观题/计算常考）
已知业务量与费用预算求 a、b：
- 设 a + 400b = 20000，a + 500b = 22000 → a=12000，b=20；540 工时 = 22800（2025 多选 ABC）
- 修理费混合成本：100 件 5000 元、200 件 7000 元 → b=20，a=3000；180 件 = 6600 元（2021 单选）

### 🎯 常考易错点
- 编制方法按业务量基础的数量特征分为**固定预算与弹性预算**（2022 单选）
- 固定预算适应性差（2020 判断 √）
- 手工车间选人工工时作业务量计量单位（2017 判断 √）
- 公式法总制造费用 = 变动费用按业务量比例放大 + 固定部分（2020 单选 4600 元）

---

## 📍 知识点 3：定期预算法 vs 滚动预算法 ⭐⭐⭐

| 对比项 | 定期预算法 | 滚动预算法 |
|-|-|-|
| 做法 | 以不变会计期间作为预算期 | 根据上期执行情况和新的预测，逐期滚动、持续推动，预算期保持固定长度 |
| 优点 | 与会计期间对应，便于对比分析 | 保持预算持续性、贴近实际、发挥指导控制作用 |
| 缺点 | 缺乏长远打算，导致短期行为 | 工作量较大 |

### 🎯 常考易错点
- 预算期始终保持 12 个月，逐月滚动 → **滚动预算**（2025 单选）
- 滚动预算法预算期**不会缩短**（2023 判断 ×）
- 随着预算执行不断补充预算，保持固定预算期长度 → **滚动预算**（2015 单选）

---

## 📍 知识点 4：预算编制程序 ⭐⭐
"上下结合、分级编制、逐级汇总"：
1. 下达目标（董事会/经理办公会）→ 2. 编制上报（预算执行单位→财务管理部门）→ 3. 审查平衡（财务管理部门）→ 4. 审议批准（董事会/经理办公会）→ 5. 下达执行（预算委员会）。

# 🧩 第三节 预算编制（主观题核心）

## 📍 知识点 1：销售预算 ⭐⭐⭐⭐⭐（全面预算的起点）

```
销售收入 = 销售单价 × 预计销售量
当期销售现金流量 = 本期销售收入×本期收现比例 ＋ 以前某期收入×本期收现比例
期末应收账款余额 = 本期销售额 × 下期收现比例
```
- 例：本月收现 30%、次月收现 70% → 3 月末应收账款 = 3 月销售额×70%（2021 单选 15400 元）
- 例：上季收 70%、下季收 30%，已知上年末应收 600 万 → 一季度现金收入 = 600＋1500×70%（2020 单选）
- 销售预算内容 = 销量、单价、销售收入（**不含销售费用**，2019 单选）

---

## 📍 知识点 2：生产预算 ⭐⭐⭐⭐⭐（唯一实物量预算）

```
预计生产量 = 预计销售量 ＋ 预计期末产成品存货 − 预计期初产成品存货
（期初结存 ＋ 预计生产量 = 预计销售量 ＋ 期末结存）
```

### 🎯 常考易错点
- **生产预算是经营预算中唯一只使用实物量计量单位的预算**；
- 生产预算在**销售预算基础上**编制，是**直接材料预算**的编制基础（2024 判断 √）；
- 期末存货按下季度销量的一定比例安排 → 求本季生产量（2020/2019/2018/2016 单选连考）；
- 生产预算不直接涉及现金收支、不作为资金预算编制依据（2018 单选 C）。

> 例：第二季度销量 2000、第三季度 2200，期末存货为下季销量 10% → Q2 生产量 = 2200×10%＋2000−2000×10% = 2020（件）（2020 单选）

---

## 📍 知识点 3：直接材料预算 ⭐⭐⭐⭐⭐

```
某种材料耗用量 = 预计生产量 × 单位产品定额耗用量
预计材料采购量 = 生产需用量 ＋ 期末材料存量 − 期初材料存量
（期初结存 ＋ 采购量 = 耗用量 ＋ 期末结存）
现金支出 = 本期采购额×本期付现比例 ＋ 上期采购额×本期付现比例
```

### 🎯 常考易错点
- 期末存量按**下月生产需用量**的一定比例安排（2023/2024 单选）；
- 与计算本期采购量无关的是**上期生产需用量**（2023 单选 B）；
- 编制直接材料预算不需要考虑**预计生产成本**（2021 单选 C）；
- 全年预计采购量 = 预计生产量×单位消耗量＋期末存量−期初存量（2017 单选 17000）。

---

## 📍 知识点 4：直接人工预算 ⭐⭐⭐⭐

- 以**生产预算**为基础编制（2022 多选 BD）；
- 人工总成本 = 预计产量×单位产品工时×小时人工成本；
- ⚠️ 工资一般全部支付现金 → **不需单独预计现金支出**（2022 多选 C 错误）；
- 是编制**产品成本预算**的数据来源之一。

---

## 📍 知识点 5：制造费用预算 ⭐⭐⭐⭐

- 制造费用 = 变动制造费用 ＋ 固定制造费用；
- 现金支出 = 制造费用总额 − 非付现部分（折旧、摊销）；
- 例：固定制造费用 10 万（含折旧 2 万）＋ 100 万件×3 元 → 现金支出 = (10−2)＋300 = 308 万（2019 单选）
- 公式法：固定 1000 + 变动 3000×120% = 4600 元（2020 单选）

---

## 📍 知识点 6：产品成本预算 ⭐⭐⭐⭐

- 产品成本预算 = 销售预算、生产预算、直接材料预算、直接人工预算、制造费用预算的**汇总**（2024/2019 多选 ABCD）；
- ⚠️ 产品成本预算**不直接涉及现金收支**（2016 单选 B）；
- ⚠️ 产品成本总预算**不含销售与管理费用预算**（2016 判断 ×）；
- ⚠️ 产品成本预算不是销售预算的编制基础，方向反了（2022 判断 ×）。

---

## 📍 知识点 7：销售及管理费用预算 ⭐⭐⭐

- 销售费用预算编制基础是**销售预算**；管理费用多属固定成本，以过去实际开支为基础调整（2022 判断 ×）；
- 不以生产预算作为编制基础的是**销售费用预算**（2022 单选 C）。

---

## 📍 知识点 8：专门决策预算 ⭐⭐⭐

- 主要是**长期投资预算（资本支出预算）**，与项目投资决策相关，周期长、金额大、经常跨年度（2024/2020/2025 单选）；
- 编制依据是**项目财务可行性分析资料及筹资决策资料**，不是经营预算（2017 判断 ×）。

---

## 📍 知识点 9：财务预算（总预算）⭐⭐⭐⭐⭐（主观题核心）

### ① 资金预算（现金预算）🔥🔥
```
可供使用现金 = 期初现金余额 ＋ 现金收入
现金余缺 = 可供使用现金 − 现金支出
期末现金余额 = 现金余缺 ＋ 现金筹措 − 现金运用
```
- 资金预算以**经营预算和专门决策预算**为依据编制（2020 判断 √、2021 多选 ABCD）；
- 生产预算（实物量）与资金预算**没有直接联系**（2018 单选 C）；
- 借款金额为整数倍、期末现金余额不低于某值 → 倒推借款额（2021 单选：−55000、要求 ≥10000、1 万整数倍 → 借 70000）；
- 现金余缺 > 最佳持有量 → 可购入短期有价证券、偿还借款本息（**抛售**有价证券是现金不足时才做）（2017 多选 ABC）。

### ② 预计利润表
- 综合反映计划期预计**经营成果**，是财务预算中**最主要的预算表之一**；
- 编制依据：各经营预算、专门决策预算和资金预算；
- 所得税费用来自资金预算（利润规划时估计的，不按利润总额×税率算）。

### ③ 预计资产负债表
- 反映计划期末预计**财务状况**；以计划期开始日资产负债表为基础，根据各预算资料调整；
- 是编制**全面预算的终点**（2024 判断 ×："终于预计利润表"错，应终于预计资产负债表）；
- 预计利润表先于预计资产负债表编制（2022 判断 √）；
- "存货"项目数据来自**直接材料预算和产品成本预算**（2016/2017 多选 CD）；
- "销售成本"数据来自**产品成本预算**（2019 单选）。

### 🎯 常考易错点汇总
1. **销售预算是起点，预计资产负债表是终点**；
2. 预计利润表反映经营成果、预计资产负债表反映财务状况（2022 单选 C 错误项）；
3. 专门决策预算（资本支出）结果会**影响**资产负债表（2019 单选 A 错误）。

# 🧩 第四节 预算的执行与考核

## 📍 知识点：执行、调整、考核 ⭐⭐

### ① 预算执行
- 预算一经批复下达，各执行单位必须认真组织实施，层层分解到岗。

### ② 预算调整
- **企业正式下达执行的财务预算，一般不予调整**；
- 可调整情形：市场环境、经营条件、政策法规发生**重大变化**，致预算编制基础不成立或执行结果重大偏差（2023/2016 多选 ABCD）；
- 调整程序：预算执行单位逐级提出书面报告 → 财务管理部门审核分析 → 集中编制调整方案 → 提交预算委员会/董事会审议批准 → 下达执行；
- 调整要求：①不偏离发展战略；②经济上最优化；③重点放在重要、非正常、不符合常规的关键性差异。

### ③ 预算分析与考核
- 由预算委员会定期召开预算执行分析会议，研究落实解决执行中存在的问题。

| 增量 vs 零基 | ⭐⭐⭐⭐ | 单选/多选/判断 | 增量=历史基础调整；零基=零起点、工作量大全灵活 |
| 固定 vs 弹性 | ⭐⭐⭐⭐ | 单选/多选 | 弹性=考虑不同业务量；公式法 y=a+bx |
| 定期 vs 滚动 | ⭐⭐⭐ | 单选/判断 | 滚动=逐期滚动、预算期保持固定长度 |
| 销售预算 | ⭐⭐⭐⭐⭐ | 单选/计算 | 销售收入=单价×销量；现金收入按收现比例拆分 |
| 生产预算 | ⭐⭐⭐⭐⭐ | 单选/判断 | 唯一实物量预算；生产量=销量+期末-期初 |
| 直接材料预算 | ⭐⭐⭐⭐⭐ | 单选/计算 | 采购量=生产需用量+期末-期初；按付现比例拆现金 |
| 制造费用预算 | ⭐⭐⭐⭐ | 单选 | 现金支出=总额−折旧等非付现 |
| 产品成本预算 | ⭐⭐⭐⭐ | 多选/判断 | 五大预算的汇总；不直接涉及现金收支 |
| 专门决策预算 | ⭐⭐⭐ | 单选 | =资本支出预算，编制依据是项目可行性资料 |
| 资金预算 | ⭐⭐⭐⭐⭐ | 单选/计算 | 可供使用=期初+收入；余缺−筹措运用=期末余额 |
| 预算调整 | ⭐⭐ | 多选 | 一般不予调整；重大变化才调 |
