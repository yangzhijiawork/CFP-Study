# 🧩 第一节 收入与分配管理概述

## 📍 知识点 1：意义与原则 ⭐⭐

- 意义：体现所有者/经营者/劳动者利益关系、维持简单和扩大再生产基本条件、优化资本结构降低资本成本、国家建设资金来源；
- 原则：**依法分配、分配与积累并重、兼顾各方利益、投资与收入对等**。

## 📍 知识点 2：分配管理（净利润分配顺序）⭐⭐⭐⭐（单选高频）

```
公司净利润分配顺序：
① 弥补以前年度亏损
② 提取法定公积金
③ 提取任意公积金
④ 向股东（投资者）分配股利（利润）
```
- 法定公积金提取比例 = 当年税后利润（弥补亏损后）的 **10%**；累计达注册资本 **50%** 可不再提取；
- 法定公积金可用于弥补亏损或转增资本，转增后余额不得低于转增前注册资本的 **25%**；
- ⚠️ 净利润分配**最后**一步 = 向股东分配股利（2014 单选 A）；
- ⚠️ 正确顺序：弥补亏损 → 法定公积金 → 任意公积金 → 分配股利（2018 单选 D）。

## 📍 知识点 3：纳税管理 ⭐⭐（了解）
筹资纳税管理（保证总资产报酬率大于债务利息率）、投资纳税管理、营运纳税管理、利润分配纳税管理（所得税 + 股利分配）、重组纳税管理。

# 🧩 第二节 收入管理

## 📍 知识点 1：销售预测分析 ⭐⭐⭐⭐⭐

### ① 定性分析法（3 种）
```
营销员判断法（意见汇集法）：营销人员对市场预测后综合分析
专家判断法：个别专家意见汇集法、专家小组法、德尔菲法（函询调查法，各专家互不通气、反复修正）
产品寿命周期分析法：推广期（增长率不稳定，历史资料缺乏，用定性分析）
                       成长期（增长率最大，用回归分析法）
                       成熟期（增长率稳定，用趋势预测分析法）
                       衰退期（增长率为负数）
```

### ② 定量分析法（2 大类）🔥🔥
```
趋势预测分析法：算术平均法、加权平均法、移动平均法、指数平滑法
因果预测分析法：最常用回归直线法
```

**（1）算术平均法**
- 适用于每期销售量波动不大的产品；
- 预测值 = 各期实际销售量之和 ÷ 期数。

**（2）加权平均法**
- 权数"**近大远小**"；现实中用得较多。

**（3）移动平均法** 🔥
```
Yn+1 = 最后 m 期的算术平均数（m 固定，m < n/2）
修正移动平均法：Y'n+1 = Yn+1 ＋（Yn+1 − Yn）（在移动平均法预测值基础上加本期与上期预测值之差）
```
> 例：样本期 3，最后 3 期销量 3500、3400、3600 → 移动平均预测 = 3500；修正 = 3500＋(3500−3475) = 3525。

**（4）指数平滑法** 🔥
```
Yn+1 = a×Xn ＋（1−a）×Yn（a 为平滑指数，取值 0.3~0.7）
```
- 销售量波动大/短期预测 → 选**较大**平滑指数；波动小/长期预测 → 选较小；
- 平滑指数越大，前期实际值对预测结果影响越大（2024 判断 √）；
- 例：2024 实际 4000、预测 3750、a=0.4 → 0.4×4000＋0.6×3750 = 3850（2025 单选）。

### 🎯 常考易错点
- 定量分析 = 趋势预测分析法 + 因果预测分析法（2020/2016 单选 D/C）；
- 回归直线法属于**因果预测分析法**（2014 单选 D）；
- 指数平滑法、移动平均法属于**趋势预测分析法**；
- 营销员判断法、专家判断法、产品寿命周期分析法 = 定性分析（2020 单选 A）。

## 📍 知识点 2：销售定价管理 ⭐⭐⭐⭐

### ① 影响产品价格的因素
价值因素、**成本因素（基本因素）**、市场供求因素、竞争因素、政策法规因素。

### ② 定价目标
实现利润最大化、保持或提高市场占有率、稳定价格、应付和避免竞争、树立企业形象及品牌。

### ③ 以成本为基础的定价方法（🔥 计算）

**（1）全部成本费用加成定价法**
```
价格×(1−税率) = 单位成本 ＋ 单位利润
成本利润率定价：价格×(1−税率) = 单位成本×(1＋成本利润率)
销售利润率定价：价格×(1−税率) = 单位成本 ＋ 价格×销售利润率
```

**（2）保本点定价法**
```
价格×(1−税率) = 单位成本（固定＋变动）
确定的是最低销售价格
```

**（3）目标利润法**
```
单位产品价格 =（目标利润总额 ＋ 完全成本总额）÷ [产品销量×(1−适用税率)]
```

**（4）变动成本加成定价法**
- 生产能力有剩余时，增量产品只负担**变动成本**（完全变动成本 = 变动制造成本 + 变动期间费用）；
- 增量产品定价基础 = **变动成本**（2018 单选 D）；
- 计划外单位价格 = 单位变动成本×(1＋成本利润率)÷(1−税率)。

### ④ 以市场需求为基础的定价方法（2 种）
- **需求价格弹性系数定价法**；
- **边际分析定价法**：边际利润 = 边际收入 − 边际成本 = 0（边际收入 = 边际成本）时价格**最优**（2025 判断 ×：不是"最低价格"，是最优销售价格）；
- 以市场需求为基础的定价方法：需求价格弹性系数法、边际分析定价法（2018 单选 D）。

### ⑤ 常考计算
- 保本点定价：保本销量 25 万件、边际贡献率 40%、固定成本 100 万 → 单价 = 100/(25×40%) = 10 元（2025 单选 D）；
- 目标利润法：销量 1000、完全成本 19000、目标利润 95000、税率 5% → 单价 = (19000＋95000)/[1000×(1−5%)] = 120 元（2021/2024 单选）；
- 目标利润法（无税）：计划 20000、目标利润 400000、完全成本 600000 → 单价 = 50 元（2020 单选 C）；
- 全部成本加成：单位制造成本 100、期间费用总额 900000/10000=90、成本利润率 20%、税率 5% → 单价 = (100+90)×1.2/0.95 = 240 元（讲义例题）。

# 🧩 第三节 价格运用策略

## 📍 知识点：四大定价策略 ⭐⭐⭐（单选/判断）

### ① 折让定价策略
现金折扣、数量折扣（一次性/累计）、季节折扣、团购折扣、预购折扣。

### ② 心理定价策略
- **声望定价**：利用知名度和信任度（名牌效应，声望越高价格越高）；
- **尾数定价**：尾数取接近整数的小数（299.9），适用于价值较小的中低档日用消费品；
- **双位定价**：向市场挂牌销售时采用两种不同标价；
- **高位定价**：根据"价高质优"心理实行高标价（必须优质产品）。

### ③ 组合定价策略
- 有互补关系：便宜的打印机 + 高价墨盒；
- 有配套关系：套装减价。

### ④ 寿命周期定价策略
- 推广期：低价吸引顾客；成长期：中等价格；成熟期：高价促销；衰退期：降价或现价+折扣。

# 🧩 第四节 分配管理（本章核心）

## 📍 知识点 1：股利分配理论 ⭐⭐⭐⭐⭐（单选/多选高频）

### ① 股利无关论（MM 理论）
- 建立在**完全资本市场**假设之上：市场强式有效、无税、无筹资费、投资决策与股利决策独立、股东对股利与资本增值无偏好；
- 结论：股利政策**不影响**公司价值/股价；公司价值由**投资决策**的获利能力和风险组合决定。

### ② 股利相关论（4 种）🔥🔥

| 理论 | 核心观点 | 股利倾向 |
|-|-|-|
| **"手中鸟"理论** | 厌恶风险的投资者偏好**确定的股利收益**，不愿留存承担未来风险 | **高股利** |
| **信号传递理论** | 信息不对称下，股利政策向市场传递未来获利能力信息 | **高股利**（能力强愿意多分） |
| **所得税差异理论** | 资本利得税负低于股利税负，资本利得更有助于收益最大化 | **低股利** |
| **代理理论** | 股利政策协调股东与管理者代理关系；高股利降代理成本但增外部融资成本；理想政策使**代理成本 + 外部融资成本之和最小** | 权衡 |

### 🎯 常考易错点
- 低股利政策适用**所得税差异理论**（2024/2017/2015 单选）；
- 高股利可减少管理者对自由现金流支配、抑制在职消费 = **代理理论**（2018 单选 B）；
- 高股利向市场传递公司实力 = **信号传递理论**（2017 单选 B）；
- 厌恶风险偏好确定股利收益 = **"手中鸟"理论**（2016 单选 D）；
- 认为股利政策影响公司价值的有：手中鸟、信号传递、所得税差异、代理（**相关论四者都有**）（2020 多选 ABCD）；
- 股利无关论假设中**不存在**"资本增值"这一假设（2019 单选 C 错误项）；
- 剩余股利政策的理论依据 = **股利无关论**（2014 单选 A）。

## 📍 知识点 2：股利政策 ⭐⭐⭐⭐⭐（本章最高频）

### ① 剩余股利政策（依据股利无关论）
```
可发放股利 = 净利润 − 投资所需资金 × 权益资本占比
```
- 优点：有助于**降低再投资资金成本、保持最佳资本结构、实现企业价值长期最大化**；
- 缺点：股利随投资机会和盈利水平波动、不利于投资者安排收支、不利于树立形象；
- 适用：公司**初创阶段**；
- ⚠️ 剩余股利政策将**企业利益**放在首位；
- 例：净利润 2800、投资 3000、权益占比 60% → 股利 = 2800 − 3000×60% = 1000 万（2024 单选 C）；
- 例：净利润 2000、投资 1000、权益 40% → 股利 = 2000 − 400 = 1600 万（2025 单选 C）；
- 净利润 2500、投资 3000、权益 55% → 股利 = 2500 − 1650 = 850 万（2021 单选 A）。

### ② 固定或稳定增长的股利政策
- 每年股利固定在某一水平或按固定比率逐年稳定增长；
- **优点**：树立良好形象、增强投资者信心、稳定股价；吸引长期投资依赖股利的股东；
- **缺点**：股利的支付与盈利**相脱节**；企业无利可分时继续实施违反《公司法》；
- 适用：经营比较稳定或成长期的企业，**很难被长期采用**；
- 该政策将**股东利益**放在首位；
- ⚠️ 稳定股利不使股利与盈余挂钩（2018 多选 AB：C 是固定支付率政策优点）。

### ③ 固定股利支付率政策
- 每年按净利润的**固定百分比**分派股利（股利支付率一经确定不得随意变更）；
- **优点**：股利与盈余紧密配合，体现"**多盈多分、少盈少分、无盈不分**"（2022 单选 B）；
- **缺点**：股利支付额波动大、成为股价不利因素；容易使公司面临较大财务压力；固定支付率确定难度大；
- 该政策将企业与股东利益放在同一位置；
- ⚠️ 该政策不能向市场传递经营稳定信号（2024 判断 ×）。

### ④ 低正常股利加额外股利政策
- 事先设定较低的正常股利额，盈余较多时额外发放；
- **优点**：赋予公司较大灵活性（财务弹性大）、依靠股利度日的股东每年至少获得较低但稳定股利；
- **缺点**：容易给投资者造成收益不稳定的感觉；持续发放额外股利后被误认为"正常股利"，一旦取消可能导致股价下跌；
- 适用：盈利随经济周期波动大或盈利与现金流量不稳定的公司；
- 该政策将企业与股东利益放在同一位置；
- ⚠️ 具有较大财务弹性且使股东得到相对稳定股利收入 = 低正常股利加额外股利政策（2017 单选 A）。

### ⑤ 四政策对比（🔥 记忆）
```
剩余股利政策 → 企业利益首位
固定或稳定增长股利政策 → 股东利益首位
固定股利支付率政策 → 企业与股东利益同一位置
低正常股利加额外股利政策 → 企业与股东利益同一位置
```

## 📍 知识点 3：利润分配制约因素 ⭐⭐⭐⭐（多选）

### ① 法律因素
- **资本保全约束**：不能用资本（实收资本/股本和资本公积）发放股利；
- **资本积累约束**：必须按规定提取公积金，股利只能从可供股东分配利润中支付；"无利不分"；
- **超额累积利润约束**：为避税保留过多盈余将加征额外税款；
- **偿债能力约束**：现金股利分配后仍保持较强偿债能力。

### ② 公司因素
现金流量、资产的流动性、盈余的稳定性、投资机会（多→低股利）、筹资因素、其他因素（股利信号作用保持连续性）。

### ③ 股东因素
- 控制权（倾向低股利）、稳定收入（要求稳定股利）、避税（偏好低股利）。

### ④ 其他因素
- 债务契约（债权人限制股利发放）、通货膨胀（采用偏紧的利润分配政策）。

## 📍 知识点 4：股利支付形式与程序 ⭐⭐⭐⭐

### ① 股利支付形式（🔥 单选）
```
现金股利：最常见的方式
财产股利：以现金以外的其他资产支付，主要是公司所拥有的其他公司的有价证券（2024/2019 单选 C）
负债股利：以应付票据/公司债券支付
股票股利：以增发股票方式支付（红股）
```
- ⚠️ 财产股利和负债股利实际上是现金股利的**替代方式**，在我国实务中极少使用；
- 财产股利是**别人的**有价证券；负债股利和股票股利是**自己的**票据/债券/股票。

### ② 股票股利的影响（🔥🔥 判断/多选）
```
有影响：所有者权益的内部结构变化（未分配利润→股本+资本公积）、股数增加、每股收益下降、每股市价下降
无影响：面值不变；资产/负债/所有者权益总额不变；股份比例不变
```
- 例：每 10 股送 1 股，市价 10 元 → 未分配利润 = 5000 − 300×10 = 2000 万，股本 = 3000＋300 = 3300 万，资本公积 = 2000＋300×9 = 4700 万，权益总额不变 12000 万（2021 多选 ABC）；
- 股票股利会**改变股东权益结构**，但总额不变（2021 单选 C）；
- 发放股票股利对公司：不付现金、降低股价促流通、防恶意收购、传递发展良好信息（2017 多选 ABD）。

### ③ 股利支付程序（4 个日期）🔥
```
股利宣告日：股东会决议通过并由董事会公告的日期
股权登记日：有权领取本期股利的股东资格登记截止日期（此日收盘前买入才能领股利）
除息日：领取股利的权利与股票分离的日期；除息日当天或以后买入的股东不能领取本次股利，股价会下跌
股利发放日：向股东发放股利的日期
```
- 投资者购买股票获得收息权利的最迟日期 = **股权登记日**（2016 单选 B）；
- ⚠️ 除息日当天购买股票的投资者**没有**领取本次股利的权利（2022 判断 ×2、2014 判断 ×）。

## 📍 知识点 5：股票分割与股票回购 ⭐⭐⭐⭐

### ① 股票分割（拆股）🔥
- 将一股股票拆分成多股；
- 作用：**降低股票价格**（促进流通交易、加大恶意收购难度、为发行新股做准备）、向市场传递"公司发展前景良好"信号。

### ② 股票股利 vs 股票分割对比（🔥🔥 必背表）

| 对比项 | 股票股利 | 股票分割 |
|-|-|-|
| 面值 | **不变** | **变小** |
| 股东权益结构 | **改变** | **不变** |
| 是否股利支付方式 | 是 | 否 |
| 股数 | 增加 | 增加（更多） |
| 每股收益/每股市价 | 下降 | 下降（更多） |
| 持股比例 | 不变 | 不变 |
| 资产/负债/权益总额 | 不变 | 不变 |
| 资本结构 | 不变 | 不变 |

- 股票分割与股票股利相同点：均不改变持股比例、权益总额、资本结构、无现金流出（2025 多选 BCD）；
- 不同点：股票股利**改变**权益内部结构、股票分割**不改变**（2025 单选 D、2024 多选 BC、2022 单选 B、2019 单选 C）；
- 股票分割改变**面值**（2021 单选 A）；
- 股票分割后股本总额不变、每股净资产下降（2019 多选 CD）。

### ③ 股票回购 🔥
- 上市公司出资购回发行在外的普通股予以**注销**或作为**库存股**；
- 可回购情形（6 种）：减少注册资本（10 日注销）、与持有本公司股份的公司合并（6 个月注销）、员工持股计划/股权激励（不超 10% + 3 年注销）、股东异议回购（6 个月注销）、转换可转债（不超 10% + 3 年注销）、维护公司价值及股东权益（不超 10% + 3 年注销）；
- ⚠️ 公司**不得接受**本公司的股票作为质押权的标的。

### ④ 股票回购动机与影响
- 动机：**现金股利的替代**、改变公司资本结构、传递公司信息（稳定或提高股价）、基于控制权考虑；
- 影响：实施股权激励的回购形成利益共同体、稳定股价增强投资者信心；
- ⚠️ 股票回购改变资本结构（资产、股东权益减少）（2020 单选 A）；
- ⚠️ 回购并注销提高财务杠杆水平、改变资金成本结构（2025 判断 √）；
- ⚠️ 股票回购传递的是**股价被低估**（不是高估）的信号（2023/2017 判断 ×）；
- ⚠️ 股票回购需大量资金，**降低资产流动性**（2017 单选 D）。

## 📍 知识点 6：股权激励 ⭐⭐⭐

| 模式 | 含义 | 优点/缺点/适用 |
|-|-|-|
| **股票期权模式** | 授予激励对象未来以预先确定条件购买本公司一定数量股份的权利；不得转让、不得用于担保或偿还债务 | 优点：降低委托代理成本、锁定风险；缺点：影响现有股东权益、可能遭遇股票市场风险、可能带来经营者短期行为；适用：初始资本投入较少、成长初期或扩张期（网络/高科技） |
| **限制性股票模式** | 先以较低价格售予/赠与股票，实现预定目标后才可抛售；目标未实现公司可收回/回购；解除限售前不得转让担保 | 优点：不需支付现金对价留住人才；缺点：缺乏推动股价上涨的激励机制；适用：成熟期企业 |
| **股票增值权模式** | 股价/业绩上升时按一定比例获得差价收益 | 优点：易于操作；缺点：效果相对差、需提奖励基金、现金支付压力大；适用：现金流量充裕稳定的上市公司 |
| **业绩股票激励模式** | 年初定业绩目标，年末实现则给予股票/奖金购股 | 优点：高管与股东共同利益；缺点：业绩目标难科学确定、激励成本较高；适用：业绩稳定型上市公司 |

### 🎯 常考易错点
- 工作满三年可按每股 10 元购股 = **股票期权模式**（2020 单选 A）；
- 目标未实现公司有权收回免费赠与的股票 = **限制性股票模式**（2021/2017 单选 D）；
- 股票期权激励可能带来经营者**短期行为**（不是抑制）（2025 多选 B 错误）；
- 行权价高于股价时激励对象**不能**通过行权获利（2021 判断 ×）；
- 业绩股票激励模式只考核业绩目标、不要求股价上涨，适合业绩稳定的上市公司（2015 判断 √）。
