# 🧩 第一节 企业与企业财务管理

## 📍 知识点 1：企业及其组织形式 ⭐⭐⭐⭐⭐（历年单选/判断最爱考，约占总论 1/3 分值）

### ① 企业的定义与功能（了解即可，常考程度低）
- **定义**：依法设立的、**以营利为目的**、运用各种生产要素，向市场提供商品或服务，实行**自主经营、自负盈亏、独立核算**的法人或其他社会经济组织。
- **目标**：创造财富（或价值）。

### ② 三种组织形式对比（常考：单选对比 + 判断陷阱）

| 组织形式 | 常见形式 | 投资者 | 风险承担 |
|-|-|-|-|
| **个人独资企业** | 私营企业 | 个人 | **无限责任** |
| **合伙企业** | 普通合伙企业 / 有限合伙企业 | 两个或两个以上合伙人 | 普通合伙人**无限连带责任**；有限合伙人以出资额为限 |
| **公司制企业** | 有限责任公司 / 股份有限公司 | 个人、法人均可 | **有限责任**（以出资额为限） |

### ③ 公司制企业优缺点（⚠️ 全章最高频，几乎每年 1 题）

**优点（4 个）：**
1. 容易转让所有权
2. **有限债务责任**（股东以出资额为限，公司债务是法人债务）
3. **无限存续**（创始人和经营者退出后公司仍可继续存在）
4. 融资渠道多，更容易筹集资金

**缺点（3 个）：**
1. 组建成本高
2. **存在代理问题**（所有权与经营权分离，经营者可能损害所有者利益）
3. **双重课税**（先缴企业所得税，再缴个人所得税）

### 🎯 常考易错点（务必记住）

| 易错点 | 正确理解 |
|-|-|
| "股东承担**无限连带责任**" → ❌ 不是公司制缺点 | 有限责任恰是公司制**优点**（2022 单选 D） |
| "合伙制也有双重课税" → ❌ | **只有公司制双重课税**，合伙制没有（2016 判断） |
| "公司制受政府监管宽松" → ❌ | 设立复杂、监管**更严格**，需定期提交报告（2021 判断） |
| 代理问题的本质 | 所有者（委托人）与经营者（代理人）分离 → 代理人可能为自身利益伤害委托人利益（2016 单选） |

> 📌 **真题印证**：习题纯享第 1~6 题全考这个点 → **公司制优缺点 = 必考，背熟 4 优 3 缺**。

# 🧩 第二节 财务管理目标

## 📍 知识点 1：四大目标理论 ⭐⭐⭐⭐⭐（全章分值最高的考点，历年 7~8 题）

### ① 利润最大化（最朴素、最"短视"）
- **观点**：以实现利润最大为目标；利润 = 收入 − 成本费用
- **优点**：讲求经济核算、加强管理、改进技术、提高劳动生产率、降低产品成本；有利于资源合理配置，提高整体经济效益
- **缺点（高频考）**：
  1. **没有考虑利润实现时间和资金时间价值**
  2. **没有考虑风险问题**
  3. **没有反映创造的利润与投入资本之间的关系**（投入产出比）
  4. **可能导致短期财务决策倾向**，影响企业长远发展

### ② 股东财富最大化（上市公司专属 + 所有目标基石）
- **观点**：股东财富 = 股票数量 × 股票价格
- **优点**：① 考虑了风险因素；② 一定程度上避免短期行为；③ 对上市公司容易量化，便于考核奖惩
- **缺点**：① 通常只适用于**上市公司**，非上市公司难应用；② 股价受众多因素影响，不能完全准确反映财务管理状况；③ 强调股东利益，对其他相关者利益重视不够

### ③ 企业价值最大化（教材最推崇）
- **观点**：企业价值 = 所有者权益 + 债权人权益的市场价值，或**预计未来现金流量的现值**
- **优点**：① 考虑报酬取得时间，用时间价值计量（现值）；② 考虑风险与报酬关系；③ 把长期稳定发展与持续获利放在首位，**克服短期行为**；④ 用价值代替价格，避免外界市场因素干扰
- **缺点**：① 价值过于理论化，不易操作；② 非上市公司需专门评估，受评估标准/方式影响，难做到客观准确
- **提示**：随着上市公司数量的增加，逐渐得到广泛认可

### ④ 相关者利益最大化（股东首要地位）
- **观点**：① 强调**股东的首要地位**；② 强调风险与报酬均衡，把风险限制在可承受范围内
- **优点**：① 有利于长期稳定发展；② 合作共赢理念，经济效益与社会效益统一；③ 多元化多层次目标体系，兼顾各方利益；④ 前瞻性与现实性的统一

### 📊 四种目标核心对比表（🔥 考试必考，请背熟）

| 对比点 | 利润最大化 | 股东财富最大化 | 企业价值最大化 | 相关者利益最大化 |
|-|-|-|-|-|
| **长短期效应** | **短期行为** | 长期行为 | 长期行为 | 长期行为 |
| **是否考虑时间价值** | ❌ **没有** | ✅ 考虑 | ✅ 考虑 | ✅ 考虑 |
| **是否考虑风险** | ❌ **没有** | ✅ 考虑 | ✅ 考虑 | ✅ 考虑 |
| 其他 | —— | 单纯考虑股东利益 | 考虑股东 + 债权人 | 综合不同利益相关者 |

### 🎯 常考易错点
1. **唯一不考虑时间价值 & 风险的 = 利润最大化**（2023/2025 单选连考）
2. **唯一导致短期行为的 = 利润最大化**（2018 单选）
3. **基石关系**：利润 / 企业价值 / 相关者利益最大化 **都以股东财富最大化为基石**（2022、2015 判断）→ 没有股东财富最大化，其余目标都难实现
4. **股东财富最大化**同时占两个位置：**上市公司专属** + **共同基石**
5. **相关者利益最大化 = 股东首要地位**，不是"员工"也不是"其他相关者"（2019 判断）
6. **衡量股东财富最直观指标 = 股价**（2019 单选）
7. ⚠️ 判断陷阱：股东财富最大化"意味着先满足股东再考虑其他相关者" → ❌ 公司法规定股东权益是**剩余权益**，缴税、工资、产品服务之后才轮到股东（2020/2021 判断 ×2）

> 📌 **真题印证**：习题纯享第 7~22 题（16 题）全是这个点 → **四大目标对比表 = 第一章必背之首**。

## 📍 知识点 2：财务管理目标与利益冲突 ⭐⭐⭐⭐⭐（三大冲突，近几年多选集中区）

### ① 股东 vs 经营者（管理层）—— 解聘 / 接收 / 激励

- **矛盾点**：经营者想获取更多报酬、享受并避免风险；股东希望以较小代价实现更多财富
- **协调方式**：
  1. **解聘** —— 股东约束经营者
  2. **接收** —— 市场约束经营者
  3. **激励** —— **股票期权 + 绩效股**

> ⚠️ 高频易错：**"限制借款用于高风险项目"属于股东 vs 债权人，不属于股东 vs 经营者**（2023 单选明确考过）！

### ② 大股东 vs 中小股东

- **侵害形式（5 种，多选常考）**：
  1. 利用**关联交易**转移上市公司资产
  2. 非法占用上市公司巨额资金，或以公司名义**担保 / 恶意筹资**
  3. 发布**虚假信息**进行股价操纵
  4. 为大股东委派的高管支付**不合理报酬**及特殊津贴
  5. 采用**不合理股利政策**，掠夺中小股东既得利益
- **解决方式**：
  1. 完善治理结构（增强中小股东**投票权 + 知情权**、提高**独立董事**比例、健全**监事会**）
  2. 规范**信息披露制度**（完整、真实、及时）

### ③ 股东 vs 债权人

- **矛盾点**：① 所有者要求经营者把借款改投**高风险项目**；② 未征得债权人同意**举借新债**
- **协调方式**：
  1. **限制性借债**：事先规定借债用途限制、借债担保条款、借债信用条件
  2. **收回借款或停止借款**

### 🎯 常考易错点
- 三大冲突**全部由委托代理问题引起**（管理层与股东 / 股东与债权人 / 大股东与中小股东，2023 判断 √）
- **"不存在控股股东 → 就没有股东与债权人冲突"** → ❌ 冲突与是否控股无关（2022 判断）
- 债权人保护自己：**限制支付现金股利**也属于限制性借债的一般性保护条款（2021 多选 ABCD）
- **高风险投资对债权人**：只带来高风险、**无高收益**（风险收益不对称，2017 判断 ×）
- 协调手段三句口诀：**股东管经营者 = 解聘接收激励；股东防债权人 = 限债收债停借；中小股东靠治理 + 披露**

> 📌 **真题印证**：习题纯享第 23~29 题 → **三冲突的"协调手段配对"是单选/多选必考**。

## 📍 知识点 3：企业的社会责任 ⭐⭐⭐

- **定义**：企业在谋求**所有者（股东）权益最大化之外**所负有的**维护和增进社会利益**的义务
- **五大责任**：
  1. 对**员工**的责任
  2. 对**债权人**的责任
  3. 对**消费者**的责任
  4. 对**社会公益**的责任
  5. 对**环境和资源**的责任
- **补充**：还有义务**遵从政府管理、接受政府监督**
- ⚠️ 易错：不是只分"社会公益 + 对债权人"两大类（2014 判断 ×）

> 📌 **真题印证**：习题纯享第 30 题。

# 🧩 第三节 财务管理原则 ⭐⭐

## 📍 知识点：五条原则（讲义原文，逐条记）

```
财务管理五大原则（记忆口诀：系风现成利）
│
├─ ① 系统性原则 —— 财务管理是系统工程，各环节相互联系
├─ ② 风险权衡原则 —— 风险与收益要权衡，不能只追求收益忽视风险
├─ ③ 现金收支平衡原则 —— 现金流要收支平衡（这是"现金流"的正确归属！）
├─ ④ 成本收益权衡原则 —— 投入与产出要划算，讲求经济效益
└─ ⑤ 利益关系协调原则 —— 协调各方利益相关者关系
```

### 🎯 常考易错点
- 判断/多选直接给一句描述，让你选"属于哪条原则"。
- ⚠️ **"现金收支平衡"在这里是原则之一**，正好呼应你第一节学过的坑——现金流管理≠财务管理全部，它是"营运资金管理"那块内容，而"现金收支平衡"是五大原则之一，**两处别混**。

> 📌 **真题印证**：本讲义此节无独立真题，但属于"客观题送分归类题"，务必把 5 条原则名背全（漏一条=丢 1 分）。

# 🧩 第四节 财务管理环节 ⭐⭐⭐

## 📍 知识点：六大环节 & 核心

```
财务管理环节（流程线：先计划后行动）
│
├─ ① 财务预测 —— 对未来的筹资、投资等做科学预计
├─ ② 财务计划（预算）—— 把预测落到具体计划
├─ ③ 财务决策 ──────── ⭐ 财务管理核心 ⭐
├─ ④ 财务控制 —— 执行中对财务活动进行监控纠偏
├─ ⑤ 财务分析 —— 事后分析评价
└─ ⑥ 财务考核（评价）—— 兑现奖惩、改进管理
```

### 🎯 常考易错点
- **"财务决策是财务管理的核心"**，不是预算、不是控制、不是分析（🔴 最高频陷阱）。
- 财务决策的定义：**按财务战略目标总体要求，用专门方法对备选方案比较分析，选出最佳方案**。

> 📌 **真题印证（2 题全中）**：
> - 第 31 题【单选·2020】选最佳方案 → **财务决策（A）**
> - 第 32 题【单选·2024】财务管理核心 → **财务决策（B）**

# 🧩 第五节 财务管理体制 ⭐⭐⭐⭐

## 一、三种模式整体思维导图

```
财务管理体制
│
├─ ① 集权型 ──── 权限集中于企业总部
│     优点：一体化管理·决策统一制度化 / 优化资源配置·利于内部调拨价格 / 利于内部避税·防范汇率风险
│     缺点：所属单位缺主动性·丧失活力 / 决策程序复杂·失去市场弹性
│
├─ ② 分权型 ──── 权限分散于各所属单位
│     优点：因地制宜及时决策 / 分散经营风险·提高人员素质
│     缺点：缺全局观·整体意识 → 资金管理分散·资金成本增大·费用失控·利润分配无序
│
└─ ③ 集权与分权相结合 ⭐ 最推崇
      实质＝"集权下的分权"：重大决策权集中总部，赋予各单位自主经营权
      优点：吸收两者优点，避免两者缺点 → 优越性最大
```

## 二、影响集权/分权选择的因素（🔥 表格必背）

| 考虑因素 | 集权 | 分权 |
|-|-|-|
| 生命周期 | **初创期**（经营风险高） | 稳定增长期 |
| 企业战略 | 纵向一体化 | 多元化战略 |
| 市场环境 | 市场稳定 | 复杂多变、不确定高 |
| 企业规模 | 小 | 大 |
| 管理水平 | 高 | 低 |
| 信息网络 | 高 | 低 |

> ⚠️ **最易错**：初创期经营风险高 → 反而宜**集权**（降低分权决策失误风险），不是分权！（2022 单选 A 项错误）

## 三、设计原则（4 条）& 组织体制（U/H/M）

```
设计原则：
① 与现代企业制度的要求相适应
② 决策权·执行权·监督权 三权分立
③ 财务的综合管理和分层管理思想
④ 与企业组织体制相适应

组织体制（3 种）：
├─ U 型：高度集权 · 集权控制 ⭐ 最基本组织结构（产品简单、规模小，无中间管理层）
├─ H 型：高度分权 · 控股公司体制（各子公司独立性大）
└─ M 型：事业部制（集权程度较高，事业部有一定经营自主权）
```

## 四、集权与分权相结合的实践：**7 集中 4 分散**（🔥 多选必考）

```
7 项应集中（记忆：制度·机构·筹资·投资·担保·固购·分配）
① 制度制定权   ② 财务机构设置权   ③ 筹资权   ④ 投资权
⑤ 用资、担保权  ⑥ 固定资产购置权   ⑦ 收益分配权

4 项应分散（记忆：经营·人事·定价·费用）
① 经营自主权  ② 人员管理权  ③ 业务定价权  ④ 费用开支审批权
```

### 🎯 常考易错点汇总
1. **集权型缺点** = 削弱所属单位主动性、失去市场弹性（不是"资金管理分散/利润分配无序"，那些是分权缺点）
2. **初创期宜集权**（2022 真题明确 A 选项错误）
3. **业务联系越紧密 → 越宜集中** √（2016 判断）
4. **U 型典型特征 = 集权控制**（没有中间管理层，2014 单选）
5. **7 集中 4 分散**：收益分配权、财务机构设置权、对外担保权都是**集中**；业务定价权是**分散**（2011 多选 ABC）

> 📌 **真题印证（5 题全中）**：
> - 第 33 题【单选·2017】集权型导致的问题 → **削弱所属单位主动性（A）**
> - 第 34 题【单选·2022】初创期更适合分权 → **❌ 错，应集权（选 A）**
> - 第 35 题【判断·2016】业务联系越紧密越需集中 → **√**
> - 第 36 题【单选·2014】U 型组织典型特征 → **集权控制（A）**
> - 第 37 题【多选·2011】应集中的权力 → **收益分配权·财务机构设置权·对外担保权（ABC）**

# 🧩 第六节 财务管理环境 ⭐⭐⭐⭐

## 一、整体思维导图

```
财务管理环境
│
├─ ① 技术环境 —— 技术手段决定财务管理效率与效果
├─ ② 经济环境 ⭐⭐⭐（经济体制 / 经济周期 / 发展水平 / 宏观政策 / 通货膨胀）
├─ ③ 金融环境 ⭐⭐⭐（金融机构 / 金融工具 / 金融市场分类 / 货币vs资本市场）
└─ ④ 法律环境（筹资·投资·收益分配各对应法规）
```

## 二、技术环境（了解即可）
- 指财务管理得以实现的技术手段和技术条件，**决定着财务管理的效率和效果**。

## 三、经济环境 — 经济体制与周期（🔥 各阶段策略对比必背）

**经济体制**：计划经济下财务管理内容单一、方法简单；市场经济下内容丰富、方法复杂多样。

| 阶段 | 财务战略 |
|-|-|
| **复苏** | 增加厂房设备·实行长期租赁·建立存货储备·开发新产品·增加劳动力 |
| **繁荣** | 扩充厂房设备·继续建立存货·提高产品价格·开展营销规划·增加劳动力 |
| **衰退** | 停止扩张·出售多余设备·停产不利产品·停止长期采购·削减存货·停止扩招雇员 |
| **萧条** | 建立投资标准·保持市场份额·压缩管理费用·放弃次要利益·削减存货·裁减雇员 |

> ⚠️ **高频易错**：把"复苏"和"繁荣"的策略混、把"衰退"和"萧条"的策略混。**复苏=扩张起步（增加厂房设备/长期租赁）**；**繁荣=继续加码+提价**；**衰退=收缩（停扩/卖设备/停采购）**。

## 四、经济环境 — 通货膨胀（🔥 必考）

**（1）通货膨胀的影响（5 条，判断常考）**
1. 引起**利润虚增**，造成企业资金流失
2. 引起**利润上升**，加大企业权益资金成本
3. 引起资金占用大量增加 → 增加资金需求
4. 引起有价证券价格**下降** → 增加筹资难度
5. 引起资金供应紧张 → 增加筹资困难

> ⚠️ 易错：通胀**不会降低筹资难度**、**不会使市场利率下降**（2018 判断 ×）。

**（2）应对措施（初期 vs 持续期）**

| 阶段 | 措施 |
|-|-|
| **通货膨胀初期** | ① 进行投资避免风险、资本保值 ② 签订**长期购货合同** ③ 取得**长期借款**，保持资本成本稳定 |
| **通货膨胀持续期** | ① 采用较严格的信用条件、减少企业债权 ② 调整财务政策、防止资本流失 |

> ⚠️ 易错：**签订长期销货合同**是错的（会减少通胀期现金流入，**无助于**应对通胀）；要签的是**长期购货合同**（2017 单选 D）。

## 五、金融环境

**（1）金融工具（🔥 多选区分基本/衍生）**
- **基本金融工具**：货币、票据、债券、股票
- **衍生金融工具**：远期合约、期货、互换（掉期）、期权、资产支持证券

> ⚠️ 易错：**银行承兑汇票 = 基本工具**（不是衍生）；股指期货、远期外汇、股票期权都是衍生（2021 多选 ABD）。

**（2）金融市场分类（5 种标准）**

```
① 按期限：货币市场（短期）/ 资本市场（长期）⭐ 最重要
② 按功能：发行市场（一级）/ 流通市场（二级）
③ 按融资对象：资本市场 / 外汇市场 / 黄金市场
④ 按工具属性：基础性金融市场 / 金融衍生品市场
⑤ 按地理范围：地方性 / 全国性 / 国际性
```

**（3）货币市场 vs 资本市场（🔥 核心对比）**

| 对比项 | 货币市场（短期） | 资本市场（长期） |
|-|-|-|
| 期限 | **≤1 年** | **≥1 年**（可 10 年以上） |
| 构成 | 拆借·票据·大额定期存单·短期债券 | 债券·股票·期货·融资租赁 |
| 功能 | 调节短期资金融通（短期周转） | 长期资本融通（补充长期资本、扩大生产） |
| 特点 | 流动性强·价格平稳·风险小 | 收益高·风险大·借贷量大·价格波动大 |

**（4）法律环境（了解即可）**
- 影响筹资：**公司法、证券法、民法典**
- 影响投资：**证券法、公司法、企业财务通则**
- 影响收益分配：**税法、公司法、企业财务通则**

### 🎯 常考易错点汇总（金融部分）
1. **以 1 年为界**分货币/资本市场（2022/2023 单选连续考）
2. **资本市场**=股票、债券、期货、融资租赁；**货币市场**=拆借、票据、大额存单、短期债券（注意短期债券在"货币"侧）
3. 货币市场特点=**流动性强、风险小**；资本市场=**收益高、风险大**
4. 能提供**中长期资金**：股票市场、融资租赁市场（不是拆借/票据贴现）
