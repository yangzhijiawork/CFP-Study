# 🧩 第一节 财务分析与评价概述

## 📍 知识点 1：财务分析意义与内容 ⭐⭐

- 意义：判断财务实力、评价考核经营业绩揭示问题、挖掘潜力、评价发展趋势；
- 不同信息需求者关注点：
```
企业所有者：资本保值增值（获利能力指标）
企业债权人：偿债能力（最关心），同时关注盈利能力
企业经营决策者：营运/偿债/盈利/发展能力全方位综合分析
政府：因身份不同关注点不同
```

## 📍 知识点 2：财务分析方法 ⭐⭐⭐⭐

### ① 比较分析法
- 按比较对象分为：趋势分析法、横向比较法、预算差异分析法；
- 定基动态比率 = 分析期数额 ÷ 固定基期数额×100%；
- 环比动态比率 = 分析期数额 ÷ 前期数额×100%；
- 注意：口径一致、剔除偶发项目、用例外原则做重点分析。

> ⚠️ 例：第一至三年净利润 4000、5000、5600，第一年为基期 → 定基比率 100%、125%、**140%**（2021 判断 ×：第三年 112% 错）

### ② 比率分析法（3 种比率，🔥 单选）

| 比率 | 公式 | 例子 |
|-|-|-|
| **构成（结构）比率** | 某个组成部分 ÷ 总体数值 | 资产构成比率、负债构成比率 |
| **效率比率** | 所得 ÷ 所费（投入产出） | 成本利润率、营业利润率、资本金利润率 |
| **相关比率** | 某个项目 ÷ 另一个相关项目 | 流动比率、资产负债率 |

> 例：成本利润率 = **效率比率**（2017 单选 A）；流动比率 = **相关比率**（2014 单选 C）

### ③ 因素分析法
- 连环替代法：按顺序逐一替换各因素，分析各因素影响；
- 差额分析法：直接计算各因素变动的差额影响；
- 注意问题（4 条）：因素分解的**关联性**、因素替代的**顺序性**、顺序替代的**连环性**、计算结果的**假定性**；
- ⚠️ 因素分析法特征**不包括**"分析结果的准确性"（2012 单选 C）；
- 例：材料费用 = 产量×单耗×单价，计划 100×8×5=4000，实际 110×7×6=4620 → 产量影响 +400、单耗影响 −550、价格影响 +770，合计 +620。

# 🧩 第二节 基本的财务报表分析（主观题核心）

## 📍 知识点 1：偿债能力分析 ⭐⭐⭐⭐⭐

### ① 指标分类
```
短期偿债能力：营运资金、流动比率、速动比率、现金比率
长期偿债能力：资产负债率、产权比率、权益乘数、利息保障倍数
```

### ② 短期偿债能力指标（🔥🔥）

| 指标 | 公式 | 说明 |
|-|-|-|
| 营运资金 | 流动资产 − 流动负债 | 绝对值，不便于跨企业比较；为负说明部分非流动资产以流动负债为资金来源 |
| 流动比率 | 流动资产 ÷ 流动负债 | 生产企业合理最低流动比率为 2；营业周期短/应收存货周转快的企业可低一些 |
| 速动比率 | 速动资产 ÷ 流动负债 | 速动资产 = 流动资产 − 存货 − 预付款项 − 一年内到期非流动资产 − 其他流动资产 = 货币资金+交易性金融资产+应收账款+应收票据 |
| 现金比率 |（货币资金＋交易性金融资产）÷ 流动负债 | 最能反映直接偿付流动负债能力；经验值 0.2 可接受 |

- 一般关系：**流动比率 ≥ 速动比率 ≥ 现金比率**；
- 速动资产中**不含存货**（2018/2014 单选 D/B）、不含预收账款（负债）；
- 速动比率高 → 短期偿债能力强，但现金/应收占用过多、增加机会成本影响获利能力；
- 现金比率剔除应收账款影响，最能反映即时偿付能力（2017/2018 判断/单选）。

**流动比率/速动比率变动判断（🔥🔥 单选高频）**
```
以银行存款偿还短期借款：速动资产和流动负债等额减少，速动比率>1时 比率变大
用现金偿还应付账款：流动比率、速动比率均变大（比率>1时）
赊购原材料（流动比率>1时）：流动比率变小
收回应收账款：流动资产内部一增一减，比率不变
用银行存款购买存货：流动资产内部一增一减，流动比率不变
```
> 例：速动比率大于 1，用现金偿还应付账款 → 流动比率和速动比率都**变大**（2021 单选 C）

### ③ 长期偿债能力指标（🔥🔥）
```
资产负债率 = 总负债 ÷ 总资产
产权比率 = 总负债 ÷ 股东权益
权益乘数 = 总资产 ÷ 股东权益
利息保障倍数 = 息税前利润 ÷ 应付利息
            =（净利润＋所得税费用＋利息费用）÷ 应付利息
```
- **三条线公式（🔥 必背）**：权益乘数 = 1＋产权比率 = 1÷(1−资产负债率)，知一推二（2021 判断 √）；
- 产权比率高 = 高风险高报酬财务结构、财务杠杆效应强、长期偿债能力弱（2015 单选 C）；
- 利息保障倍数至少**大于 1**；越大长期偿债能力越强（2023 判断 √）；
- **应付利息 = 费用化利息 ＋ 资本化利息**（2021 判断 ×：说"只含费用化"错）；
- 例：利润总额 700、财务费用（利息费用）50、资本化利息 30 → 利息保障倍数 = (700+50)/(50+30) = 9.375（2020 单选 A）；
- 例：净利润 6600、所得税 2200、财务费用 200、应付利息 800 → (6600+2200+200)/800 = 11.25（2023 单选 A）；
- 例：净利润 750、所得税 250、应付利息 200（资本化 50）→ (750+150+250)/200 = 5.75（2025 单选 C）。

### ④ 影响偿债能力的其他因素
可动用的银行贷款指标或授信额度、资产质量、或有事项和承诺事项、经营租赁（2015 多选 ABCD）。

## 📍 知识点 2：营运能力分析 ⭐⭐⭐⭐⭐

### ① 公式总表（🔥🔥）
```
应收账款周转率（次数）= 营业收入 ÷ 应收账款平均余额
应收账款周转天数 = 计算期天数 ÷ 周转次数
存货周转率（次数）= 营业成本 ÷ 存货平均余额
流动资产周转率 = 营业收入 ÷ 流动资产平均余额
固定资产周转率 = 营业收入 ÷ 固定资产平均余额
总资产周转率 = 营业收入 ÷ 平均资产总额
```

### ② 要点
- 应收账款：分子理论上用**赊销额**，外部分析用营业收入；包含"应收账款+应收票据"；用未扣除坏账准备的金额（2020 判断 ×：说不含应收票据错）；
- 存货周转率：用**营业成本**作分子；反映存货整体周转情况，注意行业可比性；
- 平均资产 =（期初＋期末）÷ 2；
- 周转次数越高、周转天数越短 → 管理效率越高、增强短期偿债能力（2023 单选 C）。

### ③ 常考计算
- 存货周转次数 = 7000 ÷ [(2000+1500)/2] = 4 次（2022 单选 D）；
- 应收账款周转率 = 营业收入/平均应收 → 8 = 营业收入/150 → 本期收入 1200 → 增长率 20%（2020 单选）；
- 总资产周转率 = 30%÷20% = 1.5（2018 单选，杜邦关系）。

## 📍 知识点 3：盈利能力分析 ⭐⭐⭐⭐

```
营业毛利率 = 销售毛利 ÷ 营业收入（销售毛利 = 营业收入 − 营业成本）
营业净利率 = 净利润 ÷ 营业收入
总资产净利率 = 净利润 ÷ 总资产 = 营业净利率 × 总资产周转次数
净资产收益率（ROE）= 净利润 ÷ 股东权益 = 总资产净利率 × 权益乘数
```
- 营业毛利率越高 → 产品盈利能力越强；
- 营业净利率反映每 1 元收入最终赚取的利润；
- 总资产净利率越高 → 资产利用效果越好；
- 净资产收益率越高 → 股东和债权人利益保障程度越高；**是杜邦分析体系的核心指标**；
- ⚠️ ROE 不是越高越好，分析时注意财务风险。

## 📍 知识点 4：发展能力分析 ⭐⭐⭐⭐

```
营业收入增长率 = 本年营业收入增长额 ÷ 上年营业收入总额×100%
总资产增长率 = 本年资产增长额 ÷ 年初资产总额×100%
资本保值增值率 = 扣除客观增减因素后所有者权益期末总额 ÷ 所有者权益期初总额×100%
```
- "资本保值增值率"中的资本 = **所有者权益**；
- 资本保值增值率用**期末总额 ÷ 期初总额**（不是增加值比期初）（2025 判断 ×）；
- 总资产增长率 = 增长额 ÷ **年初**资产总额（2023 判断 √）；
- 资本保值增值率、资本积累率反映发展能力（2018 单选 B）。

## 📍 知识点 5：现金流量分析 ⭐⭐⭐⭐

### ① 获取现金能力分析
```
营业现金比率 = 经营活动现金流量净额 ÷ 营业收入（每 1 元收入得到多少现金流，越大越好）
每股营业现金净流量 = 经营活动现金流量净额 ÷ 普通股股数（反映最大分派股利能力）
全部资产现金回收率 = 经营活动现金流量净额 ÷ 平均总资产
```

### ② 收益质量分析
```
净收益营运指数 = 经营净收益 ÷ 净利润 =（净利润 − 非经营净收益）÷ 净利润
现金营运指数 = 经营活动现金流量净额 ÷ 经营所得现金
             = 经营活动现金流量净额 ÷（经营净收益 ＋ 非付现费用）
```
- 净收益营运指数**越小** → 非经营收益占比越大 → 收益质量**越差**（2017 判断 ×：说越大越差错）；
- 净收益营运指数反映**净收益与经营净收益**关系，不是与现金流量关系（2019 判断 ×）；
- 现金营运指数反映收益质量（2018 单选 C）；理想现金营运指数为 1；
- 现金营运指数 < 1 → 部分收益尚未取得现金、收益质量差、取得同样收益占用更多营运资金。

# 🧩 第三节 上市公司财务分析

## 📍 知识点 1：每股收益 ⭐⭐⭐⭐⭐

### ① 基本每股收益
```
基本每股收益 = 归属于普通股股东的净利润 ÷ 当期发行在外普通股加权平均数
当期发行在外普通股加权平均数 =（期初股数×报告期时间 ＋ 新发行股数×已发行时间 − 回购股数×已回购时间）÷ 报告期时间
```
- **送股（股票股利）不考虑权重**（股东权益没变、投资资本没变，所增股数期初已存在）；**增发新股考虑权重**（2017 单选 A）；
- 例：期初 8000 万股，2 月 8 日 10 送 10 → 16000 万股，11 月 29 日发新股 6000 万 → 加权平均数 = 8000＋8000＋6000×1/12 ≈ 16500 → 每股收益 = 25000/16500 ≈ 1.52 元。

### ② 稀释每股收益（🔥 潜在普通股）
- 潜在普通股：**可转换公司债券、认股权证、股份期权**（2020/2017 单选：库存股、不可转换优先股不是）；
- 假设稀释性潜在普通股在发行日就全部转换为普通股；
- 可转换债券：分子加税后利息，分母加转股股数（按时间加权）；
- 认股权证/股份期权：分子不变，分母加增加的普通股股数（考虑时间权数）；
- ⚠️ 认股权证行权价格**低于**当期普通股平均市场价格 → 应考虑稀释性（2022 判断 √）。

## 📍 知识点 2：每股股利 ⭐⭐⭐
```
每股股利 = 普通股股利总额 ÷ 期末发行在外普通股股数
```
影响因素：盈利能力、股利发放政策、投资机会。

## 📍 知识点 3：市盈率 ⭐⭐⭐
```
市盈率 = 每股市价 ÷ 每股收益
```
- 市盈率越高 → 投资者对股票收益预期越看好、投资价值越大，但**投资风险也越大**；
- 影响因素：盈利能力的成长性、投资者所获报酬率的稳定性、利率水平变动；
- 市盈率越高表明投资者越看好投资预期（2014 判断 √）；
- 例：每股市价 30.4、每股收益 1.52 → 市盈率 20 倍。

## 📍 知识点 4：每股净资产 ⭐⭐⭐
```
每股净资产 = 期末普通股净资产 ÷ 期末发行在外普通股股数
```
- 反映每股股份能分配的企业账面净资产价值；股票市价相近时，每股净资产越高 → 发展潜力和投资价值越大、投资风险越小。

## 📍 知识点 5：市净率 ⭐⭐⭐
```
市净率 = 每股市价 ÷ 每股净资产
```
- 市净率较低的股票投资价值较高（但要注意低市净率也可能反映不良预期）；
- 例：市价 20、净利润 400、净资产 500、股数 100 万 → 每股净资产 5 → 市净率 4（2020 单选 A）。

## 📍 知识点 6：管理层讨论与分析 ⭐⭐
- 上市公司定期报告的重要组成部分；
- 对过去经营状况评价 + 对未来发展趋势前瞻性判断；
- 披露原则：**强制与自愿相结合**（2019 多选 D 错误）；
- 包括两部分：报告期间经营业绩变动的解释 + 前瞻性信息。

# 🧩 第四节 财务评价与考核

## 📍 知识点 1：杜邦财务分析体系 ⭐⭐⭐⭐⭐

### ① 公式（🔥🔥 必背）
```
净资产收益率（ROE）= 营业净利率 × 总资产周转率 × 权益乘数
```
- **净资产收益率是杜邦分析体系的起点和核心**（2018 判断 √、2025 判断 ×："总资产净利率为起点"错）；
- 三因素分别反映：营业净利率（盈利能力）、总资产周转率（营运能力）、权益乘数（偿债能力/财务杠杆）（2020 多选 BCD）；
- 杜邦分析体系所涉及指标：营业净利率、总资产周转率、权益乘数（2018 单选 D 错误：起点不是总资产收益率）。

### ② 常考计算
- 营业净利率 20%、总资产净利率 30% → 总资产周转率 = 1.5（2018 单选 D）。

## 📍 知识点 2：沃尔评分法 ⭐⭐
- 将若干财务比率用线性关系结合评价信用水平；选 7 种财务比率，总比重 100 分。

## 📍 知识点 3：经济增加值（EVA）⭐⭐⭐

```
经济增加值 = 税后净营业利润 − 平均资本占用 × 加权平均资本成本
```
- 考虑了**全部资本（债务 + 股权）的机会成本**，能更真实反映企业价值创造（2021 判断 √）；
- 使经济增加值最大化与**股东财富最大化**目标一致；
- ⚠️ 只能衡量当期或预判未来 1~3 年价值创造，**无法衡量长远发展战略价值**（2023 多选 C 错误）；
- ⚠️ 不同规模/行业/成长阶段公司会计调整项和加权平均资本成本不同 → **可比性较差**，不适用横向比较（2022 单选 C 错误）；
- 例：税后净营业利润 500、债务 1000、股权 2000、WACC 10% → EVA = 500 − 3000×10% = 200 万（2022 单选 D）。

## 📍 知识点 4：综合绩效评价 ⭐⭐⭐

- 站在**企业所有者（投资人）**角度，定量 + 定性分析；
- 组成：**财务绩效定量评价（70%）＋ 管理绩效定性评价（30%）**；
- 财务绩效定量评价四个方面：**盈利能力、资产质量、债务风险、经营增长**（2018 多选 ABCD）；
- 管理绩效定性评价：战略管理、经营决策、发展创新、风险控制、基础管理、人力资源、行业影响、社会贡献；
- 财务绩效基本指标：净资产收益率、总资产报酬率、总资产周转率、应收账款周转率、资产负债率、已获利息倍数、销售增长率、资本保值增值率；
- ⚠️ 管理绩效定性评价标准**应分行业**灵活把握，不设定统一标准（2021 判断 ×）；
- 目前我国企业经营绩效评价主要使用**功效系数法**。

# 🎯 全章常考知识点速查表（考前 30 秒扫一眼）

| 知识点 | 考频 | 常考题型 | 必背要点 |
|-|-|-|-|
| 比率分析分类 | ⭐⭐⭐⭐ | 单选 | 成本利润率=效率比率；流动比率=相关比率 |
| 因素分析法 | ⭐⭐⭐⭐ | 单选/计算 | 连环替代、差额分析；特征无"准确性" |
| 流动/速动/现金比率 | ⭐⭐⭐⭐⭐ | 单选 | 速动资产不含存货；现金比率最能反映即时偿付 |
| 比率变动判断 | ⭐⭐⭐⭐⭐ | 单选 | 现金还债（>1时）比率变大；赊购（>1时）流动比率变小 |
| 资产负债率/产权/权益乘数 | ⭐⭐⭐⭐⭐ | 单选/判断 | 权益乘数=1+产权=1/(1−资产负债率) |
| 利息保障倍数 | ⭐⭐⭐⭐ | 单选/判断 | 应付利息含资本化；至少大于 1 |
| 营运能力周转率 | ⭐⭐⭐⭐⭐ | 单选/计算 | 存货用营业成本；应收含应收票据；用平均数 |
| 盈利能力指标 | ⭐⭐⭐⭐ | 单选 | ROE=总资产净利率×权益乘数 |
| 发展能力指标 | ⭐⭐⭐⭐ | 单选/判断 | 资本保值增值率=期末/期初；资本=所有者权益 |
| 获取现金能力 | ⭐⭐⭐⭐ | 单选 | 营业现金比率、每股营业现金净流量、全部资产现金回收率 |
| 收益质量 | ⭐⭐⭐ | 单选/判断 | 净收益营运指数、现金营运指数 |
| 每股收益 | ⭐⭐⭐⭐⭐ | 单选/判断 | 送股不计权重、增发计权重；潜在普通股=可转债/认股权证/期权 |
| 市盈率/市净率 | ⭐⭐⭐ | 单选 | 市盈率=市价/每股收益；市净率=市价/每股净资产 |
| 杜邦分析 | ⭐⭐⭐⭐⭐ | 单选/判断/计算 | ROE=营业净利率×总资产周转率×权益乘数；起终点=净资产收益率 |
| 经济增加值 | ⭐⭐⭐ | 单选/判断 | 税后净营业利润−平均资本占用×WACC；考虑全部资本机会成本 |
| 综合绩效评价 | ⭐⭐⭐ | 多选 | 财务定量(70%)+管理定性(30%)；四个方面 |
