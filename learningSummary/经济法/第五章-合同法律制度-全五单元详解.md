### ② 第二单元 合同订立 · 详细展开

```
第二单元 合同的订立
│
├─ ① 订约程序 ⭐⭐⭐⭐⭐
│   ├─ 要约邀请：寄送价目表/拍卖公告/招标公告/招股说明书/债券募集办法/基金招募说明书=一定是要约邀请；悬赏广告=要约；商业广告视内容
│   ├─ 要约：内容具体明确+表明受约束；生效=到达主义
│   ├─ 承诺：受要约人同意；到达生效；可撤回不可撤销
│   ├─ 实质性变更：标的/数量/质量/价款/履行期限/履行地点和方式/违约责任/解决争议方法=新要约
│   ├─ 撤回/撤销：撤回须在到达前/同时；撤销在承诺前
│   └─ 不得撤销：确定承诺期限/明示不可撤销/有理由认为不可撤销并做准备
│
├─ ② 成立与生效 ⭐⭐⭐
│   ├─ 成立时间：承诺生效/签名盖章/实际履行/确认书/订单成功/中标通知到达/拍卖落槌
│   ├─ 成立地点：约定/承诺生效地/最后签名地/主营业地
│   ├─ 缔约过失责任：合同不成立/无效/被撤销→信赖利益损失
│   └─ 报批合同：未办理批准不影响报批条款效力；不履行报批义务可解除+违约赔偿
│
└─ ③ 格式条款 ⭐⭐⭐
    ├─ 提供方提示说明义务（免除减轻责任/重大利害关系）
    ├─ 未履行义务→对方可主张该条款不成为合同内容
    ├─ 解释：按通常理解→不利提供方→非格式条款优先
    └─ 无效：人身伤害免责/故意重大过失致财产损失免责/不合理免除减轻责任加重对方责任/排除对方主要权利
```

### ③ 第三单元 合同履行 · 详细展开

```
第三单元 合同的履行
│
├─ ① 履行规则 ⭐⭐⭐
│   ├─ 提前/部分履行：债权人可拒绝（不损害债权人利益除外）；增加费用由债务人负担
│   ├─ 漏洞填补：协议补充→交易习惯→法定规则
│   │   ├─ 履行地点：不动产在不动产所在地/货币在接收方/动产在履行义务方
│   │   ├─ 履行期限：可随时履行但给必要准备时间
│   │   ├─ 履行费用：债务人负担（债权人原因增加的除外）
│   │   └─ 价款：订立合同时履行地市场价格
│   └─ 涉第三人：由第三人履行→第三人不履行债务人担责；向第三人履行（利他合同）
│
├─ ② 抗辩权 ⭐⭐⭐⭐
│   ├─ 同时履行抗辩：互负债务无先后顺序；未履行/未适当履行可拒绝
│   ├─ 后履行抗辩：有先后顺序；先履行方未履行→后履行方拒绝
│   └─ 不安抗辩（先履行方）：经营严重恶化/转移财产抽逃资金/丧失商业信誉/其他丧失履行能力；中止履行+通知；合理期限未恢复未担保→可解除
│
├─ ③ 合同保全 ⭐⭐⭐⭐⭐
│   ├─ 代位权：债务人怠于行使到期债权危及债权人债权→债权人以自己名义代位
│   │   ├─ 原告债权人/被告次债务人/第三人债务人；必要费用债务人负担
│   │   ├─ 专属于债务人自身权利不得代位（抚养赡养扶养费/人身损害赔偿/基本生活费劳动报酬/养老金等）
│   ├─ 撤销权：债务人实施不当处分财产行为危及债权→债权人撤销
│   │   ├─ 纯获益（放弃债权/担保/无偿转让/恶意延长）不要求相对人知情
│   │   ├─ 非纯获益（低价/高价/担保）要求相对人知道或应当知道
│   │   ├─ 撤销权1年（知道起）/5年（行为发生起）
│   └─ 对比：代位权以到期债权为限、撤销权以债权为限；债权人无优先受偿权
│
└─ ④ 变更与转让 ⭐⭐⭐⭐
    ├─ 变更：仅内容变更；约定不明推定未变更
    ├─ 债权转让：无须债务人同意但须通知；禁转债权（性质/约定/法律规定）
    ├─ 债务转让：免责债务承担须经债权人同意；并存的债务承担无须同意
    └─ 概括承受：经对方同意；法人合并承继、分立连带
```

### ④ 第四单元 合同消灭 · 详细展开

```
第四单元 合同的消灭
│
├─ ① 终止 ⭐⭐⭐⭐⭐
│   ├─ 原因：清偿/抵销/提存/免除/混同/解除
│   ├─ 清偿抵充：约定→指定→到期→缺担保→负担重→到期先→比例（口诀"约指到期，缺少担保，负担较重，先后比例"）
│   ├─ 抵销：法定（种类品质相同+均到期/未到期方主张）；不得抵销（劳务/不作为/抚恤金/向第三人给付/人身侵权债务）
│   ├─ 提存：债权人原因无法交付；动产；自提存之日起债务消灭、风险归债权人、孳息归债权人、费用债权人负担；5年不领归国家
│   ├─ 免除：从权利随之消灭；连带债务人免除其一→其余扣除份额后仍担剩余
│   ├─ 混同：债权债务同归一人终止；票据背书/质押不消灭
│   └─ 解除：约定/法定（不可抗力/预期违约/迟延致不能实现目的/迟延经催告仍不履行）
│       ├─ 通知到达解除；诉讼副本送达解除
│       └─ 解除权行使期限：有约定/催告合理期限/无催告1年
│
└─ ② 违约责任 ⭐⭐⭐⭐⭐
    ├─ 归责：不以过错为条件；因第三人原因违约→先向对方担责
    ├─ 免责事由：不可抗力（迟延后发生不免除）；免责条款（人身伤害/故意重大过失财产损失不得免责）
    ├─ 继续履行：金钱债务无条件；非金钱债务有例外
    ├─ 赔偿损失：直接损失+履行利益；可预见规则/减轻损失/过失相抵
    ├─ 违约金：过低可增加；过高（>损失×30%）可减少；迟延履行违约金+继续履行
    └─ 定金：≤主合同标的额20%；给付方违约无权请求返还、收受方违约双倍返还；定金vs违约金不能并用、定金vs赔偿损失可并用
```

### ⑤ 第五单元 典型合同 · 详细展开

```
第五单元 典型合同
│
├─ ① 买卖合同 ⭐⭐⭐⭐⭐
│   ├─ 所有权转移：动产交付时/不动产登记时；孳息交付前归出卖人、后归买受人
│   ├─ 一物多卖：普通动产（交付>付款>成立）；特殊动产（交付>登记>成立）
│   ├─ 风险承担：交付前出卖人、交付后买受人（风险与所有权无关）
│   │   ├─ 需运输→交付第一承运人；路货→合同成立时
│   │   ├─ 买受人违约→违反约定之日起；质量不符→出卖人承担
│   ├─ 检验期限：质保期→合理期限→2年；出卖人明知不符不受限制
│   ├─ 解除：主从物/数物/分批交货
│   └─ 特种买卖：所有权保留（动产；75%以上不得取回）；分期付款（1/5+催告→全部价款或解除）；试用（使用费无约定无偿；试用期风险出卖人）；商品房
│
├─ ② 赠与合同 ⭐⭐⭐⭐
│   ├─ 单务+无偿+诺成+双方法律行为
│   ├─ 任意撤销：财产权利转移前；但公证/公益道德（救灾扶贫助残）不得任意撤销
│   ├─ 法定撤销：忘恩负义（严重侵害/不履行扶养/不履行约定义务）；1年；致赠与人死亡/丧失行为能力→6个月
│   └─ 穷困抗辩：经济状况显著恶化可不再履行
│
├─ ③ 借款合同 ⭐⭐⭐⭐⭐
│   ├─ 自然人之间=实践合同（提供借款时成立）；其他=诺成合同
│   ├─ 利息不得预先扣除（按实际借款数额返还）
│   ├─ 民间借贷：未约定利息不支付；约定≤LPR4倍；逾期利率≤LPR4倍
│   ├─ 提前还款按实际借款期间计息
│   └─ 付息期限：不满1年返还时付；1年以上每届满1年付
│
├─ ④ 租赁合同 ⭐⭐⭐⭐⭐
│   ├─ 期限≤20年（超过部分无效）；6个月以上须书面（否则不定期）
│   ├─ 不定期租赁：当事人可随时解除（合理期限前通知）
│   ├─ 转租：经同意可转租（原合同继续有效）；未经同意出租人可解除；知道6个月未异议视为同意
│   ├─ 买卖不破租赁：所有权变动不影响租赁合同效力（适用所有租赁物）
│   ├─ 优先购买权：除外（按份共有人/近亲属/15日未表示/委托拍卖未参加）
│   ├─ 优先承租权：期限届满同等条件优先承租
│   └─ 一房数租：合法占有在先>登记备案在先>合同成立在先
│
└─ ⑤ 保证合同 ⭐⭐⭐⭐⭐（🆕2026新增破产案件保证人权利）
    ├─ 形式：书面；单独合同/保证条款/单方承诺债权人接收未异议
    ├─ 资格：国家机关/公益非营利机构一般无效；登记为营利法人有效；禁止反言（无代偿能力不免责）
    ├─ 方式：一般保证（先诉抗辩权）/连带责任保证；不明→一般保证
    ├─ 保证期间：无约定/约定不明→主债务履行期届满之日起6个月
    ├─ 主合同变更：减轻→仍担保；加重→加重部分不担；变更履行期限→保证期间不受影响
    ├─ 债权转让：未约定禁转→通知保证人；约定禁转→未经书面同意不再担保
    ├─ 债务转让：未经保证人书面同意→转移的债务不再担保；第三人加入债务→保证责任不受影响
    └─ 共同担保：物保人保并存；债务人提供物保→先物后人；第三人提供物保→债权人可择一
```

# 🧩 第一单元 合同概述

## 📍 知识点 1：合同编的适用范围 ⭐

| 对象 | 是否适用合同编 |
|-|-|
| 民事主体之间设立、变更、终止民事法律关系的协议 | 适用 |
| 政府机关作为平等主体与对方签订合同 | 适用 |
| 劳动合同 | 不适用（适用《劳动合同法》） |
| 婚姻、收养、监护等身份关系协议 | 有身份法规定则不适用；无则参照适用 |

### 🎯 常考易错点
1. "收养协议/监护权协议/劳动合同适用合同编" → ❌ 均不适用（单选 B 2019：租赁合同适用）

## 📍 知识点 2：合同的分类 ⭐⭐⭐

| 分类标准 | 分类 | 举例 |
|-|-|-|
| 有无名称 | 有名/无名合同 | 买卖合同 / 借用合同 |
| 是否需实际交付才成立 | **实践合同**（诺成之外） | 保管、定金、自然人借款（"保定自借"） |
| | 诺成合同 | 其他合同（买卖/租赁/赠与） |
| 是否要求特定形式 | 要式合同 | 融资租赁、建设工程、技术开发、担保、借款 |
| | 不要式合同 | 自然人借款、赠与 |
| 是否互负给付义务 | 单务/双务 | 赠与、保证 / 买卖、租赁 |
| 主从关系 | 主/从合同 | 借款合同 / 担保合同 |
| 是否以订立另一合同为内容 | 预约/本约合同 | 商品房认购书 / 商品房买卖合同 |

**预约合同成立条件：** ①以认购书/订购书/预订书等形式约定将来订立合同或为担保交付定金；②能确定将来合同主体、标的等内容。
**预约合同不成立：** 仅通过意向书/备忘录表达交易意向未约定将来订立合同；难以确定主体/标的。
**违反预约违约责任：** 一方不履行订立本约义务→对方可请求赔偿损失（不得请求强制履行缔约义务）。

### 🎯 常考易错点
1. "自然人借款合同属诺成合同" → ❌ **实践合同**（多选 A 2022：郑某与王某借款不选）
2. "赠与合同属实践合同" → ❌ 属**诺成**、单务、无偿合同（多选 B 2022）
3. "预约合同违反，可请求强制履行缔约义务" → ❌ 只能请求赔偿损失（判断 √ 2023：可请求承担违约责任）

## 📍 知识点 3：合同的订立形式 ⭐
- **书面形式**：合同书、信件、数据电文（电报/电传/传真/电子数据交换/电子邮件）
- **口头形式**：双方交谈方式
- **推定形式**：由特定行为推知意思
- **沉默形式**：有法律规定/约定/交易习惯时视为意思表示

> 电子邮件属书面形式（判断 √）

# 🧩 第二单元 合同的订立

## 📍 知识点 1：合同订立的程序 ⭐⭐⭐⭐⭐（极高考频）

### ① 四组重要概念

| 概念 | 定义 | 法律约束力 |
|-|-|-|
| **要约邀请** | 希望他人向自己发出要约的表示 | 无约束力 |
| **要约** | 希望与他人订立合同的意思表示（内容具体明确+表明受约束） | 有约束力 |
| **承诺** | 受要约人向要约人作出的同意要约的意思表示 | 一致则合同成立 |
| **实质性变更** | 对要约重要内容（标的/数量/质量/价款/履行期限地点方式/违约责任/解决争议方法）变更 | =新要约（反要约） |

### ② 要约与要约邀请的区分（🔥 必考）
- **一定是要约邀请**：寄送的价目表、拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书
- **一定是要约**：悬赏广告（可向不特定人发出）
- **视情况**：商业广告（内容符合要约条件的构成要约）

### ③ 要约的生效（到达主义）
- **对话方式**：受要约人知道其内容时生效
- **非对话方式（数据电文）**：进入受要约人**特定系统**（指定）或**任一系统**（未指定）；受要约人不知情乱发→以其知悉到达的时间为准
- **非对话方式（其他）**：到达受要约人能接触到的地址/住所/其他空间即为到达（不需亲自收到）

### ④ 要约的撤回与撤销
- **撤回**：通知在要约到达**之前或同时**到达
- **撤销**：在受要约人作出**承诺之前**（对话：承诺前知道；非对话：承诺前到达）
- **不得撤销**：①确定了承诺期限；②明示不可撤销；③受要约人有理由认为不可撤销并已为履行做合理准备

### ⑤ 要约的失效
1. 要约被**拒绝**
2. 要约被**依法撤销**
3. 承诺期限届满未作出承诺
4. 受要约人对要约内容作出**实质性变更**

> 提示：撤回要约不属于要约失效的情形。

### ⑥ 承诺的细化规定
- **主体**：由受要约人向要约人作出
- **内容**：与要约内容一致（非实质性变更有效，除非要约人及时反对或表明不得变更）
- **生效**：通知到达时生效（行为方式作出行为时生效）；承诺生效时合同成立
- **期限**：要约确定期限内到达；未确定→对话即时作出、非对话合理期限到达
- **超期到达**：必然超期=新要约（要约人接受则承诺有效）；偶然超期=承诺有效（要约人表示拒绝则无效）

### ⑦ 承诺的撤回
- 承诺可以**撤回**（在承诺到达之前或同时），但**不得撤销**承诺

### 🎯 常考易错点
1. 拍卖公告/价目表/招股说明书=要约邀请；符合要约条件的商业广告=要约（多选 ABC 2024）
2. 数据电文：收件人不知情、未指定系统→以**知悉到达时间**为生效（单选 B：8月2日）
3. 信件要约：到达**乙公司注册住所**（1月10日）即生效，不需到达法定代表人手中（单选 A 2025）
4. 确定承诺期限的要约**不得撤销**（单选 D 2023、多选 ACD 2022）
5. 要约失效：被拒绝/依法撤销/承诺期届满未承诺/实质性变更（多选 ABCD）
6. "乙6月4日实质性变更→要约失效日6月4日"（单选 C 2024）
7. 要约往返：5月1日要约、5月3日/5月5日为（实质性变更）新要约、5月7日为承诺（多选 ABC 2022）
8. "回复愿购买但须签书面合同=新要约" → ❌ 订立形式不属于实质性变更（单选 D 2024 不当选）
9. "梁某当面询问丁某（对话方式）→丁某次日回复=新要约"（单选 D 2020）
10. 承诺期限起算：信件未载明日期→**邮戳日期**起算（单选 B：7月5日）
11. "承诺到达后可撤销" → ❌ 承诺只能撤回不能撤销（多选 A 2023 不当选）
12. 确定承诺期限要约不得撤销（单选 B 2024 不当选）

> 📌 **真题印证**：习题第 1~45 题全考要约承诺 → **要约邀请vs要约、要约生效、不得撤销、要约失效、承诺 = 必考**。

## 📍 知识点 2：合同的成立与生效 ⭐⭐⭐

### ① 合同成立时间

| 订立形式 | 成立时间 |
|-|-|
| 合同书 | 双方签名、盖章或按指印时 |
| 实际履行原则 | 一方履行主要义务对方接受时（签名前） |
| 确认书 | 签订确认书时 |
| 网上购物 | 提交订单成功时 |
| 招标 | 中标通知书到达中标人时 |
| 现场拍卖 | 拍卖师落槌时 |
| 网络拍卖 | 电子交易系统确认时 |

### ② 合同成立地点
- 约定地点→约定地点；无约定→承诺生效地点
- 合同书/确认书→最后一方签名盖章地点；数据电文→收件人主营业地/住所地

### ③ 缔约过失责任
- **概念**：缔约过程中因过错致合同不成立/无效/被撤销→对对方损失承担赔偿责任
- **典型**：假借订立合同恶意磋商；故意隐瞒重要事实/提供虚假情况；泄露或不正当使用商业秘密；其他违背诚信
- **vs 违约责任**：适用对象（未成立/无效/被撤销 vs 生效合同）；赔偿范围（信赖利益 vs 直接+履行利益）；赔偿大小（小 vs 大）

### ④ 合同的生效
- 依法成立的合同自**成立时生效**（另有规定除外）
- **报批合同**：未办理批准手续不影响报批条款效力；不履行报批义务→对方可请求继续履行/解除+赔偿

### 🎯 常考易错点
1. "邮件磋商须以书面确认书为准（该条款一直存在）" → 乙未注意→**合同不成立**（单选 A：因双方约定签订确认书）
2. 缔约过失责任赔偿**信赖利益损失**

## 📍 知识点 3：格式条款 ⭐⭐⭐

- **定义**：为重复使用预先拟定、订立时未与对方协商的条款
- **提示说明义务**：采取合理方式提示免除减轻责任等重大利害关系条款；按对方要求说明
- **未履行后果**：对方可主张该条款**不成为合同内容**
- **举证**：提供方对已尽提示/说明义务承担举证责任（仅设置勾选/弹窗不足以证明已履行）
- **解释**：按通常理解→两种以上解释→不利于提供方→非格式条款优先
- **无效格式条款**：①造成人身伤害免责；②故意或重大过失致财产损失免责；③不合理免除减轻责任/加重对方责任/限制对方主要权利；④排除对方主要权利

# 🧩 第三单元 合同的履行

## 📍 知识点 1：合同的履行规则 ⭐⭐⭐

### ① 提前履行与部分履行
- 债权人可拒绝（**不损害债权人利益**除外）；因履行给债权人增加的费用由**债务人**负担

### ② 合同漏洞的填补（🔥 必考法定规则）

| 合同漏洞 | 法定规则 |
|-|-|
| **履行地点** | 不动产在**不动产所在地**；给付货币在**接收货币一方所在地**；其他动产在**履行义务一方所在地** |
| **履行期限** | 债务人可随时履行、债权人可随时要求履行，但给必要准备时间 |
| **履行方式** | 有利于实现合同目的的方式 |
| **履行费用** | 由**履行义务一方**负担（债权人原因增加的除外） |
| **质量要求** | 强制性国标→推荐性国标→行业标准→通常/特定标准 |
| **价款报酬** | 订立合同时**履行地**市场价格 |

### ③ 涉及第三人的合同履行
- **由第三人履行**：第三人向债权人履行；第三人不履行→**债务人**向债权人承担违约责任；增量费用由债务人承担
- **向第三人履行（利他合同）**：债务人向第三人履行；不履行→债务人向债权人（不真正利他）或第三人（真正利他）担责

### 🎯 常考易错点
1. "履行期限不明确债权人不可随时要求" → ❌ 可随时要求但给必要准备时间（多选 A 2020 不当选）
2. "履行费用由权利人负担" → ❌ 由**履行义务一方**负担（多选 B 不当选）
3. 履行地点：给付货币在**接受货币一方**所在地（多选 C）
4. 香蕉（动产）：履行地在**卖方（海口）**所在地；价款按**订立合同时海口**市场价格（单选 A）
5. 由第三人履行：李某未付款→**王某**（债务人）承担违约责任（单选 C）

> 📌 **真题印证**：习题第 46~70 题考履行规则 → **漏洞填补法定规则 = 必考**。

## 📍 知识点 2：同一双务合同中的抗辩权 ⭐⭐⭐⭐

### ① 同时履行抗辩权
- **概念**：互负到期债务、无先后履行顺序，一方在对方履行前/履行不符合约定时有权拒绝其履行请求
- **行使条件**：①同一双务合同互负债务；②双方债务已届清偿期；③无先后履行顺序；④对方未履行或未适当履行
- 只**暂时阻止**对方请求权行使，非永久消灭；因行使抗辩致迟延履行的责任由对方承担

### ② 后履行抗辩权
- 互负债务**有先后顺序**，先履行方未履行→后履行方拒绝其履行请求

### ③ 不安抗辩权（先履行方）
- **情形**：①经营状况严重恶化；②转移财产/抽逃资金逃避债务；③丧失商业信誉；④有丧失/可能丧失履行能力其他情形
- **行使程序**：中止履行+**通知**对方
- **后果**：对方恢复履行能力或提供适当担保→恢复履行；合理期限内未恢复未担保→视为表明不履行主要债务→可**解除合同**+请求违约责任

### 🎯 常考易错点
1. 同时履行抗辩条件不含"行使抗辩权当事人负有先为给付义务"（多选 D 2022 不当选）
2. 约定先付款后交货、甲公司未付款请求先交货→乙公司可行使**后履行抗辩权**（单选 B 2023）
3. 不安抗辩权情形**不包括**"变更经营方式"（单选 D 2021）
4. "有确切证据无须先中止履行可直接解除合同" → ❌ 应先**中止履行+通知**（单选 A 2025 当选"错误"表述）

## 📍 知识点 3：合同的保全 ⭐⭐⭐⭐⭐（极高考频）

### ① 债权人代位权
- **概念**：债务人怠于行使对次债务人的到期债权危及债权人债权→债权人以自己名义代位行使（该债权专属于债务人自身的除外）
- **行使条件**：①债权人对债务人债权合法且到期；②债务人怠于行使到期债权（不以诉讼/仲裁方式主张）；③次债务人对债务人的权利非专属于债务人自身
- **期前保全**：债权到期前，债务人的债权存在诉讼时效将届满/未申报破产债权等情形→债权人可代位请求
- **专属权利（不得代位）**：抚养费/赡养费/扶养费请求权、人身损害赔偿请求权、基本生活费劳动报酬、养老金失业保险金最低生活保障金
- **诉讼列置**：原告=债权人、被告=**次债务人**、第三人=债务人；必要费用由**债务人**负担
- **效果**：由次债务人向债权人履行；代位权以债权人的**到期债权**为限；债权人无优先受偿权

### ② 债权人撤销权
- **概念**：债务人实施法定不当处分财产行为（减少责任财产）影响债权实现→债权人请求撤销

| 不当处分行为 | 是否要求相对人知情 |
|-|-|
| 放弃债权（无论是否到期）、放弃债权担保、无偿转让财产、恶意延长到期债权履行期限（纯获益） | **不要求** |
| 明显不合理低价转让（<70%）、明显不合理高价受让（>30%）、为他人债务提供担保（非纯获益） | 要求知道或应当知道 |

- **诉讼列置**：原告=债权人；**共同被告=债务人+相对人**；管辖=债务人或相对人住所地法院
- **撤销限额**：以债权人的债权为限；撤销后行为自始无效；债权人无优先受偿权
- **行使期间**：自知道或应当知道撤销事由之日起 **1 年**内；自行为发生之日起 **5 年**内未行使消灭
- **必要费用**：由债务人负担

### ③ 代位权 vs 撤销权对比

| 对比 | 代位权 | 撤销权 |
|-|-|-|
| 危及方式 | 怠于行使到期债权 | 实施不当处分财产行为 |
| 被告 | 次债务人 | 债务人+相对人（共同被告） |
| 第三人 | 债务人（应当） | —— |
| 限额 | 到期债权为限 | 债权为限 |
| 必要费用 | 债务人 | 债务人 |
| 行使期限 | 诉讼时效 | 1年（知道起）/5年（行为起） |
| 优先受偿权 | 无 | 无 |

### 🎯 常考易错点
1. 代位权：范围以债权人到期债权为限（15万而非20万）、次债务人抗辩可向债权人主张、必要费用由债务人负担、以自己名义诉讼（多选 BD 2025：A、C 不当选）
2. "劳动报酬请求权/养老金/失业金可被代位" → ❌ 属专属权利（单选 C 2020：房屋租金可代位）
3. "代位权诉讼以债务人和次债务人为共同被告" → ❌ 被告=**次债务人**、债务人为第三人（单选 C 2024 不当选）
4. 撤销权：范围以债权为限、必要费用债务人负担、以自己名义、共同被告（多选 ACD 2025：B 不当选）
5. "无偿转让财产须第三人恶意才可撤销" → ❌ 无偿行为不要求第三人善意恶意（判断 √ 2025）
6. 撤销权最晚：知道之日起 **1 年**（单选 C 2023：2022.4.18知道→2023.4.18）

> 📌 **真题印证**：习题第 71~100 题全考保全 → **代位权/撤销权、专属权利、行使期间 = 必考**。

## 📍 知识点 4：合同的变更和转让 ⭐⭐⭐⭐

### ① 合同的变更
- 仅指**内容**变更（不含主体变更）；事前/事后协商一致可变更；变更内容约定不明→**推定为未变更**

### ② 合同权利的转让（债权转让）
- 债权人转让债权**无须经债务人同意**，但**应当通知**债务人；未通知→对债务人**不发生效力**（但不影响债权转让协议成立生效）
- **不得转让**：因合同性质（委托合同等）/当事人约定/法律规定（保险单未经被保险人书面同意不得转让质押）
- **禁转约定对抗性**：非金钱债权→不得对抗善意第三人；金钱债权→不得对抗（善意/恶意）第三人
- **效力**：全部转让→受让人取代原债权人；从权利一并转让（专属于债权人自身除外）；债务人抗辩可向受让人主张；债务人可向受让人主张抵销（其债权先于/同时到期）；因债权转让增加的费用由**让与人**负担

### ③ 合同义务的转让（债务转让）
- **并存的债务承担**：第三人与债务人约定加入债务并通知债权人（或向债权人表示愿意加入）→债权人可请求第三人与债务人承担**连带债务**（无须债权人同意）
- **免责的债务承担**：债务人将债务全部/部分转让给第三人→**应当经债权人同意**；未经同意→债权人可拒绝第三人履行、继续要求债务人履行

### ④ 债权债务一并转让
- 经对方同意可将权利义务一并转让
- 法人合并→权利义务由合并后法人承继；法人分立→分立后法人连带债权连带债务（另有约定除外）

### 🎯 常考易错点
1. "债权转让未经债务人同意无效" → ❌ 无须同意但须**通知**（多选 A 2025 不当选）
2. "债务人接到转让通知后对让与人的抗辩不可向受让人主张" → ❌ 可主张（多选 B 不当选）
3. "因债权转让增加费用由受让人负担" → ❌ 由**让与人**（原债权人）负担（多选 C 当选）
4. 债权拆分转让：钱某可拆分，通知后赵某向各新债权人履行，增加费用由钱某负担（多选 BC 2025）
5. "债务人将部分债务转移给第三人无须经债权人同意" → ❌ 须经同意（判断 ×）
6. 免责债务承担：乙公司同意丙承担→乙只能向**丙**主张（单选 C）

> 📌 **真题印证**：习题第 101~120 题考变更转让 → **债权转让通知、债务转让经同意、从权利转让 = 必考**。

# 🧩 第四单元 合同的消灭

## 📍 知识点 1：合同的终止 ⭐⭐⭐⭐⭐（极高考频）

### ① 合同终止的原因与效果
- **原因**：清偿、抵销、提存、免除、混同、合同解除
- **效果**：权利义务终止；从权利义务消灭；不影响解决争议方法、结算和清理条款效力；履行通知/协助/保密/旧物回收义务

### ② 清偿（抵充顺序，🔥 必背）
**数项债务并存：** 约定→债务人指定→法定（已到期→缺乏担保/担保最少→负担较重→到期在先→按比例）
> 🔥 **记忆口诀**："约指到期，缺少担保，负担较重，先后比例"

**同一笔债务给付不足：** ①实现债权的有关费用→②利息→③主债务（"从后往前"清偿）

### ③ 抵销
- **法定抵销**：双方互负标的物种类品质相同的债务；双方均到期→任何一方可主张；一方到期一方未到期→**未到期方**可主张
- **规则**：应通知对方，通知到达生效；**不得附条件或附期限**；等额抵销后消灭；剩余债权诉讼时效重新计算
- **不得抵销**：提供劳务的债务、不作为的债务、支付抚恤金/最低生活保障金/退休金、约定向第三人给付、侵害人身权益或故意重大过失侵害财产权益的损害赔偿债务、约定/法定不得抵销情形

### ④ 提存
- **原因**：债权人无正当理由拒绝受领；债权人下落不明；债权人死亡未确定继承人/遗产管理人、丧失民事行为能力未确定监护人
- **标的**：只能动产；不适于提存或费用过高的可拍卖变卖提存价款
- **效果**：自提存之日起债务消灭；风险归债权人；孳息归债权人；提存费用由债权人负担；**5 年内**不领取归国家所有

### ⑤ 免除
- 债权人免除部分/全部债务→债权债务部分/全部终止（债务人合理期限内拒绝除外）
- **要件**：免除人具备民事行为能力；债权人/代理人向债务人/代理人作出抛弃债权意思表示；不得损害第三人利益
- **效果**：从权利随之消灭；免除连带债务人之一→其余连带债务人在扣除该份额后仍担剩余

### ⑥ 混同
- 债权债务同归一人→终止（损害第三人利益除外）；从权利从债务一并消灭
- **不导致消灭**：票据未到期前背书转让（票据仍可流通）；债权为他人权利质押标的

### ⑦ 合同解除（🔥 必考）
**法定解除事由：**
| 事由 | 何时解除 |
|-|-|
| 因不可抗力致不能实现合同目的 | 立即解除（部分/全部免责） |
| 履行期届满前明确表示/行为表明不履行主要债务（预期违约） | 立即解除 |
| 迟延履行债务或违约致不能实现合同目的 | 立即解除 |
| 迟延履行主要债务，经催告后合理期限内仍未履行 | 先催告再解除 |

**解除权行使：**
- 通知到达对方时解除；诉讼/仲裁→起诉状副本/仲裁申请书副本送达对方时解除
- 行使期限：有约定按约定；无约定对方催告→合理期限；对方未催告→自知道或应当知道解除事由之日起 **1 年**内

**解除效果：** 尚未履行的终止履行；已履行的可请求恢复原状/采取补救措施+赔偿损失；因违约解除可请求违约金；主合同解除后担保人仍承担担保责任（另有约定除外）

**情势变更原则：** 合同成立后基础条件发生无法预见的、不属于商业风险的重大变化→可请求重新协商→协商不成可请求法院/仲裁机构变更或解除

### 🎯 常考易错点
1. "合同终止不影响独立存在的解决争议方法条款效力" → ✅（判断 √ 2020）
2. 数项债务抵充：应优先清偿**已到期**债务；数项均到期→优先清偿缺乏担保/担保最少（单选 B 2024：2021年借款无担保优先）
3. 抵充顺序：费用→利息→主债务（单选 A 2024：60-5-10=45）
4. "抵销可附条件和期限" → ❌ 不得附（多选 B 2023 不当选）
5. 法定抵销：支付租金可抵销；提供劳务/不作为/人身侵权赔偿不可（单选 B 2023）
6. 抵销后剩余债权诉讼时效**重新计算**（单选 A 2025）
7. 提存后毁损风险由**债权人**（张某）承担（单选 A 2023）
8. "免除连带债务人之一后，其余仍就全部债务连带" → ❌ 扣除该份额后担**剩余**（判断 × 2024）
9. 免除从权利**随之消灭**（多选 A 2023 不当选）
10. 甲乙公司合并→债权债务终止=**混同**（单选 D 2022）
11. 预期违约（甲科研所明确表示不能履行）→乙可**立即解除**+赔偿（单选 A 2025）
12. 迟延履行致不能实现合同目的→可**立即解除**无须催告（单选 B：六一表演赶不上）
13. 诉讼解除：合同自**起诉状副本送达对方**时解除（单选 C 2023）

> 📌 **真题印证**：习题第 121~160 题全考合同消灭 → **抵充顺序、抵销、提存、免除、解除 = 必考**。

## 📍 知识点 2：违约责任 ⭐⭐⭐⭐⭐（极高考频）

### ① 违约类型与承担规则
- **预期违约**：履行期到来前明确表示/行为表明不履行→对方可在履行期届满前请求承担违约责任
- **届期违约**：履行期到来后拒绝/迟延/不完全履行
- **归责**：不以违约方有过错为条件；因第三人原因违约→先向对方承担，再向第三人追偿

### ② 免责事由
- **不可抗力**：不能履行合同→部分/全部免责；**迟延履行后发生不可抗力不免责**；应通知对方+提供证明
- **免责条款**：人身伤害（任何过失不得免责）；财产损失（故意/重大过失不得免责、轻过失/无过失可免责）

### ③ 违约责任的承担形式
- **继续履行**：金钱债务无条件适用；非金钱债务有例外（法律上/事实上不能履行、标的不适于强制履行或费用过高、债权人合理期限内未请求）
- **采取补救措施**：修理/重作/更换/退货/减少价款报酬
- **赔偿损失**：直接损失+履行利益；**可预见规则**（不得超过违约方订立合同时预见或应当预见的损失）；**减轻损失**（防止损失扩大费用违约方承担）；**过失相抵**（对方有过错减少赔偿额）
- **支付违约金**：约定过低→可请求增加；约定过高（>损失×**30%**）→可请求适当减少（恶意违约请求减少一般不予支持）；迟延履行违约金+继续履行
- **定金责任**：定金≤主合同标的额 **20%**（超过部分不产生效力）；给付方违约无权请求返还、收受方违约双倍返还；**定金 vs 违约金不能并用**（择一）；**定金 vs 赔偿损失可并用**（定金不足可请求赔偿超过部分）；因不可抗力致不能履行不适用定金罚则；第三人过错致不能履行适用定金罚则

### 🎯 常考易错点
1. "行使撤销权属违约责任形式" → ❌ 撤销权不是违约责任（单选 A 2021）
2. 继续履行：支付房租可；表演唱歌/话剧（人身性质）不可强制履行；灭失古董不可（单选 C 2023）
3. "对方对损失发生有过错，可减少赔偿额" → ✅（判断 √ 2025）
4. 可预见规则：不得超过违约方**订立合同**时预见到/应当预见到因违约可能造成的损失（单选 A 2023）
5. 定金：300万房价、付80万→有效定金=300×20%=**60万**（单选 D 2025）
6. 定金10万、付3万（标的额10万×20%=2万有效）→最高返还=2万×2+超出部分1万=5万（单选 C 2024）
7. 定金+违约金择一：选择定金双倍20万＞违约金18万→赔付**20万**（单选 D 2024）

> 📌 **真题印证**：习题第 161~190 题全考违约责任 → **免责、赔偿限制、违约金、定金 = 必考**。

# 🧩 第五单元 典型合同

## 📍 知识点 1：买卖合同 ⭐⭐⭐⭐⭐（极高考频）

### ① 标的物交付与所有权转移

| 标的物 | 所有权转移时点 | 孳息（交付前/后） |
|-|-|-|
| 动产 | 交付时 | 出卖人/买受人 |
| 不动产 | 转移登记时 | —— |

**动产一物多卖（🔥 必考）：**
| 动产种类 | 归属顺序 |
|-|-|
| 普通动产 | **交付在先 > 付款在先 > 合同成立在先** |
| 特殊动产（车辆/船舶/航空器） | **交付在先 > 转移登记在先 > 合同成立在先** |

### ② 标的物毁损灭失风险的承担（🔥 必考）
**一般规则：** 交付前出卖人承担、交付后买受人承担（风险与所有权转移无关）
- 需运输：约定交付地→交付承运人后风险转移；未约定→交付**第一承运人**后风险转移
- **路货交易**：合同成立时起风险由买受人承担（出卖人知道已毁损未告知除外）
- **买受人违约**：因买受人原因致不能按期交付→自违反约定之日起由买受人承担
- **出卖人违约**：质量不符致不能实现目的，买受人拒收/解除→由出卖人承担
- **提存**：提存后风险由债权人（买受人）承担

### ③ 检验期限
- 有约定按约定（过短视为外观瑕疵异议期限；短于法定期限按法定）
- 无约定→质保期→合理期限→收到标的物之日起 **2 年**
- 出卖人明知标的物不符合约定→不受检验期限限制

### ④ 买卖合同的解除
- **主从物**：主物不符解除→效力及于从物；从物不符解除→不及于主物
- **数物**：一物不符→可就该物解除；分离使价值受损害→可就数物解除
- **分批交货**：一批不符→就该批解除；致其他各批不能实现目的→就该批及之后各批解除；相互依存→可就全部解除

### ⑤ 特种买卖合同
**所有权保留买卖：**
- 仅适用于**动产**（不适用于不动产）；出卖人保留的所有权未经登记不得对抗善意第三人
- **取回权**：买受人未按约定支付价款经催告仍不支付/未完成特定条件/将标的物出卖出质不当处分→出卖人可取回
- **不得取回**：买受人已支付总价款 **75%** 以上；第三人已善意取得

**分期付款买卖：** 未支付到期价款达到全部价款 **1/5**（≥20%）+经催告合理期限内仍未支付→出卖人可请求支付全部价款或解除合同（可请求支付使用费）

**试用买卖：** 试用期届满未表示=视为购买；试用期内已支付部分价款/出卖出租设立担保物权=视为购买；使用费无约定→出卖人无权请求支付；试用期内风险由**出卖人**承担

**商品房买卖：** 未取得预售许可证的预售合同无效（起诉前取得除外）；商业广告符合条件构成要约；法定解除权（主体结构质量不合格/严重质量问题/迟延交付经催告3个月）

### 🎯 常考易错点
1. 普通动产一物多卖：林某付款在先→归林某（单选 A 2020）
2. 特殊动产一物多卖：乙已交付→归乙（单选 C 2022）
3. 需运输未约定交付地：风险自交付**第一承运人**（3月15日）转移（单选 C 2024）
4. 买受人违约未提货→自违反约定之日（6月24日）承担风险（单选 B 2022）
5. "出卖人未交付单证资料不影响风险转移" → ✅（多选 C）
6. "提存后风险由出卖人承担" → ❌ 由买受人（债权人）承担（多选 B 不当选）
7. 质保期4年：在质保期内提出异议→乙应承担责任（多选 ABD 不当选：A/B/D说法错误）
8. 数物解除：E机器解除、F维修工具（从物）解除→可"就F维修工具与E机器部分解除"（单选 D）
9. 所有权保留：付清全款（5月6日）→所有权转移（单选 D）
10. 分期付款：未支付达1/5（6000/20000=30%）+催告→可解除+支付使用费（判断 √）
11. 试用买卖：未表示视为购买、无使用费约定视为无偿、试用期出租视为购买、风险出卖人承担（多选 ABC 2025）

> 📌 **真题印证**：习题第 191~240 题全考买卖合同 → **一物多卖、风险承担、检验、分期付款、试用 = 必考**。

## 📍 知识点 2：赠与合同 ⭐⭐⭐⭐

- **特征**：单务 + 无偿 + 诺成 + 双方法律行为
- **附义务赠与**：受赠人应履行义务；财产有瑕疵→在附义务限度内承担与出卖人相同责任
- **瑕疵担保**：一般赠与财产有瑕疵赠与人不担责；故意不告知/保证无瑕疵→赔偿
- **穷困抗辩**：经济状况显著恶化严重影响生产经营或家庭生活→可不再履行赠与义务

**任意撤销权：** 财产权利转移前；**不得任意撤销**（公证赠与/救灾扶贫助残等公益道德赠与）

**法定撤销权：**

| 情形 | 撤销权人 | 时间 |
|-|-|-|
| 严重侵害赠与人或其近亲属合法权益/不履行扶养义务/不履行约定义务 | 赠与人 | 知道之日起 **1 年** |
| 受赠人违法行为致赠与人死亡/丧失行为能力 | 继承人或法定代理人 | 知道之日起 **6 个月** |

### 🎯 常考易错点
1. 公益/公证赠与**不得任意撤销**，但可**法定撤销**
2. 法定撤销 1 年（赠与人）或 6 个月（继承人/法定代理人）

## 📍 知识点 3：借款合同 ⭐⭐⭐⭐⭐（极高考频）

### ① 借款合同种类

| 类型 | 贷款人 | 借款人 | 合同性质 |
|-|-|-|-|
| 金融借款 | 金融机构 | 企业/自然人 | 诺成 |
| 民间借贷 | 企业/自然人 | 企业/自然人 | 诺成（企业间、企业/自然人） |
| | 自然人 | 自然人 | **实践**（提供借款时成立） |

### ② 基本规定
- 自然人借款可口头/其他形式；其他借款**书面形式**
- **利息不得预先扣除**（扣除的按实际借款数额返还计算利息）
- 借款人未按约定用途使用→贷款人可停止发放/提前收回/解除合同
- 未约定还款期→借款人可随时返还；贷款人可催告合理期限内返还
- **提前还款**：按实际借款期间计算利息
- **付息期限**：不满1年→返还时付；1年以上→每届满1年付（存续<1年则返还时付）

### ③ 民间借贷计息规则（🔥 必考）
- **借期内利息**：有约定≤LPR **4倍**；未约定→不支付；约定不明→自然人借款不支持、其他结合交易习惯确定
- **逾期利息**：有约定从其约定（≤LPR4倍）；未约定→按借期内利率；未约定借期内利率→参照当时1年期LPR标准
- **逾期利息+违约金+其他费用**：总计不得超过合同成立时1年期LPR4倍

### 🎯 常考易错点
1. "自然人之间借款是诺成合同" → ❌ **实践合同**
2. 利息不得预先扣除（按实际借款数额）
3. 民间借贷利率上限：LPR **4倍**

> 📌 **真题印证**：习题第 241~270 题考借款合同 → **实践合同、利息规则、LPR4倍 = 必考**。

## 📍 知识点 4：租赁合同 ⭐⭐⭐⭐⭐（极高考频）

### ① 租赁期限
- 租赁期限**不得超过 20 年**（超过部分无效）；期满可续订（仍不得超过20年）
- **6 个月以上**须书面形式（否则无法确定期限→**不定期租赁**）
- 不定期租赁：当事人可随时解除（合理期限前通知）
- 期限届满承租人继续使用、出租人未异议→原合同继续有效（不定期）

### ② 使用、维修与改装
- 出租人应交付租赁物并保持符合约定用途
- 承租人按约定/性质使用；合理损耗不担责；不当使用致损→出租人可解除+赔偿
- 维修：出租人履行（另有约定/承租人过错除外）；出租人未履行→承租人可自行维修、费用出租人负担
- 改装：经出租人同意可改善增设；未经同意→可请求恢复原状或赔偿

### ③ 转租（🔥 必考）
- 经出租人同意可转租，**原租赁合同继续有效**；第三人对租赁物造成损失→承租人赔偿
- 未经同意转租→出租人可解除（与承租人）合同
- **出租人知道或应当知道转租但在 6 个月内未提出异议→视为同意转租**
- 次承租人代付租金：承租人拖欠→次承租人可代付（充抵其应付租金、超出可向承租人追偿）

### ④ 买卖不破租赁（所有权让与不破租赁）
- 租赁物在承租人按租赁合同占有期限内发生所有权变动的，**不影响租赁合同的效力**（适用于所有租赁物）

### ⑤ 房屋承租人的优先购买权
- 出租人出卖租赁房屋→合理期限内通知承租人；承租人同等条件优先购买
- **除外**：①房屋按份共有人行使优先购买权；②出卖给**近亲属**（配偶/父母/子女/兄弟姐妹/祖父母/外祖父母/孙子女/外孙子女）；③通知后 **15 日**内未明确表示购买；④委托拍卖在拍卖 **5 日前**通知、承租人未参加
- 未通知/妨害行使→承租人有优先购买权，可请求出租人承担赔偿责任；但出租人与第三人买卖合同效力不受影响

### ⑥ 优先承租权：租赁期限届满，房屋承租人享有以同等条件优先承租的权利

### ⑦ 一房数租：**合法占有在先 > 登记备案在先 > 合同成立在先**

### 🎯 常考易错点
1. 口头租期1年、无法确定→**有效，视为不定期租赁**（单选 D）
2. 转租：乙知道但6个月未异议→视为同意转租；乙可直接向甲索赔（丙致损）、丙代付可追偿；乙**不能**直接向丙请求支付租金（多选 ACD 2024：B 不当选）
3. 租赁期限>20年：**超过部分无效**（非合同无效）（多选 D 2024 不当选）
4. 买卖不破租赁：买卖合同有效、租赁合同继续有效（单选 B 2023）
5. 优先购买权：卖儿子/弟弟（近亲属）不适用；卖侄子（非近亲属）适用（单选 C 2025）
6. 侵害优先购买权：乙可向甲主张赔偿、乙无权主张买卖合同无效、乙可向丙主张继续租住（多选 ABC 2025）
7. 一房数租：孙某合法占有在先→归孙某（单选 A 2023）

> 📌 **真题印证**：习题第 271~310 题全考租赁合同 → **期限20年、转租、买卖不破租赁、优先购买权、一房数租 = 必考**。

## 📍 知识点 5：保证合同 ⭐⭐⭐⭐⭐（极高考频 + 🆕2026 新增）

### ① 保证合同形式
- **书面**：①单独订立的书面保证合同；②主合同中的保证条款；③第三人单方书面承诺债权人接收且未提出异议→保证合同成立

### ② 保证人资格
| 主体 | 能否保证 |
|-|-|
| 自然人（完全行为能力） | √ |
| 机关法人 | 一般×（国务院批准转贷√） |
| 居民/村民委员会 | 一般×（代行村集体职能按规定程序√） |
| 公益非营利机构（学校/医院/养老） | ×（登记为营利法人√） |
| 禁止反言 | 无代偿能力不得据此免除保证责任 |

### ③ 保证方式（🔥 必考）
- **一般保证**：约定"债务人不能履行/无力偿还时才承担"→有债务人先承担责任意思→**一般保证**
- **连带责任保证**：约定"债务人不履行/未偿还时即承担"→**连带责任保证**
- **约定不明**：按**一般保证**承担保证责任

**先诉抗辩权（一般保证享有、连带不享有）：** 主合同纠纷未经审判/仲裁并就债务人财产强制执行仍不能履行前，有权拒绝承担保证责任。
**不得行使先诉抗辩权情形：** ①债务人下落不明且无财产可供执行；②法院已受理债务人破产案件；③有证据证明债务人财产不足以履行全部债务或丧失履行能力；④保证人书面放弃

### ④ 保证期间
- 有约定按约定；无约定/约定不明→主债务履行期届满之日起 **6 个月**
- 视为无约定：约定保证期间早于或与主债务履行期同时届满
- 视为约定不明：约定承担保证责任直至主债务本息还清时止等类似内容

### ⑤ 主合同内容变更与保证责任
- 未经保证人**书面同意**变更主合同内容：
  - 减轻债务→保证人仍对变更后债务担责
  - 加重债务→保证人对加重部分不担责
  - 变更履行期限→**保证期间不受影响**（按原保证期间执行）

### ⑥ 债权债务转让与保证责任
- **债权转让**：未约定禁转→通知保证人；约定禁转→未经保证人书面同意→保证人对受让人不再承担保证责任
- **债务转让**：未经保证人书面同意转移债务→保证人对转移的债务不再承担保证责任；**第三人加入债务→保证责任不受影响**

### ⑦ 共同担保（物保+人保并存）
- 有约定按约定
- 无约定：**债务人**提供物保→**先物后人**（先实现物保）；**第三人**提供物保→债权人可择一（物保或人保）

### 🎯 常考易错点
1. "保证方式约定不明按连带责任保证" → ❌ 按**一般保证**
2. 先诉抗辩权仅一般保证享有
3. 保证期间无约定→**6 个月**
4. 未经书面同意加重债务→加重部分不担责
5. 第三人加入债务→保证责任不受影响
6. 债务人提供物保→债权人应先实现物保（先物后人）

> 📌 **真题印证**：习题第 311~350 题考保证合同 → **保证方式、先诉抗辩权、保证期间、主合同变更、债权债务转让 = 必考**。
