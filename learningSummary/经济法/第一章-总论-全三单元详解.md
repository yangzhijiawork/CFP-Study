# 🧩 第一单元 民事法律行为

## 📍 知识点 1：法律关系概述 ⭐（了解即可）

### ① 概念/定义（是什么）
- **法律关系**：由法律规范所调整的**权利与义务关系**。
- **三要素**：主体、内容、客体
  - **主体**：依法享有权利和承担义务的当事人
  - **内容**：权利义务
  - **客体**：权利义务所指向的对象

> 📌 **真题印证**：讲义案例 1.1（泡面买卖合同）——合同关系属于法律关系，受合同法律制度规范。

---

## 📍 知识点 2：民事行为能力 ⭐⭐⭐（单选/判断高频）

### ① 概念/定义
**民事行为能力** = 自然人/法人从事民事法律行为后能否自己负责。

### ② 自然人的民事行为能力（三档，数值分界线必背）

| 类型 | 年龄 | 精神状态 |
|-|-|-|
| **无民事行为能力人** | **不满 8 周岁**（Y＜8） | 不能辨认自己行为的自然人 |
| **限制民事行为能力人** | **8 周岁以上不满 18 周岁**（8≤Y＜18） | 不能完全辨认自己行为的成年人 |
| **完全民事行为能力人** | 年满 18 周岁（Y≥18） | —— |
| （视为完全） | 16 周岁以上不满 18 周岁 + 以自己的劳动收入为主要生活来源 | —— |

> ⚠️ **数值分界线**："以上/以下"含本数（≥/≤），"超过/不满"不含本数（＞/＜）。
> - 8 周岁**以上**＝≥8；**不满**8 周岁＝＜8（8 周岁整属于"以上"，属于限制民事行为能力人）
> - 题目对精神状态未作说明 → 视为正常人。

### ③ 法人的民事行为能力
- 随法人**成立**而产生、随**终止**而消灭
- 成立时间 = **签发营业执照**之时（≠领取营业执照）
- 终止时间 = **办理注销登记**之时（≠解散）

### 🎯 常考易错点
1. "不能辨认自己行为的成年人是限制民事行为能力人" → ❌ **无**民事行为能力人（"不能辨认"=无；"不能完全辨认"=限制）（2024 多选 B）
2. "8 周岁以下自然人是无民事行为能力人" → ❌ 8 周岁整属于"以上"，是**限制**行为能力人（2024 多选 C）
3. 16 周岁自立未成年人 = **视为完全**民事行为能力人（2025 单选 C 直播带货收入）

> 📌 **真题印证**：习题第 1、2 题考自然人三档 → **数值分界线 + "视为"条款 = 必考**。
> 🔥 **记忆口诀**：8 为界分无/限，18 成人，16 自立视为完全。

## 📍 知识点 3：民事法律行为概述 ⭐⭐⭐（分类对比高频）

### ① 概念/界定
**民事法律行为**需同时满足两个条件（法律要管 + 法律后果由当事人决定）：
1. 以**达到一定民事法律后果**为目的
2. 以**意思表示**为要素

> ❌ 不属于民事法律行为的典例：请客吃饭、传递信息、打扫卫生、山盟海誓、宴会致辞（法律不管）；创作行为、拆除/建造房屋、侵权行为、拾得遗失物（事实行为，法律直接规定结果）。

### ② 四种分类对比（🔥 考试常考分类）

| 分类标准 | 类型 | 含义 | 典例 |
|-|-|-|-|
| 意思表示方数 | **单方法律行为** | 一方意思表示即可成立 | 委托代理的撤销、无权代理的追认 |
| | **多方法律行为** | 两方以上意思表示一致 | 各类合同、决议行为（多数决即可，不要求一致决） |
| 是否互为对价 | **有偿法律行为** | 双方互为给付代价 | 买卖、租赁、承揽 |
| | **无偿法律行为** | 一方给付而他方不承担 | 赠与、无偿委托、借用 |
| 是否需特定形式 | **要式法律行为** | 法定/约定形式 | 融资租赁、建设工程、技术开发、担保、金融借款合同 |
| | **非要式法律行为** | 自由选择形式 | 自然人之间借款、赠与合同 |
| 依存关系 | **主法律行为** | 独立成立 | 借款合同 |
| | **从法律行为** | 从属于主行为，主行为无效则从行为随同无效 | 借款合同的担保合同 |

### 🎯 常考易错点
1. 无偿法律行为 = **赠与**（2023 单选）
2. 担保合同 = **从法律行为**（2021 单选改编）
3. 非要式合同 = 赠与合同（2025 单选；融资租赁/建设工程/技术开发均**要式**）

> 📌 **真题印证**：习题第 3、4、5、6 题全部考分类 → **单方/多方、有偿/无偿、要式/非要式、主/从**四组分类要背熟。

## 📍 知识点 4：民事法律行为效力 ⭐⭐⭐⭐⭐（全章第一高频考点）

### ① 有效要件（实质要件 + 形式要件）
| 要件类型 | 具体条件 |
|-|-|
| **实质要件** | ① 行为人具有相应**民事行为能力**；② 意思表示**真实**；③ 不违反法律、行政法规的**强制性规定**；④ 不违背**公序良俗** |
| **形式要件** | 要式法律行为还须满足法定或约定的形式要件 |

### ② 四种效力样态对比（🔥 必考）

| 效力样态 | 行为是否产生预期效果 | 关键特征 |
|-|-|-|
| **有效** | 是 | 同时满足上述要件 |
| **无效** | 否 | 自始无效、当然无效、绝对无效 |
| **可撤销** | 撤销前有效、撤销后无效 | 由撤销权人主张 |
| **效力待定** | 待定 | 取决于追认权人是否追认 |

### ③ 无效民事法律行为（🆕 2026 调整法律后果）
**无效情形（5 种）：**
1. 无民事行为能力人独立实施的民事法律行为
2. 行为人与相对人以**虚假的意思表示**实施的行为
3. 违反法律、行政法规强制性规定（但该规定不导致行为无效的除外）
4. **违背公序良俗**
5. 行为人与相对人**恶意串通**，损害他人合法权益

**法律后果（🆕）：**
- 自始没有法律约束力；部分无效不影响其他部分效力的，其他部分仍有效（如超额定金、混合赠与、竞业限制）
- **返还财产/折价补偿**：行为人因该行为取得的财产应返还；不能返还或没必要返还的折价补偿
- **赔偿损失**：有过错一方赔偿损失；都有过错的各自承担相应责任
- **收归返还**：双方恶意串通损害国家、集体或第三人利益的，追缴双方取得的财产，收归国家、集体所有或返还第三人

### ④ 可撤销民事法律行为（撤销权行使主体 + 时限）
**可撤销情形与撤销权主体：**

| 情形 | 撤销权主体 | 一句话理解 |
|-|-|-|
| **重大误解** | 行为人（当事人一方） | 对性质、对方、标的物品种/质量/规格/数量错误认识，造成较大损失 |
| **欺诈**（一方） | 受欺诈方 | 故意告知虚假/隐瞒真实情况 |
| **欺诈**（第三人） | 受欺诈方（当事人一方**知情**时） | 相对人不知情的，不得撤销 |
| **胁迫**（一方/第三人） | 受胁迫方 | 以损害相要挟，迫使其恐惧中作意思表示；第三人胁迫**无论相对人是否知情**都可撤销 |
| **显失公平** | 受损害方 | 利用对方危困状态/缺乏判断能力 |

**撤销权存续时限（🔥 必背）：**

| 权利状态 | 起算点 | 时限 |
|-|-|-|
| 不知道存在可撤销情形 | 发生之日起 | **5 年** |
| 表明放弃撤销权 | —— | 撤销权直接消灭 |
| 受胁迫 | 胁迫终止之日起 | **1 年** |
| 重大误解 | 知道之日起 | **90 日** |
| 其他（如欺诈） | 知道之日起 | **1 年** |

> 可撤销行为的撤销须由撤销权人向人民法院或仲裁机构主张（"不告不理"），一经撤销自始无效。

### ⑤ 效力待定民事法律行为（限制行为能力人 + 无权代理）
**情形：** 限制民事行为能力人实施的"双非事项"（非纯获益、非与其年龄智力相适应）行为。
- 追认权人**同意/追认** → 有效；**拒绝追认** → 无效
- **催告权**：相对人（无论是否善意）可催告法定代理人 30 日内追认；30 日内未追认 → 无效
- **撤销权**：**善意相对人**（不知道也不应当知道）可以通知方式撤销

### ⑥ 民事行为能力对效力的影响（🔥 常考判断）

| 行为人 | 情形 | 效力 |
|-|-|-|
| **无民事行为能力人** | 法定代理人代理实施 | 有效 |
| | 自己独立实施**任何**行为（含纯获益/极其细微） | **无效** |
| **限制民事行为能力人** | 法定代理人代理实施 | 有效 |
| | 自己独立实施纯获益/相适应事项 | **有效** |
| | 自己独立实施"双非事项" | **效力待定** |

### 🎯 常考易错点
1. "6 周岁王某获赠可乐无效" → ✅ 无民事行为能力人独立实施任何行为均**无效**（2024 判断）
2. 撤销权时限：欺诈 = **知道之日起 1 年**（不是发生之日起）（2024 单选：1 月 8 日知道 → 1 年内）
3. 恶意串通逃避债务（虚假表示）= **无效**（2025 单选）
4. 受胁迫/受欺诈 = **可撤销**（不是无效）（2025 单选）
5. 无效自**行为开始时**起无约束力（不是被确认无效时起）（2020 多选 D）
6. 未成年人"受赠"（纯获益）行为 = **有效**；未成年人"赠送他人"高价物 = 效力待定（2019 单选）

> 📌 **真题印证**：习题第 7~16 题全考效力样态 → **无效/可撤销/效力待定三分类 + 撤销权时限 = 必考**。
> 🔥 **记忆口诀**：无效=自始当然绝对；可撤销=误解欺诈胁迫显失公平；效力待定=限制+无权。

## 📍 知识点 5：附条件与附期限的民事法律行为 ⭐⭐⭐⭐

### ① 附条件 vs 附期限（🔥 核心对比）

| 对比点 | 附条件 | 附期限 |
|-|-|-|
| 事实性质 | **是否发生不确定**（可能发生可能不发生） | **一定会发生**（一定会到来） |
| 生效类 | 附**生效**条件（条件成就→法律关系建立） | 附**生效**期限（期限届至→建立） |
| 解除类 | 附**解除**条件（条件成就→解除） | 附**终止**期限（期限届至→解除） |

### ② 所附条件应具备的特征（5 个）
1. 必须是**将来**发生的事实
2. 必须是**不确定**的事实
3. 必须是**非法定**的事实
4. 必须是**合法**的事实
5. 必须是不与行为内容**相矛盾**的事实

### ③ 对当事人恶意的规制
- 当事人**恶意阻止**条件成就 → 视为条件**已成就**
- 当事人**恶意促使**条件成就 → 视为条件**未成就**

### 🎯 常考易错点
1. "考上研究生时合同生效"（能否考上不确定）= **附条件**（2025 单选 A）
2. "2026 国庆节/父亲去世/下一次月全食"（必然发生）= **附期限**（2025 单选 BCD）
3. "结婚时赠与房屋"（不一定会发生）= **附条件**（不是附期限）
4. 附条件但条件未成就时，合同处于**已成立、未生效**状态（2022 单选 B）

> 📌 **真题印证**：习题第 17~20 题全考附条件 vs 附期限 → **"是否确定发生"是唯一判断标准**。
> 🔥 **记忆口诀**：条件=不一定发生；期限=一定发生。

# 🧩 第二单元 代理制度

## 📍 知识点 1：代理制度概述 ⭐⭐⭐

### ① 概念/定义
**代理** = 代理人在**代理权限内**，以**被代理人名义**与相对人实施法律行为，由此产生的法律后果**直接由被代理人承担**的法律制度。
- 当事人：被代理人、代理人、相对人

### ② 代理的种类
| 类型 | 被代理人特征 | 备注 |
|-|-|-|
| **委托代理** | 民事行为能力**足够** | 可采用书面或口头形式；书面授权委托书应载明代理人姓名/名称、代理事项、权限和期间，由被代理人签名或盖章 |
| **法定代理** | 民事行为能力**不足** | 无/限制民事行为能力人的**监护人**是其法定代理人 |

### ③ 代理的适用范围
- **不得代理**（应由本人亲自实施）：订立遗嘱、婚姻登记、收养子女
- **不属于代理**：传递信息、中介行为、行纪、寄售

### 🎯 常考易错点
1. 可适用代理的 = 申请仲裁（2025 单选；遗嘱/婚姻登记/收养不得代理）
2. 委托代理**可以口头**，不必一律书面（2024 判断）
3. 监护人 = 无/限制民事行为能力人的法定代理人（2020 判断）

> 📌 **真题印证**：习题第 21~23 题考适用范围与形式 → 记住"三种不得代理"。

---

## 📍 知识点 2：特殊代理行为 ⭐⭐⭐⭐⭐（全章高频）

### ① 滥用代理权 vs 无权代理（先分清）

### ② 滥用代理权（有代理权但滥用的情形）

| 类型 | 含义 | 效力 |
|-|-|-|
| **自己代理** | 以被代理人名义与自己实施法律行为 | **效力待定**（经被代理人同意/追认有效） |
| **双方代理** | 以被代理人名义与自己同时代理的其他人实施 | **效力待定**（经双方被代理人同意/追认有效） |
| **代理人与相对人恶意串通** | 私下勾结，共同损害被代理人利益 | **无效**（串通方承担连带责任） |

### ③ 无权代理（没有代理权的代理）
**三种情形：** ① 没有代理权；② 超越代理权；③ 代理权终止后仍实施。
- **狭义无权代理** → **效力待定**（被代理人追认→有效；拒绝追认→无效）
- **表见代理**（相对人有理由相信其有代理权）→ **有效**，由被代理人承担后果

> 表见代理构成：行为人无代理权/超越/终止后代理 + 相对人有理由相信 + 相对人善意。例：业务员离职后照常签单、酒店不知情 → 公司应付款（2025 单选表见代理 D）。

### ④ 转委托代理（复代理）
- **概念**：代理人以自己名义为被代理人**选任第三人**代理
- 转委托的第三人是**被代理人**的代理人（不是代理人的代理人）
- 应取得被代理人**同意或追认**：
  - 同意 → 被代理人可就代理事务直接指示第三人，代理人仅对第三人的选任和指示负责
  - 未同意 → 代理人对第三人行为负责（紧急情况为维护被代理人利益除外）

### ⑤ 不当代理与违法代理
- **不当代理**：代理人不履行/不完全履行职责造成损害的 → 承担民事责任
- **违法代理**：代理人知道代理事项违法仍实施的 / 被代理人知道代理行为违法未反对的 → 双方承担**连带责任**

### 🎯 常考易错点
1. 自己代理、双方代理 = **滥用代理权**；超越代理权/代理权终止 = **无权代理**（多选区分）
2. 代理人与相对人恶意串通 → **连带责任**（单选 B；不是按份、不是甲分担）
3. "超越代理权订立的合同是无效合同" → ❌ **效力待定**（2022 判断）
4. 相对人有理由相信有代理权（表见代理）→ **有效**（2021 判断）
5. 代理人须以**被代理人名义**实施、法律后果归属**被代理人**（2021 单选）

> 📌 **真题印证**：习题第 24~29 题全考滥用/无权/表见 → **自己/双方代理=效力待定，串通=无效，表见=有效**。

---

## 📍 知识点 3：代理关系终止 ⭐⭐⭐

### ① 委托代理终止的情形
1. 代理期间届满 / 代理事务完成
2. 被代理人取消委托 / 代理人辞去委托
3. 代理人丧失民事行为能力
4. 代理人或被代理人死亡
5. 作为代理人或被代理人的法人、非法人组织终止

> ⚠️ **被代理人丧失民事行为能力不导致委托代理终止**（区别于法定代理）！

**被代理人死亡后，委托代理行为仍有效的情形：**
1. 代理人不知道且不应当知道被代理人死亡
2. 被代理人死亡前已实施，为了继承人的利益继续代理
3. 被代理人的继承人予以承认
4. 授权中明确代理权在代理事务完成时终止

### ② 法定代理终止的情形
1. 被代理人取得/恢复完全民事行为能力
2. 代理人丧失民事行为能力
3. 代理人或被代理人死亡
4. 法律规定的其他情形

### 🎯 常考易错点
1. 委托代理终止 = 代理期限届满/代理人死亡/被代理人取消委托（2023 多选 ABD；**被代理人丧失民事行为能力不终止**）
2. 法定代理终止 = 取得或恢复完全行为能力/代理人死亡/代理人丧失行为能力（2023 多选全选）
3. 被代理人死亡后，代理人不知情且不应当知情 → 行为**仍有效**（2025 多选 BCD）

> 📌 **真题印证**：习题第 31~33 题考终止情形 → **委托代理 vs 法定代理终止情形要区分记忆**。
> 🔥 **记忆口诀**：委托终止"疯没了"（代理人失能/死亡、被代理人死亡/取消/辞任）；法定多两条"有能力了"（取得/恢复完全行为能力）。

# 🧩 第三单元 经济纠纷解决途径

## 📍 知识点 1：经济纠纷解决途径概述 ⭐

### ① 三种途径总览
| 途径 | 解决对象 | 特点 |
|-|-|-|
| **仲裁** | 平等主体之间的合同纠纷/其他财产权益纠纷 | 一裁终局 |
| **民事诉讼** | 民商劳纠纷、非讼案件 | 两审终审 |
| **行政复议 + 行政诉讼** | 行政争议（相对人 vs 行政机关） | 复议可选/前置 |

---

## 📍 知识点 2：民事诉讼 ⭐⭐⭐⭐⭐（分值最高单元）

### ① 适用范围
- **民事纠纷案件**：房屋产权、合同、著作权、名誉权、离婚、扶养费、财产继承、污染侵权、不正当竞争等
- **商事纠纷案件**：票据、股东权益、保险合同、证券纠纷
- **劳动争议案件**：劳动合同纠纷
- **非讼案件**：特别程序（宣告失踪/死亡、选民资格、认定无/限制行为能力）、公示催告（票据丧失补救）、督促（支付令）

### ② 基本制度
| 制度 | 要点 |
|-|-|
| **合议制 vs 独任制** | 第一审：合议/独任均可；第二审：由审判员组成合议庭（无陪审员）；合议庭 3 人以上单数 |
| **可独任** | 简易程序、特别程序（选民资格/重大疑难除外）、督促、公示催告公示催告阶段；基层法院事实清楚的第一审 |
| **不得独任（新大难）** | 涉及国家利益/社会公共利益、群体性纠纷、社会影响大、新类型疑难、法律规定应合议 |
| **回避制度** | 审判人员、书记员、翻译、鉴定人、勘验人等与本案有利害关系等应回避 |
| **公开审判** | 应当公开进行；**应当**不公开：国家秘密/个人隐私；**申请**可不公开：离婚/商业秘密；**一律公开宣告判决** |
| **两审终审** | 一审不服可上诉；二审终审。例外一审终审：特别程序、公示催告、督促、小额诉讼；最高法一审判决 |

### ③ 诉讼管辖
**级别管辖：** 原则上基层人民法院管辖第一审案件。

**地域管辖：**
- **一般地域管辖（原告就被告）**：被告住所地法院管辖；住所地与经常居住地不一致 → 经常居住地（连续居住满 1 年，住院除外）
- **共同/选择管辖**：多个法院有管辖权的，原告择一；同时起诉的由**最先立案**法院管辖（立案在先）
- **专属管辖（🔥）**：不动产纠纷→不动产所在地；港口作业→港口所在地；继承遗产→被继承人死亡时住所地或主要遗产所在地
- **协议管辖**：合同/其他财产权益纠纷可书面协议选择与争议有实际联系地点（被告住所地、合同履行地、签订地、原告住所地、标的物所在地）的法院；不得违反级别/专属管辖；人身关系纠纷不适用
- **特殊地域管辖（合同）**：合同纠纷由被告住所地或**合同履行地**法院管辖
  - 运输合同→始发地/目的地；保险合同→保险标的物所在地（运输工具/货物→登记注册地、目的地、事故发生地；人身险→被保险人住所地）；票据权利纠纷→票据支付地；公司设立/股东/决议等纠纷→公司住所地；侵权→侵权行为地（实施地+结果地）

### ④ 诉讼程序
- **起诉条件**：原告与本案有直接利害关系、有明确被告、有具体诉讼请求和事实理由、属于受理范围
- **简易程序**：基层法院事实清楚、权利义务明确、争议不大；排除发回重审、审判监督、国家利益、人数众多、被告下落不明等；由审判员独任
- **小额诉讼程序**：符合简易程序前提下，标的额≤上年度就业人员年平均工资 50% 的简单金钱给付案件，一审终审；可依职权或双方约定适用
- **第二审程序**：判决书送达后 **15 日**内上诉（"爵士舞"）；裁定书 **10 日**内（"蔡依林"）；二审判决：事实清楚法律正确→维持原判；适用法律错误→改判；认定事实错误/不清、违反法定程序→发回重审或查清事实后改判
- **审判监督程序**：再审（院长提交审委会决定；上级法院提审/指令再审；当事人向上一级或原审法院申请再审，不停止执行）
- **调解程序**：一审/二审/再审均可调解；特别程序、公示催告、督促、婚姻身份确认不适用；调解书双方**签收后**生效，不得上诉
- **执行程序**：一方不履行的，对方可向人民法院申请执行（含仲裁裁决书）

### ⑤ 诉讼时效（🔥 高频）
**三权：** 起诉权（届满不丧失起诉权）、抗辩权（义务人可主张）、实体权（届满不消灭实体权利，自愿履行不受限）。

**不适用诉讼时效（6 项）：** 停止侵害/排除妨碍/消除危险；不动产物权与登记的动产物权返还财产；支付抚养费/赡养费/扶养费；缴付出资请求权；存款本息；国债/金融债券/向不特定对象发行的企业债券本息。

**时效类型：**
| 类型 | 期间 | 起算点 |
|-|-|-|
| **普通** | **3 年** | 知道或应当知道权利受损害 + 义务人之日起 |
| **长期** | **20 年**（可延长） | 权利受损害之日起（不适用中止/中断） |
| 特殊：人寿保险 | 5 年 | 知道/应当知道之日 |
| 特殊：其他保险、海上赔偿等 | 2 年/1 年 | —— |

**中止（被动/客观，最后 6 个月内）vs 中断（主动/主观，重新计算）：**
- **中止**：不可抗力、权利人被控制、无/限制行为能力人无法定代理人等，发生在**最后 6 个月内**；中止原因消除后满 6 个月期间届满
- **中断**：权利人向义务人提出请求、义务人同意履行、提起诉讼/仲裁；从中断事由发生时起重新计算；连带债权/债务中一人中断效力及于其他

### 🎯 常考易错点
1. 不动产（含房屋租赁、建设工程施工合同）纠纷 = **专属管辖**，房屋所在地法院（2025 单选 B；2023 单选 B）
2. 合同纠纷无协议管辖 = 被告住所地 **或** 合同履行地（单选 B）
3. 侵权纠纷 = 侵权行为地（实施地+结果地）+ 被告住所地（多选 ACD）
4. 公民住所地 vs 经常居住地不一致 → **经常居住地**法院管辖（单选 B）
5. 票据权利纠纷 = 票据支付地 + 被告住所地（2024 多选 AD）
6. 第二审：适用法律错误 → **改判**（不得发回重审）（2023 单选）
7. 当事人对重审案件判决/裁定**可以上诉**（单选 C 不正确）
8. 诉讼时效届满消灭的是**胜诉权**，不消灭实体权利（单选 B）
9. 不适用诉讼时效：**支付违约金请求权**适用（2025 单选 B），抚养费、排除妨碍、缴付出资不适用
10. 未成年人遭性侵害赔偿请求权 → 自**年满 18 周岁**起算（单选 B）
11. 20 年长期时效**可延长、不中止不中断**（单选 C）
12. 中止事由须发生在**最后 6 个月内**（多选 AD、2025 多选 AC）

> 📌 **真题印证**：习题第 34~70 题覆盖民事诉讼全单元 → **专属管辖、诉讼时效三权/中止中断 = 必考**。

## 📍 知识点 3：行政复议 ⭐⭐⭐⭐

### ① 概念与地位
- **行政复议**：行政相对人对行政机关的具体行政行为不服，向行政复议机关申请审查合法性、适当性的制度，是化解行政争议的**主渠道**。

### ② 复议与诉讼的选择
| 类型 | 规则 |
|-|-|
| **复议前置** | 对特定行为应先申请复议（如"纳税争议"），对复议决定不服再起诉 |
| **选择复议** | 可先复议再起诉，或直接起诉；复议已受理则不得起诉，法院已受理则不得复议 |
| **复议终局** | 法律规定复议决定为最终裁决的，不得再诉讼（如国务院裁决） |

### ③ 受案范围
**可以申请（举例）：** 行政处罚、行政强制措施/执行、行政许可、自然资源确权、征收征用、赔偿决定、工伤认定、侵犯经营自主权/土地承包经营权、排除限制竞争、违法集资摊派、不履行保护人身财产职责、不依法给付抚恤/社保、行政协议纠纷、政府信息公开等。

**不得申请：** ① 国家行为（国防外交）；② 内部行政行为（对机关工作人员的奖惩任免）；③ 抽象行政行为（行政法规规章/普遍约束力的决定命令）；④ 行政机关对民事纠纷的调解。

**复议前置案件（"小案子/不作为/法定情形"）：** 对当场作出的行政处罚不服、侵犯已依法取得的自然资源权属、认为未依法履行法定职责、政府信息不予公开、纳税争议。

### ④ 参加人与管辖
- **参加人**：申请人、被申请人、第三人（行政复议机关、复议机构不是参加人）
- **管辖总原则**：县级以上地方政府统一行使复议职责，**"找最近的一级政府"**（原则上取消工作部门复议职责）
  - 对政府工作部门行为不服 → 向本级政府申请
  - 对省部级（省政府、国务院部门）行为不服 → 向**本级**机关申请（对省级政府/国务院部门复议决定不服，可起诉也可向国务院申请裁决，国务院裁决为终局）
  - 垂直领导部门（海关/金融/外汇/税务/国家安全）→ 向**上一级主管部门**申请
  - 司法行政部门 → 本级政府 **或** 上一级司法行政部门（"一司两命"）

### ⑤ 行政复议程序
- **申请期限**：自知道或应当知道该行政行为之日起 **60 日**内；未告知权利的最长不超过 1 年；不动产超 20 年、其他超 5 年不予受理
- **受理**：5 日内审查；可书面也可口头申请；不收取任何费用
- **审理**：普通程序（"普七十"：7 日送达副本、10 日答复）或简易程序（当事人同意/政府信息公开/当场作出/款额 3000 以下/警告通报批评；3 日送达、5 日答复）
- **执行**：复议期间行政行为不停止执行（有法定情形应停止）
- **决定期限**：受理之日起 **60 日**内作出（可延长最多 30 日）；简易程序 30 日内
- **调解与和解**：可调解；和解后撤回申请，不得再以同一事实理由申请

### 🎯 常考易错点
1. 对行政处分/民事纠纷调解不服 **不能** 复议（2023 多选 CD 当选）
2. 税务/海关（垂直领导）→ 向上一级主管部门复议（2025 多选 C）
3. 司法行政部门 → 本级政府或上一级司法行政部门（2025 多选 D"一司两命"）
4. 派出所（派出机构）→ 所在地政府或上一级（2025 多选 BD 甲市政府+乙区政府）
5. 复议申请可**书面或口头**；受理不收费（2022 单选 D）
6. 复议中止 = 申请人下落不明等（2025 单选 A；死亡无近亲属、撤回=终止）
7. 复议前置：当场行政处罚、纳税争议等应先复议

> 📌 **真题印证**：习题第 71~76 题考复议受案范围与管辖 → **"找政府" + 前置情形 + 中止/终止 = 必考**。

## 📍 知识点 4：行政诉讼 ⭐⭐⭐

### ① 受案范围
- 公民/法人/组织认为行政机关具体行政行为侵犯其合法权益的，可提起行政诉讼；可附带请求对规范性文件（不含规章）审查。
- **不属于受案范围：** 国家行为、抽象行政行为、内部行政行为、行政终裁、刑诉授权行为、调解/仲裁行为、行政指导、信访复查复核、不产生外部效力的过程性行为、重复处理行为等。

### ② 管辖
- **级别**：基层法院管辖第一审；中级人民法院管辖：海关处理、国务院部门或县级以上地方政府行为、本辖区重大复杂案件
- **地域**：不动产→不动产所在地；限制人身自由→被告所在地 **或** 原告所在地；经过复议→最初作出机关所在地或复议机关所在地；其他→最初作出行为机关所在地

### ③ 程序与特殊原则
- **起诉期限**：知道或应当知道行政行为之日起 **6 个月**内；未告知起诉期限的最长 1 年；不动产超 20 年、其他超 5 年不受理
- **第一审简易程序**：当事人同意/政府信息公开/当场作出/款额 2000 元以下（"童工当小二"）
- **特殊原则**：被告举证责任（被告提供证据和规范性文件）；合法性审查；**不得调解**（行政赔偿、补偿、自由裁量权案件除外）；诉讼期间不停止执行（有例外）

### 🎯 常考易错点
1. 停产停业决定 = 属受案范围（2025 单选 D）；行政指导、信访复查、内部记过、刑诉行为不属（2025 单选 A/C、2024 单选 C/D）
2. 不动产行政诉讼 = 不动产所在地法院（2025 单选 A）
3. 调解行为不属行政诉讼受案范围（2025 判断 √）

> 📌 **真题印证**：习题第 77~80 题考受案范围与管辖 → **不受案范围 + 不动产专属管辖 = 必考**。
> 🔥 **记忆口诀**：复议"童工当小三姨夫去报警"；诉讼"童工当小二"（款额 2000 元）。

## 📍 知识点 5：仲裁 ⭐⭐⭐⭐⭐（高频 + 2026 调整）

### ① 适用范围
- **可仲裁**：平等主体之间发生的**合同纠纷**和其他**财产权益纠纷**（适用《仲裁法》）
- **不得仲裁（人身+行政）**：婚姻、收养、监护、扶养、继承纠纷；依法应由行政机关处理的行政争议
- **不适用《仲裁法》**：劳动争议（《劳动争议调解仲裁法》）、农村土地承包经营纠纷、体育仲裁

### ② 仲裁原则
- **一裁终局**：裁决作出后，就同一纠纷不能再申请仲裁或起诉；但裁决被撤销/不予执行的，可重新达成仲裁协议申请仲裁或起诉
- **自愿原则**：无仲裁协议一方申请仲裁的不受理；协议须**书面**（口头无效）
- **独立仲裁原则**：仲裁依法独立，不受行政机关/社会团体/个人干涉；不实行级别管辖和地域管辖；机构间无隶属关系，不按行政区划层层设立

### ③ 仲裁协议
**必备内容：** ① 请求仲裁的意思表示；② 仲裁事项；③ 选定的仲裁机构。
> 仲裁事项或机构没有约定/约定不明的，可补充协议，达不成补充协议才无效（非直接无效）。

**效力要点：**
- 有效的仲裁协议**排除诉讼管辖权**：一方起诉未声明仲裁协议，另一方在**首次开庭前**提交仲裁协议的，法院应**驳回起诉**；首次开庭前未提出异议的视为放弃仲裁协议（≠协议无效），法院继续审理
- 对协议效力有异议的，应在**首次开庭前**请求仲裁机构或法院作出决定；一方请求仲裁机构、另一方请求法院的，由**人民法院**裁定
- 仲裁协议**具有独立性**：合同无效、撤销、解除等不影响仲裁协议效力
- **无效情形**：① 约定事项超范围；② 无/限制行为能力人订立；③ 一方胁迫；④ 事项或机构未约定且补充不成

### ④ 仲裁机构与仲裁庭
- 机构设立须经省、自治区、直辖市人民政府**司法行政部门登记**
- **仲裁庭**：独任庭（1 人）或合议庭（3 人）；3 人合议中第三名（首席）仲裁员由当事人共同选定/共同委托指定，或由当事人各自选定仲裁员共同选定
- **回避**：与本案当事人/代理人有近亲属、利害关系、其他关系可能影响公正、私自会见或请客送礼等应回避；是否回避由仲裁机构主任决定（主任任仲裁员时由其他组成人员集体决定）

### ⑤ 仲裁程序
- **开庭不公开**：仲裁应开庭进行，当事人协议不开庭可书面裁决；仲裁不公开，协议公开可公开，但涉及国家秘密、他人商业秘密、个人隐私除外
- **和解**：申请仲裁后可自行和解；达成协议可请求仲裁庭作裁决书或撤回申请
- **调解**：裁决前可先行调解（当事人自愿的应当调解）；调解书与裁决书同等效力；调解书经**双方签收后**生效，签收前反悔的应及时裁决
- **裁决原则（🔥）**：按**多数仲裁员意见**作出；不能形成多数意见时按**首席仲裁员意见**作出（先多数后首席）；裁决书**自作出之日起**生效
- **不出庭**：申请人无正当理由不到庭→视为撤回申请；被申请人不到庭→缺席裁决

### ⑥ 强制执行与撤销裁决
- **强制执行**：一方不履行的，另一方向**人民法院**申请执行（非仲裁机构）
- **撤销裁决**：当事人可自收到裁决书之日起 **3 个月**内，向仲裁机构所在地的**中级人民法院**申请撤销（"小三"）
  - 法定撤销情形：没有仲裁协议、裁决事项超范围/无权仲裁、仲裁庭组成或程序违法、仲裁员索贿受贿徇私舞弊枉法裁决、对方隐瞒足以影响公正裁决的证据、证据伪造
  - 一方申请执行另一方申请撤销 → 法院应**裁定中止执行**；撤销则终结执行，驳回撤销则恢复执行

### ⑦ 涉外仲裁特别规定
- 可书面约定仲裁地；临时仲裁适用于涉外海事纠纷或自贸区/海南自贸港企业涉外纠纷；组庭后 3 个工作日内向仲裁协会备案；境外执行可向有管辖权的外国法院申请

### 🎯 常考易错点
1. 赠与合同纠纷 = 可仲裁（2025 单选 A）；继承、劳动争议、体育争议不适用《仲裁法》
2. 仲裁不实行级别/地域管辖（判断 ×）
3. 仲裁机构设立须经**司法行政部门登记**（2025 单选 D、单选 A）
4. 一方起诉未在**首次开庭前**提仲裁协议 → 视为放弃仲裁协议，法院继续审理（单选 B）
5. 仲裁协议**具有独立性**，合同无效不影响（单选 C）
6. 无/限制行为能力人订立的仲裁协议 = 无效（多选 B）
7. 裁决按**多数意见**，不能形成多数时按**首席意见**（2023 单选 D、多选 AC）
8. 一裁终局：被撤销后既可重新协议仲裁也可起诉（单选 C）
9. 撤销裁决 = 收到裁决书之日起 **3 个月**内向**中级人民法院**申请（判断 ×）
10. 执行申请向**人民法院**，不是仲裁机构（判断 ×）
11. 一方申请执行、另一方申请撤销 → **中止执行**（2023 单选 B）
12. 仲裁不公开；涉及国家秘密/他人商业秘密/个人隐私**不得**协议公开（多选 ABD）

> 📌 **真题印证**：习题第 81~101 题全考仲裁 → **一裁终局、仲裁协议独立性/无效、裁决原则、撤销/执行 = 必考**。
> 🔥 **记忆口诀**：撤销裁决"小三"（3 个月）+ 中院；裁决先多数后首席；仲裁协议"书面 + 三项必备"。
