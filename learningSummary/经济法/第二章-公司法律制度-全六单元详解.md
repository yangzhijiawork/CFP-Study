- 主要考点：公司法人财产权与担保、出资（含瑕疵处理）、公司组织机构（股东会/董事会/监事会）、董监高忠勉义务、股东权利与股东代表诉讼、股份（含类别股/回购）、合并分立减资、解散清算注销

### ① 第一单元 公司的基础知识 · 详细展开

```
第一单元 公司的基础知识
│
├─ ① 公司概述 ⭐
│   ├─ 责任承担：股东以认缴出资为限担责（案例2.1）
│   ├─ 按信用基础分类：资合(股份)/人合(我国无)/资合兼人合(有限)
│   └─ 按组织关系分类：母子公司 / 总分公司
│       └─ 子公司vs分公司：法人资格(√/×)、独立责任(√/×由总公司)、名称/章程/财产(√/×)
│
├─ ② 公司的法人财产权 ⭐⭐⭐⭐（高频）
│   ├─ 对外投资规则：董事会或股东会决议、章程限额
│   ├─ 对外担保规则（🔥核心）
│   │   ├─ 为股东/实际控制人担保：股东会决议、出席其他股东过半数、被担保股东不得表决
│   │   └─ 为其他主体担保：按章程由董事会或股东会决议
│   └─ 记忆口诀："担保控股找股东，担保其他找股董，出席其他表过半，金额不超章程范"
│
├─ ③ 公司的登记管理 ⭐
│   ├─ 登记机关：市场监督管理机关；分支机构向所在地登记
│   ├─ 登记事项："三人+三事+一资本+一类型"
│   │   ├─ 法定代表人：由代表公司执行事务的董事或经理担任("只懂你")
│   │   ├─ 发起人：为设立公司签署章程、认购出资并履行设立职责的人
│   │   ├─ 住所：主要办事机构所在地，只能登记一个
│   │   └─ 名称：只能登记一个，含"有限责任公司/股份有限公司"字样
│   ├─ 备案事项：章程、经营期限、出资数额、董监高、联络员等
│   ├─ 公示事项：出资信息、股权变更、行政许可、处罚等（20个工作日内）
│   ├─ 设立/变更登记：实名登记；变更30日内申请
│   ├─ 撤销登记：虚报/欺诈取得登记→撤销；直接责任人3年内不得再申请
│   ├─ 营业执照：签发日期=成立日期；正副本同效
│   ├─ 歇业管理：备案、最长不超过3年、歇业期开展经营视为恢复营业
│   └─ 年度报告公示：每年1.1~6.30报送上一年度报告
│
└─ ④ 公司财务、会计 ⭐⭐⭐⭐（高频）
    ├─ 财务会计报告：董事会负责编制；股份公司年会前20日置备、公开发行须公告
    ├─ 利润分配顺序：补亏→缴税→再补亏→提法定公积金→提任意公积金→分配
    ├─ 公积金
    │   ├─ 资本公积金：发行溢价款、无面额股计入资本部分等
    │   ├─ 法定公积金：税后利润10%，达注册资本50%可不再提；转增留存≥转增前25%
    │   └─ 任意公积金：法定后经股东会决议提取
    ├─ 补亏顺序：税前利润→税后利润→盈余公积金→资本公积金→减少资本
    ├─ 分配规则：有限按实缴比例(可约定)、股份按持股；决议后6个月内分配
    ├─ 利润分配之诉：须提交有效分配决议，公司为被告
    └─ 财务资助：不得为他人取得本公司股份提供资助(员工持股计划除外)；累计≤股本10%；董事会全体董事2/3以上通过
```

### ② 第二单元 有限责任公司 · 详细展开

```
第二单元 有限责任公司
│
├─ ① 设立 ⭐
│   ├─ 设立方式：只能发起设立（一般准则主义/特殊核准主义）
│   ├─ 股东：1~50人；自然人/法人/非法人组织；公务员不得为非上市公司股东；公司不得自为股东
│   ├─ 章程：股东共同制定、签名盖章；8项必备事项
│   └─ 设立阶段责任：以设立中公司名义→公司承受/设立人承受；以自己名义→第三人可选择
│
├─ ② 出资 ⭐⭐⭐⭐⭐（极高）
│   ├─ 资本制度：限期认缴资本制，成立起5年内缴足
│   ├─ 过渡期：2024.6.30前登记、认缴期限>2032.6.30→2027.6.30前调整至5年内
│   ├─ 加速到期：不能清偿到期债务→公司或已到期债权人可要求提前缴纳
│   ├─ 出资方式：货币+实物/知识产权/土地使用权/股权/债权/数据等；禁：土地所有权、劳务、信用、姓名、商誉、特许经营权、设定担保财产
│   ├─ 出资要求：货币存入银行账户；非货币须转移+评估（可协商）
│   └─ 出资程序：出资证明书(法定代表人签名+盖章)/股东名册(记载者主张权利)/登记(不登记不得对抗善意相对人)
│
├─ ③ 出资瑕疵处理 ⭐⭐⭐⭐⭐（极高）
│   ├─ 非货币出资未评估：委托评估→显著低于章程价额→认定未全面履行
│   ├─ 市场贬值：不承担补足责任（另有约定除外）
│   ├─ 划拨/设负担土地：责令合理期间办理变更/解除，逾期→未全面履行
│   ├─ 需办权属登记财产：交付未过户→责令补办；过户未交付→可主张交付、交付前不享权利
│   ├─ 违法所得出资：拍卖或变卖处置股权（不得直接抽回）
│   ├─ 未尽出资责任：补足+赔偿损失（含利息）；债权人可请求在未出资本息范围内补充赔偿
│   ├─ 发起人连带责任：设立时其他股东在出资不足范围内承担连带责任
│   ├─ 股东失权制度：董事会核查→书面催缴→宽限期(不少于60日)→失权通知(董事会决议)→失权股权6个月内转让或注销→30日内可起诉
│   ├─ 抽逃出资：虚构债权债务/虚增利润分配/关联交易转出/其他；股东返还+董监高连带；债权人补充赔偿
│   ├─ 股权转让后出资责任：未届期→受让人承担、转让人补充；已届期→转让人与受让人连带（受让人善意除外）
│   └─ 抗辩无效：缴付出资请求权不适用诉讼时效
│
├─ ④ 组织机构概述 ⭐：不设股东会(一人公司/国有独资)；不设董事会(设1名董事)；不设监事会(设1名监事/审计委员会)；应当设经理(股份+国有独资)
│
├─ ⑤ 股东会 ⭐⭐⭐⭐⭐（极高）
│   ├─ 职权：人事权/审批权/决议权（修改章程、增减注册资本、合并分立变更解散、发行债券）
│   ├─ 会议类型：定期(章程规定)/临时(1/10以上表决权股东、1/3以上董事、监事会提议)
│   ├─ 通知：15日以前（可另约定）
│   ├─ 决议办法：普通>1/2；特别≥2/3（修改增减、合分变解）
│   ├─ 担保决议：出席其他股东过半数
│   ├─ 不开会直接通过：全体股东书面一致同意
│   └─ 记忆口诀："十一股东，三一董，还有一个监事会"；"修改增减，合分变解，代表二三，表决过关"
│
├─ ⑥ 董事会 ⭐⭐⭐⭐
│   ├─ 职权：召集/执行/决定（经营计划、机构设置、聘解经理）/制订（分配、增减资、合分解散）
│   ├─ 成员：3人以上；任期≤3年可连任；继续履职/辞任(书面通知生效)/解任(决议作出日生效)
│   ├─ 董事长：由章程规定
│   └─ 会议：过半数董事出席、全体董事过半数通过、一人一票、关联董事表决排除
│
├─ ⑦ 监事会 ⭐⭐⭐⭐
│   ├─ 职权：监督/提议（检查财务、监督董监高、提诉讼、提议召开临时股东会）
│   ├─ 成员：3人以上；董事高管不得兼任；任期3年可连任
│   ├─ 主席：全体监事过半数选举
│   └─ 会议：每年至少1次；决议全体监事过半数
│
├─ ⑧ 职工代表制度 ⭐：监事会职工代表≥1/3；董事会(职工<300可有/≥300设有监事会时可有/未设监事会应当有)
│
├─ ⑨ 董监高规定 ⭐⭐⭐⭐
│   ├─ 任职资格限制："黑五类犯罪"(执行期满5年/缓刑考验期满2年)、剥夺政治权利5年、破产清算责任人3年、吊销执照责任人3年、失信被执行人、非完全行为能力人、董事高管不得兼任监事
│   ├─ 忠实义务：绝对禁止(侵占/挪用/个人账户/收佣金/泄露秘密)；相对禁止(竞争业务/关联交易/谋取商业机会，须报告+决议通过+关联董事排除+收入归公司)
│   ├─ 勤勉义务：列席股东会接受质询、如实提供资料
│   └─ 法律责任：执行职务致害公司赔偿；故意重大过失赔偿；控股股东/实控人指示连带
│
├─ ⑩ 决议效力 ⭐⭐⭐：无效(内容违法)/可撤销(程序违法违章程/内容违章程，60日内)/不成立(出席或表决不足)
│
├─ ⑪ 冒名/名义/实际股东 ⭐：冒名登记→冒名人担责；代持协议有效→对内按约定、对外按股东名册；名义股东处分→善意取得
│
└─ ⑫ 股东权利 ⭐⭐⭐⭐⭐（极高）
    ├─ 分类：共益权(管理)/自益权(收益)；单独股东权/少数股东权
    ├─ 法人人格否认：纵向(股东连带)/横向(关联公司连带)/一人公司(不能证明财产独立→连带)
    ├─ 查阅权：有限任股东可查复制章程/记录/决议/财报；查账簿凭证须书面说明目的、公司可拒(15日内书面答复)；连续180日+3%股东可查账簿凭证
    ├─ 股东代表诉讼：董高害公司→书面请求监事会(监事害公司→请求董事会)；拒绝/30日未诉/紧急→股东直接诉；有限任股东均可，股份连续180日+1%
    ├─ 双重股东代表诉讼：全资子公司利益受损→母公司股东可代子公司起诉
    ├─ 股权转让：内部自由/外部书面通知+优先购买权(30日未答视为放弃)；强制执行(通知+20日)；继承(章程无约定可直接继承)
    └─ 异议股东回购请求权：连盈5年不分红/合并分立转让主要财产/营业期满修改存续；60日协议不成90日可诉
```

```
│
├─ ① 设立 ⭐⭐⭐
│   ├─ 设立方式：发起设立(认购全部)/募集设立(认购≥35%)
│   ├─ 发起人：1~200人，半数以上在中国境内有住所
│   ├─ 资本制度：实缴资本制(注册资本=已发行股份股本总额)+授权资本制(可授权董事会3年内发行≤已发行股份50%)
│   ├─ 成立大会(募集设立)：股款缴足30日内召开、15日前通知、过半数认股人出席、决议过半数通过
│   └─ 募集失败：股款+银行同期存款利息返还；设立成功后不得抽回股本
│
├─ ② 股东会会议制度 ⭐⭐⭐⭐
│   ├─ 年会：非上市每年1次/上市上一会计年度结束后6个月内
│   ├─ 临时会议(2个月内)：董事<3人或<章程2/3、亏损达股本1/3、董事会认为必要、监事会提议、10%以上股东请求
│   ├─ 通知：年会20日前/临时15日前；不得对未列明事项决议
│   ├─ 临时提案权：1%以上股东10日前书面提交董事会
│   ├─ 决议：普通=出席股东过半数；特别(修改增减、合分变解、上市资产超30%担保)=出席股东2/3以上
│   └─ 累积投票制：每股份拥有与应选人数相同的表决权可集中使用
│
├─ ③ 董事会(对比版) ⭐⭐⭐⭐：职权同有限；定期每年至少2次、10日前通知；临时(1/10表决权/1/3董事/监事会提议)；代理出席(书面委托)；免责(表决时异议并记录)
│
├─ ④ 经理 ⭐：应当设置（股份+国有独资）；董事会聘任、对董事会负责；董事会可决定成员兼任经理
│
├─ ⑤ 审计委员会 ⭐⭐⭐：3名以上、过半数不得任董事以外职务；决议过半数通过
│
├─ ⑥ 监事会(对比版) ⭐⭐⭐：同有限，但会议每6个月至少1次；可设副主席
│
└─ ⑦ 股份 ⭐⭐⭐⭐⭐（极高）
    ├─ 面额股vs无面额股：全部股份择一采用；面额股可平价/溢价但不得低于票面；无面额股股款至少1/2计入注册资本
    ├─ 类别股：优先/劣后/特殊表决权/转让受限股；公司章程载明；分类表决(2/3)
    ├─ 股票应记名；同股同权同价
    ├─ 股份转让：原则自由；董监高所持1年内不得转让、任职期每年≤25%、离职半年内不得转让
    ├─ 上市公司董监高变动管理(🆕2026)：不得转让情形；"25%"计算基数(以上年年末为基数)；禁止买卖窗口期(年报半年报前15日、季报预告快报前5日、重大事件至披露日)
    ├─ 股份质押：公司不得接受本公司股份作为质权标的
    ├─ 异议股东回购：股份公司(公开发行不适用)少了"合并、分立"，只"转让主要财产"
    └─ 公司收购本公司股份：合并(股东会+6个月)/异议(6个月)/减资(10日注销)/员工持股或转债或维护价值(股东会或2/3董事出席董事会决议+3年内转让或注销+合计≤10%)；记忆口诀"合意见，励可维，610,310"
```

# 🧩 第一单元 公司的基础知识

## 📍 知识点 1：公司概述 ⭐

### ① 概念/定义
**公司**：依法设立的营利性法人，股东以认缴出资为限对公司债务承担有限责任。

### ② 公司与股东责任的承担（案例 2.1）
- 先以**公司全部财产**清偿债务；
- 股东以**各自认缴的出资**为限担责，已实缴则无需再用个人财产担责；
- 公司财产不足以清偿全部债务的，债权人可依法申请公司**破产**。

### ③ 公司的种类

**按"信用基础"分类：**

| 分类 | 股东身份特征 | 典型公司 | 表决权规则 |
|-|-|-|-|
| 资合公司 | 财力 | 股份有限公司 | 看"出席"股东态度 |
| 人合公司 | 信用 | 无限公司（我国不存在） | —— |
| 资合兼人合 | 财力＋信用 | 有限责任公司（1~50人） | 看"全体"股东态度 |

**按"公司组织关系"分类（母子公司 / 总分公司）：**

| 对比项 | 子公司 | 分公司 |
|-|-|-|
| 独立公司章程 | √ | × |
| 独立名称 | √ | × |
| 独立经营 | √ | √ |
| 领取营业执照 | √ | √ |
| 独立法人资格 | √ | × |
| 独立承担民事责任 | √ | ×（由总公司承担；特殊先以分支机构财产承担） |
| 独立财产 | √ | × |

### 🎯 常考易错点
1. 子公司具有法人资格，独立承担民事责任（2019 单选 A ✅）；分公司不具有法人资格，民事责任由总公司承担（2022 多选 ABD ✅）
2. "分公司有独立财产" → ❌ 分公司**没有**独立财产、名称、章程

> 📌 **真题印证**：习题第 1~5 题考子公司/分公司 → **子公司独立法人、分公司不独立 = 必考**。

---

## 📍 知识点 2：公司的法人财产权 ⭐⭐⭐⭐（投资 / 担保高频）

### ① 公司向其他企业投资规则
- **投资规则**：公司可以向其他企业投资，法律禁止成为对投资企业债务承担连带责任的出资人的从其规定
- **决议主体**：按章程由**董事会或股东会**决议
- **限额**：章程对投资总额/单项投资有限额的，不得超过

### ② 公司对外提供担保规则（🔥 必考，记忆口诀）

| 担保对象 | 决议主体 | 决议办法 | 金额限制 |
|-|-|-|-|
| 股东、实际控制人 | **股东会** | 出席会议的其他股东所持表决权**过半数**通过（被担保股东/被担保实际控制人支配的股东**不得参加表决**） | 不得超过章程限额 |
| 其他主体 | 按章程由**董事会或股东会**决议 | —— | 不得超过章程限额 |

> **实际控制人**：通过投资关系、协议或其他安排，能够实际支配公司行为的人（可能是股东也可能不是）。

> 🔥 **记忆口诀**："担保控股找股东，担保其他找股董，出席其他表过半，金额不超章程范"

### 🎯 常考易错点
1. 为股东担保，"不得参加表决" ≠ "不得出席股东会会议"（单选 C 2018：张某作为被担保股东可出席但不得表决）
2. 为股东担保的决议办法："出席会议的其他股东"所持表决权过半数，而非全体股东（单选 B 2018 ✅）

> 📌 **真题印证**：习题第 6~10 题全考担保决议 → **担保决议主体 + "其他股东过半数" = 必考**。

## 📍 知识点 3：公司的登记管理 ⭐

### ① 登记机关
- 市场监督管理机关是公司登记机关；分支机构向**分支机构所在地**登记机关申请登记

### ② 公司登记事项（"三人＋三事＋一资本＋一类型"）
| 登记事项 | 细节 |
|-|-|
| 法定代表人姓名 | 由代表公司执行事务的**董事或经理**担任（"只懂你"） |
| 有限责任股东/股份发起人姓名或名称 | 发起人=为设立公司签署章程、认购出资并履行设立职责的人；自然人/法人/非法人组织/外国人均可 |
| 住所 | 主要办事机构所在地；只能登记一个；跨辖区变更须迁入前申请 |
| 公司名称 | 只能登记一个；有限含"有限责任公司/有限公司"字样，股份含"股份有限公司/股份公司"字样 |
| 经营范围 | 章程规定；可修改；须批准的项目依法批准 |
| 注册资本 | 有限=全体股东认缴出资额；股份=已发行股份的股本总额 |
| 公司类型 | 有限责任公司、股份有限公司 |

### ③ 备案事项：章程、经营期限、出资数额、董监高（董事备案标明审计委员会成员信息）、登记联络员、受益所有人等

### ④ 公示事项（形成之日起 **20 个工作日**内公示）：出资信息、股权变更、行政许可、知识产权出质、行政处罚等

### ⑤ 登记规范
- **设立登记**：实行**实名登记**（人脸识别验证法定代表人、股东、发起人、董监高）；可委托代理
- **变更登记**：自变更决议/决定作出或法定变更事项发生之日起 **30 日**内申请；法定代表人的变更申请书由**变更后**的法定代表人签署
- **撤销登记**：虚报注册资本/提交虚假材料/欺诈隐瞒取得登记→受影响的利害关系人可申请撤销；直接责任人自撤销之日起 **3 年内**不得再次申请登记

### ⑥ 营业执照
- **签发日期 = 公司成立日期**
- 载明名称、住所、注册资本、经营范围、法定代表人姓名
- 正本/副本、电子/纸质营业执照**具有同等法律效力**
- 不得伪造、涂改、出租、出借、转让

### ⑦ 歇业管理（🔥 常考）
- 因自然灾害/事故灾难/公共卫生/社会安全事件等原因造成经营困难可自主决定歇业
- 歇业前**备案**、与职工协商劳动关系处理
- 歇业期限最长不得超过 **3 年**
- 歇业期间开展经营活动=**视为恢复营业**，应公示

### ⑧ 企业年度报告公示制度
- 每年 **1 月 1 日至 6 月 30 日**报送上一年度报告

### 🎯 常考易错点
1. "歇业期限最长不得超过 2 年" → ❌ **3 年**（2024 单选 B）
2. "营业执照签发日期为公司成立日期" → ✅（2022 多选 C）
3. "设立分支机构向总公司所在地登记" → ❌ 向**分支机构所在地**登记（2022 多选 D）
4. 法定代表人须是"代表公司执行事务的董事或经理"，监事不能担任（2024 单选 C：赵某任监事，不能当法定代表人）
5. "非法人组织不得成为发起人" → ❌ 非法人组织**可以**成为发起人（2024 判断 ×）
6. "公司歇业最长为 2 年" → ❌ 3 年（2024 单选）

> 📌 **真题印证**：习题第 11~20 题考登记/歇业/营业执照 → **成立日期、歇业3年、发起人资格 = 高频**。

## 📍 知识点 4：公司财务、会计 ⭐⭐⭐⭐（公积金 / 利润分配高频）

### ① 财务会计报告
- 公司应当在每个**会计年度终了**时编制，并依法经会计师事务所审计
- 由**董事会**负责编制，并对真实性、完整性、准确性负责
- 聘用/解聘会计师事务所：按章程由股东会、董事会或监事会决定
- 披露：有限按章程规定期限送交各股东；股份公司在召开股东会**年会 20 日前**置备于本公司供股东查阅；公开发行股份的公司应当**公告**

### ② 依法建账、开立账户
- 除法定的会计账簿外，不得另立会计账簿
- 对公司资金，不得以任何个人名义开立账户存储

### ③ 利润分配顺序
1. 弥补以前年度亏损（不超过税法规定的弥补期限）
2. 缴纳所得税
3. 弥补税前弥补后仍存在的亏损
4. 提取法定公积金
5. 提取任意公积金
6. 向股东分配利润

### ④ 公积金（🔥 必考数值）

| 种类 | 来源 | 用途 |
|-|-|-|
| **资本公积金** | 股票发行溢价款、无面额股计入资本部分、其他 | 补亏/扩大经营/转增资本 |
| **法定公积金** | 税后利润按 **10%** 提取；累计达注册资本 **50%** 以上可不再提取 | 补亏/扩大经营/转增资本 |
| **任意公积金** | 法定公积金提取后，经股东会决议从税后利润提取 | 补亏/扩大经营/转增资本 |

- **法定公积金转增资本**：所留存的不得少于转增前注册资本的 **25%**

### ⑤ 补亏顺序
税前利润 → 税后利润 → 盈余公积金 → 资本公积金 → 减少资本

### ⑥ 分配规则
- **分配比例**：有限按实缴出资比例（可约定）；股份按持股比例（章程另有规定除外）
- **分配时间**：股东会作出分配决议后，董事会应在决议作出之日起 **6 个月**内分配
- **分配限制**：公司持有的本公司股份**不得**分配利润
- **违法分配**：股东应退还；给公司造成损失，股东及负有责任的董监高承担赔偿责任

### ⑦ 利润分配之诉
- 股东须提交股东会已作出的含具体分配方案的**有效决议**，否则法院应驳回
- 例外：公司不分配利润是部分股东滥用股东权利所致且损害其他股东利益的除外
- 诉讼列置：原告=股东，被告=公司，共同原告=基于同一方案的其他股东

### ⑧ 财务资助（🔥 常考）
- **基本规定**：公司不得为他人取得本公司或母公司股份提供赠与、借款、担保及其他财务资助
- **例外**：① 员工持股计划；② 为了公司利益，经股东会决议或董事会按章程/授权决议
- **总额控制**：累计总额 ≤ 已发行股本总额 × **10%**
- **董事会决议办法**：全体董事的 **2/3 以上**通过
- **违规后果**：给公司造成损失，负有责任的董监高承担赔偿责任

### 🎯 常考易错点
1. "财务部门负责编制财务会计报告" → ❌ 由**董事会**负责编制（多选 C）
2. "每一个月度终了编制财报" → ❌ **会计年度终了**时编制（多选 B）
3. 股份公司财报置备时限 = 年会前 **20 日**（单选 B）
4. 法定公积金提取：累计达注册资本 **50% 以上**可不再提取（单选 A 2024：A 项法定公积金 500 万=注册资本 1000 万 50%）
5. 法定公积金转增留存 ≥ 转增前注册资本的 **25%**（2024 单选：100 万注册资本，法定公积金 80 万，转增最多 80-25=55 万）
6. 减资补亏：只能减少**实缴**注册资本（未实缴不能减少，不得免除出资义务）（单选 A：实缴 5 万）
7. "公司为他人取得本公司股份提供担保不视为财务资助" → ❌ 担保**视为**财务资助（2024 单选 D）
8. 财务资助董事会决议 = 全体董事 **2/3 以上**通过（非一致通过）（2024 单选 B）
9. 财务资助累计 ≤ 已发行股本总额 **10%**（非 20%）（2024 单选 C）

> 📌 **真题印证**：习题第 21~30 题全考公积金/分配/财务资助 → **法定公积金50%、转增25%、财务资助10%+2/3董事 = 必考**。
> 🔥 **记忆口诀**：公积金"10%、50%、25%"三个数；财务资助"员工持股除外，10%封顶，2/3董事"。

# 🧩 第二单元 有限责任公司

## 📍 知识点 1：有限责任公司的设立 ⭐

### ① 设立方式与设立原则
- **设立方式**：有限责任公司只能采取**发起设立**方式
- **设立原则**：一般行业=**准则主义**（符合法定条件即可）；金融/互联网/能源等=**核准主义**（未经审批机关批准不得设立）

### ② 对股东的要求
- **人数**：1~50 人
- **性质**：自然人、法人或非法人组织
- **限制**：国家公务员不得成为非上市公司股东；公司不得自为（自己公司的）股东；机关法人一般不能担任公司股东（依法对外投资可成为国有股东）
- **民事行为能力**：发起人必须具备**完全民事行为能力**，其他股东否

### ③ 制定公司章程
- 由**股东共同制定**，股东在章程上**签名或盖章**
- **应当载明事项**：①公司名称和住所；②经营范围；③注册资本；④股东姓名或名称；⑤出资额、出资方式和出资日期；⑥公司机构及其产生办法、职权、议事规则；⑦法定代表人产生、变更办法；⑧股东会认为需要规定的其他事项
- **约束对象**：公司、股东、董事、监事、高级管理人员

### ④ 公司设立阶段的责任承担规则

| 情形 | 公司是否成立 | 法律后果承受方 |
|-|-|-|
| 以设立中公司名义从事活动 | 是 | 公司承受 |
| | 否（设立人=1人） | 设立人承受 |
| | 否（设立人≥2人） | 设立人连带债权债务 |
| 以自己名义从事活动 | 是 | 第三人可选择请求公司或设立人承受 |
| | 否 | 同上 |

> 设立人因履行设立职责造成他人损害的，公司或无过错股东赔偿后可向有过错设立人**追偿**。

### 🎯 常考易错点
1. "有限责任设立均为股东实缴金额" → ❌ 全体股东**认缴**出资额，5年内缴足（2023 单选 A）
2. "均应采用准则主义" → ❌ 特殊行业（金融/互联网/能源）采用**核准主义**（2023 单选 B）
3. "有限责任公司可采取募集设立" → ❌ 只能**发起设立**（2023 判断 ×）
4. "设立分公司向总公司所在地登记" → ❌ 向**分支机构所在地**登记（2022 多选 D）
5. 法定代表人是"代表公司执行事务的董事或经理"（监事不可）（2024 单选 C）

> 📌 **真题印证**：习题第 31~40 题考设立/章程/责任 → **发起设立、章程必备事项、设立责任 = 高频**。

## 📍 知识点 2：有限责任公司的出资 ⭐⭐⭐⭐⭐（极高考频）

### ① 资本制度
- **资本制度**：限期认缴资本制
- **注册资本**：全体股东认缴的出资额
- **出资期限**：由章程规定，自公司成立之日起 **5 年内**缴足
- **验资**：一般公司无法定验资要求
- **最低注册资本**：一般公司无最低注册资本要求

### ② 出资期限中的特殊规定
- **增资**：股东认缴新增资本按章程自注册资本变更登记之日起 **5 年内**缴足
- **三年过渡 + 五年出资**（2024.6.30 前登记设立的公司）：
  - 有限剩余认缴期限 > 2032.6.30 → **2027.6.30 前调整**至 2032.6.30 之前
  - 剩余认缴期限 ≤ 2032.6.30 → 无需调整
  - 股份公司发起人应在 **2027.6.30 前**全额缴纳股款
- **加速到期**：公司不能清偿到期债务的，公司或已到期债权的债权人有权要求已认缴出资但未届期限的股东**提前缴纳**出资

### ③ 对异常公司的行政监管
- **认定**：认缴出资期限 30 年以上 / 注册资本 10 亿元以上 / 其他明显不符客观常识
- **监管**：认定明显异常→要求及时调整，并向省级市场监督管理部门报告

### ④ 出资方式（🔥 必考允许/禁止）

| 允许出资 | 禁止出资 |
|-|-|
| 货币 | 土地所有权 |
| 实物 | 非法财产 |
| 知识产权 | **劳务** |
| 土地使用权 | **信用** |
| 股权 | **自然人姓名** |
| 债权 | **商誉** |
| 数据、网络虚拟财产（有规定时） | **特许经营权** |
| | **设定担保的财产** |

### ⑤ 出资要求
- **货币出资**：足额存入公司在银行开设的账户
- **非货币出资**：① 依法办理财产权转移手续；② 应当评估作价、核实财产、不得高估或低估；③ 评估**不一定**由法定评估机构进行，股东可协商评估作价

### ⑥ 出资程序
- **出资证明书**：由**法定代表人签名 + 公司盖章**；载明公司名称、成立日期、注册资本、股东姓名或名称、认缴实缴出资额/方式/日期、证书编号和核发日期
- **股东名册**：有限责任公司应当置备股东名册；**记载于股东名册的股东**可依名册主张行使股东权利
- **办理登记**：股东姓名/名称属公司登记事项；未经登记不得对抗**善意相对人**

### 🎯 常考易错点
1. "设定抵押的厂房可以出资" → ❌ 设定担保的财产是**清洁无负担**财产才能出资（2024 多选 A 不当选）
2. "特许经营权可作价出资" → ❌ 不能（2024 多选 D）
3. "股东可依出资证明书主张行使股东权利" → ❌ 依**股东名册**（多选 C）
4. "非货币财产出资须法定评估机构评估" → ❌ 可**股东协商**评估作价（多选 D 正确）
5. 出资期限最晚：2024.6.30 前设立、认缴至 2035 年 → 调整至最晚 **2032.6.30**（2025 单选 A）

> 📌 **真题印证**：习题第 41~52 题全考出资 → **出资方式允许/禁止 + 5年缴足 + 加速到期 = 必考**。

## 📍 知识点 3：出资瑕疵的处理 ⭐⭐⭐⭐⭐（极高考频）

### ① 非货币财产出资的特殊处理

| 情形 | 处理规则 |
|-|-|
| 未依法评估作价 | 法院委托合法机构评估；显著低于章程价额→认定未全面履行出资义务 |
| 市场/客观因素贬值 | 不得请求补足出资责任（另有约定除外） |
| 划拨土地出资 | 责令合理期间办理土地变更手续；逾期未办理→未全面履行 |
| 设权利负担土地出资 | 责令合理期间解除权利负担；逾期未解除→未全面履行 |
| 交付未过户（房屋等） | 责令合理期间补办权属变更；补办后认定已履行；出资人主张自**实际交付**时享有股东权利→支持 |
| 过户未交付 | 公司可主张其交付；实际交付前不享有股东权利 |

### ② 以违法所得出资
- 以贪污、受贿、侵占、挪用等违法犯罪所得货币出资取得股权的，追究处罚时应当采取**拍卖或变卖**方式处置其股权（不能直接抽回，否则构成抽逃出资）

### ③ 违反出资义务的法律责任

| 主体 | 责任 |
|-|-|
| 未按期足额缴纳的股东 | 向公司足额缴纳 + 赔偿损失（含未出资利息） |
| 债权人 | 可请求未履行/未全面履行出资义务的股东在未出资本息范围内对公司债务不能清偿部分承担**补充赔偿责任** |
| 发起人（设立时其他股东） | 与出资不足股东在出资不足范围内承担**连带责任**（后加入股东无需承担） |

### ④ 股东失权制度（🔥 常考）
- **核查**：公司成立后，**董事会**对股东出资情况进行核查
- **催缴**：发现未按期足额缴纳→由**公司**向股东发出书面催缴书（未及时催缴给公司造成损失，负有责任董事赔偿）
- **宽限期**：不得少于 **60 日**（自发出催缴书之日起）
- **失权决议**：宽限期届满仍未履行→公司经**董事会决议**发出失权通知（书面）
- **法律后果**：自**通知发出之日**起，股东丧失未缴纳出资的股权
- **失权股权处理**：依法转让或减少注册资本注销；**6 个月内**未转让或注销→由其他股东按出资比例足额缴纳
- **失权异议**：自接到失权通知之日起 **30 日内**向人民法院提起诉讼

### ⑤ 抽逃出资
- **情形**：① 虚构债权债务关系转出；② 制作虚假财报虚增利润分配；③ 利用关联交易转出；④ 其他未经法定程序抽回
- **责任**：股东返还抽逃出资 + 负有责任董监高连带赔偿；债权人可请求在抽逃出资本息范围内补充赔偿

### ⑥ 股权转让后的出资责任

| 股权出资期限 | 责任承担 |
|-|-|
| **未届满** | 由**受让人**承担缴纳义务；受让人未按期足额缴纳→**转让人**承担补充责任 |
| **已届满** | 转让人与受让人在出资不足范围内**连带责任**；受让人不知道且不应知道的由转让人担责 |

### ⑦ 抗辩无效
- 基于投资关系产生的缴付出资请求权，**不适用诉讼时效**制度

### 🎯 常考易错点
1. "已交付未过户，出资人主张自交付时享有股东权利" → ✅ 支持（2024 单选 B：1月7日交付，享有股东权利日期=交付日）
2. "市场贬值应承担补足出资责任" → ❌ 无需补足（2022 单选 C：市场原因贬值不担责）
3. 违法所得出资 → **拍卖或变卖处置股权**（2019 单选 C）
4. "宽限期届满董事会应当（而非可以）发出失权通知" → ❌ 是"**可以**"发出（单选 D）
5. "股东自收到失权通知时丧失股权" → ❌ 自失权通知**发出之日**起（单选 C）
6. "设立时非货币出资显著不足，受让人善意转让股权" → 由转让人担责（多选 AB：乙丙设立时股东连带，丁善意不连带）
7. "催缴书由董事会向股东发出" → ❌ 由**公司**发出（单选 B）
8. 未届期转让股权：受让人担责、转让人补充（单选 C）；已届期转让：转让人与受让人连带（单选 D 2024）

> 📌 **真题印证**：习题第 53~70 题全考出资瑕疵 → **失权制度、抽逃出资、瑕疵处理、转让后责任 = 必考**。
> 🔥 **记忆口诀**：失权"核查→催缴→60日宽限→决议失权→6个月处理"；"未届期转让人补，已届期连带"。

## 📍 知识点 4：公司组织机构概述 ⭐

- **不设股东会**：只有一个股东的公司（股东行使职权采书面形式+签名盖章）、国有独资公司（由履行出资人职责的机构行使）
- **不设董事会**：规模较小或股东人数较少，只设一名董事（该董事可兼任经理）；国有独资公司**必须**设董事会
- **不设监事会**：规模较小或股东人数较少设一名监事；设审计委员会行使监事会职权（有限经全体股东一致同意，股份不适用）
- **应当设经理**：股份有限公司、国有独资公司

> 📌 **真题印证**：2024 多选考股份公司组织机构 → **审计委员会取代监事会（股份可）、小规模公司可简化机构 = 常考**。

## 📍 知识点 5：有限责任公司的股东会 ⭐⭐⭐⭐⭐（极高考频）

### ① 职权（股份公司同样适用）
- **人事权**：选举更换董事、监事，决定报酬
- **审批权**：审议批准董事会报告、监事会报告、利润分配方案和弥补亏损方案
- **决议权**：①修改章程；②增减注册资本；③合并、分立、变更公司形式、解散或清算（简易合并除外）；④发行公司债券（可授权董事会）
- **其他**：章程规定的其他职权

### ② 会议制度
**会议类型与召开条件：**

| 会议类型 | 召开条件 | 通知时间 |
|-|-|-|
| 定期会议 | 按章程按时召开 | 15 日以前（可另行约定） |
| 临时会议 | 代表 **1/10** 以上表决权股东提议 / **1/3** 以上董事提议 / 监事会提议 | —— |

> 🔥 **记忆口诀**："十一股东，三一董，还有一个监事会"

**召集与主持**：首次由出资最多的股东召集主持；以后由董事会召集（董事长主持）→监事会→代表 1/10 以上表决权股东

### ③ 决议办法
- **普通决议**：代表**过半数**表决权的股东通过
- **特别决议**：代表 **2/3 以上**表决权股东通过（修改章程、增减注册资本、合并分立变更形式解散）
- **担保决议**：出席会议的其他股东所持表决权过半数

> 🔥 **记忆口诀**："修改增减，合分变解，代表二三，表决过关"

### ④ 不开会直接通过
- 对股东会行使职权的事项，股东以**书面形式一致表示同意**的，可以不召开股东会会议，直接作出决定，并由全体股东在决定文件上**签名或盖章**

### ⑤ 记录与签名
- 股东会会议记录，出席会议的股东签名或盖章

### 🎯 常考易错点
1. 修改章程/增减注册资本须经代表 **2/3 以上**表决权股东通过（单选/多选）
2. "董事长有权提议召开临时股东会" → ❌ 需**监事会、1/3董事、1/10表决权股东**（多选 ABD 2023）
3. 临时股东会情形：2 名董事提议（占 5 人 2/5＞1/3 → 应召开）（多选 AC 2013）
4. "赵某 5% 表决权有权提议临时会议" → ❌ 须 **1/10 以上**（单选 B）
5. 首次股东会由**出资最多**的股东召集主持（单选 D 2023）

> 📌 **真题印证**：习题第 71~85 题全考股东会 → **职权划分、临时会议触发、特别决议2/3、担保决议 = 必考**。

## 📍 知识点 6：有限责任公司的董事会 ⭐⭐⭐⭐

### ① 职权（股份公司同样适用）
- **召集权**：召集股东会会议，并向股东会报告工作
- **执行权**：执行股东会的决议
- **决定权**：①决定经营计划和投资方案；②决定内部管理机构设置；③决定聘任/解聘经理及报酬，根据经理提名决定聘任/解聘副经理、财务负责人及报酬；④制定基本管理制度
- **制订权**：①制订利润分配方案和弥补亏损方案；②制订增减注册资本及发行债券方案；③制订合并、分立、解散、变更形式方案
- 公司章程对董事会职权的限制**不得对抗善意相对人**

### ② 董事会成员
- **人数**：3 人以上
- **任期**：由章程规定，每届**不超过 3 年**；届满连选可连任
- **继续履职**：任期届满未及时改选/辞任致成员低于法定人数→在改选董事就任前，原董事仍应履职
- **辞任**：书面形式通知公司，**公司收到通知之日**辞任生效
- **解任**：股东会可决议解任（决议作出之日生效）；无正当理由任期届满前解任→可要求公司赔偿
- **董事长**：设董事长 1 人，可设副董事长；由**章程规定**（有限）/由董事会全体董事过半数选举（股份）

### ③ 会议制度
- **召集主持**：董事长→副董事长→过半数董事共同推举 1 名董事
- **普通决议**：应当有全体董事**过半数出席**方可举行；经全体董事**过半数**通过
- **表决权**：一人一票
- **关联董事表决排除**：对关联交易/竞争业务事项决议时，关联董事不得参与表决，其表决权不计入总数；应有过半数无关联董事出席、过半数无关联董事通过
- **会议记录**：出席会议的董事签名

### 🎯 常考易错点
1. "决定内部管理机构设置" 属**董事会**职权（非股东会）（单选 B）
2. 董事长/副董事长均不能履职→**过半数董事共同推举 1 名董事**召集主持（单选 C 2025）
3. "董事辞任以通知发出之日生效" → ❌ 公司**收到通知之日**生效（单选 A 2025）
4. 董事长任期届满前不得辞职 → ❌ 可以辞职（单选 C 不当选）

> 📌 **真题印证**：习题第 86~95 题考董事会 → **职权、任期3年、辞任生效、会议过半数 = 高频**。

## 📍 知识点 7：有限责任公司的监事会 ⭐⭐⭐⭐

### ① 职权（股份公司同样适用）
- **监督权**：①检查公司财务；②对董监高执行职务行为监督、提出解任建议；③董监高行为损害公司利益时要求纠正；④依《公司法》对董监高提起诉讼
- **提议权**：①提议召开临时股东会；在董事会不履行召集主持职责时召集主持；②向股东会提出提案
- **其他**：章程规定的其他职权

### ② 履职保障
- 监事可列席董事会会议，对决议事项提出质询或建议
- 发现经营情况异常可调查，必要时聘请会计师事务所协助，费用由公司承担
- 监事会行使职权所必需费用由公司承担
- 监事会可要求董监高提交执行职务报告，董监高应如实提供

### ③ 监事会成员
- **人数**：3 人以上
- **资格**：董事、高级管理人员**不得兼任监事**
- **任期**：每届 **3 年**；届满连选可连任
- **继续履职**：任期届满未改选/辞任致低于法定人数→原监事仍履职
- **主席**：监事会设主席 1 人（股份可设副主席）；由**全体监事过半数**选举产生

### ④ 会议制度

| 项目 | 有限责任公司 | 股份有限公司 |
|-|-|-|
| 召集主持 | 主席→过半数监事共同推举 1 名监事 | 主席→副主席→过半数监事推举 |
| 开会频率 | **每年度至少 1 次** | **每 6 个月至少 1 次** |
| 临时会议 | 监事可提议 | 监事可提议 |
| 决议办法 | 全体监事**过半数** | 全体监事过半数 |
| 表决权 | 一人一票 | 一人一票 |

### 🎯 常考易错点
1. "总经理可以兼任监事" → ❌ 董事、高管**不得兼任监事**（2023 多选 B 不当选）
2. "解聘财务负责人属监事会职权" → ❌ 属**董事会**职权（单选 B）
3. 监事会职工代表 ≥ 1/3（9 人监事会至少 3 名职工代表）（多选 CD）
4. 5 人监事会职工代表至少 2 人（5×1/3）（多选 AC 2025）

> 📌 **真题印证**：习题第 96~105 题考监事会 → **不得兼任、任期3年、会议频率 = 高频**。

## 📍 知识点 9：董监高的相关规定 ⭐⭐⭐⭐

### ① 任职资格的限制性规定（不得担任董监高）

| 情形 | 具体规定 |
|-|-|
| 非完全民事行为能力人 | 无/限制民事行为能力人 |
| "黑五类犯罪" | 因贪污、贿赂、侵占财产、挪用财产或破坏社会主义市场经济秩序被判刑：执行期满未逾 **5 年**；缓刑考验期满未逾 **2 年** |
| "因罪夺权" | 因犯罪被剥夺政治权利：执行期满未逾 **5 年** |
| "搞散公司且负个人责任" | 公司破产清算：经理/董事/厂长负个人责任，清算完结日起未逾 **3 年** |
| 吊销执照 | 公司违法被吊销执照/责令关闭，法定代表人负有个人责任，吊销之日起未逾 **3 年** |
| 失信被执行人 | 因所负数额较大债务到期未清偿被列为失信被执行人 |
| "不相容职务" | 董事、高级管理人员**不得兼任监事** |

**法律后果**：违反规定选举/委派/聘任**无效**；任职期间出现上述情形→公司应当**解除其职务**

### ② 董监高的忠勉义务
- **主体**：董事、监事、高级管理人员对公司负有忠实义务；**影子董事**（控股股东、实际控制人不任董事但实际执行公司事务）同样适用

**忠实义务（绝对禁止）：**
1. 侵占公司财产、挪用公司资金
2. 将公司资金以个人名义开立账户存储
3. 利用职权贿赂或收受其他非法收入
4. 接受他人与公司交易的佣金归为己有
5. 擅自披露公司秘密

**忠实义务（相对禁止，须报告+决议通过）：**

| 事项 | 程序性要求 |
|-|-|
| 自营/为他人经营同类业务 | 向董事会或股东会报告，按章程规定 |
| 关联方与本公司订立合同或交易 | 经董事会或股东会决议通过 |
| 利用职务便利谋取公司商业机会 | 公司不能利用的机会可径自利用 |

**相对禁止事项的决议办法：**
- 关联董事**不得参与表决**，其表决权不计入总数
- 出席董事会会议的无关联关系董事**不足 3 人**→提交股东会审议
- 违反忠实义务所得收入**归公司所有**（无论是否获利）

**勤勉义务：** 应股东会要求列席会议接受质询；如实向监事会提供情况资料

### ③ 违反忠勉义务的法律责任
- 董监高执行职务给他人造成损害→**公司**承担赔偿责任
- 董监高存在**故意或重大过失**→也承担赔偿责任
- 控股股东、实控人**指示**董监高从事损害行为→与该董监高承担**连带责任**
- 公司可投保**董事责任保险**

### 🎯 常考易错点
1. "董事任职期间成为失信被执行人的，公司应当解除其职务" → ✅（2025 判断 √）
2. 2021 年乙公司被吊销，赵某负个人责任，2025 年更换董事 → **未逾 3 年，不得担任**（多选 BCD 2025）
3. "执行公司事务的控股股东、实际控制人负忠实义务" → ✅（多选 ABC）
4. "经王某同意张某可自营同类业务" → ❌ 须**向董事会或股东会报告并经董事会或股东会决议**（单选 B）
5. "无正当理由长期不出席董事会会议" 涉嫌违反**勤勉**义务（单选 C 2023）；擅自披露秘密/个人账户存储/篡夺机会均违反**忠实**义务
6. 董监高违反忠实义务所得收入**归公司所有**（无论是否获利）（单选 D 2025）

> 📌 **真题印证**：习题第 106~125 题考董监高 → **任职资格限制、绝对/相对禁止、关联表决排除 = 必考**。
> 🔥 **记忆口诀**："黑五5年缓2年，破产3年吊销3年"；忠勉"报告+决议+排除+归公"。

## 📍 知识点 10：股东会、董事会决议的效力 ⭐⭐⭐

### ① 决议效力瑕疵类型
| 效力类型 | 情形 |
|-|-|
| **无效** | 决议**内容违反法律、行政法规** |
| **可撤销** | 会议召集程序/表决方式违反法律、行政法规或章程；或决议内容违反**公司章程**（轻微瑕疵且未实质影响→法院不予支持） |
| **不成立** | 出席人数/表决未达法定要求 |

### ② 诉讼列置
- 确认决议无效/不成立：股东、董事、监事等直接利害关系人；被告=公司
- 撤销决议：起诉时具有股东资格；被告=公司；共同原告=一审法庭辩论终结前以相同请求参加诉讼的其他股东

### ③ 撤销权行使时间
- **一般情形**：自决议作出之日起 **60 日内**
- **未被通知的股东**：①自知道或应当知道决议作出之日起 60 日内；②自决议作出之日起 **1 年内**未行使的撤销权消灭

### ④ 法律后果
- 决议被宣告无效/撤销/确认不成立→公司应申请撤销据此已办理的登记
- 公司根据该决议与**善意相对人**形成的民事法律关系**不受影响**

### 🎯 常考易错点
1. "决议内容违反法律→可撤销" → ❌ **无效**（多选 BCD 2023：程序违法/内容违章程→可撤销，内容违法→无效）
2. "3 名董事同意，占全体 7 名未过半数" → **决议不成立**（单选 A 2024）
3. 决议瑕疵之诉被告=**公司**（单选 D）
4. 会议召集程序/表决方式"仅有轻微瑕疵且未实质影响"→法院**不予支持**撤销（多选 D 2023）

> 📌 **真题印证**：习题第 126~135 题考决议效力 → **无效/可撤销/不成立区分 + 60日撤销权 = 必考**。

## 📍 知识点 11：冒名股东、名义股东和实际股东 ⭐

### ① 冒名股东
- 冒用他人名义出资并将他人登记为股东的，**冒名登记行为人**承担相应责任
- 请求被冒名登记的股东承担补足出资责任或赔偿责任→**不予支持**

### ② 股权代持协议
- **对内关系**：无无效情形→合同**有效**；实际出资人与名义股东按约定处理投资权益归属；名义股东以股东名册/登记机关登记为由否认实际出资人权利→不予支持
- **对外关系**：按**股东名册**处理（非合同相对人不需遵守代持协议）

### ③ 实际股东出资不实的处理
- 债权人请求**名义股东**（登记于登记机关的股东）承担补充赔偿责任→名义股东以"仅为名义股东"抗辩→**不予支持**
- 名义股东赔偿后可向实际出资人**追偿**

### ④ 名义股东的无权处分
- 名义股东处分登记于其名下的股权→第三人可依**善意取得**主张权利；实际出资人可请求名义股东赔偿

> 📌 **真题印证**：习题第 136~142 题考名义/实际股东 → **代持对内按约定、对外按名册、善意取得 = 常考**。

## 📍 知识点 12：股东权利 ⭐⭐⭐⭐⭐（极高考频）

### ① 股东权利分类
- **按行使目的**：共益权（参与管理：表决权、提案权、质询权、查阅权、诉权）/ 自益权（获得收益：股利分配、剩余财产分配、新股认购优先权、股份转让权）
- **按行使条件**：单独股东权（一股即可）/ 少数股东权（持股达一定比例，如提议召开临时股东会）

### ② 滥用股东权利
- 股东滥用股东权利给公司或其他股东造成损失→承担**赔偿责任**

### ③ 法人人格否认制度（🔥 必考）

| 否认类型 | 情形与责任 |
|-|-|
| **纵向否认** | 股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害债权人利益→对公司债务承担**连带责任** |
| **横向否认** | 股东利用控制的两个以上公司实施上述行为→各公司对任一公司的债务承担连带责任 |
| **其他否认** | 一人公司股东不能证明公司财产独立于股东自己财产的→对公司债务承担连带责任 |

### ④ 股东查阅权（🔥 对比必考）

**查阅/复制范围：**

| 资料 | 有限责任公司 | 股份有限公司 |
|-|-|-|
| 股东会会议记录、章程、财报、股东名册、董事会/监事会会议决议 | 查阅+复制（任一股东） | 查阅+复制（任一股东） |
| **会计账簿、会计凭证** | 查阅（**不能复制**）（任一股东） | 查阅（**不能复制**）（连续 180 日+单独或合计 3% 以上股份股东） |

**查阅会计账簿/凭证的细节：**
- 应当向公司提出**书面请求**，说明目的
- 公司有合理根据认为有不正当目的→可拒绝，并自提出请求之日起 **15 日内**书面答复说明理由
- **不正当目的**：①自营/为他人经营与公司主营业务有实质性竞争关系业务（章程/约定除外）；②为向他人通报信息查阅可能损害公司利益；③请求前 3 年内曾通过查阅向他人通报信息损害公司利益
- **辅助查阅**：可委托会计师事务所、律师事务所等中介机构进行
- **保密义务**：查阅复制应遵守保护国家秘密、商业秘密、个人隐私、个人信息的规定

### ⑤ 股东直接诉讼 vs 股东代表诉讼

**股东直接诉讼：** 董监高损害**股东个人利益**→股东以自己名义直接起诉侵害方

**股东代表诉讼：**

| 项目 | 规定 |
|-|-|
| 受害利益 | 公司利益 |
| 董高侵害 | 股东书面请求**监事会**起诉（监事侵害→书面请求**董事会**） |
| 前置程序 | 受请求方拒绝 / 收到请求 30 日内未起诉 / 情况紧急 |
| 股东资格（有限） | 任一股东 |
| 股东资格（股份） | 连续 180 日以上单独或合计持有 **1%** 以上股份 |
| 胜诉利益 | **归公司**（费用由公司承担） |

**双重股东代表诉讼：** 全资子公司董事/高管/他人侵害**全资子公司**利益→母公司股东书面请求全资子公司监事会（或董事会）起诉无果后，可代全资子公司起诉（母公司任一股东/符合条件的股份股东）

### ⑥ 有限责任公司股东转让股权

| 转让类型 | 规定 |
|-|-|
| **内部转让** | 股东之间可相互转让（章程另有规定除外） |
| **外部转让** | 应当将转让数量、价格、支付方式、期限**书面通知**其他股东，其他股东在同等条件下有**优先购买权**；股东自接到通知之日起 **30 日**未答复→视为放弃；两个以上股东行使→协商比例，协商不成按转让时各自出资比例 |
| **强制执行** | 应通知公司及全体股东；其他股东自人民法院通知之日起满 **20 日**不行使→视为放弃 |
| **继承** | 自然人股东死亡，合法继承人可继承股东资格（章程另有规定除外）；其他股东不得主张优先购买权（另有约定除外） |

**股权转让后的程序：** 书面通知公司请求变更股东名册；受让人自**记载于股东名册时**起可向公司主张行使股东权利

### ⑦ 异议股东的回购请求权（🔥 必考）

**回购情形：** ①公司连续 **5 年**不分配利润而连续盈利且符合分配条件；②公司合并、分立、转让主要财产；③章程规定营业期限届满或解散事由出现，股东会通过决议修改章程使公司存续

**回购程序：** 股东会决议作出之日起 **60 日内**不能达成股权收购协议→股东可自决议作出之日起 **90 日内**向人民法院提起诉讼；公司收购的本公司股权应在 **6 个月内**依法转让或注销

> 🔥 **记忆口诀**："连盈五年不分红，合并分立转财产，规定解散还存续，股东反对可离去"

### 🎯 常考易错点
1. 自益权=剩余财产分配权（单选 C 2025）；质询权/知情权/累积投票权属共益权
2. "滥用法人独立地位逃避债务损害债权人→连带责任" → ✅（判断 √）
3. "有限责任公司股东有权复制会计账簿" → ❌ 只能**查阅不能复制**（多选 A 不当选）
4. 股份公司股东可复制**股东名册**（单选 B 2024）
5. 查阅会计账簿可委托**会计师事务所、律师事务所**辅助（多选 CD 2024）
6. 不正当目的举证责任在**公司**（单选 A 2024 说股东举证 → 错误）
7. 股东代表诉讼被告=**侵权人**，公司=第三人（单选 D）
8. 双重股东代表诉讼：全资子公司利益受损→母公司股东可代子公司起诉（多选 AB 2025、多选 ABC）
9. 股份公司股东代表诉讼须连续 180 日+1%（多选 AD 2024：连续 240 日 1.2%、连续 200 日 3% 符合）
10. 受让人自**记载于股东名册时**起可主张行使股东权利（单选 D 2024）
11. 外部转让不需征得其他股东**同意**，只须**书面通知**（多选 A 2024 正确）
12. 强制执行股权：乙 15 日行使优先购买权→可行使；丙 30 日→视为放弃（单选 B 2024）
13. 继承：章程无规定→继承人可直接继承股东资格，其他股东**不得**主张优先购买权（单选 B 2022）

> 📌 **真题印证**：习题第 143~175 题全考股东权利 → **法人人格否认、查阅权、代表诉讼、股权转让、回购请求权 = 必考**。

# 🧩 第三单元 股份有限公司

## 📍 知识点 1：股份有限公司的设立 ⭐⭐⭐

### ① 设立方式

| 设立方式 | 具体规定 |
|-|-|
| **发起设立** | 发起人认购设立时应发行的全部股份 |
| **募集设立** | 发起人认购设立时应发行股份的一部分（≥股份总数 **35%**），其余向特定对象募集或公开募集 |

> 提示：有限责任公司只能发起设立。

### ② 设立条件
- **发起人**：1 人以上 **200 人**以下；自然人/法人均可、中国/外国公民均可；**半数以上**发起人在中国境内有住所
- **认购股份**：发起设立须认足全部股份；募集设立发起人认购不得少于应发行股份总数 **35%**
- **缴足股款**：发起人在公司成立前按其认购股份全额缴纳股款
- **法律后果**：发起人不按认购股份缴纳股款/非货币财产实际价额显著低于所认购股份→其他发起人与其在出资不足范围内承担**连带责任**
- **募集限制**：发起人认购的股份缴足前，不得向他人募集股份

### ③ 章程制定主体
- 发起设立：由**发起人共同制订**
- 募集设立：发起人共同制订 + **成立大会通过**

### ④ 资本制度
- **实缴资本制**：注册资本=已发行股份的股本总额（法律/行政法规另有规定除外）
- **验资**：向社会公开募集股份的股款缴足后，应当经依法设立的验资机构验资并出具证明
- **变性**：有限变股份时，折合的实收股本总额**不得高于**公司净资产额
- **授权资本制**：章程或股东会可授权董事会在 **3 年内**决定发行不超过已发行股份 **50%** 的股份；以非货币财产出资应经股东会决议；董事会决议应经全体董事 **2/3** 以上通过

### ⑤ 募集设立中的成立大会
- 股款缴足之日起 **30 日内**召开；发起人在成立大会召开 **15 日前**通知各认股人或公告
- **出席**：应有持有表决权**过半数**的认股人出席
- **职权**：审议筹办报告、通过章程、选举董监、审核设立费用、审核非货币出资作价、决定不设立公司
- **决议**：经出席会议的认股人所持表决权**过半数**通过

### ⑥ 募集设立失败
- **失败原因**：①股份未募足；②股款缴足后 30 日内未召开成立大会；③成立大会作出不设立决议
- **法律后果**：可按照所缴股款并加算**银行同期存款利息**要求发起人返还
- 发起人、认股人缴纳股款/交付非货币出资后，除募集设立失败外**不得抽回股本**

### 🎯 常考易错点
1. "有限责任可募集设立" → ❌ 只能**发起设立**（2023 判断 ×）
2. "发起人只能自然人/最低 2 人/只能中国公民" → ❌ 1~200 人、可法人、可外国公民（单选 C）
3. "发起设立注册资本=全体股东认缴出资额" → ❌ 股份实行**实缴资本制**（判断 ×）
4. "募集设立只能在特定范围募集，不得公开募集" → ❌ 可向社会**公开募集**（经证监会注册）（单选 D 2025 不当选）
5. 授权资本制：3 年、50%、非货币出资经股东会决议、董事会 2/3 通过（多选 ABD）

> 📌 **真题印证**：习题第 176~190 题考股份设立 → **发起人1-200人、35%、实缴+授权资本制、成立大会 = 必考**。

## 📍 知识点 2：股份有限公司股东会的会议制度 ⭐⭐⭐⭐

### ① 定期（年度）会议召开时间
- 非上市公司：**每年召开一次**
- 上市公司：上一会计年度结束后的 **6 个月内**举行

### ② 临时会议召开情形（2 个月内召开）
1. 董事人数不足 3 人，或少于公司章程所定人数的 **2/3** 时
2. 公司未弥补亏损达股本总额的 **1/3** 时
3. 董事会认为必要时
4. 监事会提议召开时
5. 单独或合计持有公司 **10%** 以上股份的股东请求时

> 🔥 **记忆口诀**："董事少三少六七，亏达股本三分一，董会监会提议开，十一股东两月嗨"

### ③ 召集与主持
- 由**董事会**召集，董事长主持；董事长不能履职→副董事长→过半数董事推举 1 名
- 连续 **90 日**以上单独或合计持有公司 **10%** 以上股份的股东可自行召集主持

### ④ 通知
- 年会：会议召开 **20 日**前通知各股东（公开发行股份的公司以公告方式通知）
- 临时会议：**15 日**前通知
- 股东会**不得**对通知中未列明的事项作出决议

### ⑤ 临时提案权
- 单独或合计持有 **1%** 以上股份的股东，可在会议召开 **10 日**前提出临时提案并书面提交董事会
- 临时提案应有明确议题和具体决议事项
- 董事会应在收到提案后 **2 日内**通知其他股东并提交股东会审议
- 公司**不得提高**提出临时提案股东的持股比例

### ⑥ 决议办法
- **普通决议**：出席会议的股东所持表决权**过半数**通过
- **表决权计算**：每一股份一表决权（类别股除外）；公司持有的本公司股份**没有表决权**
- **特别决议**：出席会议的股东所持表决权 **2/3 以上**通过（修改章程、增减注册资本、合并分立变更形式解散）

### ⑦ 其他规定
- **代理出席**：应当明确代理事项、权限和期限；提交授权委托书
- **累积投票制**：每一股份拥有与应选董事/监事人数相同的表决权，可集中使用；上市公司选举 2 名以上独立董事应实行累积投票制
- **会议记录**：主持人、出席会议的董事签名；与股东签名册、委托书一并保存

### 🎯 常考易错点
1. 上市公司年会须在上一会计年度结束后 **6 个月内**（单选 A：2024.6.15 符合）
2. 临时提案权持股比例=**1%**（单选 D）
3. "董事会提议临时股东会" → ❌ 是"**董事会认为必要**"，非董事会提议；监事会提议可以（单选/多选）
4. "修改章程须经出席会议 2/3 以上股东通过" → ❌ "出席会议的股东**所持表决权** 2/3 以上"（判断 ×）
5. 累积投票制：100 万股 × 9 名董事 = **900 万票**（单选 A）
6. "股东会可对通知中未列明事项作出决议" → ❌ **不得**（单选 D 不当选）
7. 临时会议触发：董事不足章程 2/3（单选 B：章程 30 人、实有 19 人<20 → 应召开）；5% 股东提议不够 10%；单监事提议不行；亏损未达 1/3 不需召开

> 📌 **真题印证**：习题第 191~210 题考股份股东会 → **临时会议触发、决议2/3、累积投票、提案权 = 必考**。

## 📍 知识点 3：股份有限公司的董事会（对比版） ⭐⭐⭐⭐

**与有限责任公司相比，股份公司董事会的差异：**

| 要点 | 有限责任公司 | 股份有限公司 |
|-|-|-|
| 董事长产生 | 由章程规定 | 由董事会以全体董事**过半数**选举产生 |
| 定期会议 | —— | 每年度至少 **2 次**，每次 **10 日前**通知 |
| 临时会议 | —— | 代表 1/10 表决权股东/1/3 董事/监事会提议，董事长 10 日内召集主持 |
| 代理出席 | —— | 可书面委托其他董事代为出席，委托书载明授权范围 |
| 免责规定 | —— | 决议违法致公司严重损失→参与决议董事赔偿；表决时**表明异议并记录**的免除责任 |
| 会议记录 | 出席董事签名 | 出席董事签名 |

**记忆口诀：** 董事会决议违反法律→参与董事担责，异议并记录可免责。

### 🎯 常考易错点
1. "2 名监事可提议召开临时董事会" → ❌ 须**监事会**提议（单选 C 不当选）
2. "2 名董事可提议" → ❌ 须 **1/3 以上**董事（≥3 人）（单选 A 不当选）
3. "董事长副董事长不能履职时由 4 名董事推举" → ❌ 须**过半数**董事（≥5 人）推举（单选 B 不当选）
4. 免责：戊表明异议并记录→免除责任；庚未出席也免除（单选 D：仅甲、乙、丙、丁担责）

> 📌 **真题印证**：习题第 211~220 题考股份董事会 → **临时会议、代理出席、异议免责 = 高频**。

## 📍 知识点 4：经理 ⭐

- **必要性**：股份有限公司、国有独资公司**应当**设置经理；有限责任公司可以设置
- **聘解主体**：由董事会决定聘任/解聘；董事会可决定董事会成员兼任经理
- **对谁负责**：对**董事会**负责
- **列席**：经理**应当**列席董事会会议

> 📌 **真题印证**：2024 多选 → **股份/国有独资应当设经理 = 常考**。

## 📍 知识点 5：审计委员会 ⭐⭐⭐

| 要点 | 有限责任公司 | 股份有限公司 |
|-|-|-|
| 设置 | 董事会可按章程规定设置行使监事会职权的审计委员会 | 同左 |
| 成员 | 由董事组成；职工代表可成为成员 | 3 名以上；过半数成员不得任董事以外职务且无利害关系 |
| 决议 | 一人一票；经**过半数**成员通过 | 同左 |

> 设置审计委员会行使监事会职权的，**不设监事会或监事**。
> 📌 **真题印证**：2025 多选 → **过半数成员独立、3名以上 = 必考**。

## 📍 知识点 6：股份有限公司的监事会（对比版） ⭐⭐⭐

**与有限责任公司相比，股份公司监事会的差异：**
- **副主席**：可设副主席
- **会议频率**：每 **6 个月**至少召开 1 次（有限每年度至少 1 次）
- **召集主持**：主席→副主席→过半数监事推举 1 名监事

其余（职权、成员 3 人以上、董事高管不得兼任、任期 3 年、决议过半数）与有限相同。

> 📌 **真题印证**：2023 多选 → **职工代表1/3、总经理不得兼任监事、设主席、成员≥3 = 常考**。

## 📍 知识点 7：股份 ⭐⭐⭐⭐⭐（极高考频）

### ① 股票种类
- **面额股 vs 无面额股**：全部股份依章程**择一采用**；可依章程将面额股全部转无面额股或反之
- **面额股**：每一股金额相等；发行价格可平价/溢价，但**不得低于票面金额**
- **无面额股**：所得股款至少应将股款的 **1/2** 计入注册资本

### ② 普通股与类别股

| 类别股 | 含义 |
|-|-|
| **优先股** | 优先于普通股分配利润或剩余财产 |
| **劣后股** | 劣后于普通股分配利润或剩余财产 |
| **特殊表决权股** | 每股表决权数多于/少于普通股（公开发行公司不得发行此两类，但公开发行前已发行的除外） |
| **转让受限股** | 转让须经公司同意等 |

**类别股公司章程载明事项**：①分配利润/剩余财产顺序；②表决权数；③转让限制；④保护中小股东权益措施；⑤股东会认为需要规定的其他事项

**分类表决**：发行类别股的公司，修改章程/增减注册资本/合并分立变更形式解散等事项，除经出席会议股东所持表决权 **2/3** 以上通过外，还应当经出席会议的**类别股股东**所持表决权 **2/3** 以上通过

### ③ 优先股具体规定
- 优先于普通股分配利润和剩余财产，但参与公司决策管理等权利受限
- 上市公司发行优先股核心条件：最近 **3 个会计年度**年均分配利润不少于优先股 1 年股息
- 已发行优先股不得超过普通股股份总数的 **50%**，且筹资金额不得超过发行前净资产的 **50%**
- 向不特定对象发行优先股须：固定股息率、有可分配利润时必须分配、差额累积到下一会计年度、按约定股息率分配后不再参与剩余利润分配

### ④ 股票发行
- 股票采用纸面形式或证监会规定的其他形式
- 公司成立后即向股东交付股票；成立前不得交付
- **同股同权**（同类别股份同等权利）+ **同股同价**（同次发行同类别股份每股条件价格相同）

### ⑤ 股份转让
- 股东可向其他股东或股东以外的人转让；章程有限制从其规定
- 转让应在依法设立的证券交易场所或按国务院规定方式进行；以**背书方式**转让
- 股东会会议召开前 **20 日内**或分配股利基准日前 **5 日内**，不得变更股东名册
- 自然人股东死亡后合法继承人可继承股东资格

### ⑥ 法定股份转让限制

**对"原始股"：** 公司公开发行股份前已发行的股份，自公司股票在证券交易所上市交易之日起 **1 年内**不得转让

**对董监高：**
1. 所持本公司股份自上市交易之日起 **1 年内**不得转让
2. 任职期间每年转让不得超过所持股份总数的 **25%**
3. 离职后**半年内**不得转让
4. 章程可作其他限制

**上市公司董监高股份变动管理（🆕2026 新增）：**
- 不得转让情形：①上市交易之日起 1 年内；②离职后半年内；③被立案调查/处罚未满 6 个月；④被公开谴责未满 3 个月；⑤可能触及重大违法强制退市在限制转让期限内等
- "25%"细化：以**上年年末**所持股份总数为基数；所持 ≤1000 股可一次全部转让；司法强制执行、继承、遗赠、分割财产等不受 25% 限制
- **禁止买卖窗口期**：①年报/半年报公告前 **15 日**；②季报/业绩预告/快报公告前 **5 日**；③重大事件发生至披露日；④证交所规定的其他期间

### ⑦ 股份质押
- 公司**不得接受**本公司的股份作为质权的标的
- 在限制转让期限内出质的，质权人**不得**在限制转让期限内行使质权

### ⑧ 异议股东回购请求权（对比版）
- 股份有限公司（公开发行股份的股份公司**不适用**）少了"合并、分立"，只保留"转让主要财产"
- 回购程序同有限（60 日协议不成 90 日可诉）

### ⑨ 公司收购本公司股份（🔥 必考）

| 收购情形 | 决议机关 | 收购股份处理 |
|-|-|-|
| 与持有本公司股份的其他公司合并 | 股东会 | 6 个月内转让或注销 |
| 股东对合并/分立决议持异议要求收购 | 无（被动回购） | 6 个月内转让或注销 |
| 减少注册资本 | 股东会 | 10 日内注销 |
| 员工持股/股权激励 | 股东会或 2/3 以上董事出席的董事会决议 | 3 年内转让或注销；合计持有≤已发行股份 **10%** |
| 转换可转换公司债券/维护价值及股东权益 | 同上 | 同上 |

> 🔥 **记忆口诀**："合意见，励可维，610,310"（合并/异议→6个月；减资→10日注销；激励/转债/维护→3年+10%）

### 🎯 常考易错点
1. "面额股发行价格可以低于票面金额" → ❌ 不得低于票面（2025 判断 ×）
2. 无面额股所得股款至少 **1/2** 计入注册资本（单选 C）
3. "股份公司全部股份应当采用无面额股" → ❌ 依章程**择一采用**（单选 A 不当选）
4. 监事赵某 2025 年 6 月转让 20% → ❌ 上市交易 1 年内不得转让（2024 多选 A 不当选）
5. 董事钱某所持 888 股一次全部转让 → ✅ ≤1000 股不受 25% 限制（多选 B）
6. 总经理李某 2026 年 1 月离职、2026 年 3 月转让 5% → ❌ 离职**半年内**不得转让（多选 C 不当选）
7. 年报公告后 15 日内转让 → ❌ 年报公告前 15 日内禁止买卖（多选 D 不当选）
8. "公司可接受本公司股份作为质权标的" → ❌ 不得（判断 × 2024）
9. 异议股东回购股份 6 个月内转让/注销（单选 C）
10. 维护价值收购：3 年内转让或注销、合计≤10%、2/3 董事出席董事会决议、公开集中交易方式（多选 ABD）
11. "财务资助累计总额可超已发行股本总额 20%" → ❌ **10%**（2024 单选 C 不当选）

# 🧩 第四单元 上市公司的特别规定

## 📍 知识点 1：上市公司各个组织机构的特殊规定 ⭐⭐⭐

### ① 股东会特有的特别决议事项
- **事项**：上市公司在 1 年内购买、出售重大资产或向他人提供担保的金额**超过公司资产总额 30%**
- **决议主体**：股东会
- **决议办法**：经出席会议的股东所持表决权 **2/3 以上**通过

### ② 上市公司董事会秘书
- 董事会秘书是上市公司**高级管理人员**
- 职责：负责股东会和董事会会议筹备、文件保管、股东资料管理、信息披露事务
- 是董事会设置的**服务席位**，既不能代表董事会，也不能代表董事长

### ③ 上市公司关联董事的表决权排除制度（所有事项）
- 关联董事应及时向董事会书面报告
- 关联董事**不得**行使表决权，也**不得代理**其他董事行使表决权
- 由**过半数无关联关系董事**出席即可举行，决议须经**无关联关系董事过半数**通过
- 出席董事会会议的无关联关系董事**不足 3 人**→提交上市公司股东会审议

### ④ 上市公司股东持股要求
- 应当依法披露股东、实际控制人信息
- 禁止违反规定**代持**上市公司股票
- 上市公司控股子公司**不得**取得该上市公司的股份；因合并、质权行使等原因取得的，不得行使表决权，应及时处分

### 🎯 常考易错点
1. "董事会秘书可以代表董事长/董事会" → ❌ 是**服务席位**，不能代表（单选 C）
2. 关联董事排除：全体无关董事（11-2=9 名）过半数 = **5 票**（单选 A：8 名出席、2 名关联、1 名未委托）

> 📌 **真题印证**：习题第 261~270 题考上市公司组织机构 → **特别决议、董秘地位、关联表决排除 = 必考**。

## 📍 知识点 2：独立董事制度 ⭐⭐⭐⭐（🆕2026 新增较多）

### ① 独立董事概念
- 不在上市公司担任除董事外的其他职务，并与其所受聘上市公司及其主要股东、实际控制人**不存在直接或间接利害关系**或其他可能影响独立客观判断关系的董事

### ② 设置要求
- 独立董事占董事会成员比例**不得低于 1/3**，且至少包括 **1 名会计专业人士**
- **审计委员会**：成员应为不在上市公司担任高级管理人员的董事，其中独立董事应**过半数**，并由独立董事中会计专业人士担任召集人
- **决议前须经审计委员会全体成员过半数通过的事项**：①聘用/解聘会计师事务所；②聘任/解聘财务负责人；③披露财务会计报告
- 提名委员会、薪酬与考核委员会中独立董事应**过半数**并担任召集人

### ③ 独立董事职责
- **基本职责**：参与决策发表明确意见、对重大利益冲突事项监督、提供专业客观建议
- **辅助职权（🆕2026）**：下列事项应经**全体独立董事过半数同意**后提交董事会审议：①应披露的关联交易；②变更/豁免承诺方案；③被收购公司董事会针对收购所作决策及措施
- **特别职权**：独立聘请中介机构、提议召开临时股东会/董事会、依法公开征集股东权利、对损害中小股东权益事项发表独立意见（行使前三项须经全体独立董事过半数同意）

### ④ 履职方式（🆕2026）
- **会前沟通**：可与董事会秘书沟通，要求补充材料
- **出席要求**：应亲自出席；连续两次未亲自出席也不委托其他独董代为出席→董事会应在 **30 日内**提议召开股东会解除职务
- **异议处理**：投反对/弃权票应说明理由；上市公司披露决议时同时披露独董异议意见
- **独立董事专门会议**：由过半数独董推举 1 名召集主持
- **履职时间**：每年在上市公司现场工作时间**不少于 15 日**

### ⑤ 任职条件
- 具备担任上市公司董事资格
- 具有 **5 年以上**履行独立董事职责所必需的法律、会计或经济等工作经验
- 原则上最多在 **3 家**境内上市公司担任独立董事（🆕2026）
- 符合独立性要求、良好品德、具备上市公司运作知识

### ⑥ 不得担任独立董事（"不独立"情形）
1. **与上市公司有利害关系**：目前或最近 **12 个月**内在上市公司或附属企业任职（含配偶、父母、子女、主要社会关系）
2. **与主要自然人股东有利害关系**：目前或最近 12 个月内直接/间接持有上市公司已发行股份 **1%** 以上或是前 **10 名**股东中的自然人股东（及其配偶、父母、子女）
3. **与主要单位股东有利害关系**：在直接/间接持有已发行股份 **5%** 以上或前 **5 名**股东任职（及其配偶、父母、子女）
4. **与控股股东/实控人有利害关系**：在控股股东、实控人附属企业任职（及其配偶、父母、子女）
5. **其他利害关系**：有重大业务往来、为上市公司提供服务的中介机构人员等

### ⑦ 聘任程序（🆕2026）
- **提名**：董事会、单独/合计持股 **1%** 以上股东可提出独立董事候选人，经股东会选举；投资者保护机构可公开请求股东委托代为提名
- **选举**：上市公司股东会选举 **2 名以上**独立董事应实行**累积投票制**
- **任期**：与公司其他董事任期相同，连任**不得超过 6 年**
- **辞职/补选**：辞职致独董比例不符或欠缺会计专业人士→应继续履职至新任独董产生，上市公司自辞职之日起 **60 日内**完成补选

### 🎯 常考易错点
1. "独立董事可在上市公司附属企业任职" → ❌ 最近 12 个月内在上市公司或附属企业任职的**不得**担任（2025 多选 A 不当选）
2. "独立董事占比不低于 1/3" → ✅（2025 多选 B）
3. "审计委员会独立董事不低于 1/2" → ❌ 应**过半数**（＞1/2）（2025 多选 C 不当选）
4. "审计委员会由独立董事中的会计专业人士担任召集人" → ✅（2025 多选 D）
5. 被吊销执照公司法定代表人负个人责任未逾 3 年、失信被执行人、为上市公司附属企业提供法律顾问、上市公司董事的弟弟 → 均无资格担任独董（多选 ABCD 2023）

> 📌 **真题印证**：习题第 271~295 题考独立董事 → **占比1/3、任职"不独立"情形、审计委员会、辅助职权 = 必考**。

# 🧩 第五单元 国家出资公司的特别规定

## 📍 知识点 1：国家出资公司的界定 ⭐

- **特征**：遵循《公司法》+ 国家**绝对控股** + 国家**直接出资**设立
- **属于**：国有独资公司 + 国有资本控股公司（有限责任公司/股份有限公司）
- **不属于**：国有独资企业 + 国有资本参股公司 + 国家出资公司再投资设立的公司

## 📍 知识点 2：国有独资公司的特殊规定 ⭐⭐⭐

### ① 组织机构的特殊规定

| 要点 | 具体规定 |
|-|-|
| **股东会** | 国有独资公司**不设股东会**，由履行出资人职责的机构行使股东会职权；章程由该机构制定 |
| **董事会** | 应当设董事会；成员**过半数为外部董事**，并应当有公司职工代表 |
| 成员产生 | 一般成员由履行出资人职责的机构**委派**；职工代表由职工代表大会选举产生 |
| **董事长** | 设董事长 1 人，可设副董事长，均由履行出资人职责的机构从董事会成员中**指定** |
| **经理** | 由董事会聘任/解聘；经履行出资人职责的机构同意，董事会成员可兼任经理 |
| **兼职限制** | 董监高未经机构同意，不得在其他经济组织兼职（无论是否竞争业务） |
| **审计委员会** | 设审计委员会行使监事会职权的，不设监事会或监事 |

### ② 重大事项的决定权
- **应当由履行出资人职责的机构决定**：公司章程制定修改 + 增减注册资本 + 合并 + 分立 + 解散 + 申请破产 + 分配利润
- 其他权力机构职权内的重大事项，机构可**授权公司董事会**行使部分职权

### 🎯 常考易错点
1. "国有独资公司设股东会" → ❌ 不设股东会（单选 B 不当选）
2. "董事长、副董事长由履行出资人职责的机构从董事会成员中指定" → ✅（单选 C 2025）
3. "所有董事会成员均由机构委派" → ❌ 职工代表由职工代表大会选举产生（单选 D 不当选）
4. "未经董事会同意董事可兼任经理" → ❌ 须经**履行出资人职责的机构**同意（多选 A 不当选）
5. "监事会成员可以为 3 人" → ✅（多选 C）
6. "董事会成员可以没有职工代表" → ❌ 应当有职工代表且外部董事**过半数**（多选 D 不当选）
7. "减少注册资本可授权董事会行使" → ❌ 应由履行出资人职责的机构决定（单选 A 2025 不当选）
8. "发行公司债券可授权董事会" → ✅（单选 B 2025）

> 📌 **真题印证**：习题第 296~310 题考国有独资公司 → **不设股东会、重大事项决定权、兼职限制 = 必考**。

# 🧩 第六单元 其他考点

## 📍 知识点 1：公司债券 ⭐

### ① 基本规定
- 公司债券应当为**记名债券**
- 可公开发行，也可非公开发行；公开发行须经**中国证监会注册**，公告募集办法
- 发行公司债券应置备**债券持有人名册**

### ② 债券转让
- 可转让，转让价格由转让人与受让人约定
- 以**背书方式**或其他方式转让
- 转让后由公司将受让人姓名或名称及住所记载于名册

### ③ 可转换公司债券
- 股份有限公司经**股东会决议**或经授权董事会决议，可发行可转换为股票的公司债券
- 上市公司发行可转债应经证监会注册
- 债券持有人对转换或不转换有**选择权**

### ④ 债券持有人会议与受托管理人
- 公开发行债券的，应为同期债券持有人设立**债券持有人会议**
- 债券持有人会议决议对同期全体债券持有人发生效力
- 公开发行的，发行人应为债券持有人聘请**受托管理人**；发行人未按期兑付本息，受托管理人可代表债券持有人提起/参加诉讼

> 📌 **真题印证**：公司债券考点整体低频，重点记住"记名债券 + 证监会注册 + 持有人会议/受托管理人"。

## 📍 知识点 2：公司的合并 ⭐⭐⭐⭐⭐（高）

### ① 合并类型与效果
| 类型 | 形态 |
|-|-|
| **吸收合并** | A＋B＝A |
| **新设合并** | C＋D＝E |
| **效果** | 合并各方债权债务由合并后存续/新设公司**承继** |

### ② 合并程序
1. 合并各方签订合并协议
2. 编制资产负债表及财产清单
3. 股东会作合并决议（有限代表 2/3 以上；股份出席会议股东所持表决权 2/3 以上）
4. 自作出决议之日起 **10 日内**通知债权人，**30 日内在报纸或国家企业信用信息公示系统公告**；债权人自接到通知 30 日内、未接到通知自公告 45 日内，可要求公司清偿债务或提供担保
5. 办理公司变更登记

### ③ 简易合并
- **"九零合并"**：公司与其持股 **90%** 以上的公司合并，被合并公司**不需经股东会决议**，但应通知其他股东，其他股东有权请求按合理价格收购其股权或股份
- **"壹零合并"**：公司合并支付的价款**不超过本公司净资产 10%** 的，可**不经股东会决议**（章程另有规定除外）
- 上述简易合并不经股东会决议的，应当经**董事会决议**

> 🔥 **记忆口诀**："十通三告三接到，未接四五快冒泡"（10日通知、30日公告、接到30日、未接到45日）

### 🎯 常考易错点
1. "股份有限公司合并须经代表 2/3 以上表决权股东通过" → ❌ 须经"出席会议的股东所持表决权 2/3 以上"（单选 C 2025 不当选）
2. "九零合并"：甲公司持乙 90%，吸收合并乙 → 乙不需股东会决议但应通知丙股东、丙可请求回购、债权债务由甲承继（多选 ABD 2024）
3. "甲公司持乙 95%，吸收合并 → 甲、乙都不需股东会决议" → ❌ 被合并公司乙不需股东会决议，但需**董事会决议**（单选 B 2023）
4. "甲公司持乙 65%、支付价款 3 亿占净资产 16.3%" → 未达 90%、价款超 10% → 甲、乙都需**股东会决议**（单选 A）
5. 债权人在接到通知 **30 日内**、未接到通知自公告 **45 日内**可要求清偿或担保

> 📌 **真题印证**：习题第 311~330 题考合并 → **合并程序、九零/壹零简易合并 = 必考**。

## 📍 知识点 3：公司的分立 ⭐⭐⭐

### ① 分立类型与效果
| 类型 | 形态 |
|-|-|
| **派生分立** | 甲公司＝甲公司＋乙公司 |
| **新设分立** | 丙公司＝丁公司＋戊公司 |
| **效果** | 分立前债务由分立后公司承担**连带责任**（分立前与债权人就债务清偿达成书面协议另有约定的除外） |

### ② 分立程序
1. 签订分立协议
2. 编制资产负债表及财产清单
3. 作出分立决议（同合并）
4. 自作出决议之日起 **10 日内**通知债权人，**30 日内在报纸或公示系统公告**
- **注意**：分立中债权人**不享有**请求清偿债务或提供担保的权利

### 🎯 常考易错点
1. "丁公司仅能请求乙公司承担 20%/丙公司承担 80%" → ❌ 可请求乙、丙公司承担**连带责任**（单选 C）
2. 分立债权人**不享有**清偿/担保请求权（与合并不同）

> 📌 **真题印证**：习题第 331~340 题考分立 → **债务连带 + 债权人不享清偿担保权 = 必考**。

## 📍 知识点 4：公司的减资与增资 ⭐⭐⭐⭐

### ① 减资程序
1. 作出减资决议（同合并）
2. 编制资产负债表及财产清单
3. 自作出决议之日起 **10 日内**通知债权人，**30 日内在报纸或公示系统公告**；债权人 30 日/45 日内可要求清偿或担保（"减资补亏除外"）
4. 依法办理变更登记

**违法减资的法律后果**：股东应退还收到的资金，减免出资的应恢复原状；给公司造成损失，股东及负有责任董监高承担赔偿责任

### ② 减资比例
- **以等比例为原则，以非等比例为例外**（法律另有规定、有限全体股东另有约定或股份章程另有规定除外）

### ③ 减资补亏（"简易减资制度"）
- **适用情形**：依法以税后利润、公积金弥补亏损后仍有亏损的，可减少注册资本弥补亏损
- **简易之处**：债权人**无权**要求清偿债务或提供担保，但应自股东会作出减资决议之日起 **30 日内**在报纸或公示系统公告
- **限制**：减资补亏时公司**不得向股东分配**，也**不得免除**股东缴纳出资或股款义务
- **减资后**：在法定公积金和任意公积金累计额达到公司注册资本 **50% 前**，不得分配利润

### ④ 增资中股东的优先认缴/购权
- **有限责任公司**：股东在同等条件下有权优先按**实缴出资比例**认缴（全体股东另有约定除外）
- **股份有限公司**：股东**不享有优先认购权**（章程或股东会决议另有规定的除外）

### 🎯 常考易错点
1. "减资应于 8 月 20 日前通知债权人（7月21日决议）" → ❌ 应于 **7 月 31 日前**（决议作出 10 日内）通知债权人（单选 B 2024 不当选）
2. 减资补亏：**不需通知债权人**、不得向股东分配、不得免除出资义务、减资后盈余公积金达注册资本 50% 前不得分配利润（多选 BCD 2024）
3. 减资比例：以**等比例**为原则

> 📌 **真题印证**：习题第 341~355 题考减资增资 → **减资程序、减资补亏、优先认缴 = 必考**。

## 📍 知识点 5：公司的解散 ⭐⭐⭐

### ① 三组概念
- **解散**：不再继续开展经营活动
- **清算**：资产－负债＝所有者权益
- **破产**：不能清偿到期债务且资不抵债，可申请破产

> 提示：公司除因**合并、分立**而解散外，因其他原因解散的应当**清算**。

### ② 解散事由
1. 章程规定的营业期限届满或解散事由出现（可修改章程或经股东会决议存续）
2. 股东会决议解散
3. 因公司合并、分立需要解散（**无需清算**）
4. 依法被吊销营业执照、责令关闭或被撤销
5. 人民法院依法予以解散（解散诉讼）

> 公司出现解散事由，应在 **10 日内**通过国家企业信用信息公示系统公示

### ③ 解散公司诉讼
- **提起**：单独或合并持有公司全部股东表决权 **10% 以上**的股东
- **被告**：公司
- **应当受理情形**：①持续 2 年以上无法召开股东会，经营管理严重困难；②股东表决无法达到法定/章程比例，持续 2 年以上不能作出有效决议；③董事长期冲突无法通过股东会解决；④其他严重困难
- **不予受理**：①以知情权、利润分配请求权等受损为由；②以公司亏损、财产不足以偿还全部债务为由；③以公司被吊销执照未清算为由

### 🎯 常考易错点
1. "股东知情权受损提起解散公司诉讼" → ❌ 不予受理（单选 D 2024：应受理的是持续 2 年以上无法召开股东会）
2. "合并、分立解散无需清算" → ✅
3. 解散诉讼 10% 以上表决权股东、被告=公司

> 📌 **真题印证**：习题第 356~365 题考解散 → **解散事由、解散诉讼受理/不受理 = 必考**。

## 📍 知识点 6：公司的清算 ⭐⭐⭐

### ① 清算义务人与清算组
- **清算义务人**：董事
- **成立清算组**：解散事由出现之日起 **15 日内**组成清算组进行清算；清算组由董事组成（章程另有规定或股东会决议另选除外）
- **责任**：清算组成员怠于履行清算职责给公司造成损失→赔偿；故意或重大过失给债权人造成损失→赔偿；清算义务人未及时清算→赔偿

### ② 指定清算
- 逾期不成立清算组/成立后不清算→利害关系人可申请人民法院指定
- 被吊销执照/责令关闭/撤销而解散→作出决定的部门或登记机关可申请指定

### ③ 清算组职权
清理财产编制清单、通知公告债权人、处理未了结业务、清缴税款、清理债权债务、分配剩余财产、代表公司参与诉讼

### ④ 通知债权人并公告
- 清算组应自成立之日起 **10 日内**通知债权人，**60 日内在报纸或公示系统公告**；债权人 30 日/45 日内申报债权
- 申报债权期间，清算组**不得对债权人清偿**

### ⑤ 清算方案确认
- 清算组制订清算方案，报**股东会**（自行清算）或**人民法院**（指定清算）确认

### ⑥ 清偿与分配顺序（🔥 必背）
1. 支付清算费用、职工工资、社会保险费用和法定补偿金
2. 缴纳所欠税款
3. 清偿公司债务
4. 向股东分配剩余财产（有限按出资比例、股份按持股比例）

> 🔥 **记忆口诀**："清算一路散死无"（10日通知、60日公告、接到30日、未接到45日申报）

### 🎯 常考易错点
1. "清算期间可对债权人清偿" → ❌ 申报债权期间**不得**清偿
2. 清偿顺序：清算费用/工资社保补偿金→税款→债务→剩余财产分配（务必按序）

> 📌 **真题印证**：习题第 366~375 题考清算 → **清算组、通知公告、清偿顺序 = 必考**。

## 📍 知识点 7：公司的注销 ⭐⭐⭐

### ① 基本规定
- 清算结束后，清算组制作**清算报告**，报股东会或法院确认，报送登记机关申请注销公司登记
- 公司因解散、被宣告破产或其他法定事由终止的，应依法申请注销登记，由登记机关公告终止

### ② 简易注销
- **适用**：公司在存续期间**未产生债务**，或**已清偿全部债务**，经全体股东承诺，可按规定通过简易程序注销公司登记
- **责任**：股东承诺不实的，应对注销登记前的债务承担**连带责任**
- **公告**：通过国家企业信用信息公示系统公告，公告期限**不少于 20 日**；届满无异议，可在 **20 日内**申请注销登记

### ③ 强制注销
- **适用**：公司被吊销营业执照、责令关闭或被撤销，满 **3 年**未申请注销登记
- 登记机关可通过公示系统公告，公告期限**不少于 60 日**；届满无异议，登记机关可注销
- 被依职权注销的原公司股东、清算义务人的责任**不受影响**

### 🎯 常考易错点
1. "已清偿全部债务的，经全体股东承诺，可简易注销" → ✅（判断 √ 2024）
2. 简易注销公告不少于 **20 日**；强制注销公告不少于 **60 日**
3. "公司合并、分立解散必须清算" → ❌ 无需清算；但须注销登记（单选 D 2023）

> 📌 **真题印证**：习题第 376~385 题考注销 → **简易/强制注销条件与期限 = 常考**。
