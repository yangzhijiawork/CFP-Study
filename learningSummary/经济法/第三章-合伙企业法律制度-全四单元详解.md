### ① 第一单元 合伙企业概述 · 详细展开

```
第一单元 合伙企业概述
│
├─ ① 合伙企业类型 ⭐⭐⭐⭐⭐
│   ├─ 普通合伙企业：只有普通合伙人（可设特殊普通合伙）
│   ├─ 有限合伙企业：普通合伙人+有限合伙人
│   ├─ 责任承担
│   │   ├─ 普通合伙人：无限连带责任
│   │   ├─ 有限合伙人：以认缴出资额为限
│   │   └─ 特殊普通合伙：过错合伙人无限(1个)/无限连带(2个以上)，非过错以份额为限
│   └─ 表见普通合伙：有限合伙人被误认为普通合伙人→该笔交易承担与普通合伙人同样责任
│
├─ ② 损益事项 ⭐⭐⭐⭐⭐
│   ├─ 债务对外清偿：先企业财产→不足部分合伙人连带（内部规则对债权人无约束力）
│   ├─ 损益分配规则：协议约定→协商→实缴出资比例→平均
│   ├─ 两项特别约定：普通不得"全部分配给部分/部分承担全部亏损"；有限可"全部分配给部分"但不得"部分承担全部亏损"
│   └─ 个人债务：三不得(抵销/代位/自行接管)+两可以(分取收益清偿/强制执行财产份额)
│
└─ ③ 决议办法 ⭐⭐⭐⭐⭐
    ├─ 绝对禁止："国独国企上公益"不得为普通合伙人；普通竞业禁止；普通不得全分配/部分担亏；债权人三不得；有限不得劳务出资/不得执行事务
    ├─ 一致同意：除名/出质/无(限)行为能力人转有限/约定期限退伙/订立书面协议（口诀"一名植物腿在输血"）
    ├─ 过半数：指定清算人
    └─ 应当通知：普通内部转让/有限对外转让30日/强制执行/通知退伙30日（口诀"普内有外强执行"）
```

### ② 第二单元 普通合伙企业 · 详细展开

```
第二单元 普通合伙企业
│
├─ ① 设立要求 ⭐⭐⭐
│   ├─ 合伙人：2人以上；须完全民事行为能力；"国独国企上公益"不得为普通合伙人
│   ├─ 合伙协议：书面、全体签名盖章生效；修改补充须一致同意（另有约定除外）
│   ├─ 出资：普通可用劳务；非货币可协商或委托评估；劳务评估办法协商+协议载明
│   └─ 名称/登记：须标明"普通合伙"字样；营业执照签发日=成立日
│
├─ ② 财产与财产份额 ⭐⭐⭐⭐
│   ├─ 财产构成：出资/以企业名义取得收益/其他财产
│   ├─ 财产性质：独立于合伙人；清算前不得请求分割；私自转移不得对抗善意第三人
│   ├─ 份额转让：对外须一致同意+优先购买权；对内通知即可
│   └─ 份额出质：一致同意；未经一致同意出质无效（无论善意与否）
│
├─ ③ 合伙事务执行 ⭐⭐⭐⭐
│   ├─ 执行人：全体普通合伙人共同执行 或 委托一个/数个执行
│   ├─ 权利：对外代表权(执行人)/撤销权/查账权/监督权(非执行)/异议权(分别执行时暂停)
│   ├─ 义务：报告义务/禁止竞业/关联交易(须一致同意)/损害赔偿
│   └─ 对抗限制：不得对抗善意第三人
│
├─ ④ 非合伙人参与经营管理 ⭐：聘任须一致同意；非合伙人无合伙人资格；越权/故意重大过失致损担赔偿责任(非无限连带)
│
├─ ⑤ 入退伙 ⭐⭐⭐⭐⭐
│   ├─ 入伙：一致同意+书面协议；新合伙人对入伙前债务承担无限连带责任
│   ├─ 协议退伙(约定期限)：约定事由/一致同意/难以继续/他人严重违约
│   ├─ 通知退伙(未约定期限)：不给执行造成不利+提前30日通知
│   ├─ 当然退伙：死亡/吊销关闭撤销破产/全部份额被强执/丧失偿债能力/丧失资格/丧失行为能力未转有限（口诀"人财债无，资格不足，丧失能力，又不同意"）
│   ├─ 除名：未履行出资/故意重大过失致损/执行事务不正当/约定事由；一致同意+书面通知+30日内可诉
│   ├─ 退伙结算：按退伙时财产状况结算；对外承担退伙前债务无限连带
│   └─ 继承：完全行为能力可成为合伙人(一致同意)；无(限)行为能力一致同意转有限否则退伙
│
└─ ⑥ 特殊的普通合伙企业 ⭐⭐⭐⭐
    ├─ 领域：专业服务机构
    ├─ 名称："特殊普通合伙"字样
    ├─ 风险管理：应建立执业风险基金+办理职业保险
    └─ 责任：过错合伙人无限(1个)/无限连带(2个以上)；非过错以份额为限；非故意重大过失→全体无限连带
```

### ③ 第三单元 有限合伙企业 · 详细展开

```
第三单元 有限合伙企业
│
├─ ① 设立要求 ⭐⭐⭐
│   ├─ 人数：2~50人；至少1个普通+1个有限
│   ├─ 身份：仅剩有限→解散；仅剩普通→转普通合伙
│   ├─ 资格："国独国企上公益"可作有限合伙人不可作普通合伙人
│   ├─ 劳务：普通可、有限绝对禁止
│   └─ 责任：有限以认缴出资额为限（表见普通合伙除外）
│
├─ ② 运行 ⭐⭐⭐⭐⭐
│   ├─ 执行事务：普通合伙人执行；有限不执行不对外代表
│   ├─ 不视为执行事项：参与决定普通入退伙/提建议/选会计师事务所/获取财报/查阅账簿/主张权利/督促或代诉/提供担保
│   ├─ 表见普通合伙：有理由相信+交易→承担与普通合伙人同样责任
│   └─ 有限合伙人权利（如无限制即可从事）：关联交易/竞业/出质（普通则相反：关联须一致同意、竞业绝对禁止、出质一致同意）
│
└─ ③ 异动 ⭐⭐⭐⭐
    ├─ 当然退伙：有限合伙人不因"丧失偿债能力""丧失行为能力"当然退伙
    ├─ 继承：有限合伙人继承人可直接继承（不论行为能力/不需同意）
    ├─ 责任：退伙后以退伙时取回财产为限承担责任
    └─ 性质转变：有限→普通（转变前后均无限连带）；普通→有限（转变前无限连带、转变后以认缴为限）；一致同意
```

# 🧩 第一单元 合伙企业概述

## 📍 知识点 1：合伙企业的类型 ⭐⭐⭐⭐⭐（极高考频）

### ① 合伙企业的类型

| 合伙企业类型 | 普通合伙人 | 有限合伙人 |
|-|-|-|
| **普通合伙企业**（一般的普通合伙企业） | √ | × |
| **特殊的普通合伙企业** | √ | × |
| **有限合伙企业** | √ | √ |

> 提示：题目未作"特殊"说明时，默认普通合伙企业为**一般的普通合伙企业**。
> 合伙企业产生的所得，依法由合伙人**分别缴纳个人所得税**。

### ② 合伙企业债务的对外清偿规则（🔥 必考）

**普通合伙企业（一般的普通合伙企业）：**
- 对外承担时**不单独探讨**过错合伙人的责任，全体合伙人承担**无限连带责任**
- 无论是否执行合伙事务，对外均承担无限连带责任

**特殊普通合伙企业（🔥 过错合伙人单独担责）：**

| 债务情形 | 责任人 | 责任承担 |
|-|-|-|
| 因故意/重大过失造成 | 过错合伙人（1 个） | **无限责任** |
| 因故意/重大过失造成 | 过错合伙人（2 个以上） | **无限连带责任** |
| 因故意/重大过失造成 | 非过错合伙人 | 以在合伙企业中的**财产份额为限**承担责任 |
| 非故意/重大过失造成的债务 | 无过错合伙人 | **全体无限连带责任** |

> 过错合伙人因故意/重大过失造成债务，以企业财产对外承担责任后，该合伙人应按合伙协议约定对给合伙企业造成的损失承担**赔偿责任**。

**有限合伙企业：**

| 合伙人身份 | 责任承担 |
|-|-|
| 普通合伙人（1 个） | 无限责任 |
| 普通合伙人（2 个以上） | 无限连带责任 |
| 有限合伙人 | 以**认缴的出资额**为限承担责任 |
| 表见普通合伙 | 第三人有理由相信有限合伙人为普通合伙人并与其交易的，该有限合伙人对该笔交易承担与**普通合伙人同样**的责任 |

> 🔥 **记忆口诀**：责任承担"普通无限连带；有限认缴为限；特殊过错独担，非过错以份额为限；表见同普通"。

### 🎯 常考易错点
1. 普通合伙企业债务清偿：**先以企业全部财产清偿**，不足部分再要求合伙人连带（债权人不能直接跳过企业找合伙人）（单选 A 2025）
2. "甲先行清偿后可按实缴比例向乙丙追偿" → ✅ 内部追偿按亏损分担规则（单选 A 2025）
3. 特殊普通合伙：李某造假→李某无限责任、其他合伙人以财产份额为限（多选 ABCD 2018）
4. 有限合伙：乙银行可要求普通合伙人 B 清偿 80 万（单选 A、C 2023：B 普通合伙人承担无限连带）
5. 表见普通合伙：有限合伙人承担与普通合伙人**相同**责任（单选 D）

> 📌 **真题印证**：习题第 1~15 题全考责任承担 → **普通无限连带、有限认缴为限、特殊过错独担、表见同普通 = 必考**。

## 📍 知识点 2：与合伙人有关的损益事项 ⭐⭐⭐⭐⭐（极高考频）

### ① 合伙企业内部利润分配、亏损分担规则（🔥 必背顺序）
1. 按照**合伙协议的约定**办理（该约定**对债权人没有约束力**）
2. 协议未约定或约定不明确的，由合伙人**协商决定**
3. 协商不成的，按**实缴出资比例**分配、分担
4. 无法确定出资比例的，由合伙人**平均**分配、分担

### ② 两项特别约定（🔥 对比必考）

| 约定事项 | 普通合伙企业 | 有限合伙企业 |
|-|-|-|
| 约定将全部利润分配给部分合伙人 | **×（禁止）** | **√（允许）** |
| 约定由部分合伙人承担全部亏损 | **×（禁止）** | **×（禁止）** |

### ③ 追偿规则
- 普通合伙人因承担无限连带责任，清偿数额超过规定的亏损分担比例的，有权按内部亏损分担规则向其他普通合伙人**追偿**

### ④ 合伙人个人债务的清偿规则（🔥 "三不得两可以"）

| 三不得 | 两可以 |
|-|-|
| 债权人不得以其对合伙人的债权**抵销**其对合伙企业的债务 | 合伙人可**以其从合伙企业分取的收益**用于清偿 |
| 债权人不得**代位行使**合伙人在合伙企业中的权利 | 债权人可请求法院**强制执行**该合伙人在合伙企业中的**财产份额** |
| 债权人不得**自行接管**债务人在合伙企业中的财产份额 | —— |

### 🎯 常考易错点
1. "利润分配协商不成按认缴出资比例" → ❌ 按**实缴**出资比例（单选 B：甲30万乙30万丙实缴60万=1:1:2）
2. "协议约定对债权人也有约束力" → ❌ 内部规则对债权人**没有**约束力（多选 ABCD：丙获10万后其余10万可要求甲全部/乙全部/各5万/1万+9万均可）
3. "普通合伙可约定全部分配给部分合伙人" → ❌ 禁止；有限**可以**（单选 B）
4. 追偿：甲清偿9万，内部平均每人3万→甲可向丙、丁各追偿3万，**不得向乙追偿**（单选 B）
5. 个人债务：李某不得抵销对甲企业的债务、不得代位行使赵某权利（三不得）（多选 BD 2020：可收益清偿、可申请强制执行财产份额）

> 📌 **真题印证**：习题第 16~30 题全考损益 → **分配顺序、两项特别约定、三不得两可以 = 必考**。

## 📍 知识点 3：合伙企业的决议办法 ⭐⭐⭐⭐⭐（极高考频）

### ① 法定事项

**"绝对禁止"从事的事项：**

| 具体事项 |
|-|
| 1. 国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体（"国独国企上公益"）**不得**成为普通合伙人 |
| 2. 普通合伙人**不得**自营或同他人合作经营与本合伙企业**相竞争**的业务 |
| 3. 普通合伙企业的合伙协议**不得**约定将全部利润分配给部分合伙人或者由部分合伙人承担全部亏损 |
| 4. 合伙人的债权人**不得**以其债权抵销其对合伙企业的债务，不得代位行使合伙人在合伙企业中的权利，不得自行接管债务人在合伙企业中的财产份额 |
| 5. 有限合伙人**不得**以劳务出资 |
| 6. 有限合伙人**不得**执行合伙事务、不得对外代表合伙企业 |

**需"一致同意"的事项（🔥 记忆口诀）：**

| 具体事项 |
|-|
| 1. 将合伙人**除名**必须经其他合伙人一致同意 |
| 2. 普通合伙人以其财产份额**出质**必须经其他合伙人一致同意 |
| 3. 普通合伙人死亡，继承人为无/限制民事行为能力人的，经全体合伙人一致同意可成为有限合伙人 |
| 4. 普通合伙人被认定为无/限制民事行为能力人的，经其他合伙人一致同意可转为有限合伙人，否则退伙 |
| 5. 合伙协议约定合伙期限的，存续期间经全体合伙人一致同意，合伙人可以退伙 |
| 6. 合伙协议应由全体合伙人协商一致，以**书面形式**订立，经全体合伙人签名、盖章后生效 |

> 🔥 **记忆口诀**："一""名""植" "物人" "腿" 在"输血"（一致同意=除名/出质/无行为能力人转有限/约定期限退伙/订立书面协议）

**需"过半数同意"的事项：**
- 合伙企业解散时如指定一个或数个合伙人，或委托第三人担任清算人，应经全体合伙人**过半数**同意

**"应当通知"才可从事的事项（🔥 记忆口诀）：**

| 具体事项 | 记忆口诀 |
|-|-|
| 1. 普通合伙人**之间**转让全部或部分财产份额，应当通知其他合伙人 | "普内有外强执行" |
| 2. 有限合伙人向合伙人以外的人转让财产份额，应当**提前 30 日**通知其他合伙人 | |
| 3. 人民法院强制执行份额时，应当**通知全体合伙人** | |
| 4. 通知退伙：协议未约定经营期限，退伙不给事务执行造成不利影响，应**提前 30 日**通知 | |

### ② "有约定，按约定办理，无约定，需合伙人一致同意"的事项（🔥 记忆口诀）

| 具体事项 | 记忆口诀 |
|-|-|
| 普通合伙人死亡，继承人具备完全民事行为能力→取得普通合伙人资格 | "继承普通交份额" |
| 普通合伙人同本合伙企业进行交易 | |

| 新合伙人入伙 | "入伙变身改协议" |
| 普通合伙人转变为有限合伙人 / 有限合伙人转变为普通合伙人 | |

| 转让或处分合伙企业的知识产权和其他财产权利 | |
| 处分合伙企业的不动产 | "改地改名改范围" |
| 改变合伙企业主要经营场所的地点 | |
| 改变合伙企业的名称 | |
| 改变合伙企业的经营范围 | |

> 🔥 **记忆口诀**："先看约定再一致"（有约定按约定，无约定需一致同意）

### ③ 无特别规定事项的决议办法
- "对外投资"等既非法定事项也非"一致同意"事项 → 适用"有约定按约定，无约定由合伙人**一人一票过半数**通过"

### 🎯 常考易错点
1. "普通合伙人可自营与本企业相竞争的业务" → ❌ **绝对禁止**（单选 D：无论是否执行事务均不得）

4. "处分动产属一致同意事项" → ❌ 是处分**不动产**（多选 CD 不当选 B）

6. 对外投资无约定→**一人一票过半数**通过（单选 C）
7. "普通合伙人与本企业交易"、"普通转有限"、"改变经营范围"→须**一致同意**（单选 D 2023：装修店面无特别规定→过半数即可）
8. 合伙协议约定转让需 3/5 财产份额同意：丙、丁合计 62%≥3/5 → 甲可对外转让（单选 C：内部转让给丙只需通知）

# 🧩 第二单元 普通合伙企业

## 📍 知识点 1：普通合伙企业的设立要求 ⭐⭐⭐

### ① 对"合伙人"的要求

| 要求 | 具体规定 |
|-|-|
| 人数 | **2 人以上**（没有上限要求） |
| 资格 | 具有完全民事行为能力的自然人，或法人/其他组织；可以是外国自然人/法人/组织 |
| 禁止 | 国有独资公司、国有企业、上市公司以及公益性事业单位、社会团体（"国独国企上公益"）**不得**成为普通合伙人（可成为有限合伙人，其所在企业一定是有限合伙企业） |

### ② 对"合伙协议"的要求
- 由全体合伙人协商一致，以**书面**（口头×）形式订立；经全体合伙人签名、盖章后生效
- 修改/补充应经全体合伙人一致同意（另有约定除外）
- 应载明：名称和主要经营场所地点、合伙目的和经营范围、合伙人姓名/名称/住所、出资方式/数额/缴付期限、利润分配亏损分担方式、合伙事务执行、入伙退伙、争议解决办法、解散清算、违约责任等
- **注意**："合伙期限"**不属于**合伙协议应当载明的事项

### ③ 对"合伙人出资"的要求

| 出资方式 | 货币 | 实物 | 知识产权 | 土地使用权 | 其他财产权利 | 劳务 |
|-|-|-|-|-|-|-|
| **普通合伙人** | √ | √ | √ | √ | √ | √ |
| **有限合伙人** | √ | √ | √ | √ | √ | **×** |

- 非货币出资（劳务除外）可协商确定或委托法定评估机构评估
- **劳务出资**的评估办法由全体合伙人协商确定，并在合伙协议中载明
- 以非货币财产出资，需办理财产权转移手续的应依法办理

### ④ 名称和生产经营场所
- 名称中应标明"**普通合伙**"字样
- 应有生产经营场所

### ⑤ 企业登记
- 营业执照**签发之日 = 合伙企业成立日期**；领取营业执照前合伙人不得以合伙企业名义从事合伙业务
- 登记事项：名称、类型、经营范围、主要经营场所、合伙人名称/姓名/住所/承担责任方式、执行事务合伙人名称/姓名等
- 备案事项：合伙协议、出资数额/缴付期限、合伙期限、出资方式、登记联络员等
- 分支机构：向分支机构所在地企业登记机关申请登记
- **变更登记**：执行事务合伙人自作出变更决定/发生变更事由之日起 **15 日内**申请
- 实名验证：人脸识别等方式验证合伙人

### 🎯 常考易错点
1. "15 周岁少年、上市公司、慈善组织可成为普通合伙人" → ❌ 均不可（单选 D：乙合伙企业可）
2. "有限合伙人可劳务出资" → ❌ 有限**不得**以劳务出资（多选 ABC 2024：孙某有限不得劳务）
3. "著作权出资只能委托评估" → ❌ 可由全体合伙人协商或委托评估（单选 A 2024 不当选）
4. "劳务出资评估办法无须协议载明" → ❌ 须在合伙协议中**载明**（单选 B 不当选）
5. "合伙协议应载明经营期限" → ❌ 经营期限**不属于**必备事项（单选 D 不当选）
6. "合伙协议签名盖章后还需备案才生效" → ❌ 签名盖章后即生效（多选 A 不当选）
7. "设立分支机构向合伙企业所在地登记" → ❌ 向**分支机构所在地**登记（多选 B 不当选）
8. 商标使用权/应收账款/出资房屋均属企业财产；陈某对甲公司的货款债权是**个人债权**不属企业财产（单选 D 2025）

> 📌 **真题印证**：习题第 51~65 题考设立 → **合伙人资格、出资方式、成立日期、变更15日 = 必考**。

## 📍 知识点 2：合伙企业的财产与合伙人的财产份额 ⭐⭐⭐⭐

### ① 合伙企业财产的构成
1. **合伙人的出资**（全体合伙人实缴或认缴的出资，其中认缴的财产属于原始财产）
2. **以合伙企业名义取得的收益**（未分配的盈余等）
3. **以合伙企业名义取得的其他财产**（债权、受赠财产等）

### ② 合伙企业财产的性质
- **独立性**：财产权主体是**合伙企业**；财产独立于合伙人，合伙人对财产权益的表现形式仅是依协议确定的**财产收益份额或比例**
- **完整性**：清算前**不得请求分割**（法律另有规定除外）；清算前私自转移/处分财产，合伙企业**不得以此对抗善意第三人**

### ③ 普通合伙人"转让财产份额"

| 转让类型 | 规定 |
|-|-|
| **对外转让** | 除协议另有约定外，须经其他合伙人**一致同意** |
| 优先购买权 | 对外转让时，其他合伙人在同等条件下享有**优先购买权**（另有约定除外） |
| 取得身份 | 受让人经**修改合伙协议**方成为合伙人 |
| 其他合伙人未购买又不同意 | 为合伙人办理**退伙或削减**相应财产份额（不是视为同意） |
| **对内转让** | 合伙人之间转让，应当**通知**其他合伙人 |

### ④ 普通合伙人"财产份额出质"
- 以其财产份额出质，须经其他合伙人**一致同意**
- 未经一致同意出质 → **无效**（无论第三人善意与否均无法取得质权）；给善意第三人造成损失，依法承担赔偿责任

### 🎯 常考易错点
1. "合伙人私自处分合伙企业财产，可对抗善意第三人" → ❌ 不得对抗善意第三人（单选 D 2023：丁取得所有权）
2. "受让人签订合同并付款即取得合伙人资格" → ❌ 经**修改合伙协议**方成为合伙人（单选 B）
3. "未经一致同意出质，第三人善意可取得质权" → ❌ 出质**无效**（单选 B 2023）
4. 内部转让只需**通知**马某；对外转让马某同等条件有**优先购买权**→马某以 1 万购得（单选 B 2020）

> 📌 **真题印证**：习题第 66~80 题考财产份额 → **转让决议、出质无效、善意取得 = 必考**。

## 📍 知识点 3：合伙事务的执行 ⭐⭐⭐⭐

### ① 合伙事务的执行人及执行形式
- 普通合伙人对执行合伙事务享有**同等权利**，无论出资多少都有权平等执行
- 执行形式：①由**全体普通合伙人共同执行**；②**委托一个或数个普通合伙人**执行（而非"决定"）
- 作为合伙人的法人/其他组织执行事务的，由其**委派的代表**执行
- 委托一个/数个执行的，其他合伙人**不再执行合伙事务，也不得对外代表合伙企业**
- 对执行事务/对外代表权利的限制，**不得对抗善意第三人**

### ② 合伙人在执行事务中的权利

| 权利 | 事务执行人 | 非事务执行人 |
|-|-|-|
| 对外代表权（事务执行权） | √ | × |
| 撤销权 | √ | √ |
| 查账权 | √ | √ |
| 监督权 | × | √ |
| 异议权 | √ | × |

- **异议权**：合伙人分别执行事务的，执行事务合伙人可对其他合伙人执行的事务提出异议；提出异议时应**暂停**该项事务执行，发生争议按决议办法决定

### ③ 合伙人在执行事务中的义务
- **报告义务**：执行事务合伙人应定期向其他合伙人报告事务执行情况及经营财务状况；收益归企业、费用和亏损由企业承担
- **禁止竞业**：普通合伙人不得自营或与他人合作经营与本企业相竞争的业务
- **关联交易**：除另有约定或全体合伙人一致同意外，普通合伙人**不得**同本合伙企业进行交易
- **损害赔偿**：执行人因自己过错造成企业财产损失，应向企业或其他合伙人负赔偿责任

### ④ 非合伙人参与经营管理
- 除另有约定外，经全体合伙人**一致同意**，可聘任合伙人以外的人担任经营管理人员
- 被聘任的经营管理人员**不具有合伙人资格**
- 超越授权范围/故意重大过失给企业造成损失 → 承担**赔偿责任**（非无限连带责任）

### ⑤ 能否对抗善意第三人

| 事项 | 能否对抗善意第三人 |
|-|-|
| 合伙人私自转移/处分合伙企业财产 | **×** |
| 合伙人越权执行合伙事务 | **×** |
| 非合伙人越权参与经营管理 | **×** |
| 普通合伙人未经一致同意擅自出质财产份额 | **√**（出质无效） |

### 🎯 常考易错点
1. "委托张某执行，李某对张某执行事务提出异议时不停止执行" → ❌ 提出异议应**暂停**执行（单选 A 2022 不当选）
2. "约定张某和李某执行，王某和赵某不再执行" → ✅（单选 B 2022）
3. "未约定执行人时出资最少的张某无权对外代表" → ❌ 全体共同执行，均可对外代表（单选 C 2022 不当选）
4. "张某不按协议执行事务，其他合伙人不得撤销委托" → ❌ 可**撤销**委托（单选 D 不当选）
5. 非执行人钱某：有权监督执行事务、查阅会计账簿，但**无权对外代表**（多选 BCD 2025）
6. "越权执行合伙事务可对抗善意第三人" → ❌ 不得对抗（单选 A 2023：乙公司善意→合同有效）
7. 聘任非合伙人经营管理人员：越权/故意重大过失致损→承担**赔偿责任**（单选 A 2022）；不需 2/3 同意须**一致同意**（单选 D 不当选）；不取得合伙人资格（单选 BC 不当选）

> 📌 **真题印证**：习题第 81~100 题考事务执行 → **执行人权利、异议暂停、善意第三人、非合伙人聘任 = 必考**。

## 📍 知识点 5：普通合伙人的入退伙 ⭐⭐⭐⭐⭐（极高考频）

### ① 普通合伙人入伙
- **决议办法**：新合伙人入伙，除另有约定外，应经全体合伙人**一致同意**，并依法订立**书面入伙协议**
- 订立协议时，原合伙人应如实告知原企业经营状况和财务状况
- **权利与责任**：新入伙的普通合伙人与原合伙人享有**同等权利，承担同等责任**
- 对内可另行约定（更优越/更不利条件）
- **对外法定**：新入伙的普通合伙人对**入伙前**合伙企业的债务承担**无限连带责任**

### ② 普通合伙人退伙

**自愿退伙：**

| 类型 | 前提与情形 |
|-|-|
| **协议退伙**（约定合伙期限） | ①约定退伙事由出现；②经全体一致同意；③发生难以继续参加合伙的事由；④其他合伙人严重违反协议义务 |
| **通知退伙**（未约定合伙期限） | 同时满足：①协议未约定经营期限；②退伙不给事务执行造成不利影响；③**提前 30 日**通知 |

**强制退伙：**

**当然退伙事由（🔥 口诀"人财债无，资格不足，丧失能力，又不同意"）：**
1. 自然人**死亡**或被依法宣告死亡（宣告失踪不是）
2. 法人/其他组织被吊销营业执照、责令关闭、撤销，或被宣告破产（申请破产不是）
3. 合伙人在合伙企业中的**全部**财产份额被人民法院强制执行（部分份额被执行不是）
4. **个人丧失偿债能力**（资不抵债不是）
5. 必须具有相关资格而丧失该资格
6. 合伙人被认定为无/限制民事行为能力人且未征得其他合伙人一致同意转为有限合伙人

> **退伙生效日期**：退伙事由**实际发生之日**

**除名：**

| 除名事由 | 非除名事由 |
|-|-|
| （完全）未履行出资义务 | 未全面履行出资义务 |
| 因故意或重大过失给合伙企业造成损失 | —— |
| 执行合伙事务时有不正当行为 | —— |
| 发生合伙协议约定的事由 | —— |

- **决议规则**：经其他合伙人**一致同意**，可决议将合伙人除名
- **生效**：除名决议应当**书面通知**被除名人；被除名人**接到除名通知之日**生效
- **救济**：被除名人对除名决议有异议，可自接到除名通知之日起 **30 日内**向人民法院起诉

### ③ 退伙结算
- 其他合伙人应与退伙人按**退伙时**的合伙企业财产状况进行结算，退还财产份额
- 退还办法由协议约定或全体合伙人决定，可退还货币或实物
- 退伙人对给企业造成损失负赔偿责任的，相应扣减
- 内部责任：退伙时企业财产少于债务的，退伙人应按内部亏损分担规则分担亏损
- 退伙时有未了结事务的，待了结后进行结算

### ④ 退伙后的外部责任
- 退伙人对**退伙前**发生的合伙企业债务承担**无限连带责任**

| 债务形成时间 | 入伙前 | 入伙后 | 退伙前 |
|-|-|-|-|
| 普通合伙人是否承担无限连带责任 | √ | √ | √ |

### ⑤ 普通合伙人财产份额的继承

| 继承人情况 | 处理 |
|-|-|
| 完全民事行为能力人，愿意成为合伙人且符合资格 | 有约定按约定；无约定→全体一致同意成为普通合伙人；否则办理退伙 |
| 无/限制民事行为能力人 | 全体一致同意→成为**有限合伙人**；否则办理退伙 |
| 不愿意成为合伙人 | 办理退伙 |

- **合伙人资格取得时间**：**继承开始之日**起

### 🎯 常考易错点
1. "受让人自动成为合伙人" → ❌ 须经**修改合伙协议**（多选 A 不当选）
2. "原合伙人不得以更优越条件吸引新合伙人" → ❌ 可另行约定（多选 C 不当选）
3. 协议退伙情形：约定事由/一致同意/难以继续/严重违约（多选 ABCD）
4. 通知退伙三条件：未约定期限+不给执行造成不利+提前 30 日通知（多选 ABC，不含"其他合伙人一致同意"）
5. 当然退伙：自然人死亡、丧失偿债能力（单选 AC 2023）；法人资不抵债/宣告失踪**不是**当然退伙（多选 BD 2024）
6. 除名事由：未履行出资/重大过失致损/执行事务不正当（多选 ABD；"丧失资格"是当然退伙非除名）
7. "除名决议异议应自决议作出之日起 15 日内起诉" → ❌ 自**接到除名通知之日起 30 日内**（单选 C 2022）
8. "被除名人接到通知后提出异议，除名决议不生效" → ❌ 接通知之日生效（单选 B 不当选）
9. 继承：继承人**当然取得**合伙人资格 → ❌ 须按协议或经一致同意（单选 A 2018 不当选）
10. "退伙按入伙时财产状况结算" → ❌ 按**退伙时**财产状况（单选 B 不当选）
11. "退伙时企业财产少于债务，退伙人不承担亏损" → ❌ 应按规定分担亏损（单选 C 不当选）
12. "退伙人对退伙前债务不承担连带责任" → ❌ 承担（单选 D 不当选）
13. 杨某入伙时负债 30 万、退伙时 80 万 → 对**退伙前**的 80 万承担无限连带责任（单选 A 2019）
14. 新入伙有限合伙人以**认缴出资额**为限对入伙前债务担责（单选 C 2024：认缴 30 万→担 30 万）

> 📌 **真题印证**：习题第 101~135 题全考入退伙 → **入伙责任、当然退伙情形、除名、继承 = 必考**。

## 📍 知识点 6：特殊的普通合伙企业 ⭐⭐⭐⭐

### ① 设立与管理要求
- **适用领域**：以专业知识和专门技能为客户提供有偿服务的专业服务机构
- **名称**：应标明"**特殊普通合伙**"字样
- **风险管理**：应当建立**执业风险基金**、办理**职业保险**；执业风险基金从经营收益中按一定比例提取，用于偿付合伙人执业活动造成的债务，应**单独立户管理**

### ② 责任承担规则（🔥 对比必考）

| 企业债务是否因合伙人故意/重大过失造成 | 责任承担 |
|-|-|
| **是**（过错合伙人 1 个） | 过错合伙人承担**无限责任** |
| **是**（过错合伙人 2 个以上） | 过错合伙人承担**无限连带责任** |
| **是**（非过错合伙人） | 以在合伙企业中的**财产份额为限**承担责任 |
| **否**（非故意/重大过失） | 全体合伙人承担**无限连带责任** |

> 过错合伙人因故意/重大过失造成债务，以企业财产对外承担责任后，应按协议约定对给企业造成的损失承担**赔偿责任**。

### 🎯 常考易错点
1. "特殊普通合伙企业可选择建立执业风险基金或办理职业保险" → ❌ **应当**建立基金**和**办理保险（多选 BCD 不当选 A）
2. 过错合伙人无限/无限连带，非过错以份额为限（多选 ABCD 2018）

> 📌 **真题印证**：习题第 136~145 题考特殊普通合伙 → **执业风险基金、责任承担 = 必考**。

# 🧩 第三单元 有限合伙企业

## 📍 知识点 1：有限合伙企业的设立要求 ⭐⭐⭐

### ① 对"合伙人"的要求
| 要求 | 具体规定 |
|-|-|
| 人数 | **2 人以上 50 人以下**（另有规定除外） |
| 身份 | 至少应有 **1 个普通合伙人和 1 个有限合伙人**；仅剩有限合伙人→**应当解散**；仅剩普通合伙人→**转为普通合伙企业** |
| 资格 | 自然人、法人或组织均可；"国独国企上公益"**可以**成为有限合伙人但**不能**成为普通合伙人 |
| 行为能力 | 普通合伙人须具备完全民事行为能力；无/限制民事行为能力人**可以**成为有限合伙人 |

### ② 其他要求
- **名称**：应标明"**有限合伙**"字样（不允许出现"有限责任"字样）
- **劳务出资**：普通合伙人允许；有限合伙人**禁止**
- **责任承担**：普通合伙人无限/无限连带；有限合伙人以认缴出资额为限（表见普通合伙除外）
- **合伙协议**：除符合普通合伙协议规定外，还应载明：①普通/有限合伙人姓名或名称、住所；②有限合伙人入退伙条件、程序及责任；③有限与普通相互转变程序；④执行事务合伙人应具备的条件和选择程序；⑤执行事务合伙人权限与违约处理；⑥执行事务合伙人除名条件和更换程序
- **强制补缴**：有限合伙人未按期足额缴纳出资→承担补缴义务并对其他合伙人承担违约责任（其他合伙人**不需要**承担连带出资责任）

### 🎯 常考易错点
1. "有限合伙企业中合伙人一律不得以劳务出资" → ❌ 普通合伙人**可以**劳务出资，仅有限合伙人不得（单选 B 2025 当选）
2. "有限合伙企业至少应当有 2 个普通合伙人" → ❌ 至少 **1 个**普通+1 个有限（多选 A 不当选）
3. "公益性事业单位不能成为有限合伙企业普通合伙人" → ✅（多选 B）
4. "仅剩有限合伙人应当解散" → ✅（多选 C）
5. "名称中标明有限责任字样" → ❌ 标明"有限合伙"字样（多选 D 不当选）
6. 公益性社会团体只能作有限合伙人（以认缴出资额为限），王某为普通合伙人（无限责任）（单选 AD）

> 📌 **真题印证**：习题第 146~160 题考有限设立 → **1+1 结构、劳务出资禁止、名称 = 必考**。

## 📍 知识点 2：有限合伙企业的运行 ⭐⭐⭐⭐⭐（极高考频）

### ① 合伙事务的执行
- **执行人**：有限合伙企业由**普通合伙人**执行合伙事务
- 有限合伙人**不执行合伙事务，不得对外代表**有限合伙企业
- 执行人因自己过错造成企业财产损失，应向企业或其他合伙人负赔偿责任
- **执事报酬**：执行事务合伙人可要求在合伙协议中确定执行事务的报酬及报酬提取方式

### ② 有限合伙人不视为执行合伙事务的事项（🔥 8 项必背）
1. 参与决定普通合伙人**入伙、退伙**
2. 对企业的经营管理提出**建议**
3. 参与**选择**承办审计业务的会计师事务所
4. 获取经审计的财务会计报告
5. 对涉及自身利益的情况，**查阅**财务会计账簿等财务资料
6. 利益受侵害时，向有责任合伙人主张权利或提起诉讼
7. 执行事务合伙人怠于行使权利时，督促其行使权利或以自己名义为企利提起诉讼
8. **依法为本企业提供担保**

### ③ 表见普通合伙
- **对外**：第三人有理由相信有限合伙人为普通合伙人并与其交易的，该有限合伙人对该笔交易承担与**普通合伙人同样**的责任
- **对内**：有限合伙人未经授权以企业名义与他人交易，给企业或其他合伙人造成损失的，应承担**赔偿责任**

### ④ 有限合伙人的权利（🔥 对比必考）

| 事项 | 普通合伙人 | 有限合伙人 |
|-|-|-|
| **关联交易** | 有约定按约定；无约定一致同意可以交易，否则不得 | **如无限制，即可从事** |
| **经营竞业** | **绝对禁止** | 如无限制，即可从事 |
| **份额出质** | 一致同意→可以出质，否则不得出质（可对抗善意第三人） | 如无限制，即可从事 |

### ⑤ 有限合伙人财产份额的转让与强制执行
- **对外转让**：可依协议约定向合伙人以外的人转让，但应**提前 30 日**通知其他合伙人；其他合伙人在同等条件下有**优先购买权**
- **强制执行**：法院强制执行份额时，应**通知全体合伙人**；同等条件下其他合伙人有优先购买权

### 🎯 常考易错点
1. "有限合伙人参与决定普通合伙人入退伙视为执行合伙事务" → ❌ 不视为（多选 A、B 2025 当选）
2. "有限合伙人不得为本企业提供担保" → ❌ 依法为本企业提供担保是允许的（多选 C 不当选）
3. "合伙协议不得约定由有限合伙人担任执行人" → ✅（单选 B）
4. "有限合伙人提建议视为执行合伙事务" → ❌ 不视为（单选 A 不当选）
5. "执行人不得要求报酬" → ❌ 可要求在协议中确定报酬（单选 D 不当选）
6. "有限合伙人可以同本企业交易，另有约定除外" → ✅（单选 B）
7. "一个有限合伙人不承担亏损" → ❌ 禁止（多选 A 不当选）；"一个普通合伙人不享有利润分配" → ✅ 可约定（多选 D 当选）
8. 有限合伙人对外转让份额须**提前 30 日**通知（单选/多选）

> 📌 **真题印证**：习题第 161~185 题考有限运行 → **不视为执行事务8项、有限合伙人权利、表见普通合伙 = 必考**。

## 📍 知识点 3：有限合伙企业发生异动 ⭐⭐⭐⭐

### ① 有限合伙人当然退伙的情形（🔥 对比必考）

| 当然退伙情形 | 普通合伙人 | 有限合伙人 |
|-|-|-|
| 自然人死亡或被依法宣告死亡 | √ | √ |
| 法人/其他组织被吊销营业执照、责令关闭、撤销或被宣告破产 | √ | √ |
| 合伙人在企业中的全部财产份额被法院强制执行 | √ | √ |
| **个人丧失偿债能力** | **√** | **×** |
| 必须具有相关资格而丧失该资格 | √ | √ |
| 被认定为无/限制民事行为能力人 | 征得一致同意转有限→×；否则→√ | **×**（不得因此要求退伙） |

### ② 有限合伙人继承人的权利
- 作为有限合伙人的自然人死亡或被宣告死亡，或作为有限合伙人的法人/其他组织终止时，其继承人或权利承受人可**依法直接取得**该有限合伙人在有限合伙企业中的资格
- **提示**：有限合伙人继承人可以直接继承，**不需要考虑继承人的民事行为能力，也不需要其他合伙人同意**

### ③ 有限合伙人退伙后的责任承担
- 有限合伙人退伙后，对基于其退伙前的原因发生的债务，以**退伙时从有限合伙企业中取回的财产**承担责任

### ④ 合伙人责任承担总结

| 债务形成时间 | 入伙前 | 入伙后 | 退伙前 |
|-|-|-|-|
| 普通合伙人 | 无限连带责任 | 无限连带责任 | 无限连带责任 |
| 有限合伙人 | 以认缴出资额为限（表见除外） | 以认缴出资额为限 | 以取回的财产为限 |

### ⑤ 合伙人性质转变
- **决议办法**：除另有约定外，普通合伙人转变为有限合伙人，或有限合伙人转变为普通合伙人，应经全体合伙人**一致同意**
- **责任承担**（"前无限，后转变"）：

| 转变方式 | 转变前责任 | 转变后责任 |
|-|-|-|
| **有限→普通** | 有限合伙期间债务**无限连带责任** | 无限连带责任 |
| **普通→有限** | 普通合伙期间债务**无限连带责任** | 以认缴出资额为限承担责任 |

### 🎯 常考易错点
1. "有限合伙人丧失偿债能力当然退伙" → ❌ **不**当然退伙（单选 A 2023 不当选）
2. "有限合伙人被宣告失踪当然退伙" → ❌ 是**死亡**或被宣告死亡（单选 C 不当选）
3. "部分财产份额被强制执行当然退伙" → ❌ 须**全部**财产份额被强制执行（单选 D 不当选）
4. "有限合伙人丧失民事行为能力当然退伙" → ❌ 其他合伙人不得因此要求其退伙（单选 A 不当选、单选 C 2022 不当选）
5. 有限合伙人继承人可**直接**继承（不需考虑行为能力/不需同意）（单选 A 2022）
6. 有限合伙人退伙：以退伙时**取回的财产**为限担责（单选 C 2023：取回 70 万→担 70 万）
7. 新入伙有限合伙人对入伙前债务以**认缴出资额**为限担责（单选 C 2024）
8. "普通合伙人不能全部转为有限合伙人" → ✅ 仅剩有限应解散（多选 A）
9. "有限转普通，对有限合伙期间债务承担无限连带" → ✅（多选 C）
10. 转变：赵某普通转有限→对普通合伙期间债务无限连带；孙某有限转普通→对有限合伙期间债务无限连带；钱某未转变→以认缴为限（单选 AD 2024）

> 📌 **真题印证**：习题第 186~210 题考有限异动 → **当然退伙差异、继承、责任承担、性质转变 = 必考**。

# 🧩 第四单元 合伙企业的解散与清算

## 📍 知识点 1：合伙企业解散的原因 ⭐

**属于解散的原因：**
1. 合伙期限届满，合伙人决定不再经营
2. 合伙协议约定的解散事由出现
3. 全体合伙人决定解散
4. 合伙人已不具备法定人数（**＜2 人**）满 **30 天**
5. 合伙协议约定的合伙目的已经实现或无法实现
6. 依法被吊销营业执照、责令关闭或被撤销
7. 法律、行政法规规定的其他原因（如有限合伙企业仅剩有限合伙人等）

**不属于解散的原因：** 企业停业整顿、发生严重亏损、合伙人对企业有过错、有限合伙企业仅剩普通合伙人、部分合伙人死亡等

### 🎯 常考易错点
1. "甲、乙退出，30 天没有其他人入伙" → 应解散（单选 A 2024）；"约定目的已实现" → 应解散（单选 D）；"全体一致同意解散"（丙不同意）→ 不构成（单选 B 不当选）；"丙死亡" → 非直接解散原因（单选 C 不当选）

> 📌 **真题印证**：习题第 211~220 题考解散原因 → **不足2人满30天、全体决定、目的实现 = 必考**。

---

## 📍 知识点 2：合伙企业的清算 ⭐⭐⭐

### ① 清算人的确定
1. 清算人由**全体合伙人**担任（清算人不一定是执行事务合伙人）
2. 经全体合伙人**过半数**同意，可自解散事由出现后 **15 日内**指定一个或数个合伙人，或委托第三人担任清算人
3. 自解散事由出现之日起 **15 日内**未确定清算人的，合伙人或其他利害关系人可申请人民法院指定清算人

### ② 清算人的职责
1. 清理企业财产，编制资产负债表和财产清单
2. 处理与清算有关的未了结事务
3. 清缴所欠税款
4. 清理债权、债务
5. 处理清偿债务后的剩余财产
6. 代表企业参加诉讼或仲裁活动

> 清算期间企业存续，但**不得开展与清算无关的经营活动**。

### ③ 债权申报
- 清算人自被确定之日起 **10 日内**将解散事项通知债权人，**60 日内**在报纸上公告
- 债权人自接到通知之日起 **30 日内**、未接到通知的自公告之日起 **45 日内**申报债权

> 🔥 **记忆口诀**："清算一路散死无"（10日通知、60日公告、接到30日、未接到45日）

### ④ 财产清偿顺序（🔥 必背）
1. **清算费用**（管理财产费用、处分财产费用、其他费用如通告/调查/咨询/诉讼费用）
2. 合伙企业**职工工资、社会保险费用和法定补偿金**
3. 缴纳**所欠税款**
4. 清偿**债务**
5. 分配**剩余财产**

### 🎯 常考易错点
1. "清算期间应清理债权债务" → ✅（单选 A 2024）
2. "注销登记无须报送清算报告" → ❌ 须报送（单选 B 不当选）
3. "清算人只能由全体合伙人共同担任" → ❌ 可指定/委托/申请法院指定（单选 C 不当选）
4. "企业财产首先用于缴纳税款" → ❌ 先支付清算费用和职工工资社保补偿金（单选 D 不当选）
5. 清算费用：管理/聘任工作人员/咨询费用（多选 ABC；社保费用不属清算费用）

> 📌 **真题印证**：习题第 221~235 题考清算 → **清算人确定、债权申报、清偿顺序 = 必考**。

## 📍 知识点 3：合伙企业的注销与宣告破产 ⭐⭐⭐

### ① 注销
- 清算结束，清算人编制**清算报告**，经全体合伙人**签名、盖章**后，在 **15 日内**向企业登记机关报送，申请办理注销登记
- 经登记机关注销登记，合伙企业**终止**
- **责任承担**：合伙企业注销后，**原普通合伙人**对合伙企业存续期间的债务仍应承担**无限连带责任**

### ② 宣告破产
- 合伙企业依法被宣告破产的，**普通合伙人对合伙企业债务仍应承担无限连带责任**

### ③ 核心时间性规定汇总（🔥 考前必背）

| 时间 | 事项 |
|-|-|
| **30 日** | 有限合伙人对外转让份额应提前 30 日通知；通知退伙提前 30 日；被除名人 30 日内起诉；不足 2 人满 30 天解散 |
| **15 日** | 变更登记 15 日内申请；指定清算人 15 日内；报送清算报告 15 日内 |
| **10 日 / 60 日 / 30 日 / 45 日** | 清算 10 日通知债权人 + 60 日公告；债权人接到 30 日 / 未接到 45 日内申报 |

### 🎯 常考易错点
1. "合伙企业被宣告破产，普通合伙人对债务不再承担清偿责任" → ❌ 仍应承担**无限连带责任**（判断 × 2022）
2. "合伙企业注销后，原普通合伙人对债务不再担责" → ❌ 仍应承担无限连带责任

> 📌 **真题印证**：习题第 236~245 题考注销破产 → **注销/破产后普通合伙人无限连带 = 必考**。
