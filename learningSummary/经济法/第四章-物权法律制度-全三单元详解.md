# 🧩 第一单元 物权法律制度概述

## 📍 知识点 1：物的概念与特点 ⭐

**物权法律制度上的物** = 人们能够支配和利用的物质实体和自然力。

| 特点 | 含义 | 备注 |
|-|-|-|
| **有体性** | 物须具有客观物质性，系有体物 | 有体物≠有形物；权利在某些法定情形可成为物权客体 |
| **可支配性** | 可为人们支配和使用 | 日月星辰不属于物 |
| **非人身性** | 人体虽具物理属性，但基于人性尊严，活人的身体不属于物 | 与活人相分离的人体器官、组织可成为物 |

### 🎯 常考易错点
1. "太阳属于物" → ❌ 不具有可支配性（多选 A 不当选）
2. "电力属于物" → ✅（多选 B）
3. "活人的身体属于物" → ❌ 不属于（多选 C 不当选）
4. "法定的权利可以作为物权客体" → ✅（多选 D）

---

## 📍 知识点 2：物的分类 ⭐

### ① 按"物能否移动且是否因移动而损害其价值"分类

| 分类 | 含义 | 举例 | 变动要件 | 公示方法 |
|-|-|-|-|-|
| **不动产** | 不能移动或移动会损害价值 | 土地、建筑物、林木、矿藏、海域 | 登记 | 登记 |
| **动产** | 能移动且不损害价值 | 苹果、汽车、船舶、航空器 | 交付 | 占有 |

### ② 按"主从关系"分类
- **主物**：需共同使用才能更好发挥作用的两物中起主要作用的（电视机、汽车）
- **从物**：起辅助作用的（遥控器、备胎）
- 区分意义：除法律另有规定或另有约定，对主物的处分**及于从物**

### ③ 按"原物产生新物"分类
- **原物**：产生孳息物之物（母鸡、房屋）
- **孳息物**：原物所产生之物（鸡蛋=天然孳息、租金=法定孳息）

**孳息归属：**
- **天然孳息**：一般由所有权人取得；既有所有权人又有用益物权人的→有约定按约定、无约定由**用益物权人**取得
- **法定孳息**：有约定按约定；无约定/约定不明按**交易习惯**取得

### ④ 按"是否因实物分割变更性质或减损价值"分类
- **可分物**（A→A）：一袋大米、一杯牛奶；共有可分物可实物分割
- **不可分物**（A→B）：一辆汽车、一头耕牛；只能变价分割或作价补偿

### 🎯 常考易错点
1. "汽车和轮胎属于主物和从物" → ❌ 轮胎属汽车的一部分，不是主从物关系（单选 C 2023）
2. "天然孳息无约定归所有权人" → ❌ 既有所有权人又有用益物权人的，归**用益物权人**（判断 × 2023）
3. 存款利息=法定孳息（单选 D 2023）

## 📍 知识点 3：物权的基础知识 ⭐⭐⭐

### ① 物权 vs 债权的属性

| 物权的属性 | 债权的属性 |
|-|-|
| 支配性：直接支配标的物 | 请求性（请求权）：需债务人履行行为配合 |
| 绝对性（对世权）：权利人特定而义务人不特定 | 相对性（对人权）：权利义务人均特定 |
| 排他性：同一标的物不得有两个不相容物权 | 兼容性：原则上不具有对抗第三人效力 |
| 特定性：客体具有特定性 | 不特定性：合同债权客体是行为 |

### ② 物权的分类与客体

| 类别 | 物权类型 | 客体（动产/不动产/权利） |
|-|-|-|
| **自物权** | 所有权 | 动产√ 不动产√ 权利× |
| **用益物权** | 土地承包经营权、建设用地使用权、宅基地使用权、居住权、地役权 | 均为不动产 |
| **担保物权** | 抵押权（动产/不动产√）、质权（动产√/权利√）、留置权（动产√） | —— |

### ③ 物权法定主义
- **类型法定**：当事人不得创设法律不承认的物权类型
- **内容法定**：当事人不得创设与法定内容相异的内容

### ④ 物权的效力
- **优先效力**：先登记设立抵押权＞后登记设立抵押权；限制物权（他物权）＞所有权（自物权）；**留置权＞其他担保物权**
- **优先于债权**：物权存在标的物上与债权冲突时，无论物权成立于债权之前或之后，物权均优先于债权（例外："买卖不破租赁"）
- **追及效力**：标的物不论辗转至何人之手，物权人有权追及并直接支配
- **妨害排除力**：排除他人妨害，恢复正常支配

### ⑤ 物权保护
| 方式 | 含义 |
|-|-|
| 确认物权请求权 | 物权归属、内容发生争议时请求确认 |
| 损害赔偿请求权 | 侵害物权造成损害请求赔偿 |
| 标的物返还请求权 | 标的物被他人无权占有时请求返还 |
| 排除妨害请求权 | 妨害物权时请求排除 |
| 消除危险请求权 | 可能妨害物权时请求消除危险 |

### 🎯 常考易错点
1. 居住权/地役权/土地承包经营权属**用益物权**；留置权属**担保物权**（单选 C 2022）
2. 留置权客体**只能是动产**（单选 C 2023）
3. 邻居挖地窖使房屋有受损危险 → **消除危险请求权**（单选 A 2025）
4. 标的物返还请求权：假发烧毁→不能主张返还；偷游戏机/借后谎称丢失→可主张返还；已转卖给徐某→原所有权人丧失所有权不能主张返还（多选 BC）

# 🧩 第二单元 物权的取得与变动

## 📍 知识点 1：物权变动概述 ⭐

### ① 物权变动类型
| 类型 | 具体规定 |
|-|-|
| **继受取得** | 依赖前权利人意志（继承取得、受让取得） |
| **原始取得** | 无需依赖前权利人意志（无主物先占、拾得遗失物、添附、善意取得等） |
| **变更** | 物权客体、内容的部分改变 |
| **绝对消灭** | 因物的灭失导致物权消灭 |
| **相对消灭** | 物权未消灭，只是主体变更 |

### ② 公示与公信原则
- **公示原则**：物权变动须以法定公示方式（登记/交付）进行才能生效
- **公信原则**：依法定方式公示后就产生公信力，即使公示内容与实际不符，善意第三人基于信赖受保护

---

## 📍 知识点 2：不动产物权变动 ⭐⭐⭐⭐⭐（极高考频）

### ① 概述
- **基于法律行为**：签订合同 + 办理登记 → 物权转移
- **非基于法律行为**：满足法定条件 → 物权变动，不以登记为生效要件；但拟进一步处分时需依法办理登记

### ② 基于法律行为的不动产物权变动（🔥 以"登记生效"为原则）
- 不动产物权设立、变更、转让、消灭，依法登记→发生效力；未经登记→**不发生（物权）效力**
- 当事人订立的合同自**合同成立时**发生效力；未办理物权登记不影响合同效力

### ③ 例外情形
| 例外 | 具体规定 |
|-|-|
| 以无需登记为例外 | 依法属于国家所有的自然资源，所有权**可以不登记** |
| 以合同生效为设立条件 | **土地承包经营权**自合同生效时设立，未经登记不得对抗善意第三人；**地役权**自合同生效时设立，未经登记不得对抗善意第三人 |

**基于法律行为的不动产物权变动总结：**

| 不动产物权 | 变动生效时间 | 公信力 |
|-|-|-|
| 所有权、建设用地使用权、宅基地使用权、居住权、抵押权 | 登记 | 登记 |
| 土地承包经营权、地役权 | 合同生效 | 登记 |

### ④ 非基于法律行为的不动产物权变动

| 情形 | 生效时间 |
|-|-|
| 因合法建造、拆除房屋等事实行为 | 自事实行为成就时 |
| 因继承取得物权 | 自继承开始时 |
| 因人民法院、仲裁委员会的法律文书 | 自法律文书生效时 |
| 因人民政府的征收决定 | 自征收决定生效时 |

### ⑤ 不动产统一登记制度（🔥 各类登记必考）

| 登记类型 | 要点 |
|-|-|
| 总登记 | 对特定管辖区域所有不动产的全部登记 |
| 首次登记 | 第一次登记；未完成首次登记不得办理其他登记 |
| 变更登记 | 分割、合并、设立、增减时所为登记 |
| 转移登记 | 物权从转让人转移至受让人 |
| 注销登记 | 不动产灭失/放弃权利/没收征收收回/法律文书致消灭 |
| **更正登记** | 权利人书面同意或有证据证明登记错误→应更正；登记机构发现错误→通知30个工作日内更正 |
| **异议登记** | 权利人不同意更正→利害关系人可申请异议登记；**15 日内不起诉**则失效；登记不当致损→可请求损害赔偿 |
| **预告登记** | 保障将来实现物权；未经预告登记权利人同意处分不动产→**不发生物权效力**；债权消灭或**90 日内**未申请登记→失效 |
| 他项权利登记 | 在不动产上创设建设用地使用权等 |

### ⑥ 登记不一致
- 权属证书与登记簿不一致，除有证据证明登记簿确有错误外，以**不动产登记簿**为准

### 🎯 常考易错点
1. 建设用地使用权自**登记时**设立（单选 D：11月5日办理登记取得）
2. 合法购房：**登记**后获所有权；合法自建：事实行为成就时获所有权；合法拆除：拆除完毕所有权消灭；继承：继承开始时获所有权（多选 AC 2025：D 错在"登记产权后获所有权"，应自继承开始时）
3. "土地承包经营权自登记时设立" → ❌ 合同生效时（单选 C 2025 不当选）
4. "依法属于国家所有的自然资源，所有权应当登记" → ❌ 可不登记（单选 B 不当选）
5. "因继承取得不动产物权以登记为生效要件" → ❌ 自继承开始时生效（单选 C 2025 当选）
6. 法院判决：房屋判归乙的时间=法律文书**生效之日**（单选 B：9月15日）
7. 异议登记：15日内不起诉失效（多选 CD 2024：C 说"法院开庭后失效"错误、D 说"更正前须先异议"错误）
8. 预告登记失效：债权消灭或90日内未申请登记（单选 D 2025：6月20日可办理登记+90日=9月18日失效）

> 📌 **真题印证**：习题第 1~40 题全考不动产变动 → **登记生效、合同生效例外、各类登记、非基于法律行为 = 必考**。

## 📍 知识点 3：动产物权变动 ⭐⭐⭐⭐⭐（极高考频）

### ① 基于法律行为的动产物权变动

| 动产物权 | 变动生效时间（不区分动产类型） | 公信力 |
|-|-|-|
| 所有权（普通动产） | 交付 | 占有 |
| 所有权（特殊动产：车辆/船舶/航空器） | 交付 | 登记 |
| 抵押权 | 合同生效 | 登记 |
| 质权 | 交付 | 占有 |
| 留置权 | 法定产生 | —— |

> 提示：以登记产生公信力的动产物权，未经登记，**不得对抗善意第三人**。

### ② 交付的种类（🔥 必考）

| 交付种类 | 设立和转让前的占有人 | 物权变动时点 |
|-|-|-|
| **现实交付** | 出让人（出卖人） | 交付时 |
| **简易交付** | 权利人（买受人） | 民事法律行为生效时 |
| **指示交付** | 第三人（出卖人、买受人以外的人） | 受让人取得返还原物请求权时 |
| **占有改定** | 约定由出让人继续占有该动产 | 占有改定约定生效时 |

> 说明：简易交付＋指示交付＋占有改定＝**观念交付**。

### ③ 非基于法律行为的动产物权变动

**先占：** 以所有权人的意思占有无主动产（遗失物不属于无主动产），先占人基于先占取得无主动产所有权。

**拾得遗失物（🔥 必考）：**
1. 拾得人应及时通知权利人领取，或送交公安等有关部门
2. 有关部门自发出招领公告之日起 **1 年**内无人认领→遗失物归国家所有
3. 拾得人/有关部门在送交/领取前应妥善保管；因故意或重大过失致毁损灭失→承担民事责任
4. **保管费等必要支出与报酬**：未侵占→应支付必要支出、有悬赏允诺应支付报酬；侵占→无需支付

**遗失物被无权处分：** 所有权人有权追回；该遗失物通过转让被他人占有→权利人有权向无处分权人请求损害赔偿，或自**知道或应当知道受让人之日起 2 年内**向受让人请求返还原物（但受让人通过拍卖或向有经营资格的经营者购得的，权利人请求返还原物时应支付受让人所付费用，后可向无处分权人追偿）

**添附（🔥 必考）：**
| 类型 | 识别要点 | 示例 |
|-|-|-|
| **附合** | 原物能分清楚是谁的 | 错拿邻居油漆刷墙 |
| **混合** | 原物分不清楚是谁的 | 不同所有人大米倒进一个桶 |
| **加工** | 劳务和其他材料融合 | 在他人的宣纸上写书法 |

**添附物归属**：有约定按约定；无约定/约定不明依照法律规定；无法律规定，按充分发挥物的效用及保护无过错当事人原则确定；一方过错或确定归属造成另一方损害→给予赔偿或补偿。

### ④ 占有制度

**占有的分类：**

| 分类标准 | 具体分类 | 示例 |
|-|-|-|
| 是否有法律依据 | **有权占有** / **无权占有** | 基于物权占有 / 租赁结束后继续占有 |
| 是否误信有占有权源 | **善意占有** / **恶意占有** | 误以为是自己的 / 偷盗者的占有 |
| 是否有所有的意思 | **自主占有** / **他主占有** | 偷盗者 / 承租人 |
| 是否直接占有其物 | **直接占有** / **间接占有** | 质权人 / 出质人 |

**善意占有 vs 恶意占有（🔥 对比）：**

| 占有人类型 | 权利人能否请求返还原物及孳息 | 必要维护费用 | 占有物毁损/灭失 | 使用造成损害 | 保险金赔偿金补偿金"三金"以外未弥补损失 |
|-|-|-|-|-|-|
| 善意占有人 | √ | √（应支付） | √ | × | × |
| 恶意占有人 | √ | × | √ | √（应赔偿） | √（应赔偿） |

**占有保护请求权：**
- 占有物返还请求权 + 占有损害赔偿请求权 + 占有妨害排除请求权 + 占有妨害防止请求权
- **占有物返还请求权**：自侵占发生之日起 **1 年**内未行使→消灭
- 物权保护中"标的物返还请求权"除未登记动产适用诉讼时效外，原则上无行使期限限制

### 🎯 常考易错点
1. 房屋（不动产）未登记→未取得所有权；家具（动产）搬进居住视为交付→已取得所有权（单选 C）
2. 汽车：5月10日交付→取得所有权（单选 C 2023）
3. "钱某付款时交付、约定赵某继续使用一个月" → **占有改定**（单选 B 2025）
4. 简易交付：钱某1月10日取得自行车；占有改定：孙某1月11日取得（单选 A 2022）
5. "拾得遗失物6个月内无人认领归国家" → ❌ **1年**（多选 C 2022 不当选）
6. 遗失物转让：吴某可自知道/应知道受让人李某之日起**2年**内向李某请求返还；李某经拍卖购得→吴某请求返还时应支付购买费用（多选 ABD 2023）
7. 用他人油漆刷桌子 = **附合**（单选 B 2025）
8. 林某租借的车 → **他主占有**（单选 C 2022 不当选"自主占有"）
9. 恶意占有人使用动产致损应赔偿；三金以外未弥补损失恶意占有人赔偿（多选 ABC 2024）
10. 占有返还请求权 1 年（单选 D 2025）

> 📌 **真题印证**：习题第 41~90 题全考动产变动 → **交付种类、拾得遗失物、添附、占有 = 必考**。

# 🧩 第三单元 各种物权的具体规定

## 📍 知识点 1：所有权 ⭐⭐⭐⭐⭐（极高考频）

### ① 所有权的权能与特征
- **积极权能**：占有、使用、收益、处分（法律处分=相对消灭 / 事实处分=绝对消灭）
- **消极权能**（妨害排除力）：标的物返还请求权、排除妨害请求权、消除危险请求权
- **特征**：统一性（整体性）、全面支配性、恒久性（法律不限制存续期限）、弹力性（限制物权消灭权能恢复）

### ② 善意取得所有权（🔥 必考）

**构成要件（须同时符合）：**
1. 受让人受让时是**善意**的（不动产登记时或动产交付时不知道转让人无处分权且无重大过失）
2. 受让人以**合理的价格**（有偿）受让标的物（无偿受让不得主张善意取得）
3. 应登记的已经登记、不需登记的已经交付（善意取得制度**不承认占有改定构成交付**）

**效果：**
- 受让人取得所有权；原所有权人有权向无处分权人请求损害赔偿
- 举证责任：主张受让人不构成善意的，由**权利人**承担举证证明责任

### ③ 共有制度

**共有形态界定：** 共有人对共有物共有形态未作约定或约定不明的，共有人之间是否存在**家庭关系**→是=共同共有；否=按份共有。份额确定：有约定按约定，无约定按出资额，不能确定视为等额享有。

**一般事项（共有均适用）：**
- **对外关系**：产生的债权债务，对外共有人享有**连带债权、承担连带债务**（法律另有规定或第三人知道的除外）
- **管理共有物**：有约定按约定；无约定各共有人都有管理权利义务

**特殊事项（🔥 对比必考）：**

| 事项 | 按份共有 | 共同共有 |
|-|-|-|
| 管理费用/负担 | 按份额负担（可追偿） | 共同负担 |
| 处分共有物/重大修缮/变更性质用途 | 经占份额 **2/3 以上**按份共有人同意 | 经**全体**共同共有人一致同意 |

> 未依法满足绝对多数决/全体一致决即处分共有物→构成无权处分，受让人可主张善意取得。

**按份共有人处分份额：**
- 可以自由转让其份额，其他共有人在同等条件下有**优先购买权**
- 数人主张→协商确定比例；协商不成按转让时各自共有份额比例行使
- 优先购买权排除适用：共有份额因**继承、遗赠**等原因发生变化时，或按份共有人**之间**转让时（另有约定除外）
- 优先购买权行使期间：有约定按约定；无约定→转让通知载明≥15日则按载明期间、未载明或<15日则**15日**；未通知且权属未转移→知道同等条件之日起**15日**；未通知且权属已转移→权属转移之日起**6个月**

### ④ 建筑物区分所有权
- **构成**：专有部分所有权 + 共有部分共有权 + 共有部分成员权
- 共用部分具从属性，附随于专有部分
- 费用分摊、收益分配：有约定按约定；无约定/约定不明按**业主专有部分面积所占比例**确定

### ⑤ 相邻关系
- 避免邻地地基动摇或其他危险；相邻用水排水；相邻必要通行；相邻管线铺设；建造建筑物利用邻地（不得影响通风、采光、日照）；固体污染物、不可量物不得侵入

### 🎯 常考易错点
1. "受让人应承担善意的举证责任" → ❌ 真实权利人主张受让人不构成善意的，应承担举证责任（多选 A 2025 不当选）
2. "赠与人将无权处分的财产赠与受赠人可善意取得" → ❌ 无偿受让**不得**善意取得（判断 × 2024）
3. 三兄弟共同继承古董→推定为**共同共有**；甲擅自出卖给丁→丁基于善意取得/追认均取得所有权（单选 B）
4. "没有约定按份或共有一律视为按份共有" → ❌ 有家庭关系的视为**共同共有**（判断 ×）
5. 共有对外：罗某可找甲乙连带赔偿；甲承担5000元后可向乙追偿（按约定平均分摊2500元）（多选 BC 2023）
6. 重大修缮须经占份额 **2/3 以上**按份共有人同意（单选 B：含本数"以上"）
7. 6人朋友购车（按份共有、份额均等）：处分须6×2/3=4个份额→至少**4人**同意（单选 A）
8. 按份共有人可自由转让份额（无需同意）；继承不触发优先购买权（单选 C 2022）
9. 优先购买权期间：载明20日→20日；未载明→15日；未通知且未转移→知道15日；未通知且已转移→6个月（多选 ABC 2024：李某应6个月而非3个月）
10. 建筑物费用分摊按专有部分面积比例（判断 √ 2025）

> 📌 **真题印证**：习题第 91~150 题全考所有权 → **善意取得、共有、优先购买权 = 必考**。

## 📍 知识点 2：用益物权 ⭐⭐⭐⭐⭐（极高考频）

### ① 土地承包经营权

| 事项 | 非四荒地 | 四荒地（荒山/荒沟/荒丘/荒滩） |
|-|-|-|
| 承包人 | 本集体经济组织成员 | 不限于本集体经济组织成员 |
| 取得渠道 | 农业集体经济组织发包 | 招标、拍卖、公开协商等 |
| 继续流转 | 互换→备案；转让→须经发包方同意 | —— |

- **设立**：自土地承包经营权**合同生效时**设立，未经登记不得对抗善意第三人
- **承包期**：耕地 **30 年**、草地 **30~50 年**、林地 **30~70 年**；承包期限届满可继续承包
- **对外流转土地经营权**：出租、入股等方式；流转期限 **5 年以上**自流转合同生效时设立，可申请登记（未经登记不得对抗善意第三人）
- 流转原则：平等自愿、不得改变土地所有权性质和农业用途、流转期限不得超过承包期剩余期限、受让方须有农业经营能力但不限于本集体经济组织成员

### ② 建设用地使用权
- **概念**：以在他人（国家/集体）土地上拥有建筑物、构筑物及其附属设施为目的使用土地的权利
- **取得方式**：划拨（公益性、无偿性、无期限性、行政性、转让受限性）/ 出让 / 移转（转让、互换、赠与等）
- **出让形式**：协议 / 招标 / 拍卖（工业、商业、旅游、娱乐和商品住宅等经营性用地及同一土地两个以上意向用地者，应采取招标拍卖等公开竞价方式）
- **使用期限**：居住 **70 年**（届满自动续期）、商业/旅游/娱乐 **40 年**、其他 **50 年**
- **房地一体原则**：建设用地使用权与地上建筑物一并处分、一并抵押
- **附属行为**：可在使用范围内进行修筑围墙、养殖、种植花木等附属行为
- **提前收回补偿**：公共利益需要提前收回→对房屋等不动产补偿并退还相应出让金

### ③ 宅基地使用权
- **概念**：农村村民在集体所有土地上建造、保有房屋及附属设施的权利，具社会福利性质
- 无偿取得、永久性权利
- **原则禁止流转**：不得买卖、赠与、投资入股、抵押等
- **可以继承**
- 随房屋所有权转让而流转受限：受让人只能是**本集体经济组织成员**；一户一宅原则，出卖住房后再申请不予批准；受让人宅基地面积不得超过规定标准

### ④ 居住权（🔥 2026 必考）
- **概念**：自然人为满足生活居住需要，按合同约定，对他人住宅享有占有、使用的用益物权
- **设立方式**：签订**书面**居住权合同或订立遗嘱
- **设立时间**：居住权自**登记时**设立
- **特点**：无偿设立（另有约定除外）；**不得转让、继承**；设立居住权的住宅**不得出租**（另有约定除外）
- 期限届满或居住权人死亡→居住权消灭，应及时办理注销登记

### ⑤ 地役权
- **概念**：为实现自己土地（需役地）的利益而使用他人土地（供役地）的权利
- **设立**：应当采用**书面形式**订立地役权合同，地役权自**合同生效时**设立；未经登记不得对抗善意第三人
- **期限**：由当事人约定，但不得超过土地承包经营权、建设用地使用权等用益物权的剩余期限

### 🎯 常考易错点
1. "土地承包经营权转让不需发包方同意" → ❌ 转让须经发包方同意（单选 A 2024 当选）
2. "土地承包经营权期限届满不得继续承包" → ❌ 可继续承包（单选 B 不当选）
3. "土地承包经营权自登记后设立" → ❌ 合同生效时（单选 C 不当选）
4. "土地承包经营权人不得以入股方式流转" → ❌ 可以（单选 D 不当选）
5. 土地经营权流转：可出租入股、期限不超过剩余期限、不得改变所有权性质和农业用途、受让方不限于本集体成员（多选 ABC 2025：D 不当选）
6. 林地承包期 **70 年**（单选 C 2022）；"用于旅游度假村建设"❌（应农业用途）、"可向集体以外转让"❌（须本集体成员）、"自登记时生效"❌
7. "建设用地使用权只能设立在国家所有土地上" → ❌ 也可在集体所有土地上（多选 C 不当选）
8. "工业用地最高40年" → ❌ **50年**（多选 D 不当选）
9. 居住权：可约定对外出租、自登记时设立、不得转让；但**不能口头设立**（多选 ACD 2025：B 不当选）
10. 地役权：书面合同、合同生效设立、属用益物权（多选 ABC）；地役权是**需役地**所有人或使用人享有的权利（单选 D 不当选）

> 📌 **真题印证**：习题第 151~200 题全考用益物权 → **土地承包设立/期限、居住权登记、地役权合同生效 = 必考**。

## 📍 知识点 3：担保物权 ⭐⭐⭐⭐⭐（极高考频）

### 一、担保的基本理论

**典型担保方式：**

| 担保方式 | 担保性质 | 约定/法定 |
|-|-|-|
| 保证 | 信用保 | 约定 |
| 定金 | 金钱保 | 约定 |
| 抵押、质押 | 物权保 | 约定 |
| 留置 | 物权保 | **法定** |

**反担保**：债务人或第三人向担保人新设担保，以担保该担保人承担担保责任后实现追偿权的制度。
- 债务人提供：抵押、质押
- 第三人提供：保证、抵押、质押

### 二、担保物权的特性（🔥 必考）
- **从属性**：主债权债务合同无效→担保合同无效（法律另有规定除外）；担保合同中约定"担保合同效力独立于主合同"的条款**无效**
- **不可分性**：被担保债权被分割/部分清偿→担保物权仍为各部分债权而存在；主债务被分割→债务人提供担保的仍担保全部、第三人提供担保的可主张不再担保（未经其书面同意）
- **物上代位性**：担保期间担保财产毁损、灭失或被征收→担保物权人可就保险金、赔偿金、补偿金等**优先受偿**；履行期限未届满可**提存**
- **补充性**：只有债务人不履行到期债务或发生约定情形才发挥作用

### 三、担保合同无效

**法定资格与担保合同效力：**

| 提供担保主体 | 情形 | 担保合同是否有效 |
|-|-|-|
| 机关法人（国家机关） | 一般 | × |
| | 国务院批准的转贷行为 | √ |
| 居民委员会/村民委员会 | 一般 | × |
| | 依法代行村集体职能的村委会按规定程序 | √ |
| 学校/幼儿园/医疗机构/养老机构（公益非营利） | 公益设施 | × |
| | 购入/融资租赁公益设施时保留所有权 | √ |
| | 以公益设施以外财产设担保 | √ |
| | 登记为**营利法人** | √ |

**担保合同无效的赔偿责任：**
- **主合同有效 + 担保合同无效**：①债权人与担保人均有过错→不超过债务人不能清偿部分的 **1/2**；②担保人有过错债权人无过错→担保人对不能清偿部分承担责任；③债权人有过错担保人无过错→担保人不承担
- **主合同无效导致担保合同无效**：①担保人有过错→不超过不能清偿部分的 **1/3**；②担保人无过错→不承担

### 四、抵押权

**概念**：债务人或第三人（抵押人）不转移财产占有，将财产作为债权担保，债务人不履行到期债务或发生约定情形时，债权人（抵押权人）有权就该财产优先受偿。

**抵押合同**：要式合同（书面）；诺成合同（自成立生效）；**流押条款**无效（不能直接取得抵押财产所有权，只能就财产优先受偿）；对被担保债权种类/抵押财产无约定且不能补正或推定→抵押不成立。

**可抵押财产**：建筑物和土地附着物、建设用地使用权、海域使用权、生产设备/原材料/半成品/产品、正在建造的建筑物/船舶/航空器、交通运输工具、未禁止抵押的其他财产（如土地经营权）。

**不得抵押财产**：土地所有权、宅基地/自留地/自留山等集体所有土地使用权（法律规定可抵押除外）、公益非营利法人的公益设施、所有权使用权不明或有争议财产、依法被查封/扣押/监管财产。

**房地一体原则：** 国家所有：以建筑物抵押→占用范围内的建设用地使用权一并抵押；以建设用地使用权抵押→地上建筑物一并抵押。集体所有：乡镇村企业建设用地使用权不得单独抵押；以厂房抵押→占用范围内建设用地使用权一并抵押。

**抵押权的设立（🔥 必考对比）：**

| 抵押财产 | 设立规则 | 对抗规则 |
|-|-|-|
| 不动产（建筑物/建设用地使用权/海域使用权/正在建造的建筑物） | 抵押权自**登记之日**起设立 | 未经登记不得对抗善意第三人 |
| 动产（生产设备/原材料/产品/交通工具/正在建造的船舶航空器） | 抵押权自**抵押合同生效时**设立 | 未经登记不得对抗善意第三人 |

> 抵押登记记载内容与抵押合同约定不一致→以**登记记载内容**为准。

**抵押权的效力：**
- 担保范围：主债权及利息、违约金、损害赔偿金和实现抵押权费用（另有约定按约定）
- 孳息：抵押财产被扣押之日起，抵押权人有权收取天然/法定孳息（未通知清偿法定孳息义务人的除外）
- 从物：设立前产生的从物→抵押权效力及于；设立后产生的→不及于（实现时可一并处分）
- 代位物：抵押财产毁损/灭失/被征收→可就保险金/赔偿金/补偿金优先受偿；给付义务人接到通知后仍向抵押人给付的→可要求其重复给付
- 添附物：归第三人→及于补偿金；归抵押人→及于添附物（但不及于增加价值部分）；共有→及于抵押人对共有物享有的份额
- 新增/续建建筑物：正在建造的建筑物抵押效力限于已登记部分；建设用地使用权抵押后新增建筑物不属于抵押财产（可一并处分但新增部分价款无权优先受偿）

**先租后抵/先抵后租：**
- **先租后抵**（抵押不破租赁）：抵押权设立前已出租并转移占有的，原租赁关系不受抵押权影响
- **先抵后租**：抵押权已登记→租赁关系影响抵押权实现可主张终止；未登记→能证明承租人知情可主张终止

**抵押财产转让（🔥 必考）：**
- **未约定禁止转让**：抵押人可以转让，但应通知抵押权人；抵押财产转让的抵押权不受影响；抵押权人能证明可能损害抵押权→可请求抵押人将转让价款提前清偿或提存
- **约定禁止转让（未登记）**：转让合同有效；受让人对禁转约定不知情→可取得物权（但已登记的抵押权仍及于"带押物"）；知情→不能取得
- **约定禁止转让（已登记）**：转让合同有效；受让人应知情（非善意），除非代替债务人清偿致抵押权消灭，否则不能取得物权

**多重抵押清偿顺序（🔥 必考）：**
- 已登记 PK 未登记：**已登记**先于未登记
- 已登记 PK 已登记：**先登记**优于后登记
- 未登记 PK 未登记：按**债权比例**清偿
- 偿还顺序只与是否登记和登记先后有关，与债权到期时间和抵押合同签订时间无关

**抵押权顺位变更**：可协议变更顺位及被担保债权数额，但未经其他抵押权人书面同意的，**不得对其他抵押权人产生不利影响**。

**抵押权的处分：** 抵押权不得与债权分离单独转让；债权转让的抵押权一并转让（另有约定除外）；抵押权人放弃债务人财产设定的抵押→其他担保人在丧失优先受偿权益范围内免除担保责任（承诺继续担保除外）。

**抵押权的保全：** 抵押人不合理减少抵押财产价值→可请求停止；已减少→可请求恢复价值或提供担保，不恢复不担保→可请求提前清偿债务。

**抵押权的行使：** 未约定清偿顺序→实现抵押权费用→主债权利息→主债权；主债权诉讼时效期间届满→抵押权人不得主张行使抵押权。

**动产抵押特殊规定：**
- **正常买受人保护**：无论动产抵押权是否登记，抵押权人**不得对抗**正常经营活动中已支付合理价款并取得抵押财产的买受人（出卖人营业执照经营范围持续销售同类商品）
- 不属于正常买受人：购买数量明显超过一般、购买生产设备、目的在担保他人债务、与控制关系、应查询而未查询等
- **浮动抵押**：企业/个体工商户/农业生产经营者（自然人×）以其现有及将有生产设备/原材料/半成品/产品抵押；自合同生效时设立，未经登记不得对抗善意第三人
- **超级动产抵押权（价款债权抵押权）**：担保的主债权是该抵押物价款；标的物交付后 **10 日内**办理抵押登记→该抵押权人优先于买受人其他担保物权人受偿（**留置权人除外**）

**最高额抵押：** 对一定期间内将要连续发生的债权提供担保，在最高债权额限度内优先受偿；只需**首次登记**即可设立；担保的债权不确定但有最高限额；部分债权转让的最高额抵押权不得转让（另有约定除外）；债权确定情形（约定期间届满/满2年请求确定/新债权不可能发生/抵押财产被查封扣押/债务人抵押人破产解散）；实际债权余额高于最高限额→以最高限额为限。

### 五、质权

**动产质权**：债务人或第三人将动产出质给债权人占有，债务人不履行到期债务时债权人有权就该动产优先受偿。

**质押合同**：要式合同（书面）、诺成合同（自成立生效）；**流质条款**无效（不能直接取得质押财产所有权）；担保范围：有约定按约定，无约定→主债权及利息、违约金、损害赔偿金、质物保管费用和实现质权费用。

**动产质权设立：**
- 债权人自行监管：自出质人**交付质押财产时**设立
- 债权人委托监管人代为监管：自监管人**实际控制货物之日**起设立

**质权人权利与义务：**
- 有权收取质押财产孳息（另有约定除外）
- 因不能归责于质权人事由可能使质押财产毁损/价值明显减少→可要求出质人提供相应担保，不提供可拍卖变卖
- 未经出质人同意擅自使用/处分→赔偿；保管不善致毁损灭失→赔偿；可能致毁损→出质人可请求提存或提前清偿

**质权行使：** 出质人可请求质权人在债务履行期届满后及时行使质权；质权人怠于行使致损→承担赔偿责任；为债务人质押担保的第三人实现质权后有权向债务人追偿。

**权利质权：**

| 质押财产（权利） | 设立时间 |
|-|-|
| "三票"（汇票/本票/支票）、"三单"（存款单/仓单/提单）、"一债券" | 有权利凭证→交付时；无凭证→办理出质登记时 |
| 基金份额、股权、注册商标专用权/专利权/著作权财产权、应收账款 | 自办理出质**登记时**设立 |

> 土地承包经营权、建设用地使用权、房屋所有权等不动产物权**不得**用作质押。

**应收账款出质细化：** 出质后不得转让（协商同意除外）；转让价款应提前清偿或提存；以现有应收账款出质，债务人向质权人确认真实性后不得又主张不存在或已消灭；已向债权人履行则质权人不得请求债务人再履行（接到质权人通知仍履行除外）。

### 六、留置权

**成立条件：** ①债务已到期；②债权人合法占有债务人或第三人的动产；③占有的动产与债权属**同一法律关系**。

**商事留置权**：债权人与债务人均为**企业**；可不在同一法律关系（"一个放开"）；但债权不属于企业持续经营中发生的债权不得留置、不得留置第三人财产（"两个限制"）。

**留置权效力：**
- 排除适用：法律规定或当事人约定不得留置的动产不得留置
- 担保范围：主债权及利息、违约金、损害赔偿金、留置物保管费用和实现留置权费用
- 可分物：价值应相当于债务金额；不可分物：可就全部行使
- 孳息：留置权人有权收取，先充抵收取孳息的费用
- 实现：未约定履行期限→应给债务人 **60 日以上**履行期限（鲜活易腐除外）

### 七、担保物权的优先级（🔥 必考总结）

| 比较 | 顺序 |
|-|-|
| **留置权 > 超级动产抵押权** | 留置权最优先 |
| 抵押权 PK 抵押权 | 已登记>未登记；先登记>后登记；均未登记按债权比例 |
| 抵押权 PK 质权 | 先登记的抵押权>后交付的质权；先交付的质权>后登记/未登记的抵押权 |
| 抵押权 PK 所有权 | 他物权（限制物权）>所有权 |

### 🎯 常考易错点
1. "保证、抵押、质押、留置均属约定产生的物权担保" → ❌ 留置是**法定产生**；保证不属于物权担保（多选 BC 不当选 A、D）
2. 反担保：债务人和第三人均可采用抵押、质押（多选 BC；债务人不能用保证、留置）
3. 抵押财产毁损→保险赔款继续担保债权（多选 BD）
4. "登记为营利法人的学校提供担保可主张担保无效" → ❌ 不得主张（判断 √ 2024）
5. "居民委员会提供担保有效" → ❌ 无效（判断 √ 2025）
6. 主合同有效、担保合同无效、双方均有过错→担保人赔偿不超过不能清偿部分 **1/2**（单选 C 2024：60万×1/2=30万）
7. "土地所有权可抵押" → ❌ 不得（单选 A 2025）
8. 动产抵押（船舶/飞机/汽车）不需登记即可设立（多选 ACD 2024：正在建造的大楼需登记）
9. 自登记时设立：建设用地使用权、不动产抵押权（多选 BD 2023）
10. 抵押登记与合同不一致→以**登记记载**为准（单选 B）
11. 未登记的动产抵押权不因抵押物毁损而消灭，赔款继续担保（多选 AB 不当选）
12. 建设用地使用权抵押后新增建筑物不属于抵押财产（单选 ABC：A银行优先受偿4600万）
13. 先租后抵：不影响租赁（多选 BD）
14. 甲抵押给乙（已登记）、给丙（未登记）→丙抵押权未设立（单选 D 2024）
15. 未登记抵押→甲银行不得受偿；乙（先登记）优先于丙（单选 C 2025）
16. 变更顺位未经丙同意不得对丙不利→乙丁变更后丙仍300万、丁100万（单选 B 2022）
17. 抵押清偿顺序：费用→利息→本金（单选 A 2023、单选 A 2024：60-5-10=45）
18. 浮动抵押未登记→不得对抗善意第三人（单选 A 2022）
19. 超级动产抵押权（价款债权抵押权）10日内登记→最先受偿（单选 B 2025：丙最先、乙次之、丁最后）
20. 最高额抵押：有最高限制额（多选 ACD 2025：B 不当选）
21. 最高额抵押"实际债权高于最高限额抵押权无效" → ❌ 以最高限额为限（单选 A 2024）
22. 质权设立需交付：乙未交付翡翠貔貅→质权未设立（单选 C）
23. 权利质权：基金份额/股权/应收账款/商标登记设立；汇票交付设立（多选 AD 2024）
24. 应收账款转让价款应提前清偿**或提存**（单选 D 2024 不当选"只清偿"）
25. 约定不得留置→不得留置（单选 A 2025）
26. 商事留置：企业间可不属同一法律关系（判断 √）
27. 留置权人有权收取孳息（判断 × 2021）
28. 留置>登记抵押>未登记抵押（多选 AB 2022：王某留置优先、李某登记优先于吴某未登记）
