# 🧩 第一节 营运资金管理概述

## 📍 知识点 1：营运资金概念与特点 ⭐⭐⭐

### ① 概念
```
营运资金 = 流动资产 − 流动负债
```
- 流动资产：1 年以内或超过 1 年的一个营业周期内变现或运用的资产（现金、交易性金融资产、应收及预付款项、存货）；
- 流动负债：1 年或一个营业周期内偿还的债务（短期负债）；
- ⚠️ 无形资产属非流动资产，**不属于**营运资金（2020 单选 D）；
- ⚠️ 营运资金是流动资产减流动负债，不是减存货（2018 单选 B）。

### ② 流动负债分类
- 按应付金额是否确定：应付金额确定/不确定；
- 按是否支付利息：有息/无息；
- 按形成情况：**自然性流动负债**（结算程序/法规自然形成）vs **人为性流动负债**（财务人员人为安排形成）。

### ③ 营运资金特点
来源多样性、数量波动性、周转短期性、实物形态变动性和易变现性。
- ⚠️ 不是"不易变现"（2015 判断 ×）。

---

## 📍 知识点 2：营运资金管理原则 ⭐⭐
满足合理资金需求（首要任务）、提高资金使用效率、节约资金使用成本、保持足够短期偿债能力。

---

## 📍 知识点 3：流动资产投资策略 ⭐⭐⭐⭐

| 策略 | 特征 | 风险收益 |
|-|-|-|
| **紧缩的流动资产投资策略** | 维持**低水平**流动资产与销售收入比率（流动资产少） | 高风险、高收益 |
| **宽松的流动资产投资策略** | 维持**高水平**流动资产与销售收入比率（流动资产多） | 低风险、低收益 |

### 🎯 常考易错点
- 宽松策略流动资产多 → 流动性**高**（2021 多选 BC 不属于宽松特点）；
- 紧缩策略风险高、维持低流动资产（2018 判断 ×：说"较高水平"错）；
- JIT 适时制对管理水平要求高 → 应采用**紧缩**策略（2017 判断 ×）；
- 销售不稳定、难以预测 → 应维持**较高**流动资产水平（2017 多选 D 错误）；
- 增加流动资产：增加持有成本、降低收益性、提高流动性、减少短缺成本；最优投资 = 持有成本与短缺成本之和最低。

---

## 📍 知识点 4：流动资产融资策略 ⭐⭐⭐⭐（单选高频）

### ① 基础概念
- 流动资产分为**永久性流动资产**（淡季也需保持）和**波动性流动资产**（旺季临时增加）；
- 长期资金多 → 低风险低收益；短期资金多 → 高风险高收益；
- 融资的长期来源：自发性流动负债、长期负债、股东权益资本；短期来源：临时性流动负债（短期银行借款）（2021 多选 ACD）。

### ② 三种策略

| 策略 | 特征 | 风险收益 |
|-|-|-|
| **匹配融资策略** | 长期资金来源 = 非流动资产 + 永久性流动资产 | 适中 |
| **保守融资策略** | 长期资金来源 > 非流动资产 + 永久性流动资产（还支持部分波动性流动资产） | 低风险低收益 |
| **激进融资策略** | 长期资金来源 < 非流动资产 + 永久性流动资产（靠短期融资支持） | 高风险高收益 |

### 🎯 常考易错点
- 大量短期负债满足资金需求 = **激进**策略（2018 判断 ×）；
- 长期资金来源 8100 > 非流动资产 5000 + 永久性 2400 = 7400 → 保守融资策略（2017 单选 A）；
- 收益和风险均较低 = **保守**融资策略（2016 单选 A）；
- 激进策略：流动比率低、流动性风险高、财务杠杆高、资本成本**低**（2025 多选 ABC）。

# 🧩 第二节 现金管理

## 📍 知识点 1：持有现金的动机 ⭐⭐⭐⭐（单选/判断高频）

| 动机 | 含义 | 例子 |
|-|-|-|
| **交易性需求** | 维持日常周转及正常商业活动所需现金 | 支付供应商货款、季节性库存备货、提供商业信用 |
| **预防性需求** | 应付突发事件 | 应对客户违约、突发事件 |
| **投机性需求** | 抓住突然出现的获利机会 | 股价暴跌后抄底 |

- ⚠️ 企业现金持有量一般**小于**三种需求之和（为某一需求持有的现金可满足其他需求）；
- 企业临时融资能力强 → 预防性需求现金持有量**低**（2019 判断 √）；
- "双十一"备货、供应商收回信用政策 → **交易性**（2021/2020）；
- 客户违约导致资金链紧张 → **预防性**（2022 判断）；
- 股价突发下跌想买没钱 → **投机性**（2019 单选）。

---

## 📍 知识点 2：目标现金余额的确定 ⭐⭐⭐⭐⭐（主观题核心）

### ① 成本模型
```
相关成本：机会成本（正相关）、管理成本（固定）、短缺成本（负相关）
最佳现金持有量 = min（机会成本 + 管理成本 + 短缺成本）的总成本
```
- ⚠️ 成本模型考虑机会、管理、短缺成本，**不含交易成本**（2019/2024 单选/多选）；
- 机会成本 = 持有现金余额而丧失的再投资收益（2019 判断 ×：不是佣金手续费）。

### ② 存货模型
```
总成本 = 机会成本 ＋ 交易成本 = (C/2)×K ＋ (T/C)×F
最佳现金持有量 C = √(2T×F ÷ K)
（T=现金需求总量，F=每次转换成本，K=机会成本率）
```
- 最佳现金持有量 = 机会成本 = 交易成本时对应持有量（2020 判断 √）；
- 转换次数越少，交易成本越低（2025 判断 √）；
- 存货模型考虑**机会成本 + 交易成本**（2018 多选 CD）；
- 机会成本 = 现金平均持有量×机会成本率 = 30×10% = 3 万（2018 单选）；
- **成本模型和存货模型都考虑机会成本**（2020/2025 单选 B）。

### ③ 随机模型（米勒-奥尔模型）🔥🔥
```
H = 3R − 2L（H上限、R回归线/目标现金余额、L下限）
H − R = 2(R − L)
```
- 现金达上限 H → 购入有价证券降到 R；降到下限 L → 抛售证券回升到 R；在上下限内不转换；
- 适用对象：现金流入流出**不稳定**的情况；
- 例：下限 3000、上限 15000 → 15000 = 3R − 2×3000 → R = 7000（2022 单选）；
- 例：目标 200、下限 120 → H = 3×200 − 2×120 = 360（2019 单选）；
- 例：下限 15、回归线 80 → H = 3×80−2×15 = 210；现金 220 > H → 投资有价证券 = 220−80 = 140（2016 单选）。

## 📍 知识点 3：现金管理模式 ⭐⭐⭐

### ① 收支两条线管理模式
- 目的：减少现金持有成本、加速资金周转、提高资金使用效率；
- 构建：资金流向（收入户/支出户，严禁坐支）、资金流量（以收定支、最低限额资金占用）、资金流程（账户管理等）。

### ② 集团资金集中管理模式（【2026 新增】）
- 资金集中管理（司库制度）内容：资金集中、内部结算、融资管理、外汇管理、支付管理；**资金集中是基础**；
- 五种模式：统收统支、拨付备用金、结算中心、内部银行、财务公司；
- ⚠️ **财务公司**是经营部分银行业务的非银行金融机构，需中国人民银行审核批准（2014 判断 ×：说"内部银行"错）。

## 📍 知识点 4：现金收支日常管理（现金周转期）⭐⭐⭐⭐（单选高频）

### ① 公式（🔥🔥 必背）
```
经营周期 = 存货周转期 ＋ 应收账款周转期
现金周转期 = 经营周期 − 应付账款周转期
          = 存货周转期 ＋ 应收账款周转期 − 应付账款周转期
其中：存货周转期 = 存货平均余额 ÷ 每天销货成本
     应收账款周转期 = 应收账款平均余额 ÷ 每天销货收入
     应付账款周转期 = 应付账款平均余额 ÷ 每天购货成本
```

### ② 缩短现金周转期的措施
1. 加快制造与销售产成品 → 减少存货周转期；
2. 加速应收账款回收 → 减少应收账款周转期；
3. 减缓支付应付账款 → 延长应付账款周转期（2025 判断 ×：说"延长偿还期限现金周转期延长"错，应缩短）。

### ③ 常考计算
- 存货周转天数 = 360/7.2 = 50 天 → 现金周转期 = 50+40−30 = 60 天（2024 单选）；
- 存货周转率越高 → 存货周转期越短 → 现金周转期**越短**（2024 判断 ×）；
- 存货 45 + 应收 60 − 应付 40 = 65 天（2021 单选）。

# 🧩 第三节 应收账款管理（主观题核心）

## 📍 知识点 1：应收账款的功能与成本 ⭐⭐⭐⭐

- **功能**：增加销售、减少存货；
- **成本**：
```
机会成本：因投放于应收账款而放弃其他投资的收益（=占用资金应计利息）
管理成本：信用调查费、信息收集费、账簿记录费、收账费用
坏账成本：债务人无力偿还的损失
```
- 各类流动资产决策涉及成本总结：
```
现金：成本模型=机会、管理、短缺；存货/随机模型=机会、交易
应收账款：机会、管理、坏账
存货：取得、储存、缺货
```

> 📌 真题印证：应收账款机会成本 = 占用资金的应计利息（2018 单选 C）；投放应收而放弃其他投资收益 = 机会成本（2017 单选 B）。

## 📍 知识点 2：信用政策 ⭐⭐⭐⭐⭐（主观题核心）

信用政策包括**信用标准、信用条件、收账政策**三方面。

### ① 信用标准
- 信用申请者获得企业提供信用所必须达到的**最低信用水平**，通常以**预期坏账损失率**作为判别标准；
- 定性分析：**5C 信用评价系统**（品质、能力、资本、抵押、条件）；
- 定量分析：流动性与营运资本比率、债务管理和支付比率、盈利能力指标。

### ② 信用条件
由**信用期间、折扣期限、现金折扣**三要素组成。

**（1）信用期限决策**（🔥🔥 主观题必考）
```
收益（盈利）增加 = 销售量增加 × 单位边际贡献 − 增加的固定成本
应收账款机会成本 = 日销售额 × 平均收现期 × 变动成本率 × 资本成本
坏账成本 = 赊销额 × 预计坏账损失率
存货占用资金应计利息 = 存货增加量 × 单位变动成本 × 资本成本
应付账款增加导致的应计利息减少（抵减项）
增加的税前损益 = 盈利增加 −（机会成本＋收账费用＋坏账损失＋现金折扣成本等）
放宽信用期后税前损益 > 0 → 采用；< 0 → 不采用
```
- 平均收现期：无折扣按信用期；有现金折扣用加权平均（如 50% 在 10 天、50% 在 30 天 → 20 天）；
- 应收账款中只有**变动成本**占用资金（固定成本不变、利润未占用资金）；
- 现金折扣成本增加 = 新销售水平×享受折扣比例×新折扣率 − 旧销售水平×旧折扣率×旧折扣率；
- 例：信用条件 "0.8/10, N/30"，25% 客户享受折扣 → 平均收现期 = 25%×10＋75%×30 = 25 天（2021 单选）。

### ③ 收账政策
- 积极的收账政策：减少坏账损失，但增加收账成本；
- 消极的收账政策：增加坏账损失，但减少收账费用。

## 📍 知识点 3：应收账款的监控 ⭐⭐⭐⭐

### ① 应收账款周转天数
```
应收账款周转天数 = 应收账款平均余额 ÷ 平均日销售额
平均逾期天数 = 应收账款周转天数 − 平均信用期天数
```
> 例：平均余额 360、日赊销 10 万 → 周转天数 36；信用期 30 天 → 逾期 6 天（2022 单选 B）

### ② 账龄分析表
- 将应收账款划分为未到期和以 30 天为间隔的逾期账款；逾期时间越长收回可能性越小；
- ⚠️ 各月销售额变化大时，账龄分析表和周转天数可能发出类似错误信号。

### ③ 应收账款账户余额模式
- 反映一定期间赊销额在发生当月月末及随后各月未偿还的百分比；
- 用途：计划应收账款金额水平、衡量收账效率、预测未来现金流（2014 多选 ABD）。

### ④ ABC 分析法（重点管理法）
- A 类：逾期金额比重大、占客户数量比例低 → 重点催收；C 类反之；B 类介于 A、C 之间。

## 📍 知识点 4：应收账款保理 ⭐⭐⭐⭐

- 保理 = 保付代理：保理商与债权人签订协议，转让应收账款部分或全部权利与义务并收取费用；
- 分类：
```
有无追索权：有（非买断）——购货商拒付则保理商有权向供应商追索
            无（买断）——保理商承担全部收款风险
是否告知购货商：明保理（通知+三方合同）、暗保理（不通知）
是否提前预付：折扣保理（融资保理，预付一般不超过 70%~90%）、到期保理
```
- 作用：**融资功能**、减轻管理负担、减少坏账损失降低经营风险、**改善财务结构**（增强资产流动性）；
- ⚠️ 保理转让的是**未到期**应收账款（2020 判断 ×）；有追索权保理对**保理商**更有利（2016 判断 ×）；应收账款保理**不属于**资产证券化（2021 多选 B 错误）。

# 🧩 第四节 存货管理（主观题核心）

## 📍 知识点 1：存货管理的目标 ⭐⭐
保证生产正常进行、提高销售机动性、便于维持均衡生产降低产品成本、降低存货取得成本、防止意外事件发生。

## 📍 知识点 2：存货的成本 ⭐⭐⭐⭐

| 成本 | 内容 |
|-|-|
| 取得成本 | 购置成本（买价）+ 订货成本（固定/变动） |
| 储存成本 | 固定储存成本（仓库折旧）+ 变动储存成本（资金应计利息、破损变质损失、保险费） |
| 缺货成本 | 停工损失、拖欠发货损失、丧失销售机会损失、紧急额外购入成本 |

- 变动储存成本与存货数量有关：资金应计利息、破损变质损失、库存商品保险费（2017 多选 ABD）；仓库折旧费 = **固定**储存成本。

## 📍 知识点 3：经济订货基本模型（EOQ）⭐⭐⭐⭐⭐（主观题核心）

### ① 假设（了解）
存货总需求已知常数、无订货提前期、货物一次性入库、无批量折扣、储存成本与库存水平线性、独立需求、不允许缺货。

### ② 相关成本
- 相关成本：**变动订货成本 ＋ 变动储存成本**；
- 无关成本：购置成本、固定订货成本、固定储存成本、缺货成本（基本模型假设无缺货）。

### ③ 公式（🔥🔥 必背）
```
变动订货成本 = 年订货次数 × 每次订货成本 = (D/Q)×K
变动储存成本 = 年平均库存 × 单位变动储存成本 = (Q/2)×Kc
最优订货批量 Q* = √(2KD ÷ Kc)
最小相关总成本 TC = √(2KDKc)
```

### ④ 常考判断/单选
- 经济订货基本模型中**缺货成本无关**（2023 单选 B）；
- 相关成本 = 变动储存成本 + 变动订货成本（2022 多选 BC）；
- 保险储备**不影响**经济订货批量（2018 单选 C）；
- 最佳订货周期 = 360 ÷（年需求/经济批量）（2020 单选：360/(36000/600)=6 天）；
- 影响 EOQ 的因素：存货年需要量、每次订货变动成本、单位变动储存成本（2018 单选 B）。

---

## 📍 知识点 4：经济订货基本模型的扩展 ⭐⭐⭐⭐

### ① 再订货点
```
再订货点 R = L×d（L=平均交货时间，d=每日平均需用量）
```
- **订货提前期对经济订货量无影响**（2024 判断 ×）；
- 例：日需 50、订货批量 4500、交货 6 天 → R = 50×6 = 300（2021 单选 D）；
- 例：全年 7200 吨、日耗 20 吨、正常交货 3 天、延误 2 天保险 → R = (3+2)×20 = 100 吨（2019 单选 D）。

### ② 存货陆续供应和使用模型
```
EOQ = √[2KD ÷ Kc × p/(p−d)]（p=每日送货量，d=每日耗用量）
TC = √[2KDKc × (1 − d/p)]
```
- 进货期内平均库存量 = (Q/2)×(1 − d/p)（2022 单选：600/2×(1−10/30)=200 件）。

### ③ 保险储备
```
再订货点 = 预计交货期内的需求 ＋ 保险储备
保险储备的储存成本 = 保险储备 × 单位变动储存成本
缺货成本 = 一次订货期望缺货量 × 年订货次数 × 单位缺货损失
最佳保险储备：缺货损失 + 保险储备储存成本之和最低
```
- ⚠️ 保险储备储存成本 = 100×2 = 200 元（不是 100，2023 判断 ×）；
- 较高的保险储备增加储存成本、降低缺货成本（2021/2020）；
- 保险储备增加 → 再订货点**提高**（2020 多选 C 错误）；
- 例：年需 72000、最佳订货 9000、交货 3 天、保险 1000 → R = 72000/360×3＋1000 = 1600（2017 单选 A）。

---

## 📍 知识点 5：存货控制系统 ⭐⭐⭐

- **ABC 控制系统**：A 高价值重点控制、B 中价值一般管理、C 低价值简单管理；
- **适时制（零库存/看板管理）**：供应商只在生产需要时才送货，产品生产出来即被拉走；要求稳定标准的生产程序 + 诚信供应商。

# 🧩 第五节 流动负债管理

## 📍 知识点 1：短期借款 ⭐⭐⭐⭐

### ① 信用条件
| 条件 | 要点 |
|-|-|
| **信贷额度** | 银行协议规定的借款最高限额，**银行不承担必须贷款义务**（2018 判断 ×） |
| **周转信贷协定** | 银行有法律义务承诺提供不超过最高限额的贷款；对未使用部分付**承诺费** |
| **补偿性余额** | 银行要求保持贷款限额/实际借用额一定比例（10%~20%）的最低存款余额 → **提高借款实际利率**（2020 判断 ×） |
| **借款抵押** | 银行按抵押品面值 30%~90% 发放贷款 |
| **偿还条件** | 到期一次偿还（企业希望）、定期等额偿还（银行希望） |

> 例：100 万周转信贷、利率 10%、承诺费率 0.5%、实际动用 60 万 → 成本 = 60×10%＋40×0.5% = 6.2 万（2017 单选 C）

### ② 短期借款成本（🔥 三种付息方式）
| 方法 | 实际利率 |
|-|-|
| **收款法** | 到期支付利息，实际利率 = 名义利率 |
| **贴现法（折价法）** | 先从本金扣除利息 → 实际利率 > 名义利率：实际利率 = 名义利率/(1−名义利率) |
| **加息法** | 分期等额偿还 → 实际利率约为名义利率的 **2 倍** |

- 例：贴现法，6%/(1−6%) = 6.38%（讲义）；加息法 10%×2 = 20%（2020 单选）；
- 补偿性余额实际利率 = 名义利率/(1−补偿性余额比例)：6.5%/(1−12%) = 7.39%（2019 单选）。

## 📍 知识点 2：短期融资券 ⭐⭐⭐

- 发行人为**非金融企业**；发行和交易对象是**银行间债券市场的机构投资者**，不向社会公众发行交易；
- 由符合条件的金融机构承销，企业不得自行销售；
- 实名记账，在中央国债登记结算公司登记托管。

### 特点
1. 相对于公司债券，**筹资成本较低**；
2. 相对于银行借款，**筹资数额较大**；
3. **发行条件比较严格**（需一定信用等级）。

> 📌 真题印证：短期融资券无担保（2025 多选 B 错误）；筹资成本低、一次性筹资数额大、信用等级要求高（2019/2025 多选）。

---

## 📍 知识点 3：商业信用 ⭐⭐⭐⭐

### ① 概念与形式
- 商业信用 = 商品或劳务交易中，以延期付款或预收货款方式形成的借贷关系，是**企业之间的直接信用行为**；
- 形式：**应付账款、应付票据、应计未付款、预收货款**（2018/2019/2025 多选）；
- ⚠️ **预付货款**不属于商业信用筹资（2023 单选 A）；短期借款、短期融资券不是商业信用。

### ② 放弃现金折扣的信用成本率（🔥🔥 计算必考）
```
放弃现金折扣的信用成本率 = 折扣% ÷ (1−折扣%) × 360 ÷ (付款期−折扣期)
```
- 例："2/10, N/30" → 2%/(1−2%)×360/20 = 36.73%（2020 判断 ×：说 20% 错）；
- 与折扣百分比、折扣期长短、付款期长短有关，**与货款额/折扣额无关**（2024 单选 B）；
- 决策：放弃折扣成本率 > 银行借款利率 → 应取得现金折扣（借款付款）；投资报酬率 > 放弃折扣成本率 → 放弃折扣。

### ③ 商业信用筹资优缺点
- **优点**：容易获得、一般不用提供担保、有较大机动权（还款延期方便）；
- **缺点**：筹资成本高（放弃折扣成本高）、容易恶化信用水平（期限短、还款压力大）、受外部环境影响大。
